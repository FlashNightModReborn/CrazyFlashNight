# CF6 光头保安 612 / 888 · 矢量精修稿 R2

本包是可独立重建的 SVG / Python 源工程与静态动作对照。保留 CF6 原黑西装、白衬衫、红领带、墨镜和光头。没有改动生产资源、FLA、XFL 或游戏逻辑；没有在 Windows / CS6 / 游戏中验收。

## 这轮做了什么

- 在冻结R1之后重新精修581图集的10件人形身体。按原五官位置恢复压眉的窄墨镜、窄鼻梁与钝鼻头、紧闭薄唇和收紧下颌；西装翻领、圆肩、袖筒、裤褶、抓握手指和圆头薄底皮鞋均重新调整。衣服以少层曲线硬边塑形，褶皱跟随受力，不以高光条或多边形细分代替体积。
- 原图透明轮廓仅用于保轮廓和碎片连续性，内部颜色、五官和衣纹均为可编辑路径。本轮绘制件没有嵌入图片或滤镜。布料与皮革没有渐变；头部使用两个可编辑径向渐变，专用于连贯颅顶与颧颊肤色，避免R1的帽沿环带、折纸脸和面具块。没有把金属反光恢复到西装。
- 原注册点、局部坐标、导出尺寸、SWF 裁切路径和时间轴矩阵保持；肩、肘、腕、髋、膝等内部穿接端开放描线。真正衣边、鞋底、手指、脸的外缘保留轮廓线。
- 活体枪 592（图集591）及变身落地枪877（图集876）原样保留。枪的原位图/材质属于明确复用，不包含在“全矢量新绘”声明里。
- 死亡601–603的3个图集裁片，以及变身880、882–886的178个裁片，从同一新581矢量母图按原矩阵投射，合计181个填充。没有逐帧或逐块凭空画碎片。
- 8件原生死亡血液/组织形状原样保留，共用血液、枪口烟、透明helper也保留并分类。

## 克隆兽复用边界

变身887同时使用新光头人形和既有262–274十三件克隆兽。这里复用维护者认可的γ-ECHO克隆兽R3归档SVG的“stabilized / 深褐灰”版本，只按清单中的局部原点平移，没有重绘或重新配色。

这批归档SVG不等同于目前游戏的原生XFL。原生项目之后还修过死亡碎尸、爪根、牙根、骨刺连接，且归档SVG没有回写。本包的变身预览用于检查旧CF6时间轴与该已认可归档的连接；本地接入应使用用户当前已完成的native克隆兽源，核对原点后复验，不能声称已验证现役clone。

## 文件与重建

- parts：10新身体件，以及未改的592枪；atlas581.svg为新母图预览
- death-parts：11死亡专用形状
- transition-parts：变身破衣、落地枪，以及13个复用clone的局部坐标包装
- shared：原样共用效果/透明helper
- reference：冻结原图、原SVG、时间轴、依赖、精确复用映射及已认可clone归档
- source：全部重建/渲染/验证脚本；refine_core.py和refine_limbs.py是R2绘制源，atlas-art.json保存生成后的矢量母件
- previews：原/R1/R2同尺度站姿、脸、衣服及8件肢体对照，原/R2动作、死亡、变身对照与分支GIF
- qa：结构/坐标检查、616帧覆盖、181裁片覆盖报告。大批中间渲染不收入源包，可重建

需要Python 3、Pillow、NumPy、SciPy；预览需要Inkscape。所有参考输入均在包内，重建不读取外部R1工作目录。

原/R1/R2对照保留修订证据；reference/revision-r1中的两张冻结PNG及source/limb-reference-geometry.json中的R1路径仅供比较，不会替换R2图稿。

`python source/rebuild.py --assets-only` 重建全部资产并验证结构。

`python source/rebuild.py` 重建资产、全部616帧、关键原版对照、R1/R2对照、分支GIF和裁片检查。

`python source/check_fragments.py --review-flagged --scale 32` 额外重建透明尾差异的32×检查。

- 110/110 Shape的viewBox、导出尺寸和内部引用通过校验；19个本轮绘制/投射Shape没有图片和滤镜；9个非头部活体新绘件没有渐变，头部含2个肤色径向渐变，死亡/裂衣母图相应保留这2个定义。13个既有clone沿用归档本身的材质和渐变，不属于本轮新绘声明。
- 616帧均已实际渲染：611帧非空、5帧为空且与原887空尾一致，均在固定坐标画布内；另渲染98帧原版对照。
- 全部181个死亡/变身图集fill做过独立渲染。159个fill存在alpha64可见主体，其197个连通块全部保留，未发现新封闭孔或内部缺片。
- 5个fill有透明抗锯齿尾的面积差异（883f7/f9、884f4/f5/f6），8×检查时原图均无alpha64主体，等效面积约0.0036–0.015局部平方像素。32×复核中883f7、884f4/f6的极淡原尾未保留；883f9与884f5出现的小alpha64主体仍保留。两档完整统计和警示均保留。不能将本包称为逐像素轮廓复刻。详见qa/fragment-coverage报告与对照。
- 为让普通ZIP小于15MB，6个原变身SVG中重复的同一581内嵌图集改为共享定义；原clip、fill顺序和矩阵未变。该输入规范化在冻结R1阶段以714张PNG确认去重前后SHA-256全部相同，R2沿用同一规范化原始输入。
- 独立包内重建、六个GIF逐帧解码、动作/分支/关节图实看记录见qa报告。艺术对照和结构检查分别记录；结构通过不等于艺术质量通过。

源包内包含三个死亡分支及变身GIF、关键动作对照和原/R1/R2三栏图。完整PNG联系图与8件肢体三栏图另有可单独打开的visual-review普通ZIP，非分卷，不影响源包独立重建。完整常规动作GIF（197帧）和两种倒地GIF（232帧）另附普通独立文件，均小于15MB，也可由本包重建。

## 验证的含义

静态渲染保留原depth和矩阵，子元件按放置时间推进。它不执行ActionScript的stop/goto，也不模拟运行时替换、AI、碰撞或装弹逻辑。GIF按原30fps近似并在各独立片段结尾留停顿，仅便于审美审查。

本地仍需验证CS6导入、分件注册点、真实关节遮挡、游戏尺寸、枪口/手握接口、死亡三个分支、变身至现役native clone及五帧空尾的实际脚本跳转。详见INTEGRATION.md。

## R2艺术边界

本稿仍是供人工标注和本地实装验证的候选源稿。原版脸部材质为低分辨率位图，R2进行了可编辑矢量重释，并非逐像素摹写。比例和骨相由同尺度原/R1/R2图直接审查，不以alpha覆盖统计代替。新衣服的受控硬边明暗也不代表原位图的每一条柔光都被保留。
