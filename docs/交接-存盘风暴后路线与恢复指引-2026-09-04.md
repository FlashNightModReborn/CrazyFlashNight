## 2. 本会话用血换来的工程知识（不重复踩）

1. **AVM1 吞 NUL**:`String.fromCharCode(0)` 在字符串拼接中被吞（实测 lane `"A\0"+c` 退化为 `"A"+c`,KAT 对撞实锤）。哈希/HMAC 类分隔符必须以 code unit 直喂（`fnv1a32Round(hash, 0)`)。已登记 `agentsDoc/as2-anti-hallucination.md`。
2. **runner BOM**:ps1 被 Edit 类工具剥 BOM 后，PS5.1 按 GBK 解析中文字面量→路径错乱/语法错误，报"Required AS2 source is missing"或 ParserError。修 ps1 一律 python `newline=''` 读写并验 BOM。
3. **测试编写陷阱**:`shopBulkQuery` 入口即 `rotatePurchasedToken()`，其后捕获的 expectedToken 必须取 bulk 之后的值；同名药剂占袋是"可合并"假布景，造 `inventory_full` 需不可合并物占袋 + 药剂栏容量 0;replay 语义是"允许 token 不同"不是"必须不同"。
