## 单独记录的现有审计失败

`tools/audit-diplomacy-stage-select-links.js --json` 返回一项错误：

```text
completed-stage return no longer follows _root.关卡地图帧值
```

该检查器及其读取的场景转换、选关服务源码在 Git 语义上与本轮起始 HEAD 一致。使用 `git show HEAD:<path>` 的原始源码在独立 Node 进程重放静态检查，得到相同错误；实际外交地图 SWF 扫描已完成，未发现缺失 SWF。本批既未修改 AS2 返回链，也未修改或放宽此检查器，不能把该项写成通过。

这是与缩略图接入分开的既有基线问题。上述复现不证明实际游戏返回链正确，也不扩大本批修复范围。
