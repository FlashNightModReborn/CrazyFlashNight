# 选关界面-双栏工作台栈对齐评估与升级方向（2026-08-16）

**文档角色**：选关界面（`stage-select`）是否 / 如何纳入双栏工作台体系的评估终裁与批次计划，结构对齐 `docs/竞技场面板-双栏工作台栈对齐-评估与升级方向-2026-08-06.md`。
**当前状态**：P0（真值闭环）、P1（基础体系接入）、P2（交互升级：键盘路径 + pinned 决策检查器）、P3（协议加固）、P4-a（工程拆分）、P4-b（预览覆盖提升）已完成并全绿，第一批 P0–P4 全部收口；Stage 3 三维沙盘为独立专项（第二批），需另行立项启动。

## 0. 结论

值得纳入，但纳入的是**双栏工作台的基础体系**（PanelScale / 生命周期 / 焦点 / 动效 / 状态 token / 交互真实性合同），**不是**把选关地图塞进 `catalog-decision` 的固定 60/40 双栏。

选关的本质是「空间导航器 + 进入决策」，地图拓扑本身就是主要信息。推荐终态：

```text
AS2 权威状态 → StageSelect ViewModel → 2D / 2.5D / 3D 渲染器
                                  ↘ 自适应决策检查器 → enter intent → AS2 复核
```

默认保持全宽地图；选中普通关卡后显示可固定的决策检查器。只有宽度充足时才形成右栏；1024×576 下检查器应为不缩放地图的浮层 / 底部面板 / SecondaryPage。外交地图、副本任务等直达入口继续保持一步跳转。

程序切分为两段（2026-08-16 与用户确认冻结）：

- **第一批 P0–P4**：有界工程，逐批有验收门，本批完成即得全绿基线。
- **第二批 P5**：Stage 3 三维沙盘独立专项（hero slice 仍按 `docs/选关界面-webview迁移路线图.md` §5 的既定批准与 gate 执行），在第一批完成后的干净基线上启动。

## 1. 现状事实（核验基线：工作树 @ 2026-08-16，P0 闭环后）

1. **成熟度**：Stage 2 Step 2 已落地，正式入口（基地门口 / 车库 / 地下 2 层 / 停机坪 / 联合大学）默认打开 Web `stage-select`，旧 Flash `关卡地图` 仅作 fallback。它是生产面板，不是待迁移旧页。
2. **布局形态**：1024×576 全屏空间地图舞台，166 个空间定位按钮（14 直达含 10 外交绿点 + 4 副本任务），hover 卡内含难度按钮。runtime 下右侧信息栏已移除，无「右栏决策区」内容可放。
3. **壳与共享层消费量**：`stage-select-panel.js`（约 1300 行）零 `Workbench.*` / `PanelScale` / `PanelTooltip` 引用，自写 `syncStageLayout` + ResizeObserver；`panel-scale.js:16` 注释本就把 stage-select 列为预期消费者。
4. **样式**：`launcher/web/css/panels/features.css` 内 219 处 `.stage-select-*` 选择器全硬编码色，零 `--wb-*` 消费；未迁入 `css/workbench/`。
5. **数据链路**：布局 SOT 为手写 `stage-select-data.js`（.fla 已退役）；动态状态（解锁 / 挑战 / 任务 / 限制词条）由 AS2 权威经 `stageSelectSnapshot` 回包，进关 `stageSelectEnter` 由 AS2 复核执行——权威边界正确，必须保持。
6. **真值治理（P0 已闭环）**：计数基线曾三处漂移（testing-guide 164/13/9、路线图 165/14/10、实际 166/14/10），`stageNames` inventory 漏登 2 个 web 手写条目（subway、据点M），`.gitattributes` 误标 `linguist-generated` 使手写 SOT 在 PR 中被折叠。现已建立单一真值 `launcher/web/modules/stage-select/dev/stage-select-golden.js`，audit 与 qa-suite 共同消费，并新增 stageNames 覆盖完整性检查。
7. **键盘路径（实证缺陷）**：关卡节点为 `div role=button` 内嵌原生 `<button>`；卡片仅父节点 `:hover/:focus` 显示；普通节点 Enter/Space 处理器只 `logDev` 是纯 no-op（`stage-select-panel.js:512-521`）——**键盘用户当前无法进关**。难度按钮约 37×20px，低于体系 40px 命中区下限；锁定节点完全隐藏卡片、无焦点可读原因。
8. **生命周期**：每次 snapshot / busy / error 全量重建节点，焦点与选择态难以稳定；Host 请求只有 callId 映射，未达工作台 exact instance / session generation 防迟到回包标准。
9. **测试设施**：harness 31 用例（P0 后 31/31 绿），双审计工具 + FFDec 视觉对照基线齐备；mock-browser 证据不等于真实 WebView2→Host→AS2 E2E。
10. **预览覆盖**：`previewSources = external:12 / internal:76 / default:74`，约 46% 关卡仍在用默认预览帧——P4 的真实缺口。

## 2. 目标态裁决

- **D1（不套封闭 profile）**：现有六种 profile 无一与「空间导航 + 就地决策」同构。硬缩到约六成宽后，13px 地名约等效 8px、44px 命中区约剩 27px，破坏辨识与点击。**不迁入 `DualPaneShell` / `catalog-decision`。**
- **D2（纳入基础体系）**：消费 PanelScale、统一生命周期 / disposable、focus / reduced-motion、颜色与状态 token、`data-workbench-skin`；CSS 从 features.css 拆出并纳入 ratchet；生产 manifest / dev fixture / assetReport 拆分。
- **D3（决策检查器 = pinned-inspector）**：hover 可操作卡装不进现有三种 tooltip profile（simple / dense-inspect `pointer-events:none` / pinned-inspector）。引入「显式选中后的固定决策检查器」恰为 `pinned-inspector` 语义，顺带解决 D1 的 tooltip 张力。1024×576 下以不压缩地图的浮层 / 底部面板形态出现；外交 / 副本直达入口不强加难度或二次确认。
- **D4（不发明假 profile）**：`workbench-profile.js` 封闭枚举不提前加入未经验证的 spatial 类型；将来 P5 原型证明必要时，按 canonical 程序申请兄弟级 `spatial-decision`。
- **D5（协议冻结面）**：P0–P2 不动 AS2 协议与进关语义；P3 加固（panelInstanceId / sessionGeneration、关闭即清 pending、迟到回包拒绝、catalogVersion/stateRevision）只加守卫不改语义。
- **D6（CTA 合同变更留待 P2 显式裁决）**：现状「点难度即进关」是一步操作；改为「先选难度 + 唯一进入 CTA」属产品合同变更（竞技场 P0 同类裁决先例），施工前由用户拍板，不默认执行。

## 4. 验收口径

- 每批当批门禁：`audit-stage-select-layout` / `audit-diplomacy-stage-select-links` / `run-stage-select-harness --browser edge`（1024×576 / 1366×768 / 1920×1080 三视口）/ strict UI audit / css bundle / `validate-doc-governance`。
- 既有 31 用例行为合同不倒退（P2 裁决改写的除外，须在状态日志登记）。
- 触及共享层的批次当批跑 workbench ratchet / atlas，不推迟。
- 自动门与 mock-browser harness 只算工程证据；涉及真实进关 / 返回链路的结论须真实 WebView2→Host→AS2 复验，且每批状态日志写明证据上限。

## 5. 非目标

- 不把选关地图改造为目录列表；不牺牲空间语义换取形式统一。
- 不在 P0–P4 迁移外交地图场景本体、战斗结束回流与角斗场返回路径（后者需独立评估）。
- 不承诺 16 战区全量 3D 化；不建通用「SWF → 语义 3D」转换器。
- 不在 feature CSS 里造隐式布局结构；不提前向封闭 profile 枚举加 spatial 类型。
- 内容新增（如外交-黑铁阁挂接）走 golden 流程的日常条目维护，不占本批次。
