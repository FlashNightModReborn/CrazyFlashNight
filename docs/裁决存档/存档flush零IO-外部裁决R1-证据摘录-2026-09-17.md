## 原始报告表述的边界

- “Flash 先 hung，再拖死 Guardian”：现有日志只记录数秒后两者均 hung，不能给出先后因果；需要两进程线程栈/等待链。
- “Ghost 来自上一实例”：当前日志未建立 Ghost 与被代理原窗口之间的身份映射。
- “切走 Ghost 立即解冻”：17:12:02 和 17:12:12 已观测前台不是 Ghost，Activate 直到 17:12:14 才返回。
- “每次点 X 都重新做一次 AS2 flush”：fatal_blocked 分支会直接返回；连续关窗日志没有与之逐次配对的新 flush。
- “返回 false 前必已完成完整 AMF 编码”：三份源码不能证明闭源 Player 内部编码与策略检查的先后顺序。
- “存档读取成功就是 Flash 读本地 SO 成功”：该会话明确使用 launcher_snapshot:sol。
- “F6 无任何字节落盘”：只能说明被提供/被选取的权威存档未含新进度；不能覆盖其他文件或其他身份路径。
