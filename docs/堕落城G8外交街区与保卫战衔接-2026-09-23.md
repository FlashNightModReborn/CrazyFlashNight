# 堕落城 G8 外交街区与保卫战衔接

**文档角色**：本地灰盒施工与来源核对记录；不修改游戏运行资产、关卡剧情或场景接口。

前序：[G7 商业组团与地图映射调研](堕落城G7商业组团与地图映射调研-2026-09-23.md)。用户本轮指出保卫战经过商业街、酒吧门口和酒吧室内三个外交区块，授权将其连续关系与已裁决的调研结果一起施工。

## 1. 修正的问题

G7 只有三间商业门面和泛化酒吧体量，缺少原场景中辨识度很高的旧仓、围栏停车场、右侧砖楼与条纹雨棚；室内没有归属到实际楼体。事件虚线也只到酒吧附近，没有贯通至黑铁战区与摇滚捷径。

G8 把三个外交场景建成连续空间：商业街 → 外院街道 → 同栋酒吧入口与室内。酒吧室内默认有二楼和屋顶覆盖，验收剖视可隐藏上层，观察吧台、桌位、窗与出入口。剖视不会新增城市地块或改变原场景切换。

## 2. 场景证据

本轮用现有 FFDec 只读导出三个 SWF 的脚本，未编译或修改 SWF：

| 现役场景 | 脚本中的联系 | 灰盒落实 |
|---|---|---|
| `地图-堕落城商业街` | 左向回基地车库；右向进入 `地图-堕落城酒吧门口` | 商店前场与酒吧街道通过步行路相接 |
| `地图-堕落城酒吧门口` | 左向回商业街；右向进 `地图-堕落城酒吧` | 旧仓和围栏停车场居一侧，酒吧砖楼居另一侧 |
| `地图-堕落城酒吧` | 上向返回酒吧门口 | 同栋内部空间，进出同一个入口；未虚构通往黑铁战区的后门 |

脚本中的左、右、上是横版局部交互方向；城建可整体旋转，不直接换成全城东西南北。资料在本机 `tmp/fallen-city-g8-evidence-20260923/`，有三路只读导出日志与脚本。三份完整外层精灵图沿用 G2 导出的原素材，灰盒附带 `/g8-references.html` 对照页；离线图不是游戏运行截图。

[保卫战 XML](../data/stages/基地车库/堕落城保卫战.xml)包含突入市区、赶往酒吧、黑铁战区在前方、前往摇滚的既有捷径等文本。用户对三个外交区块的完整经过关系作为本轮设计依据；灰盒呈现城市尺度的叙事动线，不宣称复刻横版每一屏的几何。

## 3. 本轮建设

- 酒吧地块从原始坐标 `[480,345,100,60]` 调整至 `[470,345,110,80]`，南缘到 425，给 435 起的驻点留出街道。商业街、驻点及三级地势保持既有主体范围。
- 外院增加旧仓立柱、围栏与开口、旧料、停放车辆；右侧酒吧采用砖色楼体、窗、条纹雨棚与西部酒吧标识。
- 酒吧实体为墙、楼板、上层与屋面；真实开口通入室内。普通公共道路仍可绕过场所，避免日常交通必须穿酒吧。
- 事件线从商业街开始，经酒吧室内再返回外街，经过驻点来访前庭和外缘、西侧捷径，接到摇滚后台。突入城市的精确外部入口未被资料坐实，删除此前容易让人误认为确定路线的城外长虚线。
- 联合大学的地下工坊电梯机房并入教学楼体量，保留教学楼—地下工坊关系，移除看起来像独立地下入口的小楼。
- 摇滚后台区分维护侧和排练房，增加房名与接入侧路；试炼入口补准入登记窗、回收暂存；据点 M 普通门面补「月面保洁」招牌。
- 上轮调研未证实的深处精确地址、跨区地下贯通、黑铁驻点与关卡的唯一地址等继续保留不确定性。没有把调研建议全部直接写成设定。

## 4. 检查与验收

G8 原型仍在本机 `http://127.0.0.1:8782/`。默认视角是「商街与酒吧连续空间」；另有「酒吧室内剖视」「保卫战城区路线」。页面保留 G7 对照，增加外交原场景对照页。

静态检查：59 类道路、4425 个登记盒体通行带样本无冲突；4142 个台地样本、9048 个沙面通行带样本无埋路；实际网格 1410 条道路射线无阻挡；39 处显式接口成立。事件线另有 803 个样本确认落在已建步行道路范围内、28 条中心射线未发现穿墙。室内位于酒吧地块且屋面默认可见。

这些检查不证明角色导航、拥挤交通、车辆转弯或真实关卡体验。浏览器检查涵盖 23 个视角、剖视与事件提示开关，并保存局部截图；人类感官验收待完成。本轮没有新跑 SWE2，使用 G7 已裁决报告及本轮原场景核对。
