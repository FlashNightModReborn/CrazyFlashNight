## 游戏表现

- “基地车库”采用堕落城三维场景；19 个真实关卡及 4 项导航配置保持原 ID 和进关协议。其中两项世界导航放在总部与试炼设施附近，系统返回仍为独立按钮。
- 总览保持美术机 C4 镜头。地图名称使用短称减轻拥挤，无障碍名称、简报、难度和实际请求保持原全称。使用项目现有浅金主线加深色描边；摇滚内战引线在压制战标签下方折转，避免穿越其他标签。
- 压制战仅高亮 AS01 的 assembly；摇滚关关联 residential 背景。按主要活动、经过、服务、入口和相邻区分覆盖强度。战役范围不改变常驻归属。
- 地点特写围绕主要活动部分计算包围盒，采用较高俯角，避免被相邻舞台或大片环境带偏；保卫战保留跨商业、酒吧、黑铁与摇滚的范围。特写参数仍待人类看图，不声称是剧情规定镜头。
- 酒吧入口悬停或键盘聚焦时剖开屋壳，离开后恢复；外交仍按原流程直接进入，未改成普通难度关卡。
- 主体使用回包 unlit/固定光照，灯束和 bloom 按回包配置处理，没有叠加实时全局光。画面按交互出帧，不启动持续的空闲渲染循环。
- 离开区域、关闭面板或取消加载时释放本场景资源；图形中断或载入失败切换二维并允许继续选关，重试可恢复三维。

共享的一个实际交互修正：鼠标点击“返回总览”仍恢复原节点焦点，但不再仅因这个程序恢复的焦点弹出持久悬浮卡，防止它遮住邻近三维标签。鼠标悬停和键盘焦点卡继续保留，二维逻辑不变。

## 如何验收

启动游戏后从基地车库打开选关；如果启动器/WebView 已在修改前加载，重新启动游戏再看。游戏使用项目 `launcher/web`，本次 Web/资产改动不需要重编 Flash 或发布 native runtime。

开发验收页为 `launcher/web/modules/stage-select/dev/harness.html?viewport=1024x576&frame=基地车库&fixture=allUnlocked&player=1&review=P8-I1`。它加载生产面板和真实 GLB，但 Host、全解锁状态为模拟，不修改玩家进度；`review` 参数下简报使用原关卡文本。诊断页 [fallen-review.html](../launcher/web/modules/stage-select/dev/fallen-review.html) 提供只针对模拟 Host 的锁定、图形中断、关闭/重开及统计检查。

人类重点看：默认镜头下总部/摇滚/城防主次，中央密集入口是否容易认，压制战后街与摇滚住宅是否容易区分，保卫战特写是否合理，外交酒吧剖看和两处导航是否直观，以及真实窗口中的首次载入与切换停顿。

## I2：游戏端拉伸面异常的兼容修正候选

用户提供游览中的大片拉伸三角面截图，并确认“一打开就有，重开仍在”“只有游戏里有”；原浏览器审图正常。此前 I1 正面、协议与生命周期检查没有覆盖这次真实游戏渲染异常，不能据此判定没有问题。

本轮复核：运行 GLB 与回包字节相同；CPU 三角形数据未发现与截图相应的跨楼竖直大面；同机浏览器中复查近似侧视/俯视没有复现。因此目前仅将异常收窄到游戏运行环境相关，**尚未确认具体显卡、WebView 或驱动根因**。后续用户回复“可行”，认可本轮修正并授权建 Issue 与提交；未提供具体环境身份，因此不扩大为跨 GPU/驱动验证。

发现唯一的 32 位索引批次 `P4_RENDER_P4_Static_plain` 含 272907 顶点、172371 三角形。增加静态批次兼容适配，载入时按最多 60000 顶点分成 5 个 16 位索引批次。源 GLB 不改，三角形顺序、顶点、法线、颜色、UV、材质及语义标签保持；不是删除异常区域或改变城市布局。该处理针对大索引绘制兼容性的嫌疑，不能把它写成已证实的根因修复。

同时给模型请求加源 SHA-256 版本参数；在支持 Web Crypto 的安全上下文中核验实际响应字节，拒绝错误身份并进入既有二维回退。诊断统计给出 `loadedHashes` 与 `indexCompatibility`，便于下一次区分陈旧缓存、不同资产和渲染问题。没有关闭硬件加速、重置 WebView 缓存或改动玩家状态。

已执行 `node tools/test-stage-select-geometry-chunks.mjs`：逐项对比 6205356 个原始属性分量、三角形顺序、16 位索引上限、变换后的实际顶点包围盒与材质/语义继承。专项浏览器回归、五次关闭重开、选择分区和图形丢失恢复通过。默认镜头主绘制从 51 次变为 55 次，提交三角形仍为 361010；上传几何从 47 变为 51，纹理仍为 51。I1 数字保留为历史，当前以 I2 测量为准。

验收需要完全退出并重新启动游戏/启动器，让新的场景模块加载，再到截图角度核对。若仍有拉伸，应继续保留现场并核对游戏宿主的 WebView/GPU 环境，而非继续盲改美术模型。
