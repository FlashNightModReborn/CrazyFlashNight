# 翅虎受身与烟雾登退场

生产入口是 `敌人-飞刀小子` 的原生首帧和 `WingTigerController`，通过敌人模板安装的 `_root.翅虎初始化` 接线。敌我阵营共用受身规则，NPC 展示单位不启用。

默认参数以有效战斗帧计数，30 FPS：

| `翅虎参数` 字段 | 默认帧数 | 含义 |
|---|---:|---|
| `controlFrames` | 48 | 连续受控约 1.6 秒后受身 |
| `cooldownFrames` | 240 | 两次受身至少间隔 8 秒 |
| `freeFrames` | 8 | 连续恢复行动后结束本次受控计时 |
| `guardFrames` | 8 | 进入反击时短暂免击退与防中断 |
| `entryFrames` | 24 | 烟雾登场约 0.8 秒 |
| `retreatFrames` | 24 | 烟雾撤退约 0.8 秒 |

后续命中不重置受控计时，短暂站立也不立即归零。暂停不推进计时；封印、投掷与动作战入场冻结期间不触发受身。受身清理原击飞、硬直、击退任务，随机进入已有 `a1` 后撤或 `a2` 多段机动；无存活攻击目标时选后撤。受身不修改 HP，也不启用无敌；致死优先于受身。

登退场仅由关卡参数启用：`登场动画:a0`、`死亡动画:a1`。翅虎堂内部已配置两者；默认斗兽与其它场景保留原登场、死亡方式。登场短暂保护在动画结束时恢复，撤退在零 HP 下调用原 `死亡检测({noCorpse:true})`，保留经验、掉落、波次计数和单位卸载。

烟雾的视觉真源来自 `flashswf/arts/new/瓦巴杰克/LIBRARY/特效与子弹/逃跑烟雾.xml`。只复制两个视觉层和 17 个矢量依赖到 things5 的 `翅虎/烟雾素材`，未复制判定区、声音、子弹状态位或移除父单位的脚本。翅虎专用导出为 `翅虎烟雾`，登场、受身、撤退共用，入口可替换视觉而保持战斗规则。
