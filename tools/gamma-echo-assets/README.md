## 源和动作

- 现役原生美术位于 `flashswf/arts/new/Codex专用素材/LIBRARY/Codex/γECHO克隆兽/`。
- [认可画稿归档](../../flashswf/arts/new/Codex素材源稿/γ-ECHO克隆兽-R3/) 保存 26 个 SVG、注册点、配色来源和初始清单。归档是导入依据；后续美术编辑归原生 XFL。
- 每版 13 个身体分件，SVG 三次曲线转换为原生二次曲线，嵌套裁切保留为静态遮罩层，骨爪保留原生渐变。素材中没有栅格贴图。
- 原生连接修补覆盖脚掌趾根、两种手爪、颈部骨刺和牙根，并清理轮廓描摹遗留的游离碎点。`connections.py` 保存可重现的原生修补配方；认可 SVG 归档保留原样。
- 身体动作、根状态标签、攻击区域、发射帧和子弹伤害沿用诺亚模板。普通爪击、跳跃撕咬、跑动捕杀、撕裂嘶吼分别保持 2、2、8、5 次发射。
- 三个死亡入口为断腿前扑、断臂后仰、屈膝侧倒；每版另有六个专用残躯/碎片元件，包含肌肉断面、骨茬、碎肉和骨片。血迹与动作时点沿用原死亡时间轴，详见下方死亡补齐记录。

`native-manifest.json` 保存本次导入的来源和原生文件身份；它不是持续覆盖手工 XFL 编辑的许可。
`build.py --import-approved` 只允许覆盖与上次导入一致的文件，发现后续原生修改即停止。

## 私有 AI

[GammaEchoAI.as](GammaEchoAI.as) 是两个新单位的私有帧脚本输入。正常生成在 65 级前采用增强分支，65 级起使用继承的诺亚 AI。原普通攻击从 65 级获得刚体；本轮高等级对照未证明强制增强有收益。隔离斗兽可显式传入 `baseline` / `enhanced` 复现对照。

增强分支优先对齐轨道，近身优先撕裂嘶吼，中远距离选择跳跃或跑动捕杀；暂停、手动控制、硬直、倒地及无效目标均不能触发私有攻击。
增强模式将通用自动攻击判定范围设为 0，由私有控制器独占选招；实际攻击区域不变。轨道范围为 24、保持距离为 100；出招间隔由原动作完整时间轴约束，不在收招后增加私有等待。
攻击动画、伤害倍率、子弹段数及共享 AI 均保持原合同。

暴君型固有 **5% 吸血**，λ 型为 0。属性由生产 `BulletInitializer.inheritShooterAttributes` 传给攻击，再由 `LifeStealDamageHandle` / `HealApplier` 结算。伤害不足和强度足够的护盾不触发，死亡单位不能被此机制复活；满血以上沿用项目既有的溢出衰减。该能力不表示世界观中的死后再生。

只有隔离标定单位可以通过 `克隆兽吸血模式="off"` 关闭固有吸血以作镜像对照，普通生成忽略该诊断开关。

`gammaEchoArenaAudit` 仅是标定单位的私有诊断对象。禁止将它写入 `_arenaCalibrationSkillState`：后者属于 ArenaSkillCache 的严格结果格式。

`decode-connections.py <本轮trace> <输出目录>` 要求本轮闭合行为记录、28 张完整原生帧和 2 张静态帧；`--partial` 仅供诊断，不能作为完整验收。
`check-connections.py <解码图片目录> --output <检查结果.json>` 对 16 张完整活体姿势检查透明像素连通性（alpha > 127，至少 12 像素的游离区域）；攻击拖影和有意拆开的死亡碎尸不套用单一连通域要求。该门补充关节与轮廓审查，不替代完整动画观感验收。

## 双 Worker 对照

`arena-plan.js <plan-input.json>` 只生成冻结计划；实际运行复用 `tools/arena-calibration/run-worker-experiment.js --plan <experiment-plan.json>`。
配置必须明确两个自有 Git 资源根、各自根下的候选目录、只读测试种子、等级和重复数。机器 case/source 标识用 ASCII，中文仅用于单位类型和说明。

镜像对照只切换 AI，保留双方相同 XML 面板，并交换红蓝。**这两版继承的普通怪物初始化路径没有人形单位的蓝方三倍生命规则，不能套用 hp_min/max 除三。**
有效对照还须读回双方实际 `startMaxHp` 相等。自然超时单列；格式失败、基础设施错误和面板不等的诊断批次不合入强度统计。

每个短 shard 至多 25 局，运行预算受 Worker 工具约束。规划时为最坏帧数和启动、回收留出余量；需要更多样本时拆成新组。
原始结果、候选与 SWF 身份、资源前后校验、存档保护和独立进程回收共同构成证据。
正式入口、玩家操作和美术观感按实际复验范围报告。

`candidateMode="default"` 省略单位模式参数，检查实际默认分支；`compareToNoah=true` 则将对手换为原兵种 372。
对诺亚的比较包含阶段面板差异，不能用于估计纯 AI 收益。
`compareLifeSteal=true` 要求 `candidateMode="default"` 且关闭 `compareToNoah`。两个 Worker 都采用兵种 460，两侧 AI 与面板相同，只在基准侧关闭 5% 吸血；该结果单列为续航对照。
`analyze-arena.py <experiment-report.json> [...] --output <analysis.json>` 读取已有回执和不可变结果，复核文件哈希后分类汇总；不会启动或重放战斗。
