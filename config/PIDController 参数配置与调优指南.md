# 性能设置入口与旧 PID 配置退役说明

旧 `PIDControllerConfig.xml` 不再接入现役性能调度；修改其中的 PID 参数并重启不能调节当前控制器。历史控制理论与实验不能充当玩家操作指引。

新的本机性能方案在 **设置 → 本机与 Web → 性能方案**，提供通用/性能/画质、自动/固定、绝对绘制高度上限，以及应用/撤销/恢复推荐值。C# 保存机器偏好并调度，AS2 只测量和执行；不修改玩家游戏存档。

2026-10-09 这一收敛批仍处于开发候选和人力验收边界，不代表已正式部署。实际使用方式、范围、预算语义与当前验证入口以[动态分辨率与性能方案](../launcher/perf/flash-compositor/README.md#动态分辨率与性能方案)为准。
