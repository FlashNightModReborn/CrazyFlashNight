# 统合61式画风与小尺寸要求

打磨应让全套在同一尺度下具有一致的材质和造型语言，并让主结构在缩小时保持清楚。请用同一姿势、同一画布和同一倍率比较基准与候选。

## 画风统一

先建立少量明确规则，再用于全部分件：

- 外轮廓、主要分区线和次要接缝有稳定的粗细关系，避免每件各自决定。
- 板甲采用一致的受光面、转折面和暗面层次。边缘高光应服务于结构，不要让每条边同时发亮。
- 胸腹、肩臂和腿部的金属处理保持相近复杂度。大块板甲、关节软连接和传动机构可以有不同材质，但差异应有规律。
- 铆钉、接口、磨损、编号采用相近尺度和密度。先合并零碎信息，再补有作用的细节。
- 男女对应部件保留共同结构语言；不要把性别差异处理成两套不同材质和工艺。
- 上臂、小腿和鞋是双侧原向复用件。使用贴合局部形体的明暗，避免把强烈的世界空间左侧照明、单侧管线或方向标识画死。

data/palette-reference.json 列出当前稿常见颜色，供核对主色与辅助色。它不是颜色白名单。若改变整体配色，请保留可比的当前配色方案，并说明辨识和层次收益。

## 小尺寸优化

优先级依次为整机剪影、头肩胸与腰胯的大分区、主要机械结构，最后是表面装饰。减少某些细节应与强化主要结构共同进行。

重点检查：

- 头盔与肩甲、胸甲与手臂、腰甲与大腿、膝盖与小腿能否分开。
- 主甲板与关节间是否有清楚但不过碎的明暗差。
- 感知部件、胸炮舱门、肩部识别块是否仍能定位。
- 浅色编号、亮边与装饰是否互相争夺注意力。
- 极细线、密集并排线、小于一个输出像素的亮点是否混成噪声或脏边。
- 接缝减弱后，装甲厚度与关键转折是否仍能理解。

当某条结构线或某个装饰在目标尺寸中不足一个像素，不要求机械地保留。可以合并为面、减少数量、适度强化主要边缘，或在大图中保留但降低对比。避免全局统一加粗、全局锐化和一概抹除细节。

## 尺寸和背景

工具固定同一个 reviewCanvas。96、128、160、240、320是画布像素高度，人物只占其中一部分；实际占比取决于提供的固定骨架与留边。不得把这些档位写成已验证的游戏实像素大小。

请同时比较：

- 96、128、160画布高度的原尺寸 PNG。
- 同一小图以整数倍最近邻放大后的像素表现。
- 240或320高度的结构检查图。
- 暗、浅、蓝灰、土色及复杂底纹。

复杂底纹为合成评审背景。真实游戏镜头、角色显示高度与战斗特效遮挡在 Windows 回装后复核。

## 拼接与状态

每种性别由12个独立分件放置15次。共享上臂、小腿、鞋在双侧都需要成立。至少查看七种当前站姿以及额外的短兵站立、短兵格斗架势、刀剑站立和长柄站立关键帧。另附的作者空手关键帧用于参考，不能据此声称完整行走或攻击动画已通过。

检查肩肘腕、髋膝踝的重叠余量，不因站立好看而减少其他姿势需要的遮挡面。头盔、手和鞋跨性别共享，修改后须同时查看男女。

胸甲的闭合、开门和开火稿在未运动区域保持一致。舱门、孔口和炮口关系要连贯，不能只优化闭合帧。

## 五件物品图标

现役图标使用24×24遮罩内的部件特写。图标不是整套人物的缩略图。预览配方随工作分件更新，取景矩阵与遮罩保持当前值。

第一帧为静止闭合部件特写与径向底影，第二帧使用同样的部件、矩阵和遮罩，仅移除底影。两帧都不显示开门或开火稿。最终原生分层与离线导出的表现由 Windows 端核对。
