# 双枪枪械师等级倍率：独立修复与回归

**文档角色**：独立于 Issue 164 的倍率缺陷、局部修复与真实 Flash 验证记录。调查基线 commit `5c8a11d41d429edad0118e24d6c835a8e1469029`，叠加本地 Issue 164 修复；用户依次授权本地施工、回归、可玩接入与同步上游后提交推送，正式 runtime 发布不在本次范围。

## 缺陷与既有预期

`ShootCore.calcGunslingerTapMultiplier` 和 `calcGunslingerHoldMultiplier` 已按等级计算：1 级点按/按住间隔倍率为 `1.0/1.5`，5 级为 `14/15` 与 `25/18`，10 级为 `0.85/1.25`。技能 XML 说明要求升级增强点按收益、减轻按住射速惩罚；倍率作用于时间间隔，不是伤害。

2026-01-29 的 `1e1b879822c0b485bd33e8885310300497d4df7f` 将单武器入口和单/双枪持续回调改为等级公式，并将常量标为废弃，却未迁移 `ShootInitCore._createHandShootFunction`。该双枪入口仍使用固定 `0.85/1.25`，因此 1～9 级每次重新点按都提前取得满级点按收益；一直按住时第一段间隔使用满级值，后续才按真实等级计算。10 级恰好一致，未启用技能或全自动的分支不进入这处倍率计算。

这不是 [Issue 164](Issue164-装填打断射速调查与回归-2026-10-22.md) 的根因：原现场使用 53 式、未开启枪械师；该缺陷是旧解锁回调释放新冷却锁。两处缺陷分别保留原因和证据。

## 局部修复

双枪入口读取与单武器入口相同的技能等级，点按与按住均调用现有等级函数；该等级值也供既有后摇公式使用。没有修改等级公式、武器 XML、技能描述、换弹规则或攻击打断装填能力。

## 回归边界与用例

唯一执行入口为 `scripts/run-shoot-reload-timeline-tests.ps1`，夹具与恢复合同见 [runner 说明](../../scripts/test-runners/shoot-reload-timeline/README.md)。新增 `GunslingerDualCadenceTest` 在真实 CS6/AVM1 中调用生产双枪初始化、主副手入口、时间轮、`WeaponFireCore` 与真实弹药消费；动画跳转、库存及弹体出口为隔离夹具，不读取玩家槽位，不声明实际双枪角色动画或物理键盘验收。
