## 刀剑额外吃 0.2 倍空手 —— 用户的写法有优先级坑（同日 16:3x）

用户问「是不是改成 `(冷兵 ? 冷兵 : 0 + 空手 ? 空手 * 0.2 : 0) * 配.刀加成倍率;` 就行了」。
**不行。** 三元优先级低于 `+`，实际被解析成
`冷兵 ? 冷兵 : ((0 + 空手) ? 空手 * 0.2 : 0)` —— **只要冷兵不为 0，空手那部分完全不进账**。
用 Node 实测（AS2 优先级同 ECMAScript）：

| 冷兵 | 空手 | 用户写法 | 应有 |
| --- | --- | --- | --- |
| 60 | 150 | **60** | 90 |
| 0 | 150 | 30 | 30 |
| 100 | 0 | 100 | 100 |
| 0 | 0 | 0 | 0 |

**⇒ 教训：AS2 里嵌套三元 + 算术必须逐项加括号。** 正确写法：

    else if (类型 == "刀")  对应加成 = ((冷兵 ? 冷兵 : 0) + (空手 ? 空手 : 0) * 0.2) * 配.刀加成倍率;

（注意 `(空手 ? 空手 : 0) * 0.2` 的括号也不能省，否则 `0 * 0.2` 会黏到 else 分支）

本次只改了这 1 行 + 3 处描述性注释（分流注释 / 文件头摘要 / 倍率表注释）；
**枪械分支没动**（用户只说刀剑）。备份 `tmp/王之财宝-数值/单位函数_lsy_主角技能.as.bak3-刀吃空手`。

### 「改成空图而不是删除」可行性评估（同日，用户问可否，交付结论后**未改动任何文件**）

**实测（一次性探针，已删）**：
- 全透明 400×400 PNG = **700 字节**，`getbbox() = None`，PIL 可正常打开。
- 在该空图存在的目录上跑 `coverage()` → **仍绿**：`{244/53/74, missing:[], blank:[]}`。原因：`GENDER_VARIANT_NAMES` 把 `室友` 短路到 `男室友`/`女室友`，**从不打开 `室友.png`**。
- **对照实验**：临时 `pop('室友')` 后再跑 → `blank:["室友"]` ⇒ 空图与那条变体登记是**配套关系**，摘一个另一个就报红。

**结论**：可行、零风险、门不会红；但**不是严格更优**——
- web 任务页 / AS2 任务栏：与"删除"**等价**（都纯空白）。顺带更正：web `onerror` 先把自己 `visibility:hidden` 再换 `无头像.png` ⇒ 占位图**显示不出来**，实际就是空白。
- **C# 原生交付菜单会退化**：`File.Exists` 为真 → 走画图分支 → 画全透明图 → **空洞**，丢掉了「灰底 + 首字『室』」。
- "不会被覆盖"这条理由**与 png 是删是空无关**：保护来自 `sources.json` 里**没有** `室友` 条目（生成器只写 `prepared` 里的 14 条）；只要不把 `室友` 加回去就不会被覆盖。
