# CF6 特种兵共用身体 / 盾兵 / 撞车变体 · 材质精修候选 R3

本包是原 CF6 特种兵 559、带盾 580、带盾被车撞 629 的一套共用身体与分支适配精修候选。三个入口不是三套独立角色设计。交付可编辑 SVG、原图集坐标的矢量母件、Python 重建脚本、静态原新对照和分支 GIF。未操作本地 Windows、未改生产资源、未运行 EXE / SWF / ActionScript；不是已经通过 CS6 或游戏验收的 FLA / SWF。

## R3 材质修订

R2冻结保留。本轮在R2已校正的原造型上恢复有选择的连续材质响应：黑布用低饱和漫反射和受力褶暗部，皮手套和靴有局部圆鼓光；黄色软袖、织带和皮袋各按原体积设置暖色明暗，避免亮塑料或金属漆。银脊、呼吸器、护臂硬边、膝甲和刀刃使用较窄反射亮带与相邻暗带。红镜与哑黑头壳分开，不添加光晕。

原/R2/R3 三方图使用同一注册、联合裁切和倍率；R2几何、原裁切和矩阵均保留。材质质量与结构覆盖分别审阅；候选仍需用户人工标注，并非最终风格签字。

- 黑色战术制服、金棕肩带/袖部、红色眼罩、银灰中脊及呼吸面罩、腰挂匕首、双扣腿带、侧袋、三条护膝筋和CF冠冕盾徽均保留。

## 重建

需要 Python 3、Pillow、NumPy、SciPy；预览需要 Inkscape。原有脚本不会执行游戏或 ActionScript。

只重建 152 件与结构检查：

`python source/rebuild.py --assets-only`

完整重建、559帧静态渲染、原新对照、19个分支GIF及逐帧解码、轮廓与碎片检查：

`python source/rebuild.py`

完整中间帧 SVG/PNG 体积较大，不放进交付压缩包；由冻结输入可重新生成。静态关键帧对照和 GIF 按包说明附带。

## 原始来源与限制

用户提供的 CF6 分卷归档静态提取的 Flash8 projector 内嵌 SWF：SHA-256 `b52af10e2dda43332e0b2ffb9549d2fad474f298b9f6c67d848ffc33ff589b01`。身体原图集483，盾原图集560。原来源、矩阵、裁切、时轴、根链接名及复用映射已冻结在 `reference/`。原SVG通过 `original-svg-bundle.json.gz` 无损去重保存，重建入口会先恢复并逐件核对原始SHA-256。要单独运行子脚本时，先执行 `python source/restore_reference.py`。

渲染对嵌套子 Sprite 按 placedAt 计算局部帧龄并取模；未模拟 stop/goto、脚本动态换装或交互触发。排除原非图像 helper 277/280/285/310。GIF 用30/30/40ms近似原30fps，分支末尾人为停450ms。静态图/GIF不证明游戏中的分支选择、衔接或计时。接入边界见 `INTEGRATION.md`。

三方对照用于比较冻结R2与R3；若需重新生成，额外提供冻结R2目录并执行 `python source/review_three_way.py --r2-root <R2目录> --fullbody`。R3资产、原/R3关键帧及GIF重建不依赖R2目录。
