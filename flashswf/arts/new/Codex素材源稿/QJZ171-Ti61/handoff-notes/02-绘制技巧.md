# 绘制技巧：面、边、孔与光效的分工

## 先画完整部件，再靠装配遮挡

总装中的弹箱位于远侧，独立元件仍包含完整箱体、闭合上盖与提手。前景机匣、侧杆和护圈产生遮挡。这样移动弹箱或接入现有换弹流程时，隐藏部分仍有连续图形。

严格侧视中的盖沿和提手也服从侧视。不能为了展示“顶面”而随意加一个俯视梯形；把错误侧面的箱壁放到后层，也不会修正观察侧。

## 每一种表面先定义亮度怎样穿过

| 表面 | 渐变安排 | 要避免的读法 |
| --- | --- | --- |
| 黑化长管 | 沿管径变化，偏心窄亮峰，沿长度连续 | 沿整根长度渐亮，或变成几条等宽黑白条 |
| 白色涂层宽面 | 宽缓受光和轻微面区变化，局部才有窄折边 | 中央尖峰配双黑边，把平板照成圆管 |
| 红色承接面 | 保留红漆主体，仅在搭接处集中压暗 | 整块都发光，或被一圈黑影压成泥红 |
| 灰色固定件 | 小面积受光与接触暗面，主次反差不同 | 每个螺钉都有同样亮的银环 |
| 黑色骨架/握持面 | 低峰值、较缓变化，必要轮廓保持分离 | 为所有黑件加同一条银边 |

渐变域是材料明暗的坐标范围。先调方向、位置和长度，再调色标；形状落在域外时，继续增加色标通常不会解决“看起来只有纯色”的问题。

## 区分厚度、倒角、接缝和接触阴影

厚度边是一段有宽度的侧面；倒角是主面与侧面之间的较窄转折；接缝是两件的边界；接触阴影集中在遮盖关系实际发生的位置。四者各自承担不同信息。

本次白甲采用短厚度边和局部暗带，露出的红座保留颜色。灰边宽度随所在面和投影变化，避免所有板件都像同一批塑料外壳。斜梁、白甲包边和锁扣各有自己的轮廓，接触处才建立搭接。

![机匣与弹箱接触关系](figures/机匣原生细节.png)

小五金最后处理：先保证扣件能读成一个跨边的实体，再画少量针脚、轴头和亮面。弱节点可以在小图中合并进黑框；关键锁扣仍需保留方向与两端归属。

## 孔洞由几何保证

枪口三个孔、侧杆开孔和枪托窗口是真实负形。孔缘的近侧短亮边、内侧灰面与深暗面帮助读出厚度，孔中心保持相应的透明或底层透视关系。

![枪口原生放大图](figures/枪口原生细节.png)

实际透明孔不能用黑色实心面替代；孔后若被另一部件挡住，显示的是该部件的颜色。核对时看透明导出和分件隔离图，避免把正常的后层物体误判为堵孔。

## 红光的四层作用

1. **实体灯芯/灯窗**：定义光源形状和安装位置。
2. **红色亮芯与较小暖色中心**：缩小后保留最稳定的发光提示。
3. **近晕**：连接芯与周围表面，避免像贴上去的纯色点。
4. **宽柔晕**：在相邻表面产生局部染色，强度与范围服从所属灯组。

本轮保留了原装备点光组件的数据，并按新表面调整缩放、旋转和椭圆域。后盖是点群，前侧是单点，上盖与弹箱仍是短条；没有把所有发光处换成同一种圆斑。

径向透明度在渐变色标内变化，外圈回到透明。应把光晕与原实体色面分开，避免通过降低整件透明度影响轮廓和实体材料。

## 枪管细丝的画法

先用暗槽确定细丝在黑管上的位置，再画红色主体，最后补较窄暖色亮芯。主线连续且稳定，副线更短、更弱；折转数量有限，走向与枪管长轴有关。夹环与连接座保持在正确前景层，遮住对应线段。

缩小检查时看三件事：黑管是否仍是黑管，主线是否连续，副线是否抢过主线。不要为保住所有分叉而把整条线加粗到改变管身读法。

## 一轮有效的局部修改

先指出具体问题，再只改与它有关的形状或材料。调整顺序为：表面分类 → 渐变域 → 亮峰和暗部比例 → 接触边与小件 → 实际尺寸。每轮使用同画布、同位置、同背景做前后对照。

定稿检查优先看整体和 160 px 样本，放大图用于解决接缝、孔缘与叠色问题。可迁移的是这套观察顺序；这件武器的绝对坐标、配方数量和分件数量不应直接套到下一件素材。
