# U3 睡眠面板：Web 拨针闹钟候选

**范围与授权**：关联 [#30](https://github.com/FlashNightModReborn/CrazyFlashNight/issues/30)。2026-09-19 用户授权实现并推进到人类测试，明确接受打开后使用普通 Web Panel 暂停，与旧版不一致。后续要求保留原 Flash 美术精神，并让视觉随目标时间平滑变化；候选视觉、取消与入睡旅程通过后，同日授权推进本地／云端构建共识、正式部署、推送及 issue／卡片收口。

## 1. 产品行为

- 原基地高级床、普通床、大学宿舍继续调用同一 `加载外部UI` 入口。该入口对原睡眠 URL 转接 `SleepPanelService.openPanel()`，不再加载睡眠 SWF；其他通用 UI 消费者保持原路线。
- 表盘时针、分针可拖动；分针跨 12 点连续进退小时。默认吸附五分钟，Shift 拨针、分钟按钮、键盘和 24 小时输入支持分钟精度。保留 06:00 / 19:00 快捷选择和上午／下午切换。
- 调整是本地草稿。确认入睡才由 AS2 设置世界时刻；取消不写时钟。确认成功后 Web 淡出并经普通 exact-owner 关闭路线恢复游戏。
- 打开面板暂停游戏。昼夜关闭时显示原因并禁止入睡；昼夜冻结时允许设定时刻且保留冻结设置。
- 没有新增治疗、奖励、时间存档、日历或训练快进。睡眠仍是运行态时刻跳转，后续按现役时钟继续运行。

## 2. 原画与时间预览

编辑真源为 `flashswf/UI/睡觉界面/LIBRARY/`。`tools/export-sleep-art.py` 复用现有 XFL→SVG 引擎，派生太阳脸、月亮脸以及两张卡片装饰；原作者的矢量路径保留，旧静态文字不烘焙进新控件。月亮使用原夜晚卡片上部插画的显式 viewBox 裁切。输出位于 `launcher/web/assets/sleep/`，manifest 记录源、工具、配方、输出 SHA-256 和体积；四张 SVG、派生配色模块及 manifest 合计约 750 KB。

表壳、皮革与指针为 Web SVG，日月、外框与快捷选项使用原画，交接时的淡星轨为 Web 衔接底纹。字体复用已登记的思源宋体标题角色。局部材质色收在 `launcher/web/css/sleep/tokens.css`，不改变共享 DLS 语义色。

源文本哈希显式使用 UTF-8/LF 规范化，派生文件按 `.gitattributes` 固定 LF 后逐字节核验，避免 Windows checkout 换行转换造成假漂移；源码与暂存 Git tree 的全部源哈希已比对一致。

配色由闹钟目标分钟连续驱动：04:30–06:30 进入晨曦，17:00–19:30 进入暮色；这是美术预览曲线，不是 AS2 光照／奖励规则的副本。拨针时美术预览读取吸附前的连续角度，实际草稿和指针仍立即按既有精度吸附。底色、珐琅与日月共用有速度上限的逐帧追随曲线，快速反向从当前画面续接，松手后平滑收敛到草稿；日月错峰淡出淡入，避免双脸重影。正文与刻度的墨色独立缓和变化，入睡按钮保持金底深字。减少动态效果偏好直接显示目标配色并停止帧循环；关闭面板回收动画。

生成与检查：

```powershell
python tools/export-sleep-art.py
python tools/export-sleep-art.py --check
node tools/test-sleep-runtime.js
```

## 3. 权威与协议

| Web cmd | Host / AS2 action | AS2 handler | response | 写入 |
|---|---|---|---|---|
| `snapshot` | `SleepTask` / `sleepSnapshot` | `SleepPanelService.execute` | `sleep_response` → `panel_resp` | 读 |
| `commit` | `SleepTask` / `sleepCommit` | 同上 | 同上 | 一次设置运行态时刻 |
| `query` | `SleepTask` / `sleepQuery` | 同上 | 同上 | 只查询原操作 |

公开 opener 仅接受 `world_sleep` 及 AS2 发出的 token。Host 校验 `panel=domain=sleep`、当前 `panelInstanceId` 和精确 payload；共用 `PanelPendingCallTracker` 与 `PanelRuntime.PanelRequestMux`。payload 为 `{v:1,token}`，commit 另带整数 `targetMinutes`（0–1439）。

AS2 token 绑定床铺打开、普通对象场景 owner、存档槽与场景标志，避免 MovieClip 同路径重建的引用别名。新床铺打开及 `SceneChanged` 退休旧编辑会话。一次 commit 的结果冻结；同 token 重放不会再次跳时，不同目标被拒绝。`WeatherSystem.setSleepTime()` 同时写目标时刻和当前帧基准，避免下一次刷新补上旧帧差，并请求天气刷新。

Host 对不确定投递、超时和畸形成功保留原 token／目标；关闭、断线和重开不解除未知结果，只查询原 token。AS2 保存本进程最近 32 个会话收据；收据不存在时明确失败，不根据新快照猜测旧操作。无持久化事务或跨启动账本。

## 5. 实机首轮反馈修正

用户截图出现黑色表盘、白色按钮无可见文字及标题上方装饰压盖。检查发现配色代码依赖运行时读取 CSS 自定义属性，却未验证读数，空值会进入颜色计算；候选的 Web 热重载实际关闭，运行中修改 CSS 与 lazy JS 还会留下旧页面／新脚本组合。现从同一 tokens 真源派生有限 RGB 配色模块，与面板 lazy 依赖一起加载；无效配色明确阻止提交，不再计算 NaN 颜色。主按钮单独计算前景对比度，装饰框下移到内容之后，移除拥挤的顶端小字。配色模块由 tokens 真源同轮生成并纳入 manifest、lazy 依赖和必要资源检查；不另维护手抄色表。全部目标分钟已补主按钮对比度断言，浏览器夹具也加入缺失 CSS 配色属性与真实计算样式检查。

后续拨针反馈暴露了另一条不连续路径：时针的整小时草稿吸附会让目标配色跨格，同时拖动 CSS 把过渡缩到 100 ms；正文使用的自适应金色还被用作按钮底色，导致按钮跟着翻色。已将角度预览、草稿吸附和逐帧美术追随分离，取消拖动时的短过渡；底色、珐琅、日月同步取同一追随值，主按钮独立保持金底深字。新增浏览器逐帧采样覆盖小时跳格、途中反向、主按钮全程对比度、日月不叠脸、关闭重开；媒体偏好事件夹具验证立即停帧及恢复。该夹具不等同操作系统偏好设置或实际 WebView2 动效验收。

候选热重载关闭，修正后需正常退出并重启以获取同版 Web 资源；不自动关闭用户正在使用的真实存档会话。用户已反馈最终配色可行，后续实机业务验收见下节。

## 6. 人类测试（合并为三段）

1. 用本地候选启动入口进入已解锁的床铺，拨动指针经过清晨、黄昏与午夜，试一次直接输入和快捷选择。检查原画气质、渐变、数字可读性、指针命中及操作手感；可用的高级床／普通床／大学入口分别记录实际覆盖情况。
2. 调整后用取消、Esc 或 × 关闭，再打开；确认世界时刻未因草稿跳变、游戏正常恢复、场景和输入没有残留。
3. 确认一次 06:30 或自选时刻入睡，观察淡出与关闭；重开读取当前时刻，应从目标时刻正常前进（冻结设置下保持目标值）。检查关闭后移动与再次开床是否正常。
