# CF6 动作音效核查与原生播放接线

**文档角色**：已接入 CF6 单位的音效来源、缺失统计、确定性装配和验证入口。所有新增播放均调用 `_root.播放音效`；八个新角色 SWF 不携带音轨、DefineSound 或 StartSound。八个素材生成器共用 [build.py](build.py)，调用时机随动作装配，实际声音交给现有原生 SFX 管线。

## 本轮发现与修复

当前核查范围为兵种 461–469 与 472–474 的十二个目录身份；大头及老头两形态为避让上游主线同伴，由尚未提交的 470–472 迁至 472–474，历史证据保留原编号。另包括既有克隆兽 372、女特工 373、派生克隆兽 459／460。光头保安两种目录身份共用原作动作根，因此新素材库对应十一个原作根；派生克隆兽也不重复计作独立原作单位。

按原作 StartSound 的动作位置计数，八库共有 50 处，此前缺失 45 处，另 5 处由 Wings 现有 CF7 劈砍声覆盖。这里的 90% 只描述这些动作位置，**不代表全部声音文件或玩家实际听感的缺失比例**。脚本随机叫声、枪械声音、变形过场和旧单位改编另外核查。

| 新素材库 | 原作动作位置 | 此前缺失 | 处理 |
|---|---:|---:|---|
| 男／女僵尸 | 6 | 6 | 攻击、投掷、落地；女僵尸受击与倒地改回原女声 |
| 蛮蛮 | 6 | 6 | 突刺、劈砍、受击、死亡；删除两个残留时间轴音轨声明 |
| Wings | 7 | 2 | 补首段刀声与落地；原脚步、枪声和五次连斩改编保留 |
| 两阶段特种兵 | 4 | 4 | 匕首与破盾；补随机受击、投掷及死亡叫声，枪声仍来自装备 |
| 两型光头保安 | 3 | 3 | 变身与落地；补受击／死亡叫声，保留 SPAS12 枪声 |
| 大刀机器人 | 7 | 7 | 光束、刀招、受击和机械死亡 |
| 大头机器人 | 4 | 4 | 两段光束、冲击机械声与受击 |
| 老头两种形态 | 13 | 13 | 刺击、机械动作、红束和死亡；补脚本叫声及角色变形段 |

[cues.json](cues.json) 记录原 sprite／帧／soundId 与当前动作位置；当前 70 个动作调用、两处女声替换、三种机器人的一次性爆炸声分别记录。强度校准将老头重束改为四段持续射击，新增三处原声复用；这些改编不计作原作漏接。人形老头的原关卡枪声配置为“无”，本次四发增加现有 `shoot.wav`，明确属于新表现。

Wings、特种兵及光头保安的死亡片段从自然首帧进入时原先会先后触发两次叫声，已改为每个死亡身体一次；直接跳入相应分支仍能发声。暂停时不触发新增动作声，旧身体不能以迟到帧继续播放。

旧克隆兽及两个派生单位保留现有脚步、爪击、跳跃、着陆和嘶吼调用，但共用的 `soundheadexplode.wav` 在原生预载目录缺失。已从 `things1` 原工程复制原文件，字节、CRC 与工程元数据一致。原作克隆兽有九处时间轴声响，但 CF7 重写了移动、连招和死亡段，不能把这九处直接计作九处缺失或零处缺失；其现有调用与声音文件逐一核对，两个死亡位置另作实际调用复验。

旧女特工与 Wings 共用原作根，七处原作效果位置中五处已有 CF7 斩击声，另外两处漏了首段武器声和落地声；首段原有叫喊不能代替武器声。两处均已补回，保留其现有 CF7 女声、动作和枪声。[legacy-cues.json](legacy-cues.json) 绑定两处来源及改动前字节哈希；[restore-legacy-cues.py](restore-legacy-cues.py) 只加入独立脚本层，移除此层后必须逐字节还原原文件。Wings 装配时排除这层，由自己已有的接线负责，六十个生成元件及 SWF 均保持不变。

因此，八个新库的缺失统计仍是 `45 / 50`；旧女特工另补两处，不能再算成第十二个独立原作根。旧克隆兽的缺文件问题单列。当前新库夹具覆盖 81 条调用路由，另有先前已通过且消费者未改的八条旧单位／派生单位路由，共 89 条；新增持续束后的新库调用已重新执行，旧八条没有在强度校准中重跑。它们不证明扬声器输出或人类听感。

## 来源与资源

原 CF6 SWF 的 SHA-256 为 `b52af10e2dda43332e0b2ffb9549d2fad474f298b9f6c67d848ffc33ff589b01`。只读解析 DefineSound、StartSound、导出表及实例闭包，不改写原文件。[assets.json](assets.json) 绑定 44 份提取资源、soundId、原包元信息与每文件哈希，总计 1,401,498 字节；其中 41 份为原 MP3 载荷，3 份为按原音量包络离线生成的 PCM WAV。加上恢复的旧 WAV，总增量为 45 份、1,537,990 字节。

[legacy-assets.json](legacy-assets.json) 单独绑定旧资源恢复。[audit.py](audit.py) 解码全部新提取音效，检查非空、非静音、有限采样及完整解码；它不是原生输出端听音验收。原 male-zombie 和旧女特工的 CF7 叫声改编保留，通用血肉／金属碰撞继续由正式伤害管线负责。

## 音效交付验证（强度校准前历史）

本轮九个资源 SWF 均由真实 CS6 发布并取得新鲜 Compiler `0/0`。最终选定的回归为 **3180 项行为断言、116 项原生绘制断言，零失败**，包含 86 条音效调用及 24 个死亡绘制点。14 块大头碎片另有逐块非空像素检查，防止只生成实例、实际没有嵌入可见图形。原生图片由 Agent 检查，未代签人类观感或端点听音。

斗兽采用 30／60／99 级、双方交换阵营、独立候选进程和只读种子。三类机器人的最终资源共完成 66 场：

| 单位与对手 | 场次 | 胜／负／平／超时 | 结论 |
|---|---:|---|---|
| 大头机器人 → 方舟爪豪 | 6 | 4／2／0／0 | 30、99 级各一败，尚未达到稳定胜出定位 |
| 大刀机器人 → 诺亚试验体α（黑铁会改造人，347） | 12 | 12／0／0／0 | 本轮全部胜出 |
| 大刀机器人 → 方舟爪豪 | 12 | 0／12／0／0 | 保留落败对照 |
| 老头两阶段 → 方舟兽王 | 18 | 0／18／0／0 | 均完成一次阶段交接，削血目标未达标 |
| 老头两阶段 → EXUSIAI 指挥官 | 18 | 0／18／0／0 | 均完成一次阶段交接，削血目标未稳定达标 |

老头的对手最终净损血包含对手回复，不等于累计造成伤害。各等级平均值如下；36 场中仅 4 场进入此前的 50%–80% 区间，全部来自 EXUSIAI 组，不能称强度验收通过。

## 重建与验证命令

后续强度校准的动作、倍率、面板与对战结论以[大头当前版本](../cf6-headbot-assets/README.md)和[老头当前版本](../cf6-elder-assets/README.md)为准；上节 3180 项行为、116 项绘制与 84 场对战保留其原身份，不替代新版本验证。持续重束的三处新增声音随本轮四段动作实际复验。

从仓库根执行，提取时传入上述哈希对应的合法原文件：

```powershell
chcp.com 65001
python -X utf8 -B tools/cf6-audio/extract.py --source-swf <原CF6.swf> --write
python -X utf8 -B tools/cf6-audio/extract.py --source-swf <原CF6.swf>
python -X utf8 -B tools/cf6-audio/restore-legacy.py --write
python -X utf8 -B tools/cf6-audio/restore-legacy.py
python -X utf8 -B tools/cf6-audio/restore-legacy-cues.py --write
python -X utf8 -B tools/cf6-audio/restore-legacy-cues.py
# 先完成受影响素材的真实 CS6 发布，再重建绑定实际 SWF 哈希的音效夹具。
python -X utf8 -B tools/cf6-audio/build-test-fixture.py
python -X utf8 -B tools/cf6-audio/build-test-fixture.py --check
python -X utf8 -B tools/cf6-audio/build-legacy-test-fixture.py --check
scripts/run-cf6-audio-tests.ps1
scripts/run-cf6-legacy-audio-tests.ps1
python -X utf8 -B tools/cf6-audio/audit.py --source-swf <原CF6.swf> --baseline-zip <修改前源码与SWF包.zip> --output <新审计目录>
```

修改 `cues.json` 后须逐个运行所属素材库的生成器和 `--check`，再用明确的独立 XFL 目标交给真实 CS6 编译；不重编主 XFL 或 native runtime。`build-test-fixture.py` 同时绑定实际 SWF 哈希，因此必须在发布完成后生成，再执行 `--check` 和原生 runner；发布前生成的绑定不能代替新 SWF 的调用证据。行为夹具实际加载发布 SWF，拦截 `_root.播放音效`，校验指定动作、自然死亡去重和暂停；这证明调用路由，不证明扬声器输出或音量混音。当前身体限制由帧脚本显式检查，音效夹具未单列 MovieClip 路径复用试验。爆炸伤害和新招式的验证归三个机器人各自入口。

旧女特工的独立编译目标是 `flashswf/arts/new/素材库-诺亚新敌人/素材库-诺亚新敌人.xfl`。本轮旧库的 352 段已有 DoAction 字节码全部保留，仅增加标记和两处音效共三段；三个克隆兽与旧女特工共八条调用探针通过。该比较不覆盖 placement 和 ClipActions，不能代替其他单位的完整体验验收。

四个旧 CF6 单位的实例闭包同样没有 StartSound。诺亚整库仍保留其他单位既有的 32 个声音定义和 84 个时间轴事件，本轮没有改动；不得把 CF6 闭包的零音轨结论扩大到整库。

本轮全部成功、失败及恢复材料集中在[战斗与音效证据](evidence/20261017-combat-audio/summary.json)。45 份音效随八个新角色 SWF 和更新的诺亚素材库一起交付；完整退出游戏再启动以重新预载。主观音量、音色和战斗体验由玩家验收，正式 runtime 发布状态独立记录。
