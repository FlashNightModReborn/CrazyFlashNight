# 漫画节拍级运镜 — 设计、schema 与分镜表（2026-10-07）

**文档角色**：设计方案 + 逐句分镜表（可直接施工）。基线：2026-10-07 工作树。
**前置决策**（已与用户对齐）：相机从"格驱动"改为"节拍（台词行）驱动"；运镜作为对既有画面资产的再创作——同一格资产在不同台词节拍上呈现不同情绪与力度；第一版只做五原语（推/拉/摇/定/震）+ 格间平滑过渡，词汇表后续随新章节扩充；所有运动在 reduced-motion / 低特效下全部静止。

## 1. 运镜词汇表（第一版）

### 1.1 五原语

| 原语 | 语义 | 典型用法 |
|---|---|---|
| `push` 推近 | 聚焦、压迫、情绪升温 | 对峙渐紧、台词落点强调 |
| `pull` 拉远 | 释然、孤独、事后冷静 | 自嘲、反悔、过场 |
| `pan` 摇/平移 | 阅读引导、视线转移 | 宽格左→右、长邮件逐段 |
| `hold` 定 | 冷眼、尴尬、蓄力 | 喜剧 deadpan、短句重锤前的静止 |
| `shake` 震 | 冲击、打断 | 音效字（"喀嗒！"）、爆发瞬间 |

### 1.2 双轴参数

- **情绪**选原语与缓动；**力度** `intensity` ∈ [0,1] 连续，映射：推/拉幅度（3%–15%）、平移行程（rect 内可活动范围的 30%–100%）、震动幅度（1–6px）与时长（80–250ms）、缓动锐度。
- 缓动枚举：`linear | ease-in | ease-out | smoothstep`（smoothstep 公式 `k*k*(3-2*k)` 沿用现有结尾拉远实现）。
- 格间过渡：默认 350ms smoothstep 三轴 `{x,y,s}` 插值（泛化 `book-comic-panel.js:15` 的结尾拉远结构）；`cut` 保留给音效/打断类节拍。

### 1.3 情绪 → 相机映射（分镜表的速查口径）

| 情绪 | 处理 | 力度参考 |
|---|---|---|
| 自嘲/低落 | hold 或极慢 pull | 0.2 |
| 转折/起意 | 慢 push | 0.3 |
| 喜剧爆发 | punch-in（快速 push，ease-out） | 0.6–0.8 |
| 紧张对峙 | 跨行持续慢 push，画框逐格收紧不回头 | 0.3–0.5 |
| 音效/打断 | cut + shake | 0.5 |
| 宣战/高潮 | 大幅快速 push 或定格 | 0.8–1.0 |
| 过场 | pull 到整页（现有结尾机制） | — |

## 2. schema 扩展草案

line 级（挂 `lines[]` 条目上，缺省=继承格默认）：

```json
"camera": {
  "motion": "push | pull | pan | hold | shake",
  "intensity": 0.0,
  "easing": "smoothstep",
  "anchor": [0.5, 0.5],
  "panTo": [0.8, 0.5]
}
```

- `anchor`：运动锚点，rect 内归一化坐标，缺省格中心。
- `panTo`：仅 pan 用，平移终点锚点。
- panel 级新增 `"transition": {"type":"smooth|cut","durationMs":350}`（缺省 smooth/350）。
- 派生器校验（`tools/build-book-comic-content.js:2` 的校验链插入点）：camera 存在则必须是对象；motion 枚举封闭；intensity/easing/anchor/panTo 类型与值域检查；**未知键报错**（该校验器风格是 throw 快速失败）。
- 派生器 `--check` 是字符串全等比对（`:3`）——改 JSON 后必须先跑 `node tools/build-book-comic-content.js` 再生再测试。
- `handoffText` 已证实无消费方（全仓仅 JSON 与产物命中），schema 宽进宽出无隐藏消费者。

**宽格黑边顺带修**：现所有格中心对齐、宽格上下留不对称黑边（p1 上下各约 57px）。节拍相机支持 anchor 后，宽格默认锚点上移消除死区；pan 时注意留边暴露。
