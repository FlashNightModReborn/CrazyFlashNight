## 当前合同与参数

唯一当前合同在 [插件 README](../../data/items/equipment_mods/README.md#6-curve---曲线变换)。
新类型 `saturatingAdd` 处理乘区后的当前值 x：`round(x+32x/(x+48))`。
单装磁稳时连续近似为 `1.2I+32I/(I+40)`；真实消费者先对 percentage 取整，再对曲线取整。
高速端/低速端间隔倍率分别趋近 2/1.2，零值、负值、非有限输入与坏参数不产生新值。

选 K=40 ms 是为了把截图 TTI 的 140 ms 调到 193 ms，与“+20%/+25ms”对照相同，
同时保留高速端倍率上限；原 K=62.5 只到 203 ms。30 FPS 的冷却向上量化模型中，
218/203 ms 都属于 7 帧，193 ms 属于 6 帧；这仅用于挑选可证伪的体验候选。

| 常规枪原间隔 | 旧式结果 | 当前候选结果 |
|---:|---:|---:|
| 30 ms | 86 ms | 50 ms |
| 50 ms | 110 ms | 78 ms |
| 80 ms | 146 ms | 117 ms |
| 140 ms | 218 ms | 193 ms |
| 250 ms | 350 ms | 328 ms |
| 500 ms | 650 ms | 630 ms |

组合按现有管线执行：percentage 加算 → 独立 multiplier → curve → flat；
同属性 curve 按 mods 遍历顺序后者覆盖前者，不新增叠加约定。
合成夹具冻结 TTI 额外 -10% 后为 178 ms，独立 ×1.25 再 +7 ms 后为 243 ms。
当前另一个 interval 百分比插件辉光射线弹也属互斥弹药；组合夹具不冒充现役可安装构筑。
插件说明增加中文“柔性增加，最多 +32毫秒”，装前/装后预览仍使用生产计算器的最终发/秒。
