## 1. 案件概述

玩家主存档 `crazyflasher7_saves` 最后可核实的成功保存时间为 **2026-09-11 00:25:31**；之后已收集的失败会话持续记录 `flush failed (result=false)`，旧 sol 与 JSON shadow 冻结（金钱 2,025,211 / 等级 41 三源一致）。09-18 的 ProcMon 材料仍只有**字符串级证据**：对应日志有 8 次 flush=false，PML 扫描没有找到目标 SOL 相关路径；尚未闭合事件时间、PID、操作和捕获完整性。**不能据此排除文件系统层或宣布已经证明零 I/O**；也不排除更早的初始化失败或文件调用前的用户态拒绝。根因未锁定。

次生损害：fail-fast 设计下 dirtyMark 永真 → 事件驱动存档全部转为真实全量存盘；关机栅栏拦截退出（玩家杀进程逃生）；reveal 期 launcher UI 线程两次停滞（一次至进程被杀、一次约 24s 后自愈，具体等待关系未确定，见 §3）；多实例残留导致 BGM 叠播。

- 装配面板绑定存在且 flush_failed 时 fence 拦退（`DetachRecovery.cs:306-316`）；无绑定直接放行（:264-268）。
