# #230 位移方向专项

小跳、闪现、装备滑步（`战技小跳`）在路由起手时保存面向和两轴输入。纵向输入优先选择斜移段；只有水平输入且与起手面向相同时前进，否则后撤。相反方向双键互相抵消，无输入保留原后撤。动画分支和后续移动共用这一次选择，不再逐帧反转输入或重复覆盖跳帧。

沿用原动作的距离、负重计算和碰撞入口；拔刀术等演出中转向动作继续使用自己的规则。连招下一段重新采样。旧斜向移动方法显式从 `this._parent` 取角色，保留逐帧转向规则，避免定义时间轴裸 `_parent` 的作用域歧义。此次不实现特殊位移 Epic 的其他几何与落地治理。

```powershell
scripts/run-movement-direction-tests.ps1 -TimeoutSeconds 600
python -X utf8 tools/movement-direction/build-test-host.py --check
scripts/run-movement-timeline-tests.ps1 -TimeoutSeconds 600
```

第一项检查方向决策与采样生命周期。第二个 runner 通过根目录的 `MovementDirectionHost` XFL，直接共享导入已发布 `things0.swf` 的三项位移动作和拔刀术。发布位置在仓库根目录，使其与生产共享库的间接资源 URL 一致；生成的 SWF 不提交。

时间轴检查覆盖三动作、左右面向、水平/纵向/斜向/空输入，在起手后反转按键，核对真实帧脚本发出的位移方向和距离。另有四种拔刀术→闪现片段，分别保留允许转向和锁向拒绝时的原规则，检查下一段重新采样。测试夹具用记录器替代碰撞移动，角色和武器环境为内存夹具；它证明已发布时间轴与方向策略的连接，不代替实战连招、射击受击现场或窄纵深地图手感验收。通过与否以本轮 fresh runId、Compiler 0/0 和完整行为记录为准。
