### 关键做法（都过了自检与像素预览）

- **左上角是"撕掉一块"不是平切角**：轮廓走 `TL_a → TL_c → TL_b` 两段，
  `TL_c = (-hw+1.5, -hh+2.5)` 往纸里凹，两段各用 `_torn(..., amp 0.40~0.46)` 参差。
- **受潮水渍**（最容易画错的一步）：
  - 水渍 = 暗影（`DAMP` 只比纸深一点点）→ **用受光亮色 `MID` 把里面"洗"一遍** → 水线环。
    中间若拿 `BODY` 去洗，整块就变成比周围暗的"泥斑 / 补丁"（第一版踩过）。
    真实水渍是**边缘浓、中间反而发白**（纸泡透后褪色）。
  - 水线环用 `ring_blob()`：**同一个多边形**里"外圈正走 + 内圈倒走" → 非零环绕挖空。
  - 暗影层画在文字**之下**（受潮区字迹仍然清楚），水线画在文字**之上**。
  - 泡水边缘带：`chain_strip(S1, inset(S1, 0.62), 左边∨下缘)` 取沿边一圈的暗带。
    ⚠ 段落判定必须写成 `q[1] > -4.2 and (q[0] < -3.6 or q[1] > 5.6)`：只写"左边∨下缘"
    会把左上撕裂缺口附近的 `inset` 顶点也圈进来（凹角处 inset 会算出界外的点），
    自检立刻报"色斑出界"。
- 霉斑：小 blob（`MOLD #6E4416`），散在水渍附近。

## 物品/技能 description 的 HTML 标签写法（查证）

`description` 会被当 HTML 渲染，链路：
`引擎_鸡蛋_lsy_物品系统.as:108` 塞进 `itemArr[6]` → `UI交互_lsy_物品栏UI.as:256`
→ `_root.处理html剧情文本(txt)`（`交互_lsy_对话文本.as:102`：`\r\n`→`<BR>`、`${PC_NAME}`→角色名）
→ `infotext.htmlText`。所以**换行直接敲回车**即可，不用手写 `<BR>`。

- XML 里标签**必须转义**：`&lt;i&gt;` / `&lt;/i&gt;`；想显示字面 `<` 写 `&amp;lt;`
- 项目数据实际用过的标签统计：`font` 1040、`BR` 22、`u` 2、`b` 1、**`i` 0 次**
  （`武器_刀_重斩.xml` 的强调写法是 `&lt;font face="fixedsys"&gt;&lt;u&gt;…&lt;/u&gt;&lt;/font&gt;`）
- AS2 代码里拼字符串用**单引号**且常大写（`"<FONT COLOR='" + COL + "'>"`、`<B>`、`<BR>`）；
  XML 数据里用**双引号**（`&lt;font face="fixedsys"&gt;`）—— AS2↔C# wire 对双引号属性做了专门保留
- 居中只能靠 `<p>` 的 align：`&lt;p align="center"&gt;…&lt;/p&gt;`；`<p>` 是段落级、前后自带换行。
  项目里此前 **0 处用过 align 标签**
