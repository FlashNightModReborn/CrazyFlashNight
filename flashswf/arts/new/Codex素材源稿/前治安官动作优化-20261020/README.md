# 前治安官动作优化源稿

用户于 2026-10-21 提供 `前治安官.rar`，包内工程由 Animate 24 于 2026-10-20 保存。原 RAR 保留完整可编辑 XFL；旁边两份 XML 是原包中动画元件的逐字节副本，SHA-256 由 `manifest.json` 固定。不要直接修改这些冻结输入。

`tools/former-sheriff-assets/authored_actions.py` 读取冲刺第 15–30 帧和 76 帧刺击的右臂动作，只迁移矩阵。共享身体画稿、盾牌硬件、灯光回调、攻击接口和换装仍由现有 AS2 工程持有，不导入原包 AS3 发布设置。

玩家继续使用 152 帧换装容器和 16 帧冲刺循环；前治安官固定盾冲同步此循环，二阶段移动动作扩为 49 帧，首尾回公共持盾姿势。玩家原有展开、蓄力、六帧步态刹停分支及还枪时长不变。刺击仍为 76 帧、24/36/48 出手；取刀段的单帧反向跳动作局部平滑，刀柄与腕口按现有接口重新闭合。

这份源稿不包含游戏内体验验收，也不授予数值调整、提交、推送或正式 runtime 发布权限。
