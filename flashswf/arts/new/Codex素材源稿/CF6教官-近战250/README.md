# 教官近战动作美术工程

用 Adobe Animate 2024 打开 [教官近战.xfl](编辑工程/教官近战.xfl)。舞台左边是 **A 无盾刺击，34 帧**，右边是 **B 持盾盾击，59 帧**。双击要改的角色，直接编辑其时间轴的关键帧、变换和补间。双击后按 Enter 可查看这个元件的动作。需要移动锁定层的分件时，先解锁该层。

两项动作来自 Greatly anti-cloud 提供的《特种兵2.rar》，文件 716。B 在原稿库中的名字是「持盾匕首刺击」。原稿用普通兵及 G36 表现动作，游戏装配会使用当前教官的黑色身体、腰挂、刀、盾和实际装备。教官另有一段持盾刺刀，继续使用它自己的动作。

## 时间轴里如何找到分件

B 的「图层_18」是盾牌。头、身体、枪、双手、腿脚、军刺都有独立层名。盾击使用父子绑定和自定义缓动，拖动父层前可先锁定暂时无需调整的层。顶部「真实近战判定」保留原稿标记，第 14 帧出现一次。「攻击生命周期」来自原件，其第 55 帧仍有历史动作脚本，完整动作含末尾收势共 59 帧。游戏的出手、判定及结束事件由装配层安排。

A 沿用作者原文件的「原始深度」层名。下表的数字就是图层名后缀，上方图层会盖住下方图层。

日常调姿请在动作时间轴上选分件实例。要改教官绘图本身，换皮的归属与装配入口见[特种兵与教官制作说明](../../../../../tools/cf6-soldier-assets/README.md)。调整准备用于实战的帧数或命中瞬间时，同时核对实际教官动画与对应判定。

## 将改稿接回游戏

1. 在 Animate 中保存编辑工程。回到仓库根目录运行以下命令。首条命令会启动本机 Animate 对副本取样。如果它显示「打开 JSFL 文件」，选择「作为命令运行」。工作副本在取样完毕后关闭，艺术家手中的补间和绑定会保存在源工程中。

   ```powershell
   python -X utf8 -B tools/cf6-soldier-assets/instructor_melee_source.py --bake
   python -X utf8 -B tools/cf6-soldier-assets/build.py --import-instructor-melee
   python -X utf8 -B tools/cf6-soldier-assets/build.py --check-instructor-melee
   ```

2. 检查两段动作的帧数，再按[装配与验证说明](../../../../../tools/cf6-soldier-assets/README.md)编译素材并实际播放，核对教官外观、刀盾轨迹与命中时机。源工程、取样与装配结果应一起交接。只检验已有取样是否对应当前源稿时，省略 `--bake` 即可。不在默认位置安装 Animate 的机器可传 `--animate "实际安装路径/Animate.exe"`。
