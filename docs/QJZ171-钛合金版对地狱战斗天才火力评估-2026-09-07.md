# 钛合金QJZ171与M134对地狱战斗天才的火力评估

**状态：设计计算历史快照，未实战测量。** 本文主表使用当时5%自带暴击；用户随后已将基础配置定为55级、2345威力和17%暴击，现已落盘，见[数值记录](QJZ171-钛合金版数值落盘-2026-09-07.md)。负重量效果仍未实装。 用户指定挑战战斗天才作为毕业场景，并确认 M134 每消耗1发弹药为5个联弹单元、每单元2段，合计10段；171每发对单敌按2.5次独立伤害结算估计。本报告按此口径计算，不再将5.95霰弹预算值当作单敌实测段数。

## 结论

在给定出伤次数、+13武器/防具、枪械攻击10级以及持续有效命中的条件下：

- M134暴力版＋60级先进防护服五件，物理减伤后的普通火力约73961/秒。
- 钛合金五甲＋55级四层试算档171（基础威力2345），普通火力约25642/秒，为前者34.67%。
- 171满档0.15%击溃、10%斩杀全程在线时，对本场目标的理想接触模型击杀时间约66.4秒；M134约50.8秒。满档171仍慢约30.6%。
- 维持888原型威力时，即使满档机制，模型也约需102.3秒，是M134的2.01倍。

这表明百分比机制能把旧甲组合带进处理高血量目标的竞争区间，但当前2345试算本体并没有在这一固定配装对照下追平M134。0.15%/10%上限不需要突破；基础威力、完整套装在线率、机动和能源循环仍需一起定案。

不能直接使用 `data/enemy_properties/换皮敌人与战宠.xml` 的6000 HP上界：发布SWF在50级以上覆盖为 `hp_min=-1390000`、`hp_max=320000`，基础防御端点覆盖为950/1050。默认敌人属性装载只填缺项，不能覆盖这些已赋值的专用参数。

`_root.根据等级计算值` 使用最大等级基准60，即分母59；HP与防御允许100级外推。先取整HP成长值，再乘地狱倍率：

```text
HP = floor(-1390000 + 1710000 × 100 / 59) × 2.5 = 3770762.5
防御 = floor(950 + 100 × 100 / 59) = 1119
物理伤害比例 = 300 / (1119 + 300) ≈ 0.2114165
```

该敌人还有56%的懒闪避参数、按单次受伤占当前HP比例触发的反制，以及100级硬直免疫。懒闪避参数不等于固定56%全程丢伤；它有按伤害/最大HP的阈值。发布脚本未添加具体护盾层，通用空壳AdaptiveShield的容量/强度为0。本报告不把懒闪避、反制动作、走位、无敌窗口或玩家生存过程硬塞成一个猜测的固定折扣，因此下表是有效接触火力及理想用时，不是通关实测。

`DressupInitializer` 先把装备枪械威力加入武器power；`ShootInitCore.calculateWeaponPower` 再结算枪械攻击10级的1.8倍和固定30。这比把610简单等同610点通用伤害更强，尤其有利于多段高频M134。

```text
武器输入 = round(基础威力 × 3.04) + 五甲强化后gunpower合计
子弹威力 = 武器输入 × 1.8 + 30
单段普通物理伤害 = (子弹威力 + 五甲强化后damage合计) × 300/1419
```

171的5%概率、1.5倍暴击按普通伤害期望1.025倍计入；M134本体没有该暴击项。不叠加独行者、配件、主动技能、毒、佣兵或宠物。只比较已经有效接触的出伤，角色等级差引起的闪避判定不在这张表内。

## 出伤次数、射速和换弹

- M134：用户确认5×2=10段/每次扣弹，150ms在30FPS时间轮中向上取整为5帧，即6次扣弹/秒，按60普通伤害段/秒计算。1800发弹容在这些击杀时间内不需换弹。
- 171：每次扣弹2.5次独立结算，270ms向上取整为9帧，即约3.333次扣弹/秒、8.333次结算/秒；2.5用每次2/3交替的离散示例实现。
- 换弹：按当前长枪元数据controlledSegments=[9,5,8,10]、fixedTail=3计算。171的reloadPenalty=50对应52帧，约1.733秒；本表未开启快速换弹，并在满匣周期里保守保留一个普通射击tick边界。

10段只用于M134普通伤害倍率；不能据此把击溃处理器也调用10次。击溃运行在每次完整伤害管线的联弹处理之后。本次固定先进防护服五件没有击溃，所以不需猜M134的独立击溃调用次数。

## 火力与击杀时间

“普通DPS”是正在开火期间的物理减伤后伤害，包含171现有暴击期望，不包括百分比击溃、斩杀及换弹空窗。时间列则逐发扣血、降低最大HP、检查斩杀，并计入所需换弹。

半档用于隔离负重兑换曲线的效果；实际五甲＋血剑＋双P90＋20重171正好-17，所以无其他改装时对应满档。半档可理解为额外装备/改装把最终重量抬到-8.5，表中为隔离变量暂不附加这些装备的其他属性。

击溃开头的47135/秒会随敌人最大HP下降而减小，不能把它与普通DPS相加后当成整场恒定火力。斩杀也使用击溃后的当前最大HP，而不是原始377万的固定10%。2345档仅0.15%击溃、暂不加斩杀时约70.3秒；加10%斩杀后66.4秒，说明这场对照中击溃贡献了主要改善。

## 差距与边界

2345档普通DPS比M134低65.33%；满档机制把时间差缩小到约30.62%。在这个单独场景模型里，保持其他参数并只反求171基础威力，约3756才能首次把离散用时降到M134的约50.8秒附近。这只是差距量级诊断，不是建议直接实装的威力，也不能用单个Boss的追平点代替工作簿和跨场景平衡。

本报告固定的是先进防护服五件。纯普通伤害还可以将手套换为贯空天盖手套，理论提升约0.8%；更重要的是60级末日铁拳现有0.15%击溃会进入人物基础击溃，M134可以通过换装继承。后者应作为进一步的百分比机制对照，但必须按真实整串伤害管线调用次数计算，不能把10个普通伤害段直接乘成10次击溃。没有把固定五件套对照冒充M134完整极限配装的天花板。

171拟定的五甲/专属盾在线条件按100%覆盖率处理。真正交战时JK的反制、位移、攻击压迫，以及钛合金套未施工的MP循环、盾破碎与重启都可能增加用时。该模型不能证明标准入口业务验收，也不能证明真实通关时间。
