## 设计决策

用户先确认美术流程有效，再要求建立独立物品；定位为 **37 级、1 层高价金币机枪**，60 发弹容、低射速、大威力，以超重步枪式节奏区别于高速压制机枪。888 是认可的威力彩蛋，不为凑数改穿刺、弹药或层数。此次明确授权配置数据及完成 evidence。

| 配置 | 本次值 | 依据 |
|---|---|---|
| 分类 / 使用栏 | 机枪 / 长枪 | 保留机枪身份，不纳入大容量压制机枪 |
| 等级 / 重量 | 37 / 24 kg | 位于 35–40 级段；重量体现重火力代价 |
| 威力 / 弹容 / 间隔 | 888 / 60 / 240 ms | 名义 250 发/分；运行时帧调度和换弹会改变持续射速 |

| 换弹惩罚 / 散布 | 50 / 5 | 以换弹和机动代价约束短点射强火力 |

### 巴雷特子弹口径

用户明确确认巴雷特子弹按正常穿刺子弹填写，因此依据 WBR-PIERCE-003 取 `pierce=2`。原资产位于 [巴雷特子弹.xml](../flashswf/arts/原版素材库-子弹/LIBRARY/子弹-普通与穿刺组/巴雷特子弹.xml)，索引与 [bullets_cases.xml](../data/items/bullets_cases.xml) 也存在该链接。该老式弹体依赖自身时间轴处理后续碰撞；名称没有“穿刺”字样，不能把名称分类器的 FLAG 结果当作全部行为证明。

这里记录的是明确的平衡口径，未把未知的逐目标穿透数量等同为运行时实测。没有再叠加反器材、口径或原型名带来的隐含系数。火光、音效及命中特效复用已有巴雷特资源，无新增专属生命周期或技能。

### 冲击力语义

[GunStatsBuilder](../scripts/类定义/org/flashNight/gesh/tooltip/builder/GunStatsBuilder.as) 与 [EquipmentStatProjector](../scripts/类定义/org/flashNight/arki/item/equipment/EquipmentStatProjector.as) 使用 `floor(500 / impact)` 显示面板冲击力；[ImpactHandler](../scripts/类定义/org/flashNight/arki/component/StatHandler/ImpactHandler.as) 以伤害乘 50 再除该原始值累积冲击。故 XML 从 20 改到 4，是面板 25 升到 125。公式同样传 XML 原值 4，不能传显示值 125。

### 独立价格层

设计顺序是先确定购买限定高价金币 +1，再确定穿刺品类及报价，最后反验；不是枚举层数让旧价格入带。

- DPS `weightLayers=1`：唯一贡献 `acquisition.high-price=+1`。
- 审计专用 `priceLayers=1`：用户已选定的高价金币层，符合工作簿 `装备价格!D25`。不把总 DPS 层数普遍映射为价格层；运行时 balance 仍只有原有八输入。
- `category=2`：独立来自 `装备价格!D13` 的穿刺类定价规则；物理 `damageType=1`，长枪价格双枪系数为 1。
- 推荐金币价 `37 × 3900 × 1.6¹ × 2 × 1.6⁰ ÷ 1 = 461760`。
- 现价取整为 460000，`priceRatio=0.9961884962`，落在 0.8–1.25 审计带内。

### 获取路径

新物品只接入 [Pig.json](../data/shops/npcs/Pig.json) 的 `catalog.53`。未配置 K 点、合成、任务、礼包、关卡或敌人装备发放。证据检查器每次读取当前价格和有效等级，并扫描 `data/`、`config/`、`scripts/` 的 XML/JSON 精确名称及 AS 具名引用；定义自身、派生字典、资产索引不算获取路径。出现其他引用时停止确认，先查其语义。

静态具名扫描不证明任意动态拼接脚本都不存在。此次同时核对 [礼包目录](../data/items/消耗品_礼包.xml) 使用显式 entries，及 [单位初始化掉落物](../scripts/逻辑/单位函数/单位函数_fs_aka_玩家模板迁移.as) 只从该单位已有装备生成掉落，不从全物品表自动抽取；QJZ171 未加入任何 NPC 装备。玩家丢弃已购装备、存档修改器和开发测试发放不构成新的正常获取预算。

| 指标 | 值 |
