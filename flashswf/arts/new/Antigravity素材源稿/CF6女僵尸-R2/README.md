# CF6 女僵尸硬边矢量重绘 R2

这是可独立重建的 SVG / Python 源工程及静态对照候选。目标为 CF6 原版导出 `aw-僵尸-女`，根元件 1694。不是 CF7 金发女僵尸。没有改动生产资源，没有操作本地 Windows，也没有生成经过 CS6 或游戏验证的 FLA / SWF。


## R2 本轮修改

- 按用户反馈增大眼窝上下暗部开口，增加内侧眉压与凶相，保留近远眼透视与厚下眶。
- 恢复明显尖牙利嘴：长短不齐的上下尖牙有相对咬合方向，不再缩成牙点。保持原张口轮廓与红棕发。
- 去除肢体穿接端点的闭口线，保留真实外轮廓和衣装边缘；肩、肘、膝、踝、腕按原rig作选择性开放描边与连续明暗，不制作逐姿势补丁。
- 上衣中心由硬直横扣板修为窄交错系带，左右衣片向系结点收拢，并衔接下方金棕竖带；躯干改动限定在图集中央小区域，其余衣装外形与覆盖不变。
- 原版 / R1 / R2 的头、站姿、伸手攻击、弯肘和屈膝对照随包附带，便于直接复审。

## 美术范围

- 10 个活体分件（1619–1628）重新手绘为少层硬边明暗、深色轮廓的可编辑路径。
- 保留红棕短发、近圆张口尖叫、破碎眼眶及厚下眶、金棕系带破衣裙、黑长手套和高跟长靴。
- 肤色与布料去除原版连续柔光；黑皮靴和手套采用压暗的非闭合褶面，不使用发亮护膝环。
- 原 `viewBox`、SVG 导出宽高、局部坐标和注册点保留。原 SWF 裁切轮廓与矩阵不改。
- 头及肢体填色外缘使用原 alpha 的纯矢量轮廓约束；关节穿接处仅开放描线，以保留发梢、指缝、靴拱和细小死亡碎片。颜色、结构和内部阴影为手绘路径；没有对原有阴影做色阶化，也没有在替换 SVG 中嵌入位图。

## 动作和死亡范围

- 活体：站 1629 / 44 帧；走 1630 / 39；攻击 1631 / 87；受击 1632 / 42；抓 1633 / 28；倒地 1634 / 116。合计 356 帧。
- 受击元件的标签为 a0=1、a1=23；未套用男僵尸动作长度。
- 死亡元件 1693 共 191 帧：a0=1–79（爆头前倒）、a1=80–148（断小腿飞出后跪倒）、a2=149–191（完整身体前扑）。
- 58 个死亡专用 Shape 中，55 个原生血液/组织矢量逐字节保留；1635、1637、1639 的 23 个位图 fill 均来自头 1627，使用新矢量母件按原矩阵及裁切路径投射。没有逐片独立乱画。
- a1 断腿直接使用活体腿鞋；a2 使用活体分件。这与男僵尸的死亡依赖不同。

## 文件

- `parts/`：10 件活体 SVG。
- `death-parts/`：58 件死亡 SVG。
- `source/`：全部可重建脚本；`core-art.json`、`limbs-art.json` 是原图集坐标的矢量母件。
- `reference/`：本包冻结的原 Shape SVG、原图集、身份/矩阵/裁切/时间轴及分支证据。原位图只用于参考与轮廓来源，不进入替换 SVG。
- `previews/`：原/新全身、头、衣裙、25 个活体关键姿势、51 个死亡关键姿势、3 个独立死亡分支 GIF。
- `qa/`：68 件结构校验、547 帧覆盖、23 fill 连通块报告及独立路径重建结果。
- `asset-manifest.json`：每件类型、坐标与 SHA-256。

完整 547 帧中间 SVG/PNG 不重复装入压缩包，可由脚本生成。动作总 GIF 可单独交付，也可由脚本生成。源工程无需男僵尸 R5 包或其他工作目录。

## 重建

需要 Python 3、Pillow、NumPy。预览另需 Inkscape；细片连通检查另需 SciPy。已经在独立路径从冻结输入成功重建。

仅重建 68 件及基本校验：

`python source/rebuild.py --assets-only`

完整重建、547 帧静态渲染、对照图、碎片检查和 GIF：

`python source/rebuild.py`

## 实际已验证

- 68/68 件的 viewBox、导出宽高与原件一致，无嵌入图片、渐变或滤镜；内部引用可解析、ID 不重复。
- 55 件原生死亡矢量字节一致。
- 547/547 候选静态帧非空，均在固定坐标画布内；另渲染 76 张原版关键帧作对照。
- 23/23 位图残片替换可见；原 28 个 alpha64 连通块全部存在，无新增封闭透明孔，无内部缺片或超过 10% 的面积损失。细边因 alpha 转为路径会有小幅增益，不声称逐像素相同。
- 候选接触表、全身/头/衣裙和碎片预览均经过实际图像检查。对照接触表每对原/新使用同一裁切和缩放；底层帧 SVG/PNG 保留完整固定坐标视口。

## 验证边界

这里是原始 SWF 时间轴矩阵的静态组合。源文件头为 30 fps，GIF 用 30/30/40ms 近似，并在分支结束人为停顿。GIF 不证明实际游戏的死亡选择、stop/goto 或脚本控制。

原死亡第 79、148、191 帧存在混淆动作代码；未执行或假定其控制流。攻击/受击等中的非图像 helper 元件也未模拟，排除 ID 记录在覆盖报告。CS6 / Animate 导入、实际关节接缝、层级遮挡、注册点导入行为、游戏尺寸及运行时分支仍需接入验证。
