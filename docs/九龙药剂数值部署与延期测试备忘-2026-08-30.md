# 九龙药剂数值部署与延期测试备忘（2026-08-30）

## 当前边界

本批已落盘九龙一至三型和 `狴犴·零型` 的物品配置、药效类型、公式 v2、家常菜调整与 68 项药剂/食品平衡证据。

2026-10-15 已完成图标装配：25 个现有物品全部改用九龙专属矢量图标，另有负屃三型预留素材；正式素材库与 `things-new` 已通过 CS6 发布，并更新受影响的 Web 图标。源稿、命名与装配证据见 [九龙药剂素材说明](../flashswf/arts/new/Codex素材源稿/九龙药剂/README.md)。这次是美术资产接入，不改变下述药效运行时和医院投放的验收状态。

医院当前真值仍位于 `data/stages/基地门口/医院.xml` 的第三子关卡 `资源箱`：固定配置 `抗生素 20~30` 与 `肾上腺素 20~30`。图标前置已完成，新增韧性/全抗路径仍待同一版运行时验收，医院经济与关卡投放继续按下述矩阵单独验证。

## 美术就位后的医院配送

目标是医院主配送九龙八条一型线，并保证玩家不能稳定拿齐全套。实现时在现有 `资源箱/<Parameters>` 中为每个一型写独立 `<掉落物>`，用 `<概率>` 的 0..100 百分比能力分散命中，再用 `<最小数量>/<最大数量>` 控制批量。`狴犴·零型` 可以作为必给公共应急品，普通抗生素/肾上腺素保留少量以维持医院语义。

建议先用以下候选做经济模拟，不在本轮冻结进关卡：

| 条目 | 候选概率 | 候选数量 | 目的 |
|---|---:|---:|---|
| 八种九龙一型，各自独立 | 35% | 3~6 | 平均出现约 2.8 条产品线，形成随机战前储备 |
| `狴犴·零型` | 100% | 5~10 | 给高难支线稳定的韧性应急余量 |
| 抗生素 / 肾上腺素 | 100% | 各 5~10 | 保留医院基础医疗识别 |

正式落盘前必须用实际回收价复算箱子期望金币价值，并确认概率受逆向/PRD 时的长期数量；若一型可高价出售，优先下调数量或回收价，而不是压低战斗配额。还要核对资源箱当前 direct/Web 分类和容量边界，不能仅以 XML 可解析推断全部候选规则一定能完整呈现。

## 延期验证矩阵

| 旅程 | 必验结果 |
|---|---|
| 加载与清单 | `list.xml` 能载入 25 个九龙物品；名称、价格、说明和图标 linkage 均有效 |
| Tooltip | 新增韧性、全抗、完整恢复文案正确；`buffDomain` 不显示 |
| 八条一型效果 | HP/MP 缓释、防御、七抗、伤害、空手、速度、韧性逐项命中正确属性 |
| 域互斥 | 同域后用覆盖前用；一个 `meal` 与一个 `enhancer` 可并存；即时医疗不清域 |
| 缓释与到期 | HP/MP Tick 总量、炼金、刷新和到期恢复无残留，域注册保存真实外部 ID |
| 七抗路径 | 电/热/冷/波/蚀/毒/冲七个叶子同帧增加并在到期同帧还原；换装重建魔抗对象后仍重绑到新对象 |
| 装备 toughness | 增量等于 `基础韧性系数 × value / 100`，不会二次乘已有装备 toughness；换装、覆盖、到期后韧性上限与面板同帧刷新 |
| `狴犴·零型` | `remainingImpactForce=0`、`impactDecayBaseForce=0`，韧性条满；`lastHitTime` 和已发生硬直/击飞/倒地不被改写 |
| 药剂输入 | 双药剂栏 8 个物理槽正常消耗库存，四条共享冷却语义不回归 |
| 医院资源箱 | 每条概率与数量符合配置，不出现长期空箱或稳定全套；重复开箱/重试不复制奖励 |
| 经济 | 医院批量投放的期望战斗价值和卖店回收不能形成明显金币套利 |
| 美术 | 25 个既有物品的临时图标已替换并完成发布与离线回读；仍需在完整游戏的小图、掉落栏、库存和 Tooltip 中进行人眼验收。负屃为预留美术，尚无物品配置 |

## 证据与退出条件

静态门继续运行：

```powershell
cd tools/cf7-balance-tool
npm run potion-balance-check
```

但以下三个状态必须分开记录：

1. `formula_checked`：公式单测、XML 与 68 项派生证据闭合；
2. `runtime_tested`：Flash 中完成上表药效旅程；
3. `hospital_deployed`：图标就位、经济复核后才修改并实测医院资源箱。

只有 `runtime_tested` 后才可把螭吻、狴犴一至三型和零型移出 `runtime-test-pending`；只有工作簿登记药剂 v2 并更新快照 SHA 后，才能把全局 `authorityStatus=workbook-registration-pending` 提升为已登记。
