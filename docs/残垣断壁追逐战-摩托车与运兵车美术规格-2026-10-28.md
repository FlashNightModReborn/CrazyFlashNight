## 1 制作目标与范围

玩家驾驶A兵团战斗吉普带键盘逃离军阀营地。敌方轻载具从后方追上，超车至前方实施截击；镜头内双方同向行驶，敌方乘员向后开火。

制作两种敌方底盘：一辆双人侧斗摩托、一辆开放后厢的军用运兵卡车。摩托只有司机和一名射手，射手可替换为普通突击兵、狙击兵、弹药兵；卡车后部露出三个普通乘员位置，按上述三类依次换批，最后换一名体型更大的重装兵。

视觉重点是乘员武器和减员过程。敌车应有军阀制式装备、廉价修补和成建制运输的感觉，不画成盗贼夸张拼装车，也不升级为坦克或封闭装甲车。

本次规格的完整交付包括两底盘、固定司机表现、四种既有兵种的车载适配、普通乘员共用坠落动作、卡车最终爆炸和残骸。玩家吉普动态化、键盘乘坐、道路、接应队员和直升机属于关卡其他美术范围，另行安排，不混入这两种敌车的完成声明。

## 3 视角 方向与比例

### 3.1 画面方向

以CF7与P13已有的侧视斜俯角为基准，保留可见车顶、近侧车身和少量远侧结构。不得自行改成正后方追尾镜头、顶视赛车或写实三维渲染。

本次新车主方向统一为车头朝屏幕右方，后方在左，司机向右驾驶，攻击乘员向左开火。P13原预览车头朝左，做对照合成时整体翻转到右，不能只翻车轮或只翻人物。

制作近侧、远侧遮挡所需的分层，允许游戏对整车镜像。文字、车牌和数字不要烘焙为必须读清的真实信息；如使用非对称军阀徽记，应作为可独立纠正朝向的贴花层。

### 3.2 尺寸对照

用同一画面内P13的可见车体长作为J，测量前后保险杠之间的主体，不把突出枪管、导弹、烟雾和阴影计入J。先把现有普通军阀站姿与P13按游戏内合理比例放在同一标尺板，再制作新车。

| 对照项 | 首稿目标 | 判断标准 |
|---|---|---|
| 侧斗摩托可见主体长 | 约0.55至0.65 J | 明显小于吉普，能辨认两个人和三个轮子 |
| 运兵车可见主体长 | 约1.35至1.55 J | 明显大于吉普，仍可与完整吉普同时进入战斗视野 |
| 普通乘员 | 沿用同场普通军阀人物比例 | 不为塞进侧斗缩成玩具人，也不把卡车三人挤成巨人头 |
| 重装乘员 | 保留现役重装兵相对普通兵的体量 | 占据原三人火力区的主体，一人即可形成明显轮廓变化 |
| 车厢栏板 | 遮住普通乘员下半身与动作适配接缝 | 肩、枪和头要能在最终缩放下清楚分辨 |

这些是美术首稿范围，不是现实车辆工程尺寸或已测得的游戏坐标。不得把单个肢体的350像素每米直接乘到整车；最终尺寸由P13、实际人物和目标视野的合成确认。

同屏对照至少提供摩托加吉普、卡车加吉普两张图，标明缩放值。若卡车过长使玩家无法看见来弹或道路，调整整车布置和镜头方案，不能只将三个士兵缩小掩盖问题。

## 4 双人侧斗摩托

### 4.1 结构与角色

工作名称为「军阀侧斗摩托」。采用结实的军用越野摩托加近侧侧斗，三轮结构明确。主车有一名固定司机，侧斗内有一名向后射击的乘员；不增加车尾第三人或独立炮塔。

主车和侧斗通过可见连接架成为整体。侧斗有低矮前挡板、侧壁、扶手和后部射击开口；留出完整武器和后坐空间。挡板遮住乘员腿部，便于复用现有上半身动作，但不能切掉手肘、枪托或遮挡枪口。

司机位置靠前，握住车把、保持驾驶方向。射手在近侧斗内回身向后，射击不要求司机跟着扭头，也不要求整车掉头。摩托的机动表现来自整体加减速、少量横摆和悬架动作。

### 4.2 造型与配色

以哑光军绿、灰褐或暗灰为主，军阀现有服装的红色仅作小面积识别。轮胎、护罩、连接杆、油箱和排气管结构要读得清；少量补焊、绑带和磨损即可，不堆大量尖刺、破布和外挂弹药。

射手武器是最醒目的功能差异。三种版本共用同一底盘、同一司机和同一侧斗；不要为狙击、火箭再各造一辆不同车。

### 4.3 三种射手适配

| 射手 | 站姿适配 | 保留重点 |
|---|---|---|
| 突击兵 | 侧斗内低坐或半蹲，肩与手臂可动 | 原步枪轮廓、持枪关系和三次射击的后坐 |
| 狙击兵 | 侧斗扶靠姿势，腿部被挡板遮住 | 原三发动作，不新增瞄准器材、红线或长时间蓄势 |
| 弹药兵 | 侧斗内稍抬高上身，发射筒越过挡板 | 原发射器及发射动作；枪口、后喷与司机/车体之间不发生明显穿插 |

必要时调整侧斗开口、乘员位置和手臂，而不是重画整套士兵或把武器换成未经设计的新型号。这里要求可读的画面与遮挡，不新增军事仿真规则。

### 4.4 减员与退场

射手被击败后从侧斗向后外侧脱离，再由独立坠落表现带离车辆。侧斗立即显示为空，枪口不再闪光。

司机保持存活，车辆失去攻击能力后减速退到画面后方。首版不要求摩托爆炸、司机坠落、完整翻车或可拾取残骸；退场时不再承担伤害碰撞。需交付「载人」和「空侧斗」两种可连续切换的状态，不能让乘员消失时一起删掉挡板或车轮。

## 5 运兵卡车

### 5.1 底盘与车厢

工作名称为「军阀运兵卡车」。采用两轴四轮的军用运输底盘，独立驾驶室和明显的货厢。驾驶室只露固定司机的剪影或局部，主辨识来自载人后厢，避免厚重装甲板和大炮塔使其看起来像现有步战车。

车厢前半段由篷布、支架和较高侧板遮住，表达未上前的预备乘员；后半段留出开放射击区。尾门或后栏板高度约到普通射手腰部，能够遮住腿部适配，又不遮住枪、头和主要受击反馈。

普通阶段总共九名射手，最后一名重装兵，均来自同一车厢内部。只画当前出场者与必要的补位动作，不要求把全部预备人员真实堆叠在车厢深处，也不必制作内部走廊。

### 5.2 三个普通位置

后部火力区设置远侧、中间、近侧三个位置，沿侧视透视关系错开高度与水平位置。三人的头肩和武器必须能分辨，不能平铺成三个完全重叠的剪影，也不要为了展示三人把镜头转到车尾正面。

三个位置属于同一片后厢区域，程序只需要一个共享受击区。美术锚点用于摆人、出枪口和坠落，不代表三个独立弱点或精确点杀要求。

减员顺序为远侧、中间、近侧。提供3人、2人、1人、空厢四种组合，缺人的地方应真正空出，不让幸存者自动滑动补齐。枪口闪光、烟和阴影跟随所属成员关闭。

### 5.3 换批与重装登场

三个普通位置全部空出后，下一批从遮挡后低身出现、抬起进入射击位置。建议共用一段短起身/补位动作，不制作逐人跑过全车厢、开门登车或换座路径。

重装兵使用单独的大位置，进入时关闭三个普通位置。让重装兵从前部遮挡后起身，较大肩甲、头部与机枪覆盖原火力区的主体；原栏板仍在，但可由同一段帘布或活动挡板让开。

不为重装兵增加盾牌、可破坏护甲、驾驶室弱点或新枪型。原机枪动作是主视觉，身体可以借栏板掩盖腿部，但不能把重装兵缩小到普通兵尺寸。

### 5.4 最终毁伤

重装兵被击败时先停枪并失衡，随后火光与浓烟遮住车厢，车体切换为受损残骸并向后离场。可用身体倒入车厢或局部下沉配合爆炸，不制作完整的重装兵空中翻滚。

爆炸效果与车体分离，至少包含火光、烟、少量大碎片；不要用密集小碎片掩盖车体缺件。残骸保留原车轮廓关系，不能突然替换成另一种车辆。爆炸后轮组、车厢与接地影的关系仍需成立。

不要求绘制永久停在道路上的高精度残骸场景，不制作可拆车、燃油泄漏传播或逐部件爆炸系统。

## 6 乘员与坠落动作复用

普通三类乘员尽量使用现有身体分件、头部、衣服和武器。复用的是实际可见画稿及动作关系，不是连同原单位的所有帧脚本一起嵌入。必要的车载姿势优先局限于骨盆以下、支撑手和持枪角度。

普通坠落采用共用动作结构：失衡脱离、短暂翻转或侧倒、落地翻滚/拖出画面。三类通过替换头、服装和武器保持身份；并非要求三套完全独立的全身动画，也不能用一种裸剪影忽略三者差别。

车载阶段的脚下阴影必须移除或隐藏，不能在车厢里出现踩地的黑圆。坠落脱车后使用独立地面阴影，随空中高度变化；载具与尸体各自移动，不能让落下的人继续粘在车体上。

不要把世界位移烘焙进人物坠落元件。动画以髋部或身体重心为局部原点，提供近侧与远侧遮挡所需层；初始位置、抛出速度和道路后移由接收端驱动。动画结束只提供结束标记，不自行删除世界单位或推进关卡。

不需要普通乘员四肢断裂的新血腥分支。保留现有游戏风格的受击与死亡辨识即可；重装兵走第5.4节的独立终结表现。

## 7 必需动画与状态

新制作的独立动画按30 FPS组织。原攻击内部击发时序不重排；车轮、颠簸、补位和爆炸是独立美术时钟，不能通过拉长整个人物时间轴把狙击改成慢速单发。

| 对象 | 必需状态或动画 | 设计要求 |
|---|---|---|
| 摩托底盘 | 静态、行驶循环、轻微受击、空斗退场表现 | 车轮转动与悬架分开；整体位移交给接收端 |
| 摩托司机 | 驾驶待机、行驶起伏 | 手与车把不脱离，不独立反向开火 |
| 摩托射手 | 待机、选定原攻击、受击、脱离 | 三兵种共用接口，射击期间不穿过侧斗 |
| 卡车底盘 | 静态、行驶循环、轻微受击、毁伤、残骸 | 驾驶室与后厢的起伏一致，轮组转动独立 |
| 卡车司机 | 静态驾驶或极短循环 | 不需要独立死亡和受击系统 |
| 普通乘员 | 待机、选定原攻击、受击、补位、脱离 | 支持3/2/1/0组合，保持枪口与后坐同步 |
| 重装乘员 | 起身、待机、原机枪攻击、终结失衡 | 一人大位，无完整坠落 |
| 普通坠落 | 脱车、空中、落地、结束 | 车型共享，衣服与武器适配；不烘焙世界轨迹 |
| 终战效果 | 爆炸展开、遮挡峰值、余烟 | 峰值用于切换残骸，不触发实际伤害或关卡结果 |

车轮可用稳定循环或独立旋转部件；不可用整车左右抖动代替轮胎转动。车身颠簸幅度以最终缩放下可感知但不晕动为准，炮口、乘员和栏板必须一起保持装配关系。

推荐补位表现0.6至1.0秒，与主稿的换批窗口一致。具体帧数在原生预览后确定，不因此改动单兵攻击周期。各段需有明确的首帧、稳定姿势与结束帧，便于暂停、恢复和直接切入。

## 8 分层与锚点

### 8.1 建议分层

| 从远到近的层组 | 摩托 | 卡车 |
|---|---|---|
| 独立接地层 | 整车影 | 整车影 |
| 远侧结构 | 远侧支架与轮组 | 远侧轮组、货厢远栏板 |
| 主体 | 车架、油箱、发动机、主车 | 底盘、驾驶室、车厢地板、前部遮挡 |
| 人物远层 | 司机后侧肢体、侧斗射手远侧部件 | 远侧与中间乘员、重装大位 |
| 人物近层 | 司机近侧肢体、射手近侧手臂与武器 | 近侧乘员及武器 |
| 前景结构 | 侧斗近挡板、近轮、车把 | 近侧栏板、尾门、近轮 |
| 独立效果 | 枪口、火花、少量烟 | 枪口、火花、爆炸、余烟 |

这是遮挡结构，最终层序可以按画稿调整。必须保留单独控制轮组、乘员、前景遮挡和效果的能力；不可交一张整车加人加火花的扁平图代替。

### 8.2 接口语义

下表是候选接口名，接入前还需检查库名和linkage碰撞；本轮未向任何运行注册表新增名称。

| 锚点或区域 | 含义与坐标要求 |
|---|---|
| root / ground | 近侧主轴前后轮接地点连线的中点为局部原点；X向右、Y向下，近侧接地基线为Y=0；远侧及侧斗轮保留透视所需的Y偏移 |
| wheelFront / wheelRear / wheelSidecar | 对应轮心，允许独立旋转；卡车远近轮分别保留 |
| driverSeat | 司机稳定坐姿参考点，不承担受击或独立AI |
| riderSeat | 摩托射手身体安装点，跟随侧斗悬架 |
| crewFar / crewMiddle / crewNear | 卡车三乘员安装点，缺员时其他点保持不动 |
| heavySeat | 重装大位，启用时关闭三个普通位 |
| muzzle | 每种射手自己的真实枪口，随持枪和后坐运动；不得只在车体根上画一个通用点 |
| eject | 乘员脱车起点，跟随对应座位；不能设在轮胎或车厢地板内部 |
| crewHit | 当前载人火力区的共享受击建议轮廓，独立于阴影和整车外框 |
| bodyContact | 车体用于位置分离的建议轮廓，不包含长枪管、烟和阴影 |
| explosion / wreckGround | 爆炸中心与残骸接地点，保持切换前后车体位置连续 |

每个关键姿势的锚点坐标须来自实际总装，随交付清单保存相对于root的坐标、正向轴和使用的缩放。不能只提供一个与所有动画脱节的手填坐标表。

XFL中需要运行时读取的命名接口使用MovieClip，静态画稿可用Graphic；不要把动态枪口、乘员槽或挂点仅做成无法被AS2读取的Graphic实例。接口标记在最终图中不可见，预览另提供带标记版本。

## 9 可编辑工程与交付目录

### 9.1 作者源与候选工程

允许先用分件SVG设计和合成，但最终候选应提供完整、可编辑的CS6兼容XFL，保持原生矢量分件。禁止把整车PNG塞入XFL充当可编辑矢量；PNG、GIF和视频仅作预览。

XFL使用独立的作者命名空间；建议库内以Chase/Warlord/Motorcycle、Chase/Warlord/Truck、Chase/Warlord/Crew、Chase/Warlord/Effects分组。使用可读的元件名，不把新增元件都命名为Symbol编号。

候选只保留纯美术、必要的帧标签和接口，不携带原兵种的发弹、初始化、移动、存档、奖励或自动删除脚本。根停帧及实际播放控制由接收端接入时明确添加。不得复制P13的AS3发布设置或在美术包中自行实现另一套战斗逻辑。

同一可编辑工程只维护一个真源。导入认可画稿后，原生XFL的后续修改不能被旧SVG生成器无条件覆盖；沿[跨平台素材绘制管线](跨平台素材绘制管线.md)记录源转移和派生关系。

Linux美术机可完成绘制、预览、XFL候选与静态检查；真实CS6发布、Flash原生动作、共享库消费者和游戏驾驶验证继续在Windows完成。美术包不自行提交生成SWF作为已验证运行资源，也不接管本机正在打开的CS6、TestLoader或游戏会话。

## 10 交付检查与完成标准

| 检查对象 | 必须能确认的结果 |
|---|---|
| 车型 | 摩托为司机加侧斗射手的三轮结构；卡车为运输底盘和开放后厢，不与吉普或步战车混淆 |
| 同场比例 | P13、普通兵、摩托、卡车能在统一标尺板比较，原点与缩放可复算 |
| 后向攻击 | 车辆朝右行驶时乘员能向左开火，枪口无明显穿插，司机方向与双手保持合理 |
| 三乘员可读性 | 3、2、1、0人都看得清，减员不造成剩余人跳位，空挂点不继续出现枪火 |
| 原攻击 | 突击和狙击三次击发可对照原动作；火箭和机枪保持其原辨识，不夹带新长蓄力规则 |
| 坠落 | 三普通兵保持身份，脱车后不粘着载具，脚下影、武器和衣服不会提前消失 |
| 重装与毁伤 | 一人占大位，停枪与失衡可见，爆炸遮挡足以切换同型残骸，位置无跳变 |
| 连续运动 | 轮转、车身、司机、乘员、栏板、枪口同步；停帧与恢复不暴露断件 |
| 编辑性 | 完整XFL、分件与遮罩齐全，无缺失Include/引用；无整车位图替代矢量、无意外AS3行为 |
| 性能取向 | 稳定循环、效果有结束，避免全车持续模糊滤镜和无限小碎片；低性能实测由接收端完成 |

交付同时附干净预览和带锚点的工程预览。只交单张静态整车图不能算完整交付；离线连续预览也不能写成Flash或游戏验收。报告准确列出已完成的画稿、动作与静态检查范围，以及需要Windows接手的部分。

美术机的首要交付顺序为共同视角与比例、两底盘分件、三普通乘员适配与共用坠落、卡车换批、重装和爆炸。期间的自查与修补由制作方继续完成，不为每个小步骤新增人工审批。
