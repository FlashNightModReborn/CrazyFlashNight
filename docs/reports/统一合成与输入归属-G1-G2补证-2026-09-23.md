**暂不进入新一轮人类验收或 C1。** G2 检测器可以继续独立补强，但 G1 的 RCE-2 被当前生产 WindowProc 实跑反例再次确认。

## 1. RCE-2：扩位未解决长期基准

代码位置：[桥比较与门](../../launcher/native/world-compositor/InputBridge.cpp)、[发号与取消](../../launcher/src/Guardian/WorldCompositor/WorldCompositionSurface.cs)。

`StaleEpoch24(e,f) = ((e-f)&0xFFFFFF) >= 0x800000`。
`lastEpoch` 随准入推进，但 `localFloor` 仅在失焦/菜单边界抬升，`shared.minEpoch` 仅由 Host 取消抬升。
一个持续前台、没有取消的会话内，两条比较下界可一直为 0；有限在途队列并不能约束当前代次与这两条长期基准的距离。

新模式 `InputBridgeSelfTest.exe --long-session` 在真实 Windows 窗口、共享映射、生产子类 WindowProc 上加速推进：

| epoch | localFloor / sharedFloor | 原处理器交付增量 | 应有结果 |
|---:|---:|---:|---|
| 1 | 0 / 0 | 1 | 准入 |
| 4194304 | 0 / 0 | 1 | 准入 |
| 8388607 | 0 / 0 | 1 | 准入 |
| 8388608 | 0 / 0 | **0** | 应准入，实际拒绝 |
| 8388609 | 0 / 0 | **0** | 应准入，实际拒绝 |

退出 1，`RESULT FAIL failures=2`；原始输出 `tmp/g1-long-session-20260923.log`。
每步增量均小于半范围，不伪造 floor 重置。该实验是加速端点逻辑反例，不是百万次真实物理点击，也不证明它造成了测试员当晚的短会话事故。
原默认自测仍 19/19；其中 wrap 用例主动推进两个 floor，所以未覆盖本反例。两者结果必须并列，不得选择性汇报全绿。

### 后续有限修补的约束

1. 证明**全部长期比较基准**都满足距离约束；不能再用“会话会重建”“队列只有 256”代替可执行上限。
2. 可比较两类实现：有明确生命周期与排空/撤销握手的有界会话续接；或可证明的长期单调代次与短 wire 绑定。单纯扩位不能消除同构问题。
3. 不在长按/未结束手势中隐式重置，不重放旧 Down，不同时留下两套 broker/桥，也不让失焦撤销丢失。
4. 保留本回归，并同时通过已排队未见包撤销、Cancel Post 失败、同序列新手势重新准入；真实 Guardian 配对随后补证。

这涉及协议/会话寿命选择，可按计划 §9 的 Rx 交 Pro 定向裁决；无需重开全部合成路线。

## 2. G2 检测器增量

- [Program.cs](../../launcher/perf/flash-compositor/Program.cs)：covered 相位多个独立 proof，记录输入、输出、计数与相位；禁止仅以 received/presented 增长认定 F 在变。
- [原生诊断](../../launcher/native/world-compositor/Compositor.cpp)：可选完整 ROI 回读，所有 RGB 像素的 FNV-1a 摘要、raw 1:1 输出逐像素误差；旧 ABI 3 Stats 布局不变，新导出只由显式诊断调用。
- `--stall-f`：冻结自建 fixture F，保留 S 与 P 更新，然后恢复 F；必须识别停推并证明恢复。
- `--debug-hold-frames`：停 F 与 S 状态栏更新，继续请求呈现已有纹理；要求捕获 0、呈现大于 0，不能假绿。
- `--capture-output`：误捕获 P，保留品红采样 oracle，要求明确识别 marker-leak。

先前固定三点法实测 Flash 在 covered 有 116 captured / 117 presented，四次三像素值完全相同，说明这种采样不足以排除静态取样点。
因此最终检测器采用完整 F ROI；`content-unproven` 只表示所测样本未证明内容变化，不能直接归因为焦点或 Flash 遮挡节流。
历史报告把 `Vector smash protection is enabled` 直接当作遮挡节流证据，没有建立因果链，本轮不采纳该归因。

摘要/逐像素对应证明的是离散采样间的 RGB 变化与 Present 前 GPU 输出，不是每一帧、Flash 逻辑推进、屏幕扫描或输入到显示延迟。
FNV 非密码学摘要用于变化检测；身份使用 SHA-256。额外 CPU 回读仅在显式 covered proof，不能拿此运行做性能收益结论。
冻结开关只作用于本轮自建 fixture；不隐藏/挂起真实玩家 Flash 来构造成功。
