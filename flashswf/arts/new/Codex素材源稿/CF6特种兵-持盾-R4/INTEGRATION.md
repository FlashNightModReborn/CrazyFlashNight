# R4 接入边界

按 asset-manifest.json 的原字符 ID 接入。相对 R3 只需要更新 561、575、577、578，且必须同时更新，避免活盾 CT、碎盾 CF 混用。其他 148 个文件不需要替换。

保持每个 SVG 原 viewBox、尺寸与注册点，保持原显示列表矩阵、层级与时轴。不要按 PNG 的展示裁切或接触表缩放重新定位。预览只是静态检查，不是引擎输出。

559 普通特种兵身体不变。580 持盾入口与 629 带盾撞车入口共用 561，碎盾通过 575/577/578 同步继承。手枪等原武器和共享烟血/闪光保留为原资产，本轮不把它们算作重绘。

本轮静态抽样为 7 个序列的 17 帧，完整帧清单见 qa/frame-coverage.json；其余帧没有重跑。CS6 导入、脚本事件、游戏死亡过渡和实机效果仍需后续人工验收。
