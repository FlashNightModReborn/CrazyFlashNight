# 统合61式套装打磨任务

请在这个独立包内完成统合61式套装的矢量打磨，兼顾两个目标：全套画风和细节语言一致，以及小分辨率下清楚、稳固、有辨识度。最终交付可以继续编辑的分件 SVG、多姿势与小尺寸对照，以及简短修改说明。

## 工作范围

编辑 assets/unified 中的24个 SVG：男女合计20个闭合分件，另有男女胸甲各自的开门和开火稿。保持现有骨架、局部原点、部件归属和注册坐标。允许重整轮廓细节、色块、结构线、明暗、材质和装饰密度；明显改变体量或配色的方案请单独命名说明，便于比较。

只读参考放在 baseline、references、data 和 source_snapshot。普通61、钛合金61保持原样。不要替换 Web PNG 或原生 XML，也不要从 R38 旧稿重新开始覆盖现役修正。

## 两套系列参考的用途

普通61用于理解系列轮廓、基础机械结构和部件血缘。钛合金61用于对照关节覆盖、材质分区、关键识别点和小尺寸对比。统合61目前以蓝灰主甲、较暗软连接、锈红肩部及浅色标识形成自身身份；打磨应让这套语言更协调、清楚。

统合61的地面型工程背景强调普通合金的厚重结构、动力支撑、可检修性和整机连接。头盔包含感知接口，胸甲包含缓冲和电热胸炮，腿部承担负重支撑，鞋底强调可拆换与行军，手甲承担操纵与防护。这些功能帮助判断哪些结构应保留。

## 建议工作顺序

1. 核对原包并打开 preview.html，确认基准能够正常显示。
2. 查看三套男女对照，以及统合61的闭合、开门、开火状态。读懂共享件和原点约束。
3. 用胸甲、共享上臂和一个下臂建立统一的描边、材质与细节样板。在多个姿势与小尺寸上检查后，再扩展全套。
4. 处理男女一致性、上下肢接口、共享件在双侧的表现，并同步胸甲三态的非运动部分。
5. 检查七种站姿、四个额外兵器关键帧、两种朝向、明暗背景和小尺寸图标。
6. 输出完整候选返包。

每轮必须实际生成并查看图像。若当前聊天环境无法运行代码或查看生成图，请明确说明能完成的范围，使用 examples 和参考图辅助设计，不声称已验证新的拼接结果。

## 优先判断

画风统一时，先看外轮廓与结构线、板甲厚度、关节和高光是否属于同一套语言。小尺寸时，先看头肩胸、腰胯与膝踝能否分开，主甲和软连接是否混在一起，再决定铆钉、划痕、细字和小接缝的去留。

保留这些已落实的现役修正：男女四个下臂的肘腕覆盖；胸炮三态和炮口接口；物品图标的24×24局部取景；第二图标帧仅移除底影的关系。

完整规则见 [技术与接口约束](TECHNICAL_CONTRACT.md)、[画风与小尺寸要求](STYLE_AND_READABILITY.md) 和 [返包要求](RETURN_GUIDE.md)。
