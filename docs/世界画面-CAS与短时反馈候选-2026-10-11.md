# 世界画面 CAS 与短时历史反馈

本页维护画面增强的产品行为、实现范围与验证入口。本批已完成正式运行库推广、双构建共识与部署审计，普通入口启动及窗口关闭复验通过；发布身份与边界见[发布回执](evidence/cas-low-runtime-release-2026-10-11.json)及[运行库记录](runtime-build-reproducibility.md#cas-low-release-20261011)。机器原始结果存于 `tmp/world-postprocess/`，画质接受度及其他设备的实战性能仍待推广测试。

## 产品行为

“本机与 Web”设置页提供独立、即时保存的“清晰度增强”和“动态模糊”开关。Host `UserPrefs` 是唯一保存权威，JSON 键分别为 `casEnabled`（默认 true）和 `motionFeedbackEnabled`（默认 false）。旧配置缺字段或字段类型错误时使用这些默认值；保存失败回滚原值并返回失败。切换性能方案、自动换档及重启均保留玩家选择。专用无人值守 Arena Worker 延续最低演出预算，两效果在 Worker 运行态关闭，不覆盖玩家偏好。

## 合成与参数

LOW 档按实际倍率选择源像素邻域：放大至少 1.5 倍时在捕获的源像素上执行 CAS 再重采样；1 至 1.5 倍时在一次世界绘制中按源像素间隔取五点样本，避免额外源 pass。HIGH/BEST 与 MEDIUM 延续输出像素上的 CAS。随后沿用调色和世界光照。可选历史反馈位于世界 pass 后、独立原生天气/弹道/装饰特效与不透明 HUD 前，因此原生界面不进入历史。仍位于 Flash 世界纹理中的文字会受到世界效果影响，真人验收必须检查这类文字。本轮不迭代历史反馈。

CAS 是 AMD 开源 float32、五采样、绿色通道权重的 sharpening-only 核心移植；来源固定为 `9fabcc9a2c45f958aff55ddfda337e74ef894b7f`，使用官方记录的 gamma-2 线性光近似，许可证由 ShaderBake 嵌入 DLL。未实现 AMD 的融合放大器，不引用融合放大器的倍率限制。LOW 的独立源 pass 使用整数 Load 与边界夹取，峰值系数在 CPU 计算；一张输入尺寸 BGRA8 纹理保留锐化结果，新捕获帧、尺寸或强度变化时更新，重复呈现复用。关闭、暂停或切回输出路径释放源纹理；原始捕获不修改，关闭仍是真正旁路。LOW 在缩小输入时回退输出路径。传统 unsharp setter 仅保留诊断兼容；普通游戏显式设为零，避免与 CAS 叠加。

本轮 CAS 控制量为 HIGH/BEST 0.10、MEDIUM 0.25、LOW 0.27。原生根据实际 `max(输出宽/捕获宽, 输出高/捕获高)` 增加 `0.08 × clamp(倍率−1,0,1)`，不依赖调度请求高度推测 DPI。LOW 在 2 倍和 4/3 倍放大时分别为 0.35 和约 0.297。它们是候选参数，不声明跨硬件最优或三个档位必然获得同等感知收益。强度 0 不代表关闭。

`ProbeSetPostprocessV2` 原子设置效果与 CAS 策略；请求 0 是原输出路径，1 是 LOW 自适应路径，实际阶段 1/2 分别表示源 pass / 单 pass 源邻域。1.5 倍为本机候选分界，并非跨硬件最优断言。原 v1 导出和 ABI 12 布局保留。配对 Host 要求 v2 与 `ProbeGetCasStageStats`，缺扩展即拒绝混用。阶段统计区分 requested/applied、源绘制、复用和纹理字节；每秒世界日志记录原生实际 CAS 开关、阶段、强度与倍率，配置日志不再是判断实际生效的唯一证据。

历史反馈保留两张输出尺寸 BGRA8 GPU 纹理，无正常路径 CPU 回读。新捕获帧的历史权重按 18 ms 半衰期计算，并限制最多 35%；超过 120 ms 的源间隔重置。重复呈现只按时间衰减已接受的历史，不计作新的历史采样，静止源最终回到当前画面。关闭释放历史纹理；切换效果、场景、视口、捕获暂停、颜色模式和调色参数后重置。该效果是短时残影，不是插帧或逐物体运动矢量模糊。

## 验证与证据范围

Host focused 覆盖两开关的默认值、四种组合、重启保存、换方案保留、非法类型、保存失败回滚及零 Flash 写入；设置生产脚本的 Edge harness 覆盖独立操作和重新打开保留。候选执行沿用本仓开发入口和 immutable candidate 校验，不覆盖正式 runtime。

GPU 用例位于 `OpaqueHudGpuTests.PostprocessPixelsHistoryLifecycleAndGpuCosts`，只有 `CF7_TEST_SHARED_WORLD_CANDIDATE` 指向已验证候选且会话显示器明确亮屏时执行。它使用自产窗口作为输入，检查 H/M/L 控制量、实际输入倍率、与独立 CPU CAS 算术参考的像素误差、真正旁路、历史重置/释放、HUD 排除，以及世界 GPU 时间对照；截图与结果在 `tmp/world-postprocess/gpu/`。显式诊断才读回像素与启用 GPU 时间查询。

GPU 查询覆盖本机夹具的世界绘制与效果区间，不覆盖 WGC、DWM、物理扫描或弱机器战斗收益；自产输入不是 Flash H/M/L 抗锯齿的资格证明。静态参考分数不代替运动观感。若显示器关闭，持续呈现资格应明确跳过，不能自动亮屏或将跳过写成通过。

`CasFrozenScreenshotComparisonAndGpuCosts` 使用指定的冻结截图重采样输入，验证同一原始捕获哈希下的关闭、原输出路径与本轮源路径，核对源像素算术、复用、释放、原生 HUD 排除与两种实际捕获尺寸的 GPU 区间。`CF7_TEST_CAS_REPLAY_ROOT` 显式指定本机素材目录；证据不伪称原始 Flash 纹理或完整实战，数据和图片保存在该目录。与参考的 PSNR/边缘误差仅评价重放的相似度，人类最终判断文字/轮廓收益及颗粒、闪烁、舒适度。

第二轮冻结重放在 UHD 630 上通过三项专项 GPU 用例；源像素与独立算术参考最大通道误差为 1。ABBA 对照的世界 GPU 均值在 360p/L 从上一版 CAS 的 2.282 ms 降至 1.648 ms，在 540p/L 从 2.348 ms 至 2.364 ms。与关闭 CAS 比较，另一组短重放仍有约 0.3 ms / 0.8–1.0 ms 的额外世界 GPU 时间；这些数字不能视为整局提帧。540p/L 的实际游戏日志已观察开关切换和实际阶段 2，360p/L 的同帧证据来自冻结重放，运动观感未被机器代签。

## 人工验收

使用普通正式启动入口测试本批运行库。本轮重点切换清晰度增强，动态模糊保持关闭；已有关闭偏好会保留，不能把保留旧偏好误认为默认值错误。重点在 360p/L、540p/L 比较世界内文字、角色与车体轮廓，以及移动时的锯齿/颗粒闪烁，最后重启确认选择保留。普通入口启动/关闭与 31 份受保护文件不变已复验，但未进入真实玩家槽位或执行本批实战 CAS 验收。三次可信无人值守退出检查未通过，作为独立负向证据保留，不由普通窗口关闭通过代签。没有真人反馈时保留画质接受度未验证状态；正常大小收益不明显时停止继续扩大后处理投入。
