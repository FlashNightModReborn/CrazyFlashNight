- 微调主角空手普攻衔接，优化震地、日字冲拳表现，补充兴奋剂动画和部分星座武器/
  激光棒刀光。（制作稿“美术-动画与特效”；演示 `02:45`–`03:30`）

  正常流程不可获得的彩蛋。（制作稿“美术-装备与材料”；演示 `03:50`–`08:25`）
- 增加多件霰弹枪、冲锋枪与步枪，以及高爆手雷、导弹信标；UZI 外观更新，并展示侦察队员。
  （制作稿“美术-装备与材料/新敌人”）
- 僵尸逆袭、堕落城骚动、宝石线人挑战增加补充世界观的情报物品；四项大型副本调整刷怪，
  并展示动态出生点、可破坏障碍和索降敌人。（制作稿“文案改动/关卡”；`08:40`–`10:00`）
- 推进后勤/食堂支线与多名佣兵/战宠进阶，Lee 加入“强力冲腿”，铁血肩炮可追踪；
