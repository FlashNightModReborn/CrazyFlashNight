# 堕落城 G5：可读性与通路接口集中复审

文档角色：本轮模型审阅、主控核证和下一批修复清单。日期：2026-09-23。当前被审对象为 G5 本机灰盒，不是游戏运行资产。

## 结论

用户将南侧入城路基误认为运输管道，并询问是否必须经军阀哨所进入城市。这不是孤立的材质问题：道路断面与法线、正门体块及标签优先级共同造成误读。复审还确认了遗漏的工程区、缺乏入口形态的旧地下口，以及原检查未覆盖的一些道路侧缘/转折接口相交。

下一轮应集中修复下列六组问题，保留三层城市、总部方形预留、四地标、沙侵方向提案和正常/异常入城路线的大关系。**本轮仅审阅和核证，没有修改 G5 模型。**

| 组 | 问题及证据 | 下一轮最小处理 |
|---|---|---|
| R1 道路表达 | `line()` 的路面与侧面共用顶点并计算平滑法线；同色宽坡脚抹平硬边。部分可见跨层段仍采用直通 -6 的路体，城外来路在前景积沙内终止。用户截图及入口视角确认了管道读感。 | 分离路面、边坡/挡土面与硬边；按段选择贴地路面、路堤、台阶或桥，不全局改成薄悬板。把城外主路延伸至明确画面出口，交代左右分流。 |
| R2 正门与门架 | `gate` 不在默认地标集合，`warlord` 却在；默认总览不显示正门名称。正门和货场共用体块配方；正门岗亭顶 18，横梁底 19，存在悬空间隙。 | 独立正门配方、实际支撑门架、明确待检/分流前场；总览优先保留正门与异常缺口的标识。联查驻点及试炼门架同类支撑。 |
| R3 通路侧缘与转折 | 实际网格探针确认校园西墙侵入公共路宽；总部折返梯、公共环路下坡转角、摇滚低路接梯处有邻接路体/踏步相交；一处工业残留地坪角侵入低槽道路侧缘。 | 移开墙/地坪角，给转折建立足够的真实平台或切掉重叠路体；检查完整通行断面。不得把所有相交踏步统一过滤后宣布通过。 |
| R4 工业服务支廊 | `serviceyard` 在生成 slab、标签和地区体块之前被 `continue` 跳过；实际为中层空台地，没有受控工程区身份。 | 补围界、少量检修/工程体块与入口。该范围同时覆盖总部前登阶，必须避让现有主通行带，不能把整个矩形直接围死；工程接近关系可沿现有检修院南侧入口组织。 |
| R5 旧地下口 | `oldsewer` 落入通用三盒体配方；目视为附属楼群，没有下行口。既有接近线在高台上开始，缺少明确后勤外郭接续表达。 | 补窄巷、下行槽口与受控前场，并明确后勤接近线；与大学宽入口形成区别。不能把当前缺少路面表达扩大为“整个高台不可步行”。 |
| R6 线与标注语义 | 黄色同时用于实体捷径和保卫战事件线；内部路径还使用其他近似浅色。标签碰撞排序只有选中项优先，缺少主入口/地区/设施层级。 | 实体通路统一视觉语法，事件用独立线型/箭头；标签按视角和信息层级取舍，优先解决主入口误认，不把所有设施强制常显。 |

## SWE2 运行与证据边界

使用本机 Devin CLI，模型 `swe-2-medium`，首次四路并发：A 道路表达、B 物理接口、C 镜头标注、D 功能空间。A/C/D 正常结束，各 4 项。B 在 420 秒截止时被终止，只留下截断且夹有重写内容的草稿，**没有完整有效报告**；其内容未计入完整报告数量。

随后以精简输入和实际网格命中记录进行 B2 限时复核（180 秒上限，约 42 秒结束），正常产出 3 项。最终为 **4 份完整报告、15 项原始意见**。B2 结论仍经主控核证，并非因输出完整就直接采纳。

本轮 SWE2 输入为冻结源码、布局、检查器和主控观察记录，**没有给 SWE2 图片输入**。实际浏览器目视、图像取证和网格探针由主控执行；不得称为四路独立视觉验收。运行日志、原始/补充提示词和哈希见 `tmp/fallen-city-g5-review-20260923/` 的 `manifest.json`、`RUN_STATUS.json`、`retry-manifest.json`、`logs/`、`reports/`。截图冻结与模型输入的源码以文件指纹为准，不仅依赖 HEAD。

| C-3 实体线与事件同色 | 收窄采纳，R6 | 统一物理通路语法并分离事件线；近似浅色支路不必各添一个图例项。 |
| C-4 标签碰撞与 feature 隐藏 | 收窄采纳，R6 | 按视角提高关键信息优先级，不取消合理避让；源码排序实际是选中项优先，原报告“放最后”描述不准确。 |
| D-1 死亡竞赛两条支路断开 | 驳回 | 观众支路起点为 `(185,760,2)`，在公共环路上；服务支路起点 `(440,825,2)` 恰是公共环路终点。烘焙后接续检查也通过。 |
| D-2 支廊未接检修院 | 收窄合并 R4 | 缺工程区表达成立；检修院已有南侧阶梯，不能说孤立无入口，也不强制新增西侧地下入口。需把文字“末端接”落实成可读的接近关系。 |
| D-3 旧地下口是通用三盒体 | 采纳，R5 | 近景截图确认没有地下入口形态。 |

| B2-1 环路穿校区西墙 | 采纳，R3，按侧缘侵入处理 | 中心线可通，不能称为整条路被堵死。名义道路宽度中一侧被墙占用，实际网格射线命中支持该问题。 |

| B2-3 踏步均属自身交叠，应过滤 | 不采纳整体过滤建议 | 几何归属复核发现，多数为另一条邻接梯段/平台进入当前通路侧缘。允许区分本段踏步与邻接物体，但不能因同属 stairs 或同 route id 就忽略转折处真实相交。 |

## 实际网格补查

`probe.mjs` 构建 G5 场景，对登记路段沿中心及左右各 25% 路宽、高于路面 0.6/1.6 相对单位的位置发射 534 条沿线射线；共得到 14 个路段—网格命中对。**这不是 14 条断路，也不是完整角色体积扫描。**

已核证的具体位置：

- 校园西墙世界 X 范围约 `[-75.15,-73.65]`；公共路中心 X=-75.6、半宽 2.25，路东缘延至 -73.35，二者确有重叠。
- `hq-front-stair-a` 命中上层台地和 `hq-front-landing`；`hq-front-stair-b` 命中前一梯段 `hq-front-stair-a` 的路体及末端踏步。属于台地出口/折返接口问题，不能只跳过当前梯段自身网格。
- 公共环路下坡起点命中同一 route id 的前一水平路段；即使 id 相同，也需要检查高差起坡点和平台边界。
- 摇滚低路、退路与邻接台阶在局部侧缘相交；需按接近方向和平台范围复核，不把薄踏步命中一概升级为不可通行。
- 低槽道路在工业残留地坪的一角命中，高度为 -2.3；可削角或调整局部路宽/线位，不改整片灾损区标高。

道路网格归属由实际顶面四顶点复原起终点，再与烘焙后的 roads 匹配；踏步结合生成顺序和厚度辅助归属。报告保留网格序号、命中点、包围盒和归属，方便下轮复验。原盒体/台地检查仍有价值，但不能代替墙、邻接路体和通路全宽的检查。

## 下一批修复的验收方式

1. 总览和入口近景：关掉路线提示后，能从路面、正门与待检前场辨认正常入城方向；军阀缺口仍明显是另一条争夺路线。
2. 服务支廊与双地下口：工程院、宽检修入口、窄旧口各有独立形态；入口位置与后勤接近方式可读。
3. 总部和摇滚跨层接口：侧面、俯视及沿路检查联合验证；记录哪些网格属于当前道路、邻接平台或围界，不通过放宽断言掩盖碰撞。

前序布局与施工范围见 [G2–G5 记录](堕落城G2地形与原场景对照审阅-2026-09-23.md)。本轮没有调整游戏剧情、关卡、模型源或存档，也没有提交推送。修复完成后仍须新的本机候选及人类目视验收。

### 六组修复的落实

- **R1**：道路改用分离的路面/侧面材质和硬边法线，保留永久边线与主路方向箭头；折点使用连续截面。城外来路延伸至前景边缘，服务路分流点保留平地后再起坡；门内跨低地高路采用薄桥面与实际支柱，外部引道保留有棱角的路堤。道路提示和标线按颜色合并绘制，避免每条边线额外占用一次绘制。
- **R2**：正门有独立双柱门楼、实际支撑横梁、模型牌匾、等候边带与步行分流。总览默认选中正门，正常入口和灾损缺口纳入高优先级地标。驻点、试炼门架的既有悬空梁高度同步修正。
- **R3**：总部折返登阶增加独立平台并调整两梯段间距；摇滚低路重新组织为有平台的折返登阶，退路先落到平台再转向。公共环路在起坡前/下坡后保留平段。校园西墙及其两端、商铺后沿、赛事看台和隔墙边缘退让；低槽工业地坪削去侵入道路的角。不是通过过滤邻接梯段或降低检查覆盖率得到通过。
- **R4**：将原来同时覆盖总部登阶的宽泛工程区占位，收为阶道旁的独立受控检修带（源框 `[179,281,19,45]`），补机械房、围界、门架和接街支路；公共登阶在其外侧，检修带经公共街联系大学检修院。
- **R5**：旧口区域移除会填平井口的通用整块 slab，在上层台地开实际孔洞，井底为相对标高 23；由 28 层外郭引路接下行梯、窄口与维护房。外郭引路接回总部后勤线，没有通过总部主院或新增大学地下连通。
- **R6**：实体通路采用统一基础语法，黑铁接驳及低槽路线保留辅助色；保卫战事件单独使用虚线、默认关闭。标签按选中项、正门、灾损缺口、地区和其他标记排序，保留碰撞避让而非强制全显示。

### 检查结果与界限

- `verify.mjs`：44 类通路、3852 处道路—登记盒体样本，无命中。
- `check-terrain.mjs`：3628 处道路—台地样本，无埋路；旧井口作为真实孔洞进入地形描述。
- `check-g6-terrain.mjs`：7854 处道路中心及两侧沙面样本，无埋路；待检场基础覆盖通过，实际下层折线重新计算的桥下交会净空仍为 16.8 相对单位。
- `check-g6-mesh.mjs`：沿实际道路网格执行 1120 条射线，取路中心及正负 25%/45% 路宽、高于路面 0.6/1.6 的五条截线，最终零命中。没有过滤道路自身、邻接梯段或墙体；沙面由专门检查器验证。增加覆盖后首次发现的看台、商铺和起坡点边缘问题也已修正。
- `check-g6-interfaces.mjs`：18 处登阶、平台、后勤、检修及步行分流接续成立；112 个路体均具有独立平面材质及硬边几何。工程区实体和旧口下行终点检查通过。
- `check-g6-design.mjs`：三赛事场地、四服务组、六设备组、四总部主楼及原有七处接街回归通过。

浏览器核对默认总览同时显示正门与灾损缺口；17 个预设视角、通路提示及独立事件开关实际可用。保存正门有/无路线提示、工程支廊、旧地下口、摇滚外围及总览截图。上述结果仍不是完整角色体积扫描、导航网格、车辆转弯或战斗验证，也不是人类视觉验收通过。
