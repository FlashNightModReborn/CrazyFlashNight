## 1. 配置与定位

默认值来自 `data/environment/scene_lights.v1.json`。环境 XML 的 `Environment/Lights/Light` 为背景默认；关卡 `SubStage/Lights/Light` 按 `Key` 覆盖同名灯，其余灯保留。`BasicInformation/Environment/Lights` 与原环境覆盖合同一致，存在时替换该环境的灯列表。显式 `Enabled=false` 可关闭继承灯，零能量不会被默认值吞掉。

每盏灯必须有独立 `Key`，建议使用带语义的英文标识。独立光填写 `X/Y`；绑定光填写 `AttachTo`，引用实例或出生点的 `LightKey`。绑定身份不使用 `stageInstance0` 等数组序号。一个实例可以对应多盏灯，光源也可以没有对应实例。

```xml
<Instance id="0">
    <x>900</x>
    <y>264</y>
    <Identifier>跳动的火焰</Identifier>
    <LightKey>rock-fire-left</LightKey>
</Instance>
<Lights>
    <Light>
        <Key>rock-fire-left</Key>
        <Preset>fire</Preset>
        <AttachTo>rock-fire-left</AttachTo>
        <OffsetX>22</OffsetX>
        <OffsetY>32</OffsetY>
        <Radius>170</Radius>
        <Phase>15</Phase>
    </Light>
</Lights>
```

`Lights` 与 `Instances` 同属子图。普通 XML/JSON 调参重启生效，源合同或绘制程序变更才需要配套编译。参数定义如下：

| 字段 | 含义与边界 |
|---|---|
| `Preset` | 命名默认值；每个支持字段都可逐灯覆盖 |
| `Shape` | `point` 径向、`cone` 锥光、`beam` 定宽束 |
| `X/Y`、`OffsetX/Y` | 世界位置；绑定时偏移使用锚点局部坐标 |
| `Anchor` | 实例内部点分路径；空值取实例原点，不能越过绑定实例 |
| `FollowRotation/FollowScale` | 分别选择方向与范围是否跟随；默认 false，范围默认世界单位 |
| `FollowVisibility` | 默认 true；关闭可自行控制业务状态 |
| `Radius/Length/HalfWidth` | 世界单位，半径或长度 1–1024，半宽 0.5–512 |
| `Angle` | 度数；绑定方向保留镜像的手性 |
| `Energy/Color/Color2` | 能量 0–2；RGB 整数或完整 `#RRGGBB` / `0xRRGGBB`，第二颜色用于程序动效 |
| `Animation` | `constant/flicker/pulse/sweep`，原生动效不消费游戏 RNG |
| `Amplitude/Rate/Phase/SweepAngle` | 起伏比例 0–0.8、每秒周期 0–30、相位度数、扫光幅度 0–180 度 |
| `FrameCurve` | 真实实例帧号与 0–1 强度，如 `1:1,2:0,3:1,4:0,160:0`；在整数帧间线性插值 |
| `StatePath` | 从绑定实例读取的局部布尔值或 0–1 强度；AS2 保持状态权威 |
| `RenderMode` | `cached/realtime/hybrid/visualOnly` |
| `BaseEnergy` | hybrid 的固定底光，不能高于动画最小强度；其余能量进入实时池 |
| `BudgetPool/Priority` | `scene/shared` 与 0–100 优先级，数值越大越优先 |

`visualOnly` 保留现有素材表现，不登记环境灯，也不自动修改 Flash 素材的调色或遮挡。当前光场是二维材质提亮，没有墙体深度或投射阴影。柔边与衰减仍沿用当前灯种算法，不宣称已实现逐灯可调衰减指数。

## 2. 状态、缓存与预算

AS2 随场景交接一次完整定义，并通过同一个 F 包的第九段发送变化后的姿态或状态。F9 绑定场景代次、配置 revision、序号与有界灯 id；没有变化就不发送。时钟和暂停复用现有 F6。稳定键与独立普通对象身份防止同路径 MovieClip 替换后旧灯复活；外部 SWF 在 `MovieClipLoader.onLoadInit` 后登记身份，晚到的旧场景回调被拒绝。

业务可调用 `SceneLightBridge.setEnabled(key, enabled)`，操作仅更新照明投影。需要持续移动的绑定灯更新姿态，显隐、卸载与状态曲线在暂停时仍可清理；程序动效随游戏时钟冻结。

每场景总定义上限为 128 条，其中缓存光按最多 16 条一批生成世界坐标 HDR 纹理。纹理最大边长 4096，最多 1,048,576 个像素，超过时降低空间采样密度；开销转为初始化、状态改变时的重建、内存和采样。镜头平移缩放、实时灯变化和夜视色向不重建该纹理。世界及天气、原生战斗表现共同采样；缓存光和实时光相加后统一执行亮度响应上限。

实时仍为 16 条共享记录。目录 `sceneReserve=2` 为可见且 `BudgetPool=scene` 的实时场景灯保留最多两条，其余按优先级、屏幕贡献和既有保留优势竞争，未用额度可借。`shared` 不享受场景保留。缓存灯不消费这 16 条实时记录；`Priority` 参与实时灯选择，缓存灯在容量内全部合成。高优先级或保留灯仍受对应容量约束。
