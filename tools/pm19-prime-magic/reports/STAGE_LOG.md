# 阶段记录与停止条件

所有“证明”均指随交付代码可复核的有限数学推导；所有计时与搜索命中率均只代表本次环境和当前输入。

## 阶段 1：输入审计

### 当前已证明的结论

- JSON/TXT 的矩阵逐项相同，维度为 `19×19`。
- 361 个值均为严格整数、全局互异，并通过独立的确定性 64 位 Miller–Rabin；第三套试除验证器又交叉核验了最终 seed。
- 19 行、19 列的公共和由程序复算为 `190000361`。
- 原主/副对角线为 `189975263 / 190092881`，故输入仅是半幻方。
- 元素、行和均小于 `Number.MAX_SAFE_INTEGER`；元素还小于 `2^24` 与 `2^32`。

### 当前仅有实验支持的结论

- 原脚本在补齐 SymPy 1.14 后，`n=19, seed=1, restarts=100` 逐字节复现所附矩阵；20 次同机进程级运行中位数 `0.9875 s`。

### 当前最好结果

- 完整、可机读的 `input_audit.json`；上传 JSON SHA-256 为 `dbc911a354b3d27a1217118a465f17b7633adff76720c4ffb0d6c314e4919dc6`。

### 当前主要阻塞

- 原脚本没有锁定依赖；当前基础环境直接运行会因缺少 `sympy` 失败。

### 下一步实验

- 使用不依赖原生成器的路线 A 升级；所有最终结果由独立验证器验收。

### 放弃某条路线的证据

- 无；仅拒绝把 JSON 中的 `all_prime/all_distinct` 声明当证据。

## 阶段 2：路线 A 双置换升级

### 当前已证明的结论

- 双置换问题与 `(assignment f, involution tau)` 模型双向等价；`tau` 的循环型恰为 `1^1 2^9`。
- 两条对角匹配的并为 9 个不交四环与一条中心公共边。
- 已构造至少 9 个互不相同的精确 witness：正式 seed bank 8 个，独立 VNS 分支另 1 个。
- seed00 的行列置换、两个 assignment、involution、JSON、二进制由不导入编译器/验证器的第三套脚本完成 26 项交叉核验。

### 当前仅有实验支持的结论

- 两阶段编译器对 100 个确定性 stream 为 `100/100` 成功；中位 `70.94 ms`，P95 `243.60 ms`，P99 `292.96 ms`。
- 直接二维 VNS 的 100×1 秒实验仅 `1/100` 命中；说明其平台严重，但不是一般失败率定理。

### 当前最好结果

- 8 个完整 seed 全部满足 40 条目标线；seed00 canonical SHA-256 为 `a5e002e9047e02dba2608428ef7416493a0b1ce9148e6e77f3d57be04084413d`。

### 当前主要阻塞

- 无。本实例的“是否存在双置换解”已由 witness 解决。

### 下一步实验

- 将 seed bank 交给 orbit engine；保留 CP-SAT/有界 DFS 作为其他实例的精确尾部。

### 放弃某条路线的证据

- 放弃把直接 QAP/VNS 作为正式主算法：同预算稳定性明显差；不等于否定其发现 witness 的价值。

## 阶段 3：路线 B trade 与路线 C

### 当前已证明的结论

- 标准 `2×2 [[+t,-t],[-t,+t]]` 只保数值边际，通常不保固定质数多重集。
- 双行/双列零和子集交换的合法条件、元素集合不变量和对角 `O(1)` delta 已证明。
- 有界支持 trade 图一般可能不连通；局部失败不能作为全局无解证据。

### 当前仅有实验支持的结论

- 初始 seed 有 800 个 proper 双行 trade、542 个 proper 双列 trade，经典 `2×2` proper trade 仅 2 个。
- 三步可把残差降至 `(22,52)`、`E1=74`；该状态的深度 2 完整邻域没有精确命中。
- 初始 move delta 生成格为 `2Z^2`，目标修正没有静态模障碍。

### 当前最好结果

- trade 路线最好 `E1=74`，但路线 A 已有 `E1=0` 的真实完整 seed。

### 当前主要阻塞

- move 合法性随状态改变；静态增量格可达不等于存在可执行序列；连通性未知。

### 下一步实验

- 仅在新实例路线 A 失败时做 3–6 行/列 CP-SAT large-neighborhood，不继续盲目加深单步贪心。

### 放弃某条路线的证据

- 对当前实例停止投入路线 B/C：不是证明其无价值，而是路线 A 已用更小成本精确解决，继续搜索不改变交付决策。

## 阶段 4：运行时 orbit

### 当前已证明的结论

- `pi R = R pi` 的同步行列置换严格保四类线和。
- `|H|=2^9*9!=185794560`。
- 加入单轴反转与转置后的无重复自然坐标群为 `|G|=4|H|=743178240`，不是 `8|H|`。
- 全局互异值使纯坐标稳定子平凡，故单 seed 轨道大小恰为 `|G|`。
- 8 个正式 seed 经精确群关系判定属于 8 个不同 `G` 轨道，合计 `5945425920` 个状态。

### 当前仅有实验支持的结论

- Python 参考实现对小阶群穷尽 identity/inverse/closure；19 阶 1,000,000 次独立群采样并逐次全量复算不变量全部通过。

### 当前最好结果

- 可严格均匀直采的 `4 × 2^9 × 9!` 参数化；不需要随机游走或失败重试。

### 当前主要阻塞

- 无数学阻塞。seed-specific 偶然 automorphism/transversal 未穷尽，但不进入可信运行时群。

### 下一步实验

- 在目标 Chromium 测 renderer/Worker，而不是继续扩大纯数学样本。

### 放弃某条路线的证据

- 放弃局部生成元随机游走作为默认：短周期与强相邻相关没有产品收益；独立直采成本已足够低。

## 阶段 5：工程验收

### 当前已证明的结论

- Python 编译器与验证器不共享质数/关键验证逻辑；binary 是 16-byte header + 361×U32LE，共 1460 bytes。
- TypeScript 热路径只做群采样与 361 次搬运，不做质数判定、CSP 或行列复验。

### 当前仅有实验支持的结论

- 以最终 `PERFORMANCE_REPORT.md` 和机器可读 benchmark JSON 为准。

### 当前最好结果

- 见根目录 README 的一键复现命令。

### 当前主要阻塞

- 云端 Chromium 安全策略拒绝容器 localhost，未取得浏览器/GPU/GC 数据；上线前必须在玩家目标硬件运行已交付 benchmark 与 Performance trace。
- checkpoint 只提交完整 seed job；进程在 job 内中断会重做该 job，未达到 active-search frontier 无重复恢复的强规格。

### 下一步实验

- 集成游戏 UI 后以 5/10/30 Hz 棋盘、60/144 Hz shader RAF 做目标机 A/B。

### 放弃某条路线的证据
