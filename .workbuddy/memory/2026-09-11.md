### 时停不可靠的根因与解法（可复用到时停改造）

敌元件框 `onClipEvent(enterFrame)` 直接调 `_parent.行走()`，绕过 `stop()` 控制。
解法三件套：**短路单位自有函数名单**（行走/移动/方向改变/状态改变/攻击/各类追踪移动…）
+ **递归 `stop()` 时间轴**（记录被停过的节点，结束按序 `play()` 还原）
+ **`_封印冻结` 冻结新版 AI**（`unitAI.update()` 在 `UpdateEventComponent.onUpdate` 里）。
再加「每帧钉回原位 + 清方向输入」兜底。

**不能用 `removeMovieClip` 做临时移出**：会注销 `TargetCacheManager` / `unitAI` / `dispatcher` /
`buffManager`，且 `_deInitialized` 不复位。

**放逐必须走 `死亡检测`**（只传 `noCorpse:true`，**不传 `noCount`**）——清怪计数只在这里递减，
不然「消失了但没过图目标」。

### 给 CS6 画动效 SVG 的成套约束（多轮迭代踩出来的）

1. **保守子集**：只用字面 `#RRGGBB`；禁 `linearGradient` / `radialGradient` / `url(#id)` /
   `clipPath` / `opacity` / `transform` / `<g>`。所有坐标在 Python 里算成绝对坐标。
2. **半透明**：SVG 无法表达 opacity → 出两套配色。`天光/`(不透明色 + CS6 设 ~70% 不透明度)
   与 `天光-叠加/`(极暗色 + CS6「叠加」add 混合，靠相加凑出冷蓝白)。几何完全一致。
3. **不能用"变暗"表达"淡出"**：普通混合下深色在亮地图上会变成一道黑边，不是"光变弱"。
   一切淡入淡出都用**几何量**（宽度 / 半径 / 长度收到 0）。
4. **非零环绕规则**：多根小图形（刻度齿、射线）若拼进同一个 `<polygon>`，路径绕中心一周后
   会把整个圆盘填实。**每根必须各自成多边形**。
5. **环形/扇环**：`外圈正走 + 内圈倒走` 一个多边形即可挖空，不需要 clipPath。
6. **循环无缝**：所有周期量必须是**整数周期**（呼吸 2 次、光丝漂 1/2/3 次、闪烁 2/3 次）。
   验收手段：`build_loop(0)` 与 `build_loop(N)` 逐坐标比对必须 0 差异。
7. **分段序列的接缝**：`爆发_14` 与 `光柱_00` 必须是同一个函数在 phase=0 算出来的 → 逐点相同。
   做法：爆发段相位取 `(i - (N-1)) / LOOP_N`（负相位），而不是 `i/N`。
8. **容易漏的「顿帧」**：子段边界用 `u=(i-9)/5` 时，i=9 的 u=0 会和上一段收尾值完全重合 → 画面顿住。
   改成 `u=(i-8)/6`，让边界帧的 u 已经是 1/6。
9. **碎片采样密度**：把一条臂切成 n 段后，每段的采样段数要按 `span` 折算
   （`max(6, int(TOTAL_STEPS * span))`），否则每片都按整条臂采样 → 体积翻 6 倍（实测 535KB/帧 → 83KB）。
10. **消散别做"缩回/变小"**：要做**碎开飞散** —— 臂裂成 n 段（裂缝张开 + 各自切向/径向散开 + 两端收细），
    球裂成扇环 + 内芯扇片。碎片基准半径必须**独立于底球半径**，否则会跟着底球一起缩回成环。
11. **夹到画布内**：飞散的碎片朝上的那几片会被画布上沿硬切一道直边（半透明叠加时特别显眼），
    要按 `min(cy, H-cy, cx, W-cx) - 40` 夹半径。
12. **画布加高时的连带项**：柱高翻倍要同步放大边缘毛边频率与 `EDGE_STEPS`
    （否则边缘变成一节节长直线），光丝/浮尘数量也要跟着翻倍（否则柱内纹理密度掉一半）。

**本套最终参数**：画布 7600×5680；GROUND 5360；SPIRAL_CY 3760（相对地面 1600 不变）；
3 道对数螺旋臂，角跨度 0.31 圈（**必须 < 1/臂数**，否则几道臂铺满整圈退化成"圆环"）；
R0 620 → R1 3200；7 层等宽柱；`ARM_FRAG_N=9`、`ORB_SHARD_N=14`。
爆发 15 帧（收聚 0-4 / 爆炸 5-8 / 碎散 9-14）+ 光柱 15 帧无缝循环。

**自检脚本 `_verify.py` 查四件事**：CS6 子集合规 / 几何越界 / 循环首尾逐点重合 / 爆发↔循环接缝逐点相同。

**「把这两层分离成单独元件」不解决性能问题**（用户问过）：
Flash Player 每帧把**整个舞台的可见矢量**全部栅格化一遍，开销取决于矢量**总数**，
不取决于分装在几个 MovieClip 里。拆元件只解锁两件都不白拿的事：
- `cacheAsBitmap` 只对「自身静止、仅被外部做位移/缩放/旋转」的内容有效；光丝浮尘是
  **自己沿时间轴流动**的，开缓存反而每帧重建位图 → 更慢
- 独立时间轴降帧率（45 帧每张停 3 帧）：Flash 仍每帧重绘整个舞台，对矢量绘制帮助有限

**真正把开销压到接近 0 的正解是位图化**，不是拆元件：光丝本质是**可平铺竖纹纹理**，
做一张 512×512 PNG 上下平铺两层、其中一层做位移造成「流动」，外套矩形遮罩。
位图 blit 比矢量便宜一个数量级，代价是重复感与缩放清晰度。本次未采用，留在
`CS6接入说明.md` §7.5/§7.6 作为选项。

### 追加：preview.html 暂停/重播按钮失效（一个遗漏赋值连带毁掉整页）

**症状**：天光卡的「暂停」「重播」按钮点了没反应。**实际损坏范围远大于此**。

**根因**：`Sky` 构造函数签名为 `function Sky(stageId, tagId, btnId)`，但函数体里只赋了
`this.stage` / `this.tagId`，**漏了 `this.btnId = btnId;`**（同文件的 `Ring` 有写，所以对比看不出来）。
后果链：构造函数末尾的 `this.sync()` → `getElementById(undefined)` 返回 null →
`b.textContent = ...` 抛 TypeError → 异常从 `new Sky(...)` 冒泡出来 →
**`(function(){...})()` IIFE 在那一行整段中断**，后面所有代码都没执行：
- 天光的 暂停/重播 从未绑定 onclick
- 天光的 模式/配色/CS6混合/背景 四个分段按钮也全没绑定
- **`var B = new Ring(...)` 根本没跑到 → 圆阵卡片其实从来没动过**，页面上「帧 0 / 8」是
  HTML 里写死的字面量 + 静态深色背景在冒充，用户没察觉

**修复**：
1. 补 `this.btnId = btnId;`
2. `sync()` 加 `if (!b) return;` 兜底 —— 以后 id 写错不会再让整页脚本崩掉
3. `start()` 的 `t0` 改为按当前 step 回推（`t0 = performance.now() - step * HOLD / FPS * 1000`）：
   原来每次 `start()` 都重置 `t0 = performance.now()`，导致**暂停后再播放会跳回第 0 帧**
   （等于变相重播）。`Ring.start()` 同样修
4. 「只看爆发」模式下播完把 `playing = false` 并 sync（按钮切回「播放」），
   再点 `toggle` 视为重播 —— 否则播完后按钮永远显示「暂停」且点了没反应

## 天启大封印 · 6. 消失与循环归属（宿主自毁由脚本代劳）

**用户提问**："消失也不用手写吗？会自动消失吗？循环总需要写代码吧，15帧播放循环的动画。"

### 核对到的事实

**`SealDomain` 不会销毁宿主** —— 全文件只有一处 `removeMovieClip`（第 446 行），
删的是**被放逐的敌人**，不是宿主。

`终止`（第 187 行）只做：结算单位 → `状态.已结束 = true` → `状态.宿主 = null` →
`移除任务`。**宿主元件的 MovieClip 会永远留在 `_root.gameworld` 里**（天光一直亮）。

### 代码改动：`封印` 里新增 `_挂宿主收尾`

```as2
_root.主动战技函数.长枪.天启大封印._挂宿主收尾 = function(宿主, 状态):Void {
    if (宿主._收尾已挂 === true) { return; }          // 幂等
    宿主._收尾已挂 = true;
    宿主.onEnterFrame = function():Void {
        if (this._parent == undefined) { delete this.onEnterFrame; return; }  // 防泄漏
        if (this.封印状态 != undefined && this.封印状态.已结束 === true) {
            delete this.onEnterFrame;
            this.removeMovieClip();
        }
    };
};
```

在 `封印` 末尾调用（天光 attach 之后）。**为什么不用 onUnload**：宿主是被主动
`removeMovieClip` 的一方，`onUnload` 只在"别人删它"时触发；我们要的是"它自己发现该走了"。

**触发销毁的三种情况**：50 秒到点 / 手动 `解除` / 宿主被换场景连带卸载（`_parent` 为 undefined）。

⚠ 子弹元件里**不要自己写 removeMovieClip**，会和这条管理逻辑打架。

### 循环：不用写代码

`封印` 里那句 `宿主.stop()` **只停宿主本级**，AS2 的 `stop()` 不递归 →
挂在宿主下的天光（子元件）照常播放。

| 元件 | 循环怎么做 |
|---|---|
| 法阵旋转 | 元件时间轴做循环 MC（复制准星来的，本来就自带播放） |
| 天光呼吸/循环 | 天光元件最后一帧 `gotoAndPlay(1)`，或 CS6 里做成循环 MC |
| 天光播完停住 | 最后一帧 `stop()` |
