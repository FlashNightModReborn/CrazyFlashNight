## 3. 不变量与最小接口

### 3.1 责任边界

- `PanelHostController` 继续拥有 exact 面板实例、打开关闭和原暂停交接；协调器只读取现有身份，不复制业务状态机。
- AS2 继续拥有复活扣币、奖励、存档、交易、退出与玩法。焦点/图形失败不能重发业务写、解锁未知结果或推断成功。
- 键盘逻辑目标、指针手势目标、真实 OS 焦点分别表达。`InputEpoch` 不是业务 revision，HWND/PID 数值不是完整端点身份。
- 每个 Down 只选一次目标；Up/Cancel 只能结束该手势。失焦、替换、捕获丢失或无效几何撤销旧资格；Cancel 不合成 Click，也不默认给 Web 补 MouseUp。
- 世界源、HUD、Web 的坐标变换与当前可交互呈现使用同版几何；出队不能把旧坐标直接套进新尺寸。桥收到旧包时必须在 SetFocus/原窗口过程之前拒绝。
- 保留已发布 AS2 中性化与 Host 光照配对；关闭合成器、露出原 Flash 不是当然正确的回退。失败回到完整配套候选，不单独替换桥 DLL。

### 3.2 先约定语义，不提前造通用框架

主控在 A0 开始时把下列字段落到本阶段实际类型中，更新本节映射；不再另建一份永久协议正文：

| 概念 | 必须表达 | 不能冒认 |
|---|---|---|
| 端点身份 | 当前 Flash 实例、HUD HWND/实例、panel instance/document generation | 同 PID 全部合法；只用 focus generation 代表 exact panel replacement |
| 输入信封 | 序号、输入代次、手势归属、原时钟域、几何版本 | 增改 AS2 封闭业务消息只为追踪方便 |
| 投递状态 | 本地拒绝/消费/透传、未入队/已入队、端点接收、原处理返回 | `delivered=true` 代表全部成功 |
| 恢复资格 | 来自仍有效的用户返回或会话内交接；执行前复核 | NULL 持续时间替代用户意图 |
| 呈现状态 | 首帧准入、尺寸/几何匹配、设备健康、预期是否推进、活性未知 | 时间戳证明语义 scene 或已扫描到屏幕 |
| Native 更新 | tile/内容与几何代次、局部边界/clip、预乘 alpha、脏区、buffer 生命周期 | 每帧全屏重画上传 |

增量复杂度限于一个协调入口、Flash/Native/Web 三类适配、一个呈现根。A0 不要求提前实现全部协调器；通过窄接口接入现役保护。新共享结构、字段或文件必须有本阶段消费者，不预建任意 provider、通用场景图或持久事务框架。

代码根为 `launcher/src/`，原生桥根为 `launcher/native/world-compositor/`。新桥协议由一个 SWE2 lane 贯通 C# 与 C++，不能把两端分给无共享冻结接口的不同作者。

桥撤销不能只作为一条排在旧包后面的取消消息。可复用现有共享映射或其他最小机制，但必须用反例证明接收端在处理旧包前已经看见撤销；共享布局、版本、内存可见性、溢出策略和退出恢复同批验证。不把普通日志当作 ACK，不盲重放失败输入。

A0 同时分离捕获“曾经 ready”和当前推进证据，先观测停帧/暂停/阻塞差异；不新增自动重启游戏或重复抢焦策略。钩子线程迁移若显著扩大范围，先记录受控阻塞结果，交主控决定是否进入后续输入承载替换。

复用测试：`FocusTraceTests`、`FocusTracePhysicalHistoryTests`、`NativeHudInputRoutingTests`、`WindowManagerFocusRestoreTests`、`PanelFocusRestoreGateTests`、`KeyboardHookStateTests`、`WorldCompositorTests`。新增只测反例与不变量，不写实现镜像测试。

## 5. 首批 C0：源／输出隔离的决定性实验

候选拓扑：S 保留现役 Guardian/Flash 来源角色；F 是独立 Flash 进程中嵌入 S 的实际窗口；P 是不同顶层根的玩家呈现窗口，候选 `P.Owner=S`，不是 S 的 `WS_CHILD`。这是实验假设，不是所有系统都已验证的宿主合同。

优先复用 `launcher/perf/flash-compositor/` 小样、`WorldCompositorController`、`NativeCompositorSession`、原生 `Compositor.cpp`。先做隔离实验，再改生产装配。不要在这一阶段搬完 HUD 或替换 Web 后端。

| 实验 | 方法与对照 | 通过条件 |
|---|---|---|
| C0.1 对象隔离 | 记录 S/P/F 的路径、PID/TID、句柄生命周期、父子/owner关系、实际 capture HWND | P 输出不处在选定源捕获子树；不是只比较窗口标题 |
| C0.2 自捕获负控 | 仅 P 显示变化标记，检查原始源帧；另设故意捕获输出的错误配置 | 正确配置看不到标记，错误配置能被检测；诊断像素读回不进入生产每帧路径 |
| C0.3 源活性与几何 | 真 Flash 运行：正常、完全覆盖、部分遮挡、移动、最小化恢复；可用设备上测跨屏/DPI/负坐标 | 应推进时确有新源内容；暂停/静态另计；重复 Present 旧纹理不算源活性；恢复后几何匹配 |
| C0.4 玩家入口与焦点 | 检查任务栏、Alt-Tab、关闭/恢复、真实 Flash 按键；记录操作驱动是否主动激活 | 无第二裸源入口/闪现、无互相抢焦；未具备物理设备的项目明确未测，不冒充全兼容 |

实验必须能够失败。仅 WS_VISIBLE、捕获创建成功、最后一帧可见均不足；不以 `WDA_EXCLUDEFROMCAPTURE` 默认绕过自捕获或破坏正常录屏。当前 HWND 捕获 API 的 Windows 版本要求按官方 API 核对，不能沿用 WGC 大类的较低版本数字。

**阶段出口**：形成最小可运行候选和 C0 结论（成立、明确失败或部分未知），携带实际身份、原始指标及限制，交 Pro 节点 R1。C0 的关键条件失败时不批量迁移；保留现役完整版本，比较 A0＋B 收缩路线，不自动启动替换 Flash 宿主。

## 6. C1 与 B：条件性任务，不提前锁死实现

C0 成立后，主控结合 R1 复核实际接口，再细化以下任务；保留同一本文，不另建竞争施工计划。

### C1：一个真实 Web 面板＋两个 Native 代表样本

- 用 `surgery` 姓名草稿与取消，真实 opener→页面→关闭→世界；不得另造相似 demo。首次接手检查 [lazy 注册](../launcher/web/modules/panels-lazy-registry.js)、`plastic-surgery.js`、`plastic-surgery-runtime.js`、共享外观预览、对应 CSS 与现役 Host task，复用业务处理器。
- CompositionController 适配 visual、鼠标/滚轮、capture、光标、真实 OS 焦点、Tab 与中文 IME、父窗口/DPI变化、故障恢复和所需可访问性。SDK 版本不代签现场 Runtime；运行时能力拒绝要有可识别原因。
- 合成器面板态显示与 AS2 原暂停责任分开处理；不顺带重写暂停协议。
- 带入一个现役 Native 交互目标和一块现役 PlayerInfo 分块缓存，证明统一命中与 GPU 承载，而非只有世界＋网页。
- 先用无持久写目标验证路由；复活/返回业务纵切只在用户授权的测试范围与存档恢复合同内执行。首轮 surgery 不点付费应用。
- Web 捕获丢失/取消不能默认通过补 MouseUp 实现；必须证明页面不会因此提交。旧、新端点不得同时消费同一手势。

**出口 R2**：真实文本输入/取消/返回、Flash 按键释放、Native 样本和缓存成本成立；Pro 对接口稳定性与失败反例复核后，才扩大 B。缺某能力时明确停在 C1，或保持现役 Web 后端先做 B，不能称 Web 已统一。

### B：批量适配与退休

1. 按 controller/绘制资产/窗口外壳拆分职责，逐层接入主 HUD、对白、资源、bottom/buff，再接伤害数字与光标。
2. 保留 PlayerInfo 字形、蒙版、图标及光栅缓存；GPU 常驻资源只上传脏块，几何移动优先改变换。
3. 每迁一个端点，只启用一条输入/显示后端；其取消、模态和业务身份与原行为对照。
4. 逐个退休旧 Form、InputShield/CDP 路由及自主恢复回调，核运行窗口清单和重开资源释放，不只删除源码。
5. 粒子/天空只保留排序、世界/屏幕坐标、调色域和生命周期接点；不为未来透明度预造深度图或另一个引擎。

## 7. Kimi 主控与 SWE2 的执行分工
