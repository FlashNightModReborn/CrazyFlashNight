## 继承与编辑边界

15 个主要分件的位置、层序、外层比例、握持注册点和枪口接口继承现役 QJZ171。新稿尾端轮廓多出 2 个原生像素，保留同一制作标尺，不按灯光或外壳外框重新缩放。图标第 1 帧继承 24×24 遮罩和机匣特写，第 2 帧继承完整展示及掉落倍率。

保持每个独立形状外的 `DOMGroup`，避免 AN/CS6 编辑时合并重叠填充。枪管红色灯丝属于枪管分件；八个灯组属于各自机匣、上盖、后盖和弹箱部件。不要把光效提到武器外壳，也不要把原生矢量扁平化为位图。

游戏内首轮反馈认为枪管纹路在正常倍率下偏橙。现役 XFL 已按 `barrel-color-correction.json` 修色：主线改为接近装甲的正红 `#F2151B`，红底 `#B20E13`，桃橙高光换为较弱的浅粉红 `#FFC2C8`；线芯从 1.55/0.75 px 调整为 1.8/0.9 px，收敛外晕。其余金属色、纹路路径、分组、注册点与动画保持。`source/` 中的 SVG 是未改动的交接来源；从它重建时需重新应用该局部修色，不可覆盖现役校正。

射击动画使用 `tools/weapon-animation/profiles/qjz171-ti61.json`，30 fps、10 帧、4 个前部运动分件，局部峰值 48 px；runtime 已绑定独立物品。`qjz171.json` 和默认测试夹具恢复原型绑定。生产 AS2 通用控制器继续复用。
