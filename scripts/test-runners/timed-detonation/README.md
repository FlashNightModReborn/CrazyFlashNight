# 限时引爆与超时散射

`TimedDetonationProfile` 和 `TimedDetonation` 为普通 MovieClip 弹及可拦截单位弹提供配置驱动的引爆模板。首个消费者为 [FM92 炮弹配置](../../../data/items/bullets_cases.xml)。

## 行为与接入

发射后按弹体帧回调采样毫秒时钟，暂停时间不计入引信。碰撞判定先于超时判定；同一帧既命中又到期时按命中处理。碰撞、拦截或落地只引爆一次；仅未命中而到期时额外散出子弹。已配置的限时弹体不受普通弹 900 像素射程剪枝影响，场景边界与碰撞仍生效。直接移除、场景卸载会取消弹体，不留下计时任务。

在 `bullets_cases.xml` 对应弹种的 `attribute` 下声明 `timedDetonation`：

| 字段 | 含义 |
|---|---|
| `timeoutMs` | 正的有限毫秒数；到期在下一次弹体帧处理时生效 |
| `explosion.type` | 父弹爆炸弹种 |
| `explosion.powerScale` | 父弹发射时威力的倍率 |
| `explosion.fallbackPower` | 无有效原弹威力时的爆炸威力 |
| `explosion.zRange` | 爆炸的地面纵深攻击范围 |
| `timeoutScatter` | 可选；不声明即为单纯限时引爆 |
| `timeoutScatter.type/count` | 子弹种类及数量，数量为 1–32 的整数 |
| `timeoutScatter.powerScale` | 每枚子弹相对原弹的威力倍率 |
| `timeoutScatter.fallSpeed` | 相对地面的初始向下速度，必须为正 |
| `timeoutScatter.spreadDegrees` | 向下圆锥半角上限，0–45 度；落地区域模式必须大于 0 |
| `timeoutScatter.landingSpread.radiusX/radiusZ` | 可选的落点横向 / 地面纵深半径，有限非负像素，至少一项大于 0 |
| `timeoutScatter.explosion` | 子弹落地或命中时使用的爆炸配置，字段同父爆炸 |

速度使用游戏原有的每帧位移单位。散射在水平 X 与地面纵深两个方向偏移，另有独立高度下落；不会把屏幕 Y 误作地面纵深。子弹不继承父弹的超时散射配置，因而不会递归增殖。

未声明 `landingSpread` 时，保留原有的圆锥随机半径与方位分布。声明后按横向均匀、纵深交错排列落点；4 枚的默认排布依次为 `(-radiusX,-radiusZ)`、`(-radiusX/3,+radiusZ)`、`(+radiusX/3,-radiusZ)`、`(+radiusX,+radiusZ)`。发射速度按当前离地高度、重力和离散落体帧数计算，在相同重力下形成稳定落地区域。低空不足以在圆锥内达到目标半径时，整体缩小对应弹体的偏移；始终保留朝下的初始主方向。中途重力改变或提前碰撞会改变实际落点。

FM92 使用 1000 毫秒、4 枚普通手雷、20 的下落速度、45 度散角上限及 `radiusX=240/radiusZ=40` 的交错落点。采用实际爆炸素材时，充分滞空的横向爆炸总宽度约为直击的 1.9 倍，地面纵深总跨度从 160 增至 200 像素。平射提前碰撞与对空超时的既有区分保持。父爆炸沿用原来的 0.7 威力倍率；每枚手雷取得原弹威力的 0.25，再沿用普通手雷爆炸的 0.7 倍率与落地触发行为。爆炸画稿、缩放与伤害参数保持原配置，不消费玩家手雷库存。

工厂在原生命周期及伤害属性初始化完成后安装控制器，保留碰撞器、单位初始化、拦截与安全回收。控制器只接管配置弹体的 `gotoAndPlay("消失")`，将原素材中“生成爆炸并删除弹体”的脚本改由共用实现执行；其他标签转发给原方法。被接管的素材必须遵守这个消失接口，不能自行播放到爆炸帧。透明弹、射线及联弹不接入本模板。

普通手雷沿用现有链接与画稿。其 `area` 旧抛物线回调在该实例上被禁用，并阻止迟到的 `onClipEvent(load)` 再安装；未配置的普通手雷保留原行为。派生物携带发射时伤害类型、元素、毒、淬毒、暴击等快照，锁定属性继承，避免切换武器后重新取值或重复消耗淬毒。

## 验证

在仓库根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run-timed-detonation-tests.ps1
```

入口复用 [focused TestLoader 事务](../run-focused-testloader.ps1)，持有编译锁、备份并恢复 scratch，检查本轮 runId、Compiler 0/0、失败哨兵和 SWF 函数尺寸。测试需要真实 Flash CS6 及当前仓库的编译路径配置。

- `TimedDetonationTest` 在真实 AVM1 中验证配置解析、无效输入、999/1000 毫秒边界、暂停恢复、命中优先、独立实例、重复触发、快照及下落几何；另测不同空爆高度的稳定落点、低空圆锥约束、单枚 / 奇数枚居中与旧圆锥兼容。
- `BulletTargetFilterTest` 沿用现有 17 项回归，检查共享队列的普通弹终止、目标过滤及命中事件合同。
- `TimedDetonationAssetTest` 加载现役 `lady.swf`、`原版素材库-子弹.swf` 与实际提供手雷爆炸的 `PTXOA馆长_JohnWick系列.swf`，经真实 XML InfoLoader、生产发射入口、工厂、单位初始化和碰撞队列验证 FM92。使用现役 17 的飞行速度，另测高速超过旧射程；覆盖无目标、早期与到期时敌人接触、撞场景、待超时弹被拦截、死亡事件、左右朝向、无 area、直接移除及未配置普通手雷；最后用实际墙钟与原生帧回调检查 1 秒超时、4 枚普通手雷的初始下落、父弹原生卸载及场景卸载取消。覆盖收益用例先在无靶空中段让真实手雷落地，再采样真实爆炸时间轴，并经原队列检查侧翼 / 纵深目标的实际扣血、中心连续命中及边界外不命中；不能用面积或出弹数替代伤害断言。

独立 TestLoader 缺少游戏共享库总锚点，夹具按弹种选择三个实际素材域；矩形目标、地图命中及闪避结果受控。落地覆盖用例不模拟下落途中被敌人提前碰撞的情况；此验证不证明完整游戏关卡、手感或正式部署。
