## 问题 1：焦点在 SWF 内按 Alt，游戏画面卡死

**状态**：已定位，**未修复**（方案已验证思路，代码改动已回退，等本机具备构建条件后再实施）

### 现象

- EXE 启动进游戏，**只有焦点在 SWF 内时**按 Alt 才会卡死；焦点在 Web 面板或其它窗口时按 Alt 无此现象
- 卡死后再按任意键，SWF 立刻恢复
- 卡死期间：Web（WebView2）动画仍正常播放，但鼠标 hover 等交互不触发；SWF 完全冻结
- 按字母键时会响一声系统提示音 —— 该提示音是 Windows 通用行为（任意窗口按 Alt+字母、无匹配加速键时都会响），**与本问题无关，是两个独立现象**

### 根因：系统菜单 modal loop

Flash 是独立进程（`Adobe Flash Player 20.exe`），被 `SetParent` 成子窗口嵌入 Guardian，且 `WindowManager` 会主动把键盘焦点交给它。该窗口**残留 `WS_SYSMENU`(0x00080000)**，于是：

```
按下 Alt
  → WM_SYSKEYDOWN 送到 Flash 子窗口
  → DefWindowProc 转成 WM_SYSCOMMAND / SC_KEYMENU
  → 进入 Windows 系统菜单 modal loop
  → Flash 主线程消息泵被嵌套循环接管 → 渲染与游戏逻辑全部停摆
  → 按任意键退出循环 → 恢复
```

Web 的表现是同一机制的旁证：menu loop 会把鼠标 capture 抢到 Flash 所在线程，于是 Guardian 的 Web 收不到鼠标消息（hover 失效），但 Web 的渲染跑在 Guardian 线程上不受影响（动画继续）。如果是 Flash 自身降帧或 Guardian 卡死，不会出现这种"一半动、一半不动"的分裂表现。

### 代码定位

| 位置 | 说明 |
| --- | --- |
| `launcher/src/Guardian/WindowManager.cs:428-431`（启动早期 hidden 路径） | 只做 `style & ~WS_CAPTION & ~WS_THICKFRAME & ~WS_BORDER \| WS_CHILD`，**从未清 `WS_SYSMENU`** |
| 同上 `:664-667`（full / 重嵌入路径） | 同上，同样未清 |
| 同上 `:434-441`、`:669-676` | 只拆了菜单栏（`GetMenu`/`SetMenu`），拆不掉系统菜单 |
| 同上 `:869`、`:941`、`:1005` | `SetFocus(flashHwnd)` 主动把焦点给 Flash 子窗口 —— 决定"只有 SWF 有焦点才会触发" |
| 全仓 grep | 无 `WS_SYSMENU` / `SC_KEYMENU` / `WM_SYSCOMMAND` / `VK_MENU` 任何处理 |

补充：`logs/launcher.log` 显示实际走的是 `path=reveal`（`needFullEmbed=false`），即 style 改写只发生在启动早期的 hidden 阶段；看门狗重嵌入才走 full 路径。两条路径都要改。

### 解决方案（未实施）

**方案 A（推荐）**：两处 style 掩码各补 `& ~WS_SYSMENU`

```csharp
private const int WS_SYSMENU = 0x00080000;

style = style & ~WS_CAPTION & ~WS_THICKFRAME & ~WS_BORDER & ~WS_SYSMENU;
```

两处后面本来就有 `SWP_FRAMECHANGED`，样式会立即生效，无需额外补充调用。

副作用评估：

- `Alt+Space`（系统菜单）会失效 —— 该窗口已无标题栏，本来也用不到
- `Alt+F4` 理论上不受影响：`SC_CLOSE` 由 `DefWindowProc` 独立处理，不依赖 `WS_SYSMENU`，但**必须实测确认**；若真的关不掉，可在 `KeyboardHook` 里补一个 Alt+F4 接管
- 已确认无牵连：全仓无 `GetSystemMenu` / `TrackPopupMenu` / `AppendMenu`，只有既有的 `GetMenu`/`SetMenu`
- AS2 侧无 Alt 相关按键（grep 无 `Key.isDown(18)` 之类），不影响游戏操作

**方案 B（不推荐）**：在 `KeyboardHook` 的低级钩子里吞掉单独的 Alt。会连带影响 Alt+Tab / Alt+F4，风险明显更大。

### 回归清单

1. 焦点在 SWF 内按 Alt —— 无反应，画面继续跑
2. 按 Alt 后再按字母 —— 不再卡死（提示音仍在，属正常）
3. `Alt+F4` 仍能关闭游戏
4. 全屏 / 窗口切换触发的重新嵌入（看门狗 full 路径）依然正常
