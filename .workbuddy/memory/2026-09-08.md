## 2026-09-08 凌晨（续）：击倒小跳时序错误修复

- **现象**：击倒时不小跳，落地倒地后才开始小跳；且小跳结束后反复高频小跳。
- **根因1（时序）**：tick 里击倒判定(C2)排在**空中判定(C)之后**。但破韧/被击飞时「击倒+浮空」是常态——`ImpactStateHandler.as:206-214` 的 AIRBORNE_DOWN 分支：浮空或倒地的目标被再击中会 `状态改变("击倒")`。于是 浮空==true 先命中 C 分支 `_airSkillTick` 后 return，C2 永远走不到；等落地 浮空=false、倒地=true 才轮到 C2 → 表现为"倒地后才小跳"。
  - 修复：C2 提到 C 之前；击倒检测用 `st.indexOf("击倒") > -1`（升空函数.as:176 同口径，防状态名带后缀），并加 `st != null` 守卫。
- **根因2（高频）**：原来每 tick 只要满足 击倒||倒地 就尝试脱困，倒地持续期间小跳 CD(1s) 一到就再放 → 观感"无限小跳"。
  - 修复：`_knockdownEscapeTick` 改返回 Boolean(是否放出成功)；新增 `_wasKnockdown` 边缘检测 + `自机.单位击倒已脱困` 单次标记——新一次击倒重置标记，CD 未好则下 tick 继续重试（保证"立刻"），一旦放出即打标记，本次击倒不再触发。
- **需求澄清（维护者）**：**倒地不需要 AI 小跳**（倒地有另一套起身方式，无需 AI 干预）；**只有击倒才需要小跳**。故 C2 已移除 `self.倒地 == true` 分支，倒地回归不干预（F 分支"倒地不出招"保留）。

## 2026-09-08 凌晨（续2）：升龙拳起跳后空中技能不触发 —— A 分支吃掉整段空中

- **现象**：升龙拳跳起后 踩人/地震/震地 从不在空中触发（落地后才补地面版）。
- **根因（与击倒小跳是不同原因）**：主动跳跃同样会置 `浮空=true`（PlayerTemplateUnitFixture.as:309，落地在 :96 置 false），但**从起跳到落地 状态 一直保持"技能"**。tick 的 A 分支（`st=="技能"||"战技"`）排在 C(空中) 之前，整段空中都被 A 分支吃掉走 `_tryInterrupt`，C 分支的 `st=="空手跳"` 永远轮不到（AI 不按键，走不了 JumpDeriveAction 的 A+B 派生路径，也就不会进"空手跳"状态）。
- **修复**：A 分支内加"空中优先"——技能播放期间只要 `浮空||飞行浮空`，立刻 `_airSkillTick()` 改出空中技能组；新增 `_isCurrentAirSkill()`（_currentSkillName 命中空中组）防反复换招，已出过则静默等落地，且空中一律不再走 `_tryInterrupt`。
- **优先级顺序最终形态**：A(技能中→先看浮空，空中出招) → B(复位) → C2(击倒脱困，indexOf 匹配，倒地不干预) → C(空中/空手跳) → D 出场保护 → E 喝药 → F 倒地不出招 → G 平A保底15% → H 技能裁决 → I 平A兜底。
- 击倒(状态="击倒") 与 A 分支(状态="技能") 互斥，无冲突；击倒+浮空 走 C2 脱困（正确，优先于空中出招）。
