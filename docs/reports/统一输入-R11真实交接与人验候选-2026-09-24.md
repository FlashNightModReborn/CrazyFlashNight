# 统一输入 R11：真实双向交接与 C1 人验候选

**文档角色**：R11 实现、反例、验证范围与人验出口。  
**代码基线**：`5c02a103603ca60ccadd62348fe83753838fb0ca` 加本轮未提交工作树；不覆盖其他列车的改动。  
**出口**：专用 C1-I 只读候选，人工体验待验；不提交推送、不正式部署、不操作真实玩家存档。

## 1. 当前实现

R10 的分离组件现在接成了实际路径：Windows Raw Input → 观察线程上的协调器 → 实际 AS2 命中与生产整形 opener → 全覆盖取消 → 真实 Web 页面、Host task 和 AS2 快照 → 页面取消 → 重新授予世界。Native 样本是现役资源注释组件，PlayerInfo 仍使用现役 SVG 缓存及 GPU 上传；三类画面位于同一 DComp 树。

首击语义已由用户确认：**从外部返回时第一次点击只激活，之后的新完整点击执行业务**。激活边界有独立序列，避免仅靠周期性前台查询漏掉快速切换。窗口已在前台且可操作时不额外吞首击。

AS2 不再信任字符串目标名；它在确切轮次内对真实按钮做坐标／形状命中。GRANT 必须复用已准备的观察前缀。未知操作在分派入口拒绝，不提供任意 SWF、场景、命令或脚本加载接口。XMLSocket 使用现役 exact-process authority，绑定实际 projector PID、启动时间与路径。

Web 的鼠标和按钮键盘激活绑定完成手势；姓名文本由真实 WebView 与现役页面处理。Tab、Enter、Space、Esc 经过真实窗口刺激。游戏表面鼠标路由核对实际命中 HWND，避免将其他窗口或 IME 浮窗上的点击再投到下面的游戏表面。移动、尺寸和 DPI 更新会换 geometry；世界坐标扣除 letterbox，恢复准入前核验合成器已经呈现对应输出尺寸。

## 2. 本轮找到并修补的具体问题

| 问题 | 本轮证据与处理 |
|---|---|
| 周期快照抢先消费新 Down | 实跑出现 Raw 包已到而新 Begin 未准入。健康流不再被周期快照覆写；快照只重建 Unknown／启动前持键。最终 grant 另做当前桌面、前台、注册、两次松键查询及队列检查，查询不改边沿账本 |
| 暂时失去 neutral 证明后卡在 Held | 系统快照可先看到 Up，而 Raw Up 尚在途中。允许保留一个真实 End，等待合格状态恢复后完成一次；任何新边沿、取消、几何或来源变化都会撤销它，且有两秒上限，不合成 Up |
| 来源快速重建被 UI 轮询漏过 | 原来可能只看到“恢复后的 Healthy=true”，但仍持旧 generation 的 grant。现在即使没观察到中间 unhealthy，也必须因 generation 改变撤销旧授权 |
| 合法 opener 的异步回包 | 完成凭证只保留当前确切手势与观察前缀；实际 opener 回到 Host 后才能一次性换为 OpenIntent。更晚的新输入或环境变化使旧请求失效，不重放点击 |
| 未来轮次控制消息被当成旧消息丢弃 | UI 缓存可能落后观察线程。现在保留更晚轮次的控制／数据，等新快照处理；只丢弃确实过期的消息。此前永久 Revoking 的失败日志保留 |
| JSON 字段顺序影响键盘激活 | WebView 消息和脚本参数的属性顺序不同；轮次改为逐字段比较，不能用序列化字符串是否相同来判等 |
| 旧 Web HWND 跨轮次接受迟到按键 | `late-key-negative` 在旧接法中实际改变了新轮次草稿；不能用“Raw 没有新键”或 JS 已改 epoch 来认定原生窗口取消完成 |

这些是 **新 C1 候选中确认的问题**，不能据此追认此前玩家反馈与它们同因。

## 3. Web 退休方案与代价

已经暴露过输入的 WebController 在取消后执行真正的 `Close()`，解除 visual 和事件订阅；只有确切退休后才替换 Web scope incarnation，并重新取得全部取消／准备回执。旧 sender、panel instance、generation、轮次和已退休键盘 HWND 都不能给新实例授权。

取消组合时，生产姓名控件恢复到组合开始前的已确认文字；当前草稿随后从旧页面取出。新控制器先读取真实 AS2 快照，再恢复本地草稿，最后确认 page-ready。没有重放用户按键、没有恢复旧编辑 token，也没有让 Web 取得保存／扣费权威。

这比保留同一原生键盘端点更保守，代价是切换／失焦恢复时的页面重建延迟和焦点位置重置。本轮只在隔离候选使用；真人确认 IME、Tab、等待与光标体验后，再决定后续优化。不能将一次安全修复直接推广为普通游戏已全部迁移。

传输队列故障与 Raw 来源故障分别有恢复门。实际 Flash 连接结束则退出并退休整套专用 VM，不在断链旧 VM 上制造取消证书；重新启动建立新 session。付费拒绝和真实存档隔离沿 R10 保持。
