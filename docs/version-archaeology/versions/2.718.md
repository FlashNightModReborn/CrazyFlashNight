玩家变化：

- 同一次单开或批量开包获得的同类可堆叠物品会先合并，减少待领取格子；装备逐件保留。

### 30 秒回答：当前版本到底更新了什么

从 2.71 到当前 2.718，大学二期及教学链已经形成清楚路线，情报线前八段可定位但第九段存在物品来源断点；核电站与体育老师切磋是当前最适合直接体验的新关卡，另外五个新增目录项仍处于联调、空图、半成品或异常状态。雪山场景加入可定位的持续降雪；敌人差分中有 6 名新敌人可战、1 名新友军可见、3 名既有强敌完成专属属性配置。战斗还加入四项技能、成套搓招、插件、次级穿刺、护盾、半自动与逐发装填变化；43 件新增武器和多组防具有独立正常来源，另有大量物品仍只是定义。

Launcher 侧则重做了启动、多存档、建角、地图、选关、任务、情报、战队、商店、仓库、材料、合成、构筑、技能、双药剂、调制、设置、理发、竞技场、战斗反馈、复活与基地结算。下面每项都给出从哪里进入；没有正常入口的军阀演习和黑市不会混成正式玩家玩法。

### 可靠性与规则修复，怎样在正常游玩中感知

- 装填按半自动、逐发、弹管和装填负担区分；最清楚的测试方式是同场地连续用普通弹匣枪、逐发枪和弹管霰弹枪，记录从空仓到第一发可射击及装满的节奏。
- 冲击连携启用后，用两把不同手枪把一只手打空再换弹，可以直接验证半换弹；切回关闭状态做前后对照。
- 护盾已经进入承伤链。用能量干扰盾或会生成护盾的技能，对同一敌人比较有盾／无盾时的承伤；不要把属性插件误当作实体盾牌。
- 佣兵会按所持武器调整预计输出、追击与撤退。先让佣兵休息更换近战／远程武器，再分别出战，观察距离与决策变化。
- 修复了战宠出战数量卡死、吸血效果异常复活、插件属性显示／计算、攻击模式切换、最小化恢复黑屏、面板关闭层级、焦点抢回、连续复活和返回基地残留等问题。修复项不要求玩家重做特定支线；在对应正常流程中不再出现旧异常即是结果。

### 玩家常见问题

#### 当前最新稳定版是什么？

仍是 2.71。

#### 2.718 是什么？

它是 2.71 之后持续推进的当前开发阶段标识，界面显示 DEV / UNSTABLE。

#### “28 个新任务”是不是都能完成？

不是。大学二期 10 段与教学 4 段有清楚路线；情报线前八段可定位，第九段开始被无来源物品阻塞；铁枪两段仍属联调；体育老师还有一个重复委托数据。

#### “新增 7 个关卡”是不是 7 个完整副本？

不是。核电站和体育老师切磋最适合正常体验；新人救援是联调版，环线东北站接近空图，据点 M 尚未完成，外交—隧道据点有界面异常，总备处站清理没有明确任务／NPC 入口。

#### “新增 180 个物品”是不是都能拿到？

不是。43 件新增武器有独立正常来源，3XF 电棍只由隐藏佣兵持有，另有 37 件没有独立产出入口；防具、插件、情报和消耗品也存在同样的“定义已有、来源未接”情况。正文已经把正常来源和不要寻找的内容分开。

#### “新增 20 个敌人”是不是都能遇到？

不是。能按正常路线打到的新敌人有触手僵尸、爆胖僵尸、望风鸢、贝斯、诺亚虔信者和体育老师；闪流步兵只作为友军出现。Gazer、Itinerant、Surveyor 在 2.71 已经能遇到，这次是专属属性化；其余 10 项没有接入任何关卡。

#### 八个药剂槽是不是八条冷却？

不是。它是两组×四槽，通过 6 键切组；同一列跨组继续共享原来的四条物品冷却。

#### 领奖时关掉面板会丢奖励吗？

普通关闭后，同一进程内可以从基地右上继续领取；只有“放弃剩余”并二次确认才会永久结束。但本文记录的开发快照不保证强退或重启后的恢复，所以请在退出 Launcher 前领完。

#### 为什么某个更新点在我的构建里没有？

2.718 仍在开发，当前也没有稳定整包。先核对构建日期和本文状态；标为“开发中／当前不要找”的内容本来就不应按正式路线寻找，最终可下载版本以正式发包说明为准。

## 玩家体验定位母表（内部编辑真源）

这份母表只解决一个问题：玩家或视频作者看到某条更新后，能否立刻知道“从哪里进入、需要什么前置、具体做什么、应该看到什么”。玩家正文与视频稿必须共用本表的体验编号；没有明确入口的内容，不得用“自己去找找看”掩盖。

### 定位口径

| 标记 | 含义 | 玩家该怎么理解 |
|---|---|---|
| 正常路线 | 当前源码给出正式菜单、NPC、任务或关卡入口 | 可以按表中路径准备体验；正式录像仍应在冻结构建复跑一次 |
| 条件路线 | 入口明确，但需要特定任务进度、物品或等级 | 先满足“前置”，不要在未达进度的存档里漫无边际寻找 |
| 构建复核 | 源码能定位流程，但当前正式入口没有覆盖完整的写入与重启旅程 | 玩家稿可以说明功能，视频必须先实跑再使用结果镜头 |
| 开发预览 | 只有目录、数据、半成品、异常入口或影子入口 | 不作为正常可玩内容引导；玩家无需为此搜索 |
| 清单定义 | 只证明定义存在，没有正常获取、生成或完成路线 | 只进入数量统计，不写成“可获得／可遭遇／可完成” |

精确定位至少包含“入口、前置、操作、可见结果、边界”五项。缺任一项时，正文必须降级为“开发预览”或“清单定义”。

#### 可复现解析口径

- 两端都直接读取 Git blob；键去除首尾空白、空键不计，使用区分大小写的精确字符串集合。
  新增为“截止树 − 2.71”，删除为“2.71 − 截止树”；文件拆分或定义搬家不算新增，不做模糊重命名。
- **物品**：解析 `data/items/list.xml` 的 `<items>` 引用，再读取对应
  `data/items/*.xml`，取 `/root/item/name`。引用文件 14 → 52，原始条目
  1,420 → 1,600，唯一名称 1,418 → 1,597。基线重复 `TheGirl头-NPC`、`小F头部`，
  截止树另重复 `三戈戟二型`；重复只计一次。唯一删除项是 `板砖`，不把 `砖` 或 `砖头`
  推断为重命名。截止树新增的 `<itemSets>` 不参与物品数量。
- **技能**：读取 `data/skills/skills.xml` 的 `/Skills/Skill/Name`。两端始终有 80 个
  预留槽，统计非空唯一名称；id 39、45、72、73 分别填入扭转乾坤、龟派气功、冲击连携、
  内力爆发。
- **任务**：解析 `data/task/list.xml` 的文件引用，再读取 JSON 顶层 `tasks[].id`，
  统一转字符串。引用文件 11 → 13，新增 `iron_spear_tasks.json` 和
  `intelligence_tasks.json`；两端无重复 ID、无删除。
- **关卡**：解析 `data/stages/list.xml` 的目录引用并先去重，再读取各目录
  `__list__.xml`，以 `目录/StageInfo.Name` 为复合键。两端根清单均有 19 条原始引用、
  17 个唯一目录；`诺亚前线基地深处第二层`、`雪山` 的重复引用先折叠。同名但不同目录的
  关卡分别计数。
- **敌人**：解析 `data/enemy_properties/list.xml` 的文件引用，再以各 XML
  `/root` 直接子元素的 `LocalName` 为键。引用文件 9 → 14；两端无重复键、无删除，
  `displayname` 不参与统计。

### 中间过程不单列为玩家更新

- 提交标题含“开始”、“准备”、“占位”、“初步”、“尝试”、“未完成”、“未实装”、
  “暂无伤害判定”、“做到一半”、“待后续”的内容，默认不能凭该提交进入正文。
- 若后续有明确收口，只写收口后的玩家能力，不把早期 WIP 当作额外更新数量。例如：
  体育老师使用 `cc23eb1763`，起身回旋踢使用 `087d158709`，龟派气功使用
  `5a385c9058` 及后续修复。
- “新增素材”、“完成动画”、“加入图标”不能单独证明对应武器、敌人、技能或关卡已经可玩。
- 数据目录出现条目只证明定义存在；没有来源、生成点或任务闭环时，不写“玩家可以正常获得/
  遭遇/完成”。
- 历史 SWF 随提交变化不能单独证明当前构建已由 Flash CS6 编译和人工验收。

4. 回非战斗地图取回，核对弹药、插件和强化快照。
5. 若有 30／50 级宠物，分别拍两段进阶门槛；没有就只展示门槛，不假装解锁。

#### SH-46 消耗品、食品互斥与无来源清单（IT-C01～IT-C04）

录医务室格格巫的大 HP 药剂与化学品生产的合成纳米毒。再把番茄、牛肉罐头放入快捷药剂槽：先番茄后罐头拍伤害＋4→＋5，再反向拍＋5→＋4；结论只能是同属性后用者替换／刷新，不得剪成＋9。补字幕说明不同属性可并存、即时 HP／MP 药不属于此规则。

随后用编辑卡明确列：43 件新武器有独立正常来源、3XF 电棍只由隐藏佣兵持有、37 件没有独立正常来源；再列当前不要找的插件、消耗品和宠物。这张卡是防止玩家盲刷的重要内容，不可因时长删掉。

### 逐镜头执行卡：Launcher 常用流程

#### SH-50 NativeHud、地图、任务、情报与选关（UI-03～UI-08）

一镜到底：展开顶部刘海扫七个正式游戏入口与四个辅助入口→点右上地图→切基地／阵营／防区／学校→点一个锁定热点看原因→返回→打开任务详情与事件日志→打开已收集情报与术语目录→从真实世界关卡触发点进入选关→区域→节点→难度→入关。

另录一个带任务标记的副本节点，证明会打开单个 exact 委托；再从刘海任务页打开，证明没有 taskId 时不提供任意副本浏览。测试菜单不入镜。

#### SH-51 战队、商城、NPC 商店、战备箱与地图箱（UI-09～UI-15）

1. 战队四页签各停 2 秒，至少真实完成一次出战／休息。
2. 刘海商城：分类→商品→购物车→改数量→真实购买一件。
3. 世界 NPC 商店：买一件再卖一件，显示单价与总价。
4. 战备箱：Ctrl＋单击一件，拍先合并同名堆叠再找空格；点批量存入／取出→逐件勾选→重复点击取消一件→执行转移，另拍 Esc 在提交前退出。右栏依次演示 ‹／›、点“X / Y”、PageUp／PageDown、Ctrl＋Home／End；字幕写单批最多 50、装备调制禁用快移、目标满或同步失败会停队刷新。
5. 地图箱：Enter、双击或 Ctrl＋单击直领；Space 只选择再确认；普通单击只选择；Ctrl＋A 全收；普通关闭后同场景重开同一箱。

严禁把基地结算的“单击直领”套到地图箱。

#### SH-52 材料档案与合成采购（UI-16～UI-17）

完整连续旅程：搜索一个缺口材料→看敌人／关卡／商店／配方来源→跳 NPC 商店并高亮→返回原材料→跳嵌套配方→规划数量 2→看到背包／已装备／战备箱拆分数量→按提示取出或卸下→材料齐全后实际合成→关闭重开核对产物与扣料。

任何一步失败都保留录像并收窄旁白；不能只拍作者 harness。

#### SH-53 构筑、双药剂与调制（UI-18～UI-21）

1. 构筑页：无选槽的完整背包→点槽→单击预览→Space 取消→拖入高亮槽提交。
2. 配置 2×4 药剂；入关按 6 切组，先用 I 组第 1 列，再切 II 组同列，拍共享冷却；另拍 3 秒切组冷却。
3. 调制四入口各跑一条：强化、交换、进阶、配件。至少一条成功、一条等级锁定、一条槽容量或材料不足。
4. 关闭重开确认已提交结果；不得把预览画面当完成。

#### SH-54 设置、理发、UI 音效与点歌机（UI-22～UI-23、FB-04～FB-05）

从右上齿轮与旧设置入口各进一次，证明汇入同一面板；切三页，改一个键后保存，试听音量，拍 0.6×／2.2×静态镜头预览。基地一层找理发师，拍当前→试戴→确认→即时换发型；重开存档核对。最后从刘海辅助进点歌机，选曲、seek、暂停／恢复，并与游戏暂停做对照；关 Web UI 音效后重演一次面板选择。

#### SH-55 正式竞技场（UI-24）

基地车库→选关→DEATH MATCH角斗场→难度→挑战浏览器→选卡→看阵容／风险／押金／奖金→开始挑战→实际战斗。堕落／爬升没有已知敌人时拍空态；不要从“其他→测试”进入。

#### SH-56 未开放玩法边界（UI-25～UI-26）

军阀演习和黑市只使用编辑卡说明“目前只有测试／影子入口，无正式玩家入口”，默认不拍测试菜单。若维护者坚持给开发预览，画面全程加角标，且明确不写生产资产。

### 逐镜头执行卡：反馈、复活与结算

#### SH-60 物资 Feed、五种伤害数字与对账（FB-01～FB-03、FB-09）

1. 同一战斗连续触发普通／精英／Boss 击杀、拾取、耗药和换弹；拍左下×N／负数及头像层级。
2. 商店买入再卖出同一物品，拍获得／失去方向。
3. 同一敌人、同一武器、同一连段依次切“彻底关闭／平衡·目标锚定摘要／总伤·每目标连段累计／经典·Flash逐段散开／逐发·Burst完整矩阵”；每次字幕标模式。
4. 加一个背包换位或仓库转移镜头，说明所有权不变所以不会出现 Feed。
5. 选择“逐发”或“平衡”，拍一次斩杀“斩”；用龟派气功蓄出临时盾后受击，拍“盾＋吸收值”；再打开伤害对账日志，翻一页展示每页 24 条与最近最多 32768 段。

字幕明确：“暴击没有独立‘暴’字，只能比较最终伤害与频次。”禁止后期制作一个游戏里不存在的暴击文字。

#### SH-61 胜利后继续探索（FB-06）

在正式关卡胜利后先不点右上条，继续走动和攻击 10 秒；再拍有任务时的“前往交付／回基地”双按钮。另用失败素材拍只有“回基地”。不得添加不存在的“继续”按钮。

#### SH-62 连续死亡与复活（FB-07）

死亡→特写复活币数量→点“复活×N”→“正在复活…”→人物恢复→立刻普攻和两个普通技能→同图再次死亡并复活。禁复活关卡只拍“禁复活”状态，不绕过。设置页的尝试复活可作为救援入口补镜头。

#### SH-63 基地行动报告与领取（FB-08）

从 SH-61 的回基地按钮连续录到基地自动开结算：

1. 慢滚左栏，拍关卡、难度、结果、时间、击杀和物资获得／消耗；切完整／紧凑。
2. 右栏切待领奖励／材料存量。
3. 奖励格单击领一件、Enter 领一件、Ctrl＋A 批量领。
4. 用近满背包触发库存整理，转移物品后返回并继续领取。
5. 普通关闭，拍基地右上“继续领取”，重开后恢复；只拍“放弃剩余”的确认框，不真的放弃。

字幕必须出现：“当前冻结版本只保证同一进程内继续领取；领奖完成前不要强退，重启后的待领奖励恢复尚未支持。”
