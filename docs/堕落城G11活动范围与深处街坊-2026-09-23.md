# 堕落城 G11 活动范围与深处街坊

**文档角色**：G10 审阅结论的合并施工及本地人类验收候选记录。前序为 [G10 逐地点审阅与裁决](堕落城G10逐地点攻击审阅与范围裁决-2026-09-23.md)。用户已授权施工并推进到下一人力验收节点。

## 1. 交付范围

G11 仍在本机 `http://127.0.0.1:8782/`，保留 42 个验收地点，单元由 67 个增至 70 个。新增 DF01 维修背巷、DF02 居民街坊内院、AS01 市区服务院与集结街段。重点验收 P07 深处、P04 压制战、P18 保卫战、E05 城防归属，以及 T01 内部入口。

本轮同步落实主要活动、经过联系、共享服务、入口锚点、相邻参照五类关系。验收页分别用金、蓝、绿、米白、灰表示，活动面有地面范围提示，行军有蓝色路线。点击单元查看本关关系及独立的常驻功能／控制说明；不再以单一“建筑归属”混合表达这些含义。

原有 67 个单元的 `owner` 字段保持不变。新增单元的具体位置属于本轮设计候选，不声称原剧情指定了门牌。

## 2. 深处：从主街进入背巷与内院

- 旧城区主街新增向北的楼间穿行巷，经既有维修支路进入住宅组团。路线避开旧排屋，不通过原先靠南货运端的 OT02 作为深处终点。
- HS01 北侧住宅保留；HS02、HS03 的部分中间体量重排，留出进入层次。两侧仍是居民楼，中央分别为低矮维修屋、穿行背巷与更内部的围合院落。
- DF01 在较外层，带工坊挑棚和维修暂存；DF02 有北翼、两侧服务翼和开放院门。主街到院内已有连续通路。
- P07 将 DF01/DF02 作为主要活动，OT01 作为经过联系，HS02/HS03 仅为相邻参照。没有把整排住宅或全区住民划为通缉犯控制区。
- OT02 物理位置和编号保留，名称改为货运侧背街楼段，以便 G10 批注仍能追溯。

主要路线为原始坐标 `(651,415) → (651,330) → (655,330) → (655,290) → (680,290) → (680,250) → (675,250) → (675,220)`。这是一条依建筑间隙组织的进入路线，不强制增加一圈无用途绕行。

## 3. 市区集结与跨区战役

P04 按主线 54 的“在市区而非大本营”调整。新增 AS01 日常服务小院，事件期间可承担集结；活动面覆盖小院及其前方市区街段，原城区排屋为接近联系，居民楼与技术维修点为相邻参照。RK 舞台不再默认列入其主要活动或终屏。

P18 列出商业街前场、酒吧内外、黑铁门前、摇滚终段四个主要活动面，并关联相关单元。商业街保留作战语义；区域之间的行军由真实道路上的蓝线表达。城外精确突入口仍不坐实，大学支援到场也没有被转换为校园本体发生战斗。

P14 内战补后台／前场接应关系和模因回环说明；排练室仅作相邻参照，不凭背景复用推断必须在室内交战。G10 原金色事件虚线仍可手动打开作对照，G11 默认使用活动范围与行军线。

## 5. 验收数据与批注

地点 `relations` 记录五类单元关系，`activityAreas`、`activityPath`／`routeIds`、`anchors` 分别表达范围、路线与内部锚点。`buildings` 保留为涉及单元集合，兼容逐栋选择；活动渲染层位于验收查看器，不进入实际地形或道路碰撞网格。

G11 使用独立批注键和导出版本，JSON 导出同时保留关系类别及范围说明。G10 对照页和原批注入口保留，不自动迁移旧版“可保留”为新版通过，也不清空旧反馈。
