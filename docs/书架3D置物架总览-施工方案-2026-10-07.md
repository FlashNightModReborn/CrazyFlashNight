# 书架 3D 置物架总览 — 施工方案（2026-10-07）

**文档角色**：施工方案（前期探索收口）。基线：2026-10-07 工作树（注意 `main` 上有他人进行中的荒漠选关施工，见文末禁区）。
**前置决策**（已与用户对齐）：书架总览首屏化（不再直进第一本书）；可玩书走"主机游戏碟盒合集"拟物思路；3D 场景实现，复用选关 diorama 管线，不走 DLS/CSS 设计语言；外围 DOM chrome（工具栏/阅读器/详情页）仍在 DLS 内。

## 1. 目标形态

- 打开书架面板 → **总览态**：3D 置物架，可读内容为书脊、可玩内容为《闪客快打》合集碟盒（六碟一盒）。
- 点书脊 → 进入对应书的阅读态（现有 reader）；点碟盒 → 进入现有章节详情页（"开盒"交互属二期，一期点盒即进详情）。
- 碟位语义：原版碟恒可玩（Ruffle）；重制碟位 cf2–cf6 为空位（= 现有 `remake.available` 仅 cf1 的图形化）。
- 原版播放器 CRT 外框：做在父侧 `#bookshelf-original` 容器（`bookshelf.css:98-104`），**不动**隔离文档 `player.html/player.js`（CSP 与 Ruffle config 冻结，`test-bookshelf-original.js:86-90` 钉死）。

## 3. 交互逻辑改造点（`launcher/web/modules/bookshelf-panel.js`）

1. **新增第四态"总览"**：`render()` 现按三态分流（`:185-306`：is-reading / is-original / detail）。新增 `selected === null`（或独立状态位）→ 显示 `#bookshelf-overview` 3D 场景。
2. **onOpen 不再直进阅读态**：`:54` 的 `render(); read();` 改为 render 总览 + 仍发 `snapshot`（`:92` 的 `read()` 保留——snapshot 是原版准入等 gating 的前提）。
3. **保留深链锚**：`:155`（inRun/pendingRun 自动 `selected='crazy-flasher'`）与 `:178-183`（自动 return commit）是 settle/unknown/readfail 场景的核对 UX，**必须保留直达章节详情的行为**，不能停在总览。
4. **3D 拾取不产生写**：点书脊/碟盒只改 `selected` 走现有 render 链；commit 仍只发生在详情页按钮。对照 desert-browser 的"零写"断言思路（test-stage-select-desert-browser.js:81-86）。
5. **cleanup 对称**：3D 场景 dispose 挂进 `cleanup()`（`:359-368`）；`onRebind` 是 cleanup+onOpen 重建（`:369`），天然兼容。书架 close 无 ack 等待（`:354-358`），GL 释放可同步做（不需要 warlord 的 quiesce 握手）。

### 绝不能碰的合同

- 命令面：`snapshot/commit/query`（`bookshelf-runtime.js:88-91` 正则硬卡；Host 映射 `BookshelfTask.cs:163-173`；合同冻结 `launcher/contracts/panel-contracts.v2.json:471-506`）。
- 消息信封 `{type,panel,domain,cmd,callId,panelInstanceId,payload}`（`bookshelf-runtime.js:78-81`）。
- commit kind 枚举 `play/switch/return/settle`（`BookshelfTask.cs:123-146` 槽位裁决，Web 不造目标）。
- `bookshelf_transition` / `bookshelf_transition_complete` 过场握手与双 rAF 回执（`:109-140`）。
- 原版准入窗口 gating（`BookshelfTask.cs:235-240`；`bookshelf-panel.js:193`）。
- `selected` 值域与别名 `'repair-campus'→'crazy-flasher'`（`:19`）。

## 5. 资产管线（照 desert 链缩小）

**铁律：生产 GLB 走"美术源 → 导出器 → 导入器（--check + manifest）"，不能手放 GLB。**

1. 设计稿 JSON（架体尺寸/碟位锚点/相机机位）→ `docs/design-data/`（先例：desert-spatial-draft.json）。
2. 架体与碟盒是方盒子，体量为选关的零头：可手工小 Blender 场景或写 `tools/bookshelf-graybox/`；美术技法用 BM-009（烘焙顶点色 + unlit，固定视角首选，`docs/三维选关场景创作与交接经验.md:55-69`）。
3. 导出 GLB（全内嵌、Uint16 索引——小场景天然满足）+ anchors JSON + report。
4. `tools/import-bookshelf-shelf.py` 纳管进 `launcher/web/assets/bookshelf/shelf/`（scene.glb + config.json + manifest.json 含 audit 块与逐文件 sha256），`--check` 可复核。
5. 场景运行时读 config（normalize 模块仿 `stage-select-desert-config.js`，含 `validateEmbeddedGlb`）。
6. 书脊文字用 canvas 动态渲染进贴图（改配置不重画）。
7. 架体建模参考：游戏内现成置物架素材 `flashswf/backgrounds/elements/置物架A.swf`（被 `data/environment/stage_environment.xml:364` 引用）。

**封面/碟面素材**：
- CF1 可用 FFDec 从 `flashswf/originals/crazy-flasher-1.swf` 导标题画面（开发资产，允许；导出先例 `tools/build-bookshelf-pages.py:49-51`）。
- **CF2-6 是商业资产、不入仓**（`launcher/contracts/bookshelf-original.v1.json:24`），不能导出进仓库——碟面自绘（标题字+底色+风格化图形）是最干净路线。
- 原版 FLA 书架/书脊元件（`flashswf/UI/书架界面.fla`）可用 ffdec-cli 列表确认 characterId 后导 SVG/PNG 作书脊贴图参考；若烘焙为图标，在 `data/items/asset_source_map.xml` 补 symbolName 精确化（该表现有 :107/:3292 两条整包引用）。

## 6. 体积与性能纪律

- 现有 GLB 参照：8.6MB/8.2MB/33MB/84MB 递增——书架场景目标**远小于 base-gate（8.6MB）**，audit（bytes/meshes/triangles/materials/images）写进 manifest。
- 浏览器测试断言：triangles/draw calls 预算（先例 `triangles>150000 && calls<100` 的反例上限，书架应定得更紧）、静止零出帧、N 次开关资源数稳定、context loss → DOM 目录 fallback → 重试、canvas 与宿主尺寸一致。
- `crypto.subtle` 依赖安全上下文：harness 是 http://127.0.0.1（安全上下文）OK；生产 overlay 自定义 scheme 需在真实 WebView2 复验（desert 同款风险）。
