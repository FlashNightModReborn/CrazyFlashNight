# 犀牛 R09 来源与静态接入

来源为用户提供的 `R09-犀牛坦克-Animate交付包`。外部主稿使用 Animate 24 / AS3；这里只导入零履带相位下的平射与 15°抬炮端点，保留原生矢量分件，移除控制脚本、动态时间轴和炮口逻辑标记。

静态接入的唯一编辑源位于 `flashswf/levels/地图-军阀基地/` 的 `Codex/犀牛R09/` 库目录。来源哈希和元件/采样帧映射在 [来源.json](来源.json)，日常编辑、三处固定车号、比例、派生同步及 CS6 发布见 [工具说明](../../../../../tools/rhino-map-assets/README.md)。

此目录只保存来源记录，不包含另一个运行时素材库。原始完整动画仍属于外部交付，未声称完成 AS3→AS2 动态控制迁移。
