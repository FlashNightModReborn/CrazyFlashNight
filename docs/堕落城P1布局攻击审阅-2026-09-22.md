## 五组应先画清的关系

### R1：保卫战必须有完整的跨区行动路线

**原文依据**：[保卫战](../data/stages/基地车库/堕落城保卫战.xml) L56 要求找到并保护仪器与重要单位；L585 要求赶到酒吧；L1140、L1146 指向黑铁会战场与摇滚公园；L1495—1507 明确有已挖通的小路；L2065—2066 绑定保护仪器的失败条件。

**下一稿动作**：在平面图上画出“城外进入 → 市区 → 酒吧 → 黑铁控制的战场 → 捷径 → 摇滚公园干扰设备”的连续关系，并给设备留一处功能位置。优先将黑铁战场接在城市驻点的外郭/控制街段，再以侧向走廊接摇滚；这只是待图面核实的最小方案，不能因为存在黑铁总部，就把战场强行搬到总部主院。

“被攻击的黑铁会”与“堕落城保卫战”是不同事件。前者复用总部背景，不能据此推定后者经过总部。旧背景文件被复用也不单独证明精确距离。无需新增一座“保卫战大楼”，也不将整场战役局限为守正门。

### R2：军阀必须有抵近摇滚资产的关系

**原文依据**：[主线文本](../data/task/text/text1.json) `$MAIN_GET_28` / L1549 提到摇滚领地遭军阀侵吞、黑铁会袖手旁观；[摇滚关卡](../data/stages/基地车库/摇滚公园.xml) L535—541 出现脱离黑铁管制及黑铁与军阀合作的指控。角色立场应保留，但当前布局需容纳所述冲突。

**下一稿动作**：右侧沙海哨所不能只面对右侧居民区。至少画出其进入工业争夺区后，与摇滚外缘仓储/资源地块接触的路线。优先让摇滚的外部资产沿低位工业环线延伸，不必为此整体搬动左下演艺核心，也不能直接打通军阀至居民区的内防线。

该路线不必就是攻占摇滚舞台的路线。阶段性的默许、资源争夺、交战与暂时制衡可以共存；不能把黑铁—军阀关系涂成贯穿全剧情的永久敌对或永久同盟。

### R3：同时标明新旧城区、两处地下入口和既有工程接口

**原文依据**：[大学支线](../data/task/text/school_texts.json) `$SIDE_GET_40003` 明确大学拥有新城区宽敞入口，摇滚和黑铁所在老城区另有危险窄入口；[目录](../data/stages/基地车库/__list__.xml) L35 将大学控制的最大入口放在城缘；[主线](../data/task/text/text1.json) `$MAIN_GET_72` / L4205 以侦察判断指出黑铁控制的入口可能被诺亚用于突袭。

**下一稿动作**：大学核心靠工业城防；其外围服务带朝驻点展开；检修院落在这条服务带仍接近城市边缘的低处，不能只因为靠近驻点就被推到城市中央。新城区/老城区是建设年代，不能直接等同中层/下层。

另外为黑铁老城侧入口明确预留位置，可候选落在总部后勤外郭或其控制街段。标明其与遇袭线的关系，但不能把侦察中的“极大概率”画成已证实的完整地下进军路线。不新增必需的可点击节点，也没有依据编造大学入口曾易手给黑铁的剧情。

[水厂档案](../data/intelligence/水厂外勤档案.txt) L19、L77 已给出 V-15C 至地下主干管、下水道入口的联系与封死处置；L86、L229 涉及设备移交和地铁通风系统。下一稿保留这些接口的去向与封闭属性；**设备移交不是一条实体管线，管线相连也不是可步行通路**。不在这一轮为地铁、排水和工业管廊绘制全网确定拓扑。

### R4：货运需要画出不同成本与控制范围

**原文依据**：[假肢市场情报](../data/intelligence/堕落城假肢市场动荡.txt) L5、L9、L11、L14 描写过路费、保护费、附庸经营与运输被劫；[学校与摇滚敌对的缘由](../data/intelligence/学校与摇滚敌对的缘由？.txt) 涉及原料、加工、集散与工业地位；[冻链经济](worldbuilding/14-贵金属与冻链经济.md) 区分中游消费、定价与小额流通。

**下一稿动作**：在公共货场—大学—摇滚—住区之间，标出大学加工/鉴定接口、摇滚库存/维护院以及混居侧收购点；不要求把城外矿山塞进绿色片区。至少区分公共货运、黑铁重要运输的受控接驳，以及经过较高风险地带的替代路线，并标一个人货分流点。

游寇邻货场的意义可以是独立劫掠、收购、竞争或受约束合作；当前原文未证明它是永久税务承包者。不得把其邻货场的本轮提案引用为关卡目录事实。也无需让每条道路都设收费岗，或把黑铁全部运输写成完全无风险。

## 未采纳的推断与需要收窄的建议

- **北区荒漠不能推出固定来沙向。** C-1 的高置信度“源冲突”不成立。需要保留荒漠、军阀外部补给与尘都各区的地理关系，不能据此指定风向；草图左右亦未绑定地理方向。
- **局部设施调用不等于局部护盾仍可用。** B-3 以此推出黑铁主动不扩展护盾，偷换了底稿含义。技术断裂、接口占据和制度阻隔可继续作为提案；公共品成本或有意阻挠只能是可选强化，不能覆盖用户已经选择的原因。
- **WP没有重投围墙，不等于不能拥有大型工业或电子防护设施。** D-1 的直接冲突判断过强，D-2 中“因此护盾只能由统合出资”的结论也缺依据。下一稿区分工业结构、副产防御价值与新增防护功能，并标建设年代待定；无需先排除WP。
- **护盾与主束关系仍是提案边界。** 北区毁坏和其他区主体幸存并不排除局部防护的存在；它也不证明护盾扛住主束。保持作用范围、时段和损毁机制待定，不把“幸存原因已被占用”当排他事实。
- **符线笔记仍是角色观察。** D-4 提醒来源强度有价值，但其修复建议“东段重合为事实”反而强于原文“结构性相似、并非完全重合”。沿旧设施发展是作者当前方向，符线与护盾的具体同源关系仍待证，不能由这份笔记直接推出。
- **公共赛事不等于无主。** B-4 可转成运营/征费边界的待补项，但不能先规定黑铁最多收什么费，也不能把赛事定义为无人运营。现有多个历史赛事中心不要求本轮编造搬迁或重开史（A-5）。
- **三据点邻接不自动证明共同所有权。** B-5 的历史加固建议可保留，当前底稿已经区分宿主设施、有限遗产与现役独立势力，不构成必须推翻聚合的矛盾。
