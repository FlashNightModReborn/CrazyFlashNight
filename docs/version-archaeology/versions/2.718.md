# 2.718 开发阶段记录与更新视频提纲

**记录状态**：`source_verified / current DEV / release unknown`

**核验日期**：2026-08-29

**代码基线**：`53290308dfd8e90ae85944c9c5ea58ca30997442`

2.718 是 2.x 主线中的当前 E 阶段标识，不是已经发出的稳定整包。E 阶段持续到 AS2
权威彻底转移；只有形成面向玩家的稳定发包节点时才追加一位，普通开发提交继续沿用当前
阶段号并由 `DEV / UNSTABLE` 区分。历史小版本没有同一套连续语义，也不存在需要补齐的
2.710–2.717。

## 玩家真正会感受到的变化

以下内容均已进入当前源码，可作为后续 2.718 前瞻视频的主体素材：

- **启动与存档更可靠**：启动器转为 C# 宿主，逐步接管 AS2/C# 存档传输、主要数据权威和
  多存档入口，退出链路也补上了僵尸进程防护。
- **常用界面迁入启动器**：选关、仓库、理发店、设置、关卡结果等流程逐步改为
  C# + Web 面板，交互和高 DPI 适配持续统一。
- **物品操作改成工作台**：商城、战备箱、仓库、角色构筑、竞技场和装备调制逐步复用
  双栏工作台，玩家能在同一套候选、槽位、拖放与注释体验中完成操作。
- **构筑自由度提高**：佣兵换装、角色构筑、双药剂组八槽/共享冷却，以及装备进阶、
  插件变换、强化度交换形成了更完整的配置闭环。
- **挑战内容增加**：军阀战术演习、佣兵精确标定、黑市鉴定小游戏和跨子图限时关卡进入源码。
- **战斗反馈更直接**：左下角增加物品获得/击杀播报，打击伤害数字迁入原生层，常驻 HUD
  与面板提示也进一步统一。
- **声音与界面偏好统一**：Web 界面使用统一的语义音效，并同步音乐/音效静音偏好。
- **关卡收尾更完整**：关卡结果、奖励领取、返回基地、转场和复活恢复形成连续流程，减少
  结算后卡在错误界面或残留交互的情况。

### 录制清单

1. 每章至少准备一组“玩家输入 → 可见反馈 → 结果落地”的连续镜头，避免只拍静态面板。
2. 存档、物品与角色镜头使用专门验收档，遮住本机路径、账号和诊断信息。
3. 高亮四组前后对照：选关、仓库、角色构筑、关卡结算。
4. 战斗反馈用同一场景、同一武器拍原生伤害数字和 Loot Feed，便于观众直观看差异。
5. 只有经过当前构建人工验收的画面进入“可用”叙述；未完成角色创建前门等在制内容另列预告，
   不混入本期已进入源码的主体清单。

### 稳定发包后补齐

- Release URL、标签、发布时间、资产名/大小与标签提交；
- 最终玩家更新摘要 3–8 条；
- 实际可下载整包中的版本号与 `STABLE` 状态画面；
- 与视频每个章节对应的最终验收构建；
- 若 Release 说明链接本视频，在本页把状态提升为 `release_verified`。
