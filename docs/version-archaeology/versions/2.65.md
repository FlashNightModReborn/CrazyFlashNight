## 玩家向草稿

2.65 稳定整包页所链接的更新前瞻展示了以下玩家变化：

- 任务界面展示了重做版本，并把事件日志用于查看任务线和任务记录。
  （故事板 `00:05`、`00:20`）
- 地图传送界面与烹饪界面展示了调整后的画面。（故事板 `00:45`、`01:05`）
- 视频展示了废城“第一防线防区”、陷落城“商业街”等区域，以及多个人物外观。
  （故事板 `01:25`–`02:25`）
- 动画与特效部分展示了普通攻击、技能表现、兴奋剂释放动画和武器刀光等调整。
  （章节卡 `02:40`，演示 `02:45`–`03:30`）
- 装备与材料部分展示了新食材、大圣套装和多件套装/武器；大圣套装画面明确标为
  彩蛋装备，正常流程无法获取。（章节卡 `03:45`，演示 `03:50`–`04:15`）
- 挑战副本展示了“情报书”产出，画面说明其用于补充重置版世界观信息。
  （故事板 `08:40`、`08:50`）
- 关卡改动部分说明四个大副本受到调整，并明确僵尸、盗贼挑战模式提高了难度；僵尸副本
  还展示了动态刷怪点及会随波次被破坏的井盖、卷帘门等障碍。
  （章节卡 `09:05`，说明/演示 `09:10`、`09:55`、`10:00`）
- 杂项部分展示了主线任务 14 后开放的食堂支线、佣兵进阶专属技能、铁血肩炮跟踪，
  以及按住 `Ctrl` 拾取装备后直接穿戴。（章节卡 `10:40`，演示 `10:45`–`12:30`）

画面还在 `12:20`–`12:25` 写有“增加两个新被动技能，具体作用待定”。它只能证明当时
公开过开发方向，不应写成已定稿或已交付的玩家功能。
