# 血色光剑天秤 R04

交付源为 `Ti61-Lightsaber-Game-Handoff-R04.zip`，来源SHA、命名映射、矩阵和短周期见[assembly.json](assembly.json)。

唯一可编辑源是[Codex专用素材XFL](../../Codex专用素材/Codex专用素材.xfl)中的`Codex/Ti61-血剑/`。R04原生分件与逐帧矢量保留，AS3生命周期已改为[专属AS2装备脚本](../../../../../scripts/逻辑/装备函数/血色光剑天秤.as)。不维护另一份同名FLA。

新画稿沿原握持原点旋转90度，三个刀口使用旧武器矩阵。普通静态展示保留基础红刃与柄灯首帧；持刀呼吸、纹路和自损触发的爆发由装备生命周期控制。旧外壳的整体GlowFilter不继承。

发布目标仅为该素材库；行为脚本编入asLoader。两帧图标与纸娃娃通过物品素材工作台定向生成和应用。完整规则与验证边界见[迁移记录](../../../../../docs/血色光剑天秤-R04材质与装备脚本迁移-2026-09-08.md)。
