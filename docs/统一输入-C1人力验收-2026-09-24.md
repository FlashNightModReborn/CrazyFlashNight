# C1 统一输入：只读候选人验

**状态**：R13 长宽比与恢复专项补验已由用户确认“可行，有效”；下方步骤保留作回归参考。不是普通关卡或正式发布。

运行 `powershell -File tools/run-c1-input-acceptance.ps1`（仓库根目录下）。入口先核验本机候选清单和文件哈希，运行时再核验代码闭包及 WebView 版本；失败不会回退到其他版本。无需重新编译 Flash。源码改动、候选固定方式和证据见 [R11 报告](reports/统一输入-R11真实交接与人验候选-2026-09-24.md)。

只操作标题为 **CF7 C1 live** 的主窗口。这是独立测试场景，使用可丢弃角色和真实整形页面；不加载玩家存档，Host 与 AS2 两侧都拒绝付费提交。人物素材只用于建立真实服务上下文，不是完整关卡或纸娃娃展示验收。

## 已完成的补验：长宽比与恢复

仍从同一个根目录入口启动。打开整形页面并输入已确认文字，反复拉成窄高／宽扁窗口再还原，也可在刚打开时就开始缩放。停手后应恢复“可操作”，草稿和新的完整点击正常，取消后能返回世界。

极窄窗口下，页面等比缩小并留空属于预期；人物和文字被拉扁、停手后一直不能恢复不属于预期。其他此前未发现问题的体验无需整套重跑。详见 [R13 报告](reports/统一输入-R13长宽比与恢复活性-2026-09-24.md)。

## 原三组操作（留作回归参考）

每次等标题显示“可操作”后开始新的操作，合计约五分钟。

1. **单击与文本**：单击场景中的“整形手术”，在姓名框输入中文；使用真实输入法候选窗、Tab、Enter／Space、Esc 和页面取消。关注是否一次正常点击就能打开、文字是否漏字或重复、取消后能否再次打开。这里只编辑草稿，不测试确认付费。
2. **切出与返回**：输入一段已确认的文字，另起一段尚未确认的中文组合，然后切到其他应用。也试一次按住 Shift 或鼠标后切出、在外部松开再返回。外部应用不应被抢走前台；返回时首击只激活，松开后新的完整点击生效。已确认草稿应保留，未确认组合应取消，旧按键或松开事件不应触发新操作。
3. **窗口与注释**：移动窗口、调整大小、最大化／还原、最小化／恢复；鼠标移入左下资源信息，再移出。关注按钮命中、场景与 HUD 对齐、注释消失、恢复后首个新操作。若有不同缩放的显示器，可补一次跨屏移动。

Web 输入端点在撤销后会被退休并重建，可能有短暂的“正在恢复输入”。请同时反馈这段等待是否可接受，以及中文输入法候选窗、Tab 与光标位置的实际体验。自动协议测试没有代签这些感受。

## 回传

关闭主窗口后，启动脚本自动把本次身份、事件和退出结果归档到 `logs/c1-input-acceptance/<本轮目录>.zip`。浏览器 profile、执行二进制和玩家存档不进入该 ZIP。

在对话中回复三组操作的结果；异常写“大约时间＋操作＋看到的现象”即可，日志由 Agent 自行核对。退出成功只表示候选正常结束，不代表人验通过。
