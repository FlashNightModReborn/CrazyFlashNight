# CF6 CT教官 R9 — 两粒领扣与袖章浅条配色呼应

R8冻结保留。本轮是严格小范围调整，不重设造型或配色。

## 核对与实现
原CF6工程基底487翻领扣：近扣主体#b9a04d、独立亮面#dfc66d，远扣主体#b49a4c；R8分别变为#474845、#545552、#454643深灰。
R8袖章实际包含暗红底与浅条。**本轮呼应浅条#947664暖棕铜色，不是把领扣平涂暗红。**
两扣主体使用含#947664的低调金属渐变（暗边→小亮区→暗面），近扣原独立亮面改#b69d86。原深色描边、形状、尺寸、位置完全保留；不恢复原来的亮黄。
袖章自身以及其他金属、布料、盾徽、头部、膝甲、动作注册均不变。

## 确切范围
仅parts/487.svg内soldierAlpha487的原子节点21/22/23三条路径的fill改变，并增加一个必要渐变定义r9-collar-copper。
同一三路径位于26个共用身体atlas变体，均同步；**共27文件改变：1母件+26变体。其余16输出与R8逐字节相同**（其他13母件+3碎盾变体）。某些碎片视口不显示领扣，但其共享身体图集也保持一致。
完整交付仍为14个母件、29个变体；详尽文件清单和三条原路径见qa/r9-change-scope.json。
qa/validation-r9.json对所有43SVG反向归一：除三条fill和新增渐变外，整个XML树与R8完全一致，包含原几何、描边、裁切、矩阵、注册和其他颜色。
