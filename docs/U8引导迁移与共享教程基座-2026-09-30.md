# U8 引导迁移与共享教程基座

**关联**：[U8 #35](https://github.com/FlashNightModReborn/CrazyFlashNight/issues/35)。首版候选已编译并启动，但维护者判定战斗地图的视觉表现明显回退，视觉验收不通过。修正版恢复现场白色图示，将告示板教程合入 Web 帮助；新的自动回归、候选和玩家感官验收分别记录。当前运行身份以本地开发入口的 active pointer、candidate metadata 和 runtime manifest 为准。

## 范围与呈现

原 7 项入口保持原任务和关卡触发权威，`加载引导界面` 转接到 `NativeGuidanceService`，不再加载旧引导 SWF。

| 原资源 | 目录 ID | 呈现 |
|---|---|---|
| 引导-开始游戏 | start | 原触发自动打开 Web 帮助的“开始游戏”；基本操作、互动与装备、奔跑三个内容节 |
| 引导-地图传送 | map | 原触发自动打开 Web 帮助的“地图与任务” |
| 引导-战斗 | combat | 原场景位置的白色方向键与攻击/跳跃图示 |
| 引导-奔跑 | run | 原场景位置的白色连按、Shift 与方向键图示 |
| 引导-拾取 | pickup | 原场景位置的白色按键、鼠标左键与 Ctrl 组合图示 |
| 引导-打开箱子 | crate | 原场景位置的白色互动键与文字 |
| 引导-打开箱子2 | crate-safe | 原场景左侧的白色互动键、破坏及物品销毁警告 |

文本及 `visual` 图示由 [guidance-catalog.json](../launcher/data/guidance-catalog.json) 维护，Web 投影由 [生成器](../tools/generate-guidance-catalog.js) 派生。图示只有有界 key、text、mouse 三类元素，使用 1024×576 作者坐标，不接受脚本或任意绘制命令。原 5 个现场布局以原 FLA 为参照，读取旧 SWF 导出的静态帧复核；动态键标签由 AS2 当前绑定填入。目录中的有界 `keyLabels` 同时供 Native 与 Web 使用，把实际 KeyManager 的中文方向键名称转成箭头，并为长键名提供可读缩写，避免小键帽截断。Native 使用既有 `native.combat.label` 无衬线角色，避免把 HUD 衬线正文套到键帽图示；细暗边仅提高场景上的可读性，不填充大块背景。

现场提示保留原延迟渐显、玩家距离淡出和场景清理，完全穿透鼠标，不新增暂停或业务写入。两个告示板教程由目录中的 `surface:help` 路由到现役 Web 帮助；`start` 等原延迟到非零透明度后才打开，Web 采用正常帮助面板的输入和暂停生命周期。自动打开时传入当次键位与 exact 条目；手动打开帮助仍明确显示默认键位。主帮助中的图示复用同一份 `visual`，并在文字中显示键帽。

主帮助页新增“操作教程”目录，保留基本操作、世界观和彩蛋页。工作台的收纳帮助在同一 Panel 内使用 `WorkbenchComponents.SecondaryPage`，返回、Esc、焦点恢复、背景 inert 和销毁均走现有基座。原收纳帮助正文保留在“功能说明”中。调制、角色构筑的原帮助入口继续由各自领域维护。

## 共享边界

`native_guidance` v1 是 AS2→Host 的显示快照，身份为 `ng:<seq>`、`sceneId`、递增 `revision`。Host 严格检查字段、数值、键位和目录 ID；同 request 不允许改变场景或内容身份。隐藏、关闭、断线和迟到队列均防止旧显示复活。`nativeGuidanceAction` 只回送关闭意图，Host 核对当前显示，AS2 核对相同请求、场景与当前世界。关闭可以引用本请求已经发送的正整数 revision，拒绝未来或非法版本；这样渐显或改键产生的新快照不会使在途关闭失效。它不推进任务、发奖励或修改存档，且不开放 Web 通用调用。

自动教程复用 `PanelHostController.TryOpenTrackedPanel` 的 caller-reserved instance 与执行门，不重绑或驱逐已有面板。有其他面板时等待其关闭；失败尝试有界。关闭帮助只消费对应 exact instance，并向 AS2 回送当前 request 的关闭意图；场景隐藏、请求换代和断线则撤销 queued open，并精确关闭自身窗口，不能关闭后来手动打开的帮助或其他业务面板。页面 init 只接受目录中标注 `surface:help` 的条目与封闭键位对象；畸形输入拒绝挂载。

对话图片和引导图片共用 `DialoguePortraitService.LoadSceneImage` 的资源读取、缓存和所有权合同，并共用 `GuidanceImageLayout` 的 contain 绘制。引导页的可选 `image` 只接受 `flashswf/images/` 内的路径。图像生命周期绑定 request、scene、page asset epoch、transport epoch；透明度或键位更新不使当前页正在加载的图片失效，换页和断线则拒绝迟到图片。当前 7 项为文本内容；后续对话图片教程仍需独立盘点内容与触发权威，不能由显示设施自动取得剧情控制权。

## 演示、录制与新增领域

[tutorial-journeys.json](../launcher/data/tutorial-journeys.json) 同时声明领域、已纳入门禁的功能和每步结果。首个领域为 `workbench`，覆盖 Ctrl 单件转移与批量选择后提交；这两项不代表整个工作台的全部功能已有轨迹。

演示适配器复用正式 `InventoryUI.renderOwnedSlot` 和 `InventoryWorkbenchQuickTransfer.QuickTransferController`，使用固定的内存物品与传输端口。演示不嵌入活玩家页面、不打开第二个 Panel、不发送真实库存请求、不持久化练习。

新领域通过 `GuidanceTutorials.registerDomain(id, create)` 注册。适配器须提供本页内的 `root`、`execute`、`snapshot`、`reset`、`subscribe`、`destroy`；只能操作自身固定演示状态。主目录和领域帮助均使用 `GuidanceTutorials.mount`，无需为新领域复制播放器。先用 `view.record()` 记录真实组件操作，再用 `view.finishRecording()` 取得 JSON；归入对应领域的作者源、补充预期状态并生成 Web 投影。录制操作和示范都在同一个播放器中回放。

轨迹 v1 支持有界 click、Ctrl 修饰键、目标内相对点击点、页面内相对鼠标路径及每步预期状态。播放时核对当前领域、页内目标、组件可用状态与预期结果；错误或关闭立即取消后续步骤。其他语义动作须扩展并验证明确的适配器合同，不能转成任意脚本或真实业务自动化。

## 2026-10-01：结算优先与教程跳过

维护者反馈关卡胜利后不显示结算。本机 07:05 的日志显示：首次奖励暂存已 committed，地图教程的 `native_guidance` show 抢在 loot 请求前到达；帮助页面随后打开，后续关卡报告多次返回 `loot_flow_busy`。这是自动教程与返回结算的准入交错，不能通过清除玩家结算权威或重发奖励处理。

自动教程现在由两层合同约束：AS2 在结算、切场、开战预约或非 idle loot lane 时维持同一显示请求的 opacity=0，完全空闲后才恢复。奖励完成暂存会释放场景出口，此时报告可能尚未申请，单靠 observation owner/lane 会提前判为空闲，因此额外读取 `StageRunSession.hasUnpresentedSettlementReport()`，覆盖这个窗口而不改变出口或奖励权威。Host 在 tracked open 实际执行前复核结算 coordinator 为 Idle 且无 ActiveBinding，PanelClosed 本身不能解除等待，BindingSettled 才通知重试。被业务准入撤销的 queued open 不消费显示失败预算，旧请求、旧场景与断连的请求不能复活。

自动教程固定底栏直接提供“跳过本次”与“关闭教程弹窗”，均可键盘操作。“关闭教程弹窗”将全部自动教程改为刘海屏通知提醒，适用于本机所有玩家槽位并记住选择；关闭使用帮助面板当前 exact instance，不推进任务或改变奖励。提醒沿现役 `INotchSink.AddNotice` → NativeHud → NotchWidget 刘海屏通知栈，以独立 `tutorial` 类别显示教程名称和右上角帮助入口，不暂停、不夺取焦点；同一触发只提示一次，结算/切场等待期间不提前提示，过期场景或断连请求不能复活。沿用通知栈的临时行和淡出行为，从帮助入口手动选择该条目。

`tutorialsAutoOpen` 默认 true。Help composition 端点的窄命令 `tutorial_preference:disable_auto_open` 只接受 version 1、callId 与当前 exact panelInstanceId，只允许将这一偏好关闭；Host 保存成功回 `tutorial_preference_result` 后才关闭当前教程，失败回滚并保留页面，结果未知不盲重发，迟到回包不关闭新实例。“设置 → 本机与 Web”继续使用 Settings Host 严格布尔白名单，可重新开启自动弹窗。手动帮助和五项现场白色图示保留；手动重开帮助时移除自动教程底栏。两种偏好入口共用同一 UserPrefs 权威，不写玩家存档。
