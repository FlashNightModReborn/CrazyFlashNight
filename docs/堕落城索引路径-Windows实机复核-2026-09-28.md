## 本轮结论

在 Windows 11、本机 WebView2 153.0.4234.48、Intel UHD 630 / GTX 1650 的 ANGLE/D3D11 及 Microsoft WARP 上，
四轮共 40 个 cell 完成采集。没有观察到原截图中的跨建筑大块拉伸三角面。
两个历史/当前概览相机与两个补充低角度均完成 raw Uint32、5×Uint16、nonindexed 的硬件对照，以及 raw/chunked 软件对照。

四轮均保留 `status=completed / classification=mixed_result_manual_review_required / exit=1`。
逐像素完全一致在本机没有普遍成立，不能把这四轮涂成绿，也不能由 exit 1 宣称已复现游戏故障。
32 组图像比较中，差异最多 200 / 589824 像素，约 0.03391%；所有最大通道差均小于 64。
差异集中于局部小区域，并且 WARP 中同样出现微小差异；这些观测未呈现报告中的巨大拉伸面。
该层结论是“本轮独立 WebView2 未复现原故障”，不是证明历史环境无故障或已经确定驱动根因。

## 判别器修正与验证

原分类器将 `!All(raw==chunked)` 用作复现条件，一个相机的差异即可错误进入全局复现分支。
本地补丁要求两个相机都满足指定反事实；实际后端身份不足、哈希缺失、不完整矩阵与不稳定捕获均不能判通过。
增加相机/响应哈希/index mode/draw count 核验、逐 cell 中间结果、全新输出目录、非激活窗口和整轮有界进程管理。

14 项分类回归通过，涵盖单相机差异、对照失败、未知/软件后端、缺失像素证据与不完整矩阵。
新鲜真实 GLB 几何回归通过：1 个大批次、172371 triangles、5 个 chunk、6205356 个原始属性分量逐项一致。
新鲜结构审计为 0 index/buffer 结构错误；>65535 引用 371236 次，123752 个三角形实际依赖 32 位范围。
本机小工具构建 0 error，保留 1 个已知 WindowsBase MSB3277 warning；没有编译或测试整套 Launcher、Flash。
复现入口归[诊断工具 README](../tools/issue122/README.md)。
