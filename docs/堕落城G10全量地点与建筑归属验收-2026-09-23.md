# 堕落城 G10 全量地点与建筑归属验收

**文档角色**：全量灰盒候选、建筑归属与集中反馈入口的施工记录；不是游戏资源发布或人类验收通过记录。

前序：[G9 逐地图清单与大学组团](堕落城逐地图细化清单与G9大学组团-2026-09-23.md)。用户要求取消逐个小片区交付的节奏，下一个节点应允许逐地点、逐建筑集中提供反馈。本轮因此同时推进剩余片区和验收工具。

## 1. 本轮范围

本机 `http://127.0.0.1:8782/` 为 G10。共 42 个验收地点、67 个有实体归属的建筑／院落单元：主地图 19、大学子场景 12、其他外交子场景 3、城市支撑 5、试炼内部测试子场景 3。

所有地点可独立选择、切镜头、显示所属建筑编号及原图。67 个单元都有模型对象且都可从清单进入，没有仅列出名称的空编号。但「全量候选」不等于「全量完成精修」或「全量通过」；室内子图主要验收它属于哪栋楼、如何进入，不另造一栋楼冒充每个房间。

当前模型、生成器与查看器在 `tmp/fallen-city-graybox-20260923/`；生成后的 `layout.json` 包含 `buildings` 与 `reviewLocations`。目录和场景枚举来自现役数据，关联和体量则是待人类判断的城建方案。

## 2. 集中验收操作

1. 选择「主地图」逐一看 19 个入口，或选择「全部地点」连续查看全部 42 项。上下地点按钮保留顺序，URL 记录地点编号与范围。
2. 点击建筑按钮，例如 `OT03 月面保洁门面`：镜头定位、模型高亮、显示单栋边框和编号引线，并列出其归属、职能与依据边界。也可恢复本地点整组或切俯视。
3. 展开原场景对照；完整精灵图与首帧裁切图分别标注。部分战斗背景只能支持局部特征，不能据裁切图声称完整楼群精确复原。
4. 每个地点可记录「待看／需要调整／可保留」及文字意见，最后统一导出 Markdown 或 JSON。批注暂存本机浏览器，不自动发给他人、不写游戏数据、不产生自动验收结论。

建议反馈使用「地点编号 + 建筑编号 + 问题／建议」。同一建筑可以被多个地点引用，例如摇滚的不同战斗事件共享实体，死亡竞赛共享医疗与候场。反馈导出保留原地点和所关联建筑编号，不将共享关系复制成多个城市建筑。

## 4. 全量片区细化

- 大学下水道口重建宽通道、防护墩、入口遮挡与压顶，补旧街残楼、弃车封锁、检修设备和大学守卫岗，接回已建下行通路。旧图的坍塌封锁是视觉依据，院落尺度与守卫位置是提案。
- 摇滚补主标牌及支柱、灯架、音箱面、后台门面和第二台班车；后台与排练室分别归属。外围仓场、边缘住区和混居服务面补窗列。
- 死亡竞赛补围界立柱、检修盖、赛事告示与医疗／报名／裁判／候场标识，三个场地保持不同职责。
- 旧城、深处候选街段补窗列、卷帘门、挑棚、弃置物及后街联系；月面保洁保持服务门面和独立后场。修正新增门面板与招牌重叠。
- 游寇补驻留楼门面、仓库卷门、收货物资；驻点补接待窗面、试武院界线和接驳仓设备；不把材料掉落擅自解释成已证实的产线。
- 军阀补临时宿营、路障、旧仓修补与观察平台，仍以占据遗产设施而非新建永久军营表现。
- 校外加工街、试炼准入、居民楼群和货场补各自的经营门面、控制／通风、储水、接货标识等。既有大学、商业、酒吧、总部、城防设备继续纳入统一归属验收。

## 5. 资料与不确定性

页面关联 49 个不同源 SWF，资料目录共 52 张离线参考图；同一 SWF 可能有多个内嵌场景。新增只读导出教学楼内部、内部右侧、文理教室、办公室及剑道社六份完整精灵图。

核对并修正了来源路径：教学楼内部右侧、理科教室、文科教室是 `地图-教学楼内部.swf` 内嵌场景，不是三个独立 SWF。查看器按各自内嵌图展示，不再引用不存在的文件。

缺乏证据的精确楼层、城区深处地址、黑铁关卡唯一地址、跨区地下贯通和试炼测试剧情没有升级为事实。总部资产、世界观原文、关卡 XML、外交场景切换均未被本轮灰盒修改。没有新增 SWE2 审阅；本轮沿用已裁决调研，加主控原图和代码核对。

## 6. 检查与限制

静态通路检查为 62 类道路、4462 个登记盒体通行带样本；4171 个台地样本、9129 个沙面通行带样本均无埋路。实际网格 1450 条道路射线无阻挡，42 处显式道路接口成立。保卫战动线 803 个贴路样本和 28 条中心射线通过。赛事设备、城防设备、总部四主楼保留回归。

归属检查确认 42 地点／67 单元引用闭合、所有原始源路径与参考图存在、所有建筑都有实体、总部四个主楼没有串号。归属标注曾提前建立网格包围盒，手工地形坐标变换后包围盒未更新，导致单栋边框偏移且可能影响射线筛选；已在变换后重算，重新跑实际网格检查，并检查 1419 个网格包围盒与最终顶点一致。

浏览器逐一切换 42 个地点，核对单栋定位、整组恢复、俯视、隔离、原图、酒吧剖视和跨地点批注保留。自动测试批注已清空，没有留下人类通过意见。导出逻辑另检查多行中文与建筑编号保留、排除未批注待看项及过期未知编号。

这些证据不等同于真实游戏导航、人流交通、全部战斗背景整图精确复原或人类感官验收。该节点供人类集中反馈，尚未集成游戏、提交推送或发布。
