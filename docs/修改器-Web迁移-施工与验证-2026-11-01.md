# 修改器 Web 迁移：施工与验证（2026-11-01）

**文档角色**：U11 修改工具的四页 Web 化施工记录、跨层协议与验证边界。本文不替代 [AS2 UI 迁移护栏](../agentsDoc/as2-web-panel-migration.md)，也不授权正式 runtime 发布或退役旧 Flash 修改器。

**本轮范围**：经济、物品、关卡、阵营四页；目录检索、生产、关卡调试、主线任务、单位/佣兵生成。界面是 843×400 的独立 composition 浮窗，保持旧修改器的浮动尺寸、四页布局与左侧页签，不进入 PanelHost 全屏面板、不申请面板暂停，并支持顶部标题栏拖拽。旧 Flash `修改工具界面` 继续保留在 main，不删除、不撤 placement。

## 0.1 当前原生界面修订（2026-11-09）

现役 `ModifierOverlay` 实际承载 `ModifierNativeSurface`，不再经过 WebView2；原生浮窗为 1016×550，逻辑画布为 843×456，以保留 XFL 完整上下边框。`python tools/export-modifier-art.py` 从原 XFL 生成 `launcher/web/assets/modifier/native/` 的四页底图、独立按钮和 `layout.json`；`--check` 重生成并逐字节核对闭包。按钮分别使用 `assetRect` 与原始 `hitRect`，页签使用白色 `over` 帧；兵种选框只显示名称，列表与预览遮罩使用原帧坐标。

物品格与通用 `NativeTooltipWidget` 共用 `LootIconCatalog`，支持 PNG 序列、动态 WebP、NPC 商店头像和 AS2 `itemTooltip` 文档；注释框缩放跟随修改器，物品格与背景格线使用同一坐标。主面板恢复原矩形的 alpha 204 深色半透明底，通过 `RenderFrame` 直接生成 32 位透明位图，再由 `OverlayBase` / `UpdateLayeredWindow` 做真实逐像素合成；面板外 alpha 为 0，不保留全黑底板；示例黄框/灰框不进入底图，格子由原生代码绘制。输入框由独立原生窗口承载并增加高度，注释显示时输入层退让，注释始终位于最高层；透明区域经消息过滤支持整格悬停，左侧页签不额外铺底色且阻断外部点击，分页箭头按原矩阵翻转。兵种选框只显示名称，选中态不额外画黄框，页数回到原数字位，头像在原灰块范围内强制裁剪。主窗、输入窗与游戏 Owner 的合法焦点往返不会隐藏修改器，切到无关外部窗口仍按原规则压隐。2026-11-09 的定向结果为 253 项修改器/共享组件测试通过、素材 `--check` 通过、`tools/test-modifier-runtime.js` 通过，并以真实图标、NPC 商店头像和 T800 完成原生带数据渲染。此记录不表示正式 runtime 已发布，也不替代真实游戏入口的人体验收。

## 1. 入口与权威

| 层 | 本轮职责 |
|---|---|
| NativeHud | `SETTINGS` 从 `toggleSettings` 切到 AS2 `openModifier`；发送失败只提示，不直接打开 Web。 |
| AS2 `ModifierPanelService` | 会话 token、场景/存档上下文、目录投影、全部写校验、dirty/保存、操作收据、关闭后场景动作。 |
| Host `ModifierTask` | exact owner、命令白名单、payload 校验、未知写水位、响应重建与 `panel_resp` 回包。 |
| Host `ModifierOverlay` | 独立 `CompositionHelpSurface`（1016×484，独立 WebView2 profile），预热门、浮窗几何、拖拽、关闭/断线/焦点回收。 |
| Web `modifier-window` | 四页展示、检索/分页、数量/等级草稿、二次确认、错误与对账提示；不注册普通 Panel。 |

修改器在挑战模式中拒绝打开和写入，保留旧 Flash 的可见性语义。生产物品使用 `_root.创建可拾取物`，不直接写材料集合；生成佣兵会写 `_root.可雇佣兵` 并标脏，必须保存。

## 2. 跨层闭环

| Web cmd | C# action | AS2 handler | AS2 response task | 写状态 |
|---|---|---|---|---|
| `snapshot` | `modifierSnapshot` | `readSnapshot` | `modifier_response` | 读 |
| `items` | `modifierItems` | `readItems` | `modifier_response` | 读 |
| `units` | `modifierUnits` | `readUnits` | `modifier_response` | 读 |
| `query` | `modifierQuery` | `readQuery` | `modifier_response` | 读/对账 |
| `grantMoney` | `modifierGrantMoney` | `applyGrantMoney` | `modifier_response` | 金币 +100000 |
| `grantKCoin` | `modifierGrantKCoin` | `applyGrantKCoin` | `modifier_response` | K点 +100000 |
| `spawnItem` | `modifierSpawnItem` | `applySpawnItem` | `modifier_response` | 世界拾取物 |
| `levelAction` | `modifierLevelAction` | `applyLevelAction` | `modifier_response` | 解锁/杀敌/波次/过图/关卡结束/测试图 |
| `grantTask` | `modifierGrantTask` | `applyGrantTask` | `modifier_response` | 主线任务与进度 |
| `spawnUnit` | `modifierSpawnUnit` | `applySpawnUnit` | `modifier_response` | 场景单位 |
| `spawnMerc` | `modifierSpawnMerc` | `applySpawnMerc` | `modifier_response` | 雇佣池 + 场景佣兵 |

Web→Host 使用 `{type:"panel",panel:"modifier",domain:"modifier",cmd,callId,panelInstanceId,payload}`；payload 顶层固定 `v:1, token`，写命令再加 `operationId, expectedRevision` 及命令字段。Host 回包固定 `type=panel_resp,panel=modifier,domain=modifier,cmd,callId,panelInstanceId`。

`levelAction` 的业务动作字段名为 `levelAction`，避免与 Host 可信信封字段 `action` 冲突；这是本轮协议的硬约束。

## 3. 会话、未知写与关闭

- AS2 每次打开生成 `modifier.<timer>.<seq>` token，绑定 `存档系统`、`savePath`、`关卡标志`。场景/存档切换后写返回 `context_changed`。
- 每个写带 Web 生成的 `mod.<...>` operationId。AS2 在执行前先写 `applying` 收据，成功后把结果写回同一 operationId；同一 operationId 重试只返回缓存结果。
- Host 单写飞行；超时、断线、send-false 或无法验证的回包保留 `recoveryToken/recoveryOperationId`，后续写返回 `reconcile_required`。Web 只能发 `query` 核对，不能自动重放。AS2 对同 operationId 返回缓存结果；没有记录时返回 `not_applied`，Host 才解除对账。
- 关闭由 composition 浮窗的 exact instance close 触发 Host `ModifierOverlay` 发送 `modifierPanelClosed`；AS2 只退休当前会话，保留最近操作收据供对账。`finish_stage` / `test_space` 先返回 `closeAfter`，由关闭命令在浮窗退出后执行。浮窗不暂停游戏，因此场景动作不依赖面板暂停释放。
- 旧 Flash 修改器不退役；本轮的 NativeHud 入口切换不等同于旧 XFL 已删除或主 SWF 已重发。
