## 玩家向草稿

2.50 稳定整包页所链接的更新前瞻展示了以下玩家变化：

- 美术部分展示了多种新敌人和改造体，包括“趴狗”“防暴僵尸”等画面；摇滚公园 BOSS
  与其他 BOSS 改造体也有专门的调整演示。（故事板 `01:55`–`07:00`）
- 任务/地图表现展示了通缉任务背景图更新和明暗度设置。（故事板 `08:00`、`08:25`）
- 武器部分集中展示了多把新增或精修枪械，包括 AWM、M82A1、M79、MGL 与 SPAS12 等
  示例。（章节卡 `08:50`，展示 `08:55`–`10:45`）
- 机制与 UI 部分展示了按方向键改变手雷偏角、按 `Q` 切换手雷、平板电脑快速移动、
  通缉任务推荐等级、彩蛋内容专属面板，以及敌人强化选择界面。
  （章节卡 `11:10`，展示 `11:15`–`13:10`）
- 夜间模式展示了绿色夜视画面，但画面明确标注“该效果仍在测试中”。
  （故事板 `13:25`）
- 技能部分展示了新主动技能和若干技能调整，并特别提到不使用战宠/佣兵玩家的技能配置。
  （章节卡 `13:35`，展示 `13:40`–`14:15`）
- 任务线展示了第二阶段更新、两个新支线和新的隐藏支线，并标出主线进度第 27 节点；
  新游戏开局还展示了不同流派属性加成与新手装备的选择界面。
  （故事板 `14:20`–`15:50`）

敌人、技能与任务的完整专名仍需音轨转写或人工逐镜核字。当前条目只采用画面上足够清晰的
标题与类别，不根据战斗演示推断数值、掉落或最终发包状态。
