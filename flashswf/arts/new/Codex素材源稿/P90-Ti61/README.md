# P90 钛合金61素材

当前原生编辑源为 [Codex作者库](../../Codex专用素材/Codex专用素材.xfl) 中的 `Codex/P90-Ti61/`，共用发射器与光束位于 `Codex/Ti61-共用/`。旁边的SVG和参数JSON是交付时的冻结参考，原生修改不会反向同步它们；不保留第二份可编辑FLA。

来源为 `P90-Ti61-Game-Handoff.zip`，SHA256为 `8a4e18f4e584459da9607a90e876d3ff15ea3af9682a4c85cc178ac8d3d429e5`。原生FLA SHA256为 `cfc6a4bb6bceff83312bfec8dd031bba2a24c9c3197886edf41bd60243f779d1`，原始22个元件、290个矢量形状和288个分组已按独立命名空间导入。

## 物品与原生结构

- `钛合金P90` 保留原有45级身份与基础参数，改用新机甲稿和红色瞄准光束。
- 旧美术仍由 `things.swf` 提供，交给新增的33级合成一层物品 `P90印花集` 使用。
- 游戏链接为 `枪-手枪-Codex-钛合金P90`，图标链接为 `图标-Codex-钛合金P90`。
- `弹匣` 为50帧MovieClip，弹列从49递减到0，首帧有stop；每帧数量和矩阵与现役P90一致。弹匣下方白甲与红衬属于固定机匣，不能随弹匣状态消失。
- `枪口位置` 沿用交付稿新前端的 `(107.45,-21.1)`；它与 `激光发射器.出光位置` 分开。
- 原生总装以普通P90注册坐标为基准。发射器在枪内的矩阵为 `a=d=0.26, tx=70.2, ty=-32.9`，本体内出口 `(43.5,0.75)` 对应枪内约 `(81.51,-32.705)`。

图标第一帧采用现役 `[-12,12]×[-12,12]` 遮罩，取景集中于顶置长弹匣、连续弹列和完整握持孔，左侧白甲红衬用于区分钛合金版本。当前矩阵为 `a=d≈0.36, tx=9, ty=4.2`，覆盖约三成枪长，原生保存后的精确值见 `assembly.json`。按24×24实际显示大小与普通P90、战术版、印花集并排核对；不能只留下红白甲板而失去系列共同结构。第二帧按0.275倍率展示完整实体外观。激光由装备生命周期动态挂载，因此不会延长离线图片的取景范围。

第一帧使用 `00_图标特写静态` 与 `03_弹匣/04_图标满弹静态`：保留原分件引用、安装矩阵及满弹首帧的49个弹列实例，去掉图标不需要的弹量时间轴和内层窗口遮罩。原嵌套弹匣路径在FFDec导出中会把一段遮罩外壳计入图标边界，首次实测内容边界为580×240；静态展示路径将其收回240×240（均为10倍导出）。运行时50帧弹匣继续使用原元件，第二帧仍引用完整总装。

## 灯光与接口维护

实体本体命名为 `激光发射器`。原项目用 `激光模组` 控制光束显隐，故该名称留给运行时动态红束，不能再次拿来命名整个硬件。当前P90与钛合金171共用AK74战术版式的单层纯红渐隐：`#FF0000`，起点Alpha为0.6、末端0，束体宽11.5个枪外壳局部单位，不叠加暖白芯或橙红外晕。参考来自 `flashswf/arts/things/LIBRARY/无AS链接/Symbol 3721.xml`，只复用视觉画法；现有装备生命周期继续处理出光点、镜像与显隐。

共用参考长度仍为250，中心线归零，运行时配置长度仍为750。元件文件 `02_光束视觉参考/红束_暖白亮芯.xml` 的历史路径及导出ID保留，当前图层名为“纯红渐隐束体”。旧暖白方案保存在 `assembly.json` 的历史参数中，当前参数以 `beamBands` 和 `pureRedBeam` 为准。

同轮将P90的中低亮度中性底材压暗，例如 `#606061 → #2E2E2F`、`#515152 → #272727`，保留白甲、红衬、发光件及金属高光的分层。实际替换表和光束参数记录在 `assembly.json`；冻结SVG和原交付材质JSON继续反映交付时的原稿，不作为当前配色的第二真源。

共用硬件可用于钛合金171，但两枪各自维护安装座、倍率和坐标。171的发射器放在静止机匣侧座，位于原后坐动画外层；图标则使用包含同一安装变换的静态总装。

画稿维护时保留两处真实握孔与分件DOMGroup。后托、观瞄的黑色底形随各自部件移动；灯壳、亮芯、光晕保持同件归属；接触阴影跟随对应甲片修改。渐变使用完整仿射坐标，不能按裁剪后的小包围盒重新拉伸颜色分布。
