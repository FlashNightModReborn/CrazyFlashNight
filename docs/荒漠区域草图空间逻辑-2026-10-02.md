# 荒漠区域草图空间逻辑

**文档角色**：荒漠三维选关制作前的空间设计工作稿，供后续草图、灰盒和美术交接继续使用。<br>
**状态**：2026-10-02 草图已选作首轮灰模起点；已生成独立三维审阅候选，地理与美术尚未冻结，未改游戏入口或世界观正文。<br>
**最后核对代码基线**：commit `856ac640c5c1705b2c2ea3bacfebc35e5fd14fff`。工作区存在其他装备施工，本稿不包含那些变更。

本稿接续“规划荒漠基地楼顶布局”的讨论，先解决两城方向、同一基地的前后门、军阀进攻撤收、跨城贸易与水源之间的关系。推荐骨架是：**城市北缘的监狱低台地，东向练习场与废城，西南向堕落城，东北向军阀机动走廊，西谷容纳后期残部基地**。

坐标、地点、道路折线、范围和关卡对应以 [草图数据](design-data/desert-spatial-draft.json) 为唯一参数源。坐标用于比较方案，不是现役地图实测；本稿的图形表达不修改 AS2 权威、进关协议或现有三维模型。原会话草图保留为历史推敲材料，新稿不把其百分比布局当成已定地理。

## 2 地理母图与跨尺度规则

以同一A基地为原点，横轴向东、纵轴向北，单位公里。区域图、城市接合图和基地近区从同一组节点与道路裁切；图上放大的地标只负责识别，不能拿其宽度换算建筑占地。城市中心锚点不等于城市边界，基地可以贴近城缘而离中心十余公里。

| 尺度 | 要表达的关系 | 不承担的任务 |
|---|---|---|
| 区域母图 | 山系、机器区域、军阀腹地与战线、城市群、林区、西谷与聚落组团 | 不逐栋呈现城区，不把基地炮位放大成几十公里军事地带 |
| 城市接合 | 两城、基地、公社、宪政派、收货口、近城登陆口与道路分岔 | 不把两张旧模型的镜头方向当作地理北 |
| 基地近区 | 同一监狱、正后门、边缘通行廊、图1至图3、台地与船坞接口 | 不用横版游戏画面长度反推现实公里，不直接证明弹道或车辆通过性 |

“基地居中”指视觉组织和出发参照；区域北向纵深可以大于南向，所有公路也不必经过A。近大远小留到同一灰盒的正交与弱透视比较，不移动地点坐标来解决标签拥挤。三个尺度是设计检查工具，尚未决定玩家必须使用三层切换界面。

现有堕落城的“基地车库”和“返回”是[无世界锚点的系统导航](../launcher/web/assets/stage-diorama/fallen-city/navigation-anchors.json)。同一基地的连通不能从这些按钮的屏幕位置推导。废城、堕落城与公社的建筑接合以后要回到可编辑源，不能在本轮旋转或搬动生产GLB来强行套坐标。

## 3 正门主攻与基地近区

基地放在城市北缘向荒漠伸出的低台地。东面缓坡连练习场附近的旧道路，向外分岔：东北去荒漠干道，东南去废城。军阀沿东北干道抵达东侧展开区，因此无需穿过完整废城，也无需绕过基地再攻正门。

日常道路位于练习场边缘，训练围栏、射击方向和危险区在灰盒阶段错开。草图节点表示场景相邻与关卡返回顺序，不能把日常车流画进正在使用的靶场弹着区。

候选剖面将基地地坪设为相对低地约32米，正门约30米，图1约17米，图2约8米。这些数字只检验“低台地有东坡、外围有连续接近面”，不确定最终建筑高度、道路纵坡或地层。北、西、南侧坡坎限制大队展开，东向保留开口；不必建成四面绝壁的山堡。

图2到正门的东坡上不加一道完整高山脊把射界全部封死。犀牛需要部署后形成炮击威胁，而玩家在展开前阻止它；本稿未计算具体15度条件、弹种或落点，不能宣称已经验证越障命中。基地的防守仍由地形、监狱结构、组织与作品既定信号技术共同承担。

后门车库通过西南横坡道路接堕落城北侧路网，保留正常车辆通行。该侧的转弯、受控门、城市街巷和展开空间可以降低重装主攻效率，但不使后门变成不可攻击的安全面。小股渗透与牵制仍有空间。

## 4 军事地域与战役时间

军阀的大型据点在东北，作为这次进攻的部署来源。临时补给点从主干道分岔，有两端接入；主角袭击这个哨所，不会自动摧毁整个军阀物流网络。工业后方还分别连接据点、前线基地和图外出口。

前线基地是独立的指挥、特种部队和重整节点。大型据点失守后，长官能沿北向军用道路退入；再向西北通往雪山与禁区之间的区域战线。战线在图上代表一个战区方向，不能代替“军阀前线基地”这个真实关卡，也不能把#35的战果解释成全军阀覆灭。

| 试排关系 | 本稿几何量级 | 对设计的用途 |
|---|---|---|
| A到大型据点 | 直线约43公里；候选进攻道路约44公里 | 有明确车辆机动距离，远离基地数公里级接管覆盖 |
| 据点到前线基地 | 直线约23公里；候选路约23公里 | 是另一次地点推进，保留撤退重整与支援组织空间 |
| 基地到撤收分流口 | 直线约8公里 | A/B不必一路徒步尾随到远方据点才能观察车队方向 |
| 难民营到补给点 | 直线约3公里；支路约4.5公里 | 维持附近的征用、抢夺与取回物资关系 |
| 地下船坞到登陆口 | 草图廊道约9公里 | 保持近城地下交通，不扩张为到雪山前线的长途船道 |
| A到雪山代表点 | 直线约113公里 | 只作区域参照；峰顶、山前接驳与实际航线分开 |

以上由当前折线计算，是方案参数而非实测。道路未包含所有转弯和高差，实际旅程可更长。

主线34到35仍有一个需要明确的设计假设：A/B在近郊分流口确认车队去向及拖救状况，借地面交通返回；Andy与主角随后以可用地面交通赶往据点。这个方案不依赖刚缴获的雌鹿已修好，也不要求A/B全程步行往返约80公里。

它是否赶得上反击窗口，还取决于回收、补能、收拢部队、支援赶到的时间与观察情报。后续演出需要承认旅行时间，或用情报说明目标方向尚未恢复装甲协同；若坚持“片刻内无时间跳转”，则当前距离方案必须重新比较。本轮保留这项假设，不修改任务台词或接续。

## 5 民间贸易与聚落生存

蓉都公社位于废城北缘过渡带，具体体量分为旧工厂、住区、少量可用耕地与大片失养田网。废城视图可见其靠城工厂与道路，荒漠视图可见向外展开的农田和旧渠；同一个公社不造两套主体。其缺水、工业农业争水及未控制地下水的矛盾继续保留。

东西城缘货路从公社外部路口绕过基地南侧，接堕落城收货口；公社到联合大学的已有粮食与器材贸易不必经过A院墙。宪政派从自己的支路接城市及外围路网，也不独占A的进城入口。零件的转售顺序属于经济关系，不强制每辆车逐站进入所有组织院区。

难民营地和转运哨所分别建在干道侧支路上。营地处于可避开行洪沟底的侧谷缓地，最低水源先留“旧蓄水池或送水点”候选；供应量、控制者和持续性未定。贫穷与易控制可以解释部分存续动机，但不能保证不被清洗，也不证明军阀稳定供养营地。

残垣断壁安排在南方林区北缘附近的旧聚落服务区，以破损水工或生态设施、后搭棚屋、干渠与通林缘小路承接其历史。军阀屠杀、人口逃亡和沙暴仍是明确毁弃原因；局部设施失养是补充解释，不自动切断A的地下取水或整个AVP系统。

民间货运与军用物流可以共用部分旧设施，但没有一条全区域唯一道路。跨地表水系的道路交点必须在灰盒中落实桥涵、坡道或绕行，本轮折线的相交不证明已经有可用桥梁。

后续任务接口先复用这些功能：宝石线人被军阀劫走的强化石可以落在转运院、待发货场或押运路段，矿源仍待调查；公社求援使用城郊生产过渡带，木材委托沿南方林缘展开。依据[佣兵委托](../data/task/text/mercenary_text.json)，不因为需要画贸易线就新增一座矿山或一个正式关卡按钮。

## 6 水文与地下交通

水图与交通图共享地理坐标，但分四类关系。地下取水事实不证明最终补给源，水面可航行也不证明可饮用。

| 系统 | 本稿如何表达 | 必须保留的限制 |
|---|---|---|
| 山前地表水 | 从北西山地沿西侧低地进入盆地的主水系候选 | 穿过禁区或城市污染段；有河不等于安全可用水，不能给两岸自动铺满良田 |
| 旧灌溉与输水 | 旧分水、输水和公社支渠以断续线表达 | 污染、失养、不安全通行可使设施失效；不消除公社缺水 |
| A受保护取水 | 区域地下补给候选接当地清洁水脉，另有处理储水端 | 补给区控制权不等于取水权；与城市污水、船坞和研究排水隔离 |
| AVP自治系统 | 南方林区先维持自身生态；向A可选接一条旧处理出水管线 | 可能需要提升，接处理储水端而非直接回灌保护水脉；有限供给且不经过残垣失效节点 |

地下船坞单列为交通设施，接西北近城登陆口。剖面以后分别确定饮水取水、航道、排污的标高和隔离方式；船行方向不代替水流方向。不把“雪山—公社—AVP—A—城市”串成一根任何一点失效便让全部剧情条件崩溃的水管。

第22篇仍是[地表生态审阅稿](worldbuilding/22-行星整备与地表生态.md)。一般荒漠的环境压力与设施失养，和北区已有的武器打击、纳米灾害分别保留；本稿不把两者统一成“长昼晒干”。

## 7 后期事件与关卡对应

区域母图展示跨章节地点目录，不表示这些地点从一开始同时公开、同样完好或由同一批驻军占领。西谷秘密基地的组织状态属于牛仔收拢残部之后；道路和旧设施可以更早存在。外交驻地保留独立身份和待定营区锚点，未证明它与秘密基地或旧据点同址，暂不据此制造第四座巨大堡垒。

“袭杀与圈套”安排在禁区东南外围的运输路口，位于本稿机器范围色块之外。残部从西谷经南缘旧路接近，车队沿危险贸易线抵达，A支援从东侧维护道和沟槽进入。三者在事件区汇合，支援与残部不被画成只能沿同一最后进路追逐。该支路不是主线34的军阀进攻轴。

| 正式入口 | 草图地点与表现 |
|---|---|
| 难民营地 `stage_34_0` | 居民聚落，区域层与补给点聚合，底层身份分开 |
| 军阀临时补给点 `stage_34_1` | 干道旁的转运哨所 |
| 残垣断壁 `stage_34_2` | 林缘旧聚落，救人圈套发生于此 |
| 基地 `stage_34_3` | 同一监狱的围攻事件，覆盖外围、内部及屋顶，不只指图2炮位 |
| 军阀据点 `stage_34_4` | 东北大型驻地 |
| 军阀前线基地 `stage_34_5` | 独立指挥与重整地点 |
| 军阀秘密基地 `stage_34_6` | 西谷后期残部基地 |
| 袭杀与圈套 `stage_34_7` | 禁区外围危险运输事件区 |
| 外交军阀 `stage_34_10` | 待定现驻地锚点，保留独立入口 |

## 8 本轮反例审查与下一步

| 反例 | 本稿处理 |
|---|---|
| 北上图中废城在西、堕落城在东 | 统一东区与西区身份，镜头不再决定地理方向 |
| 军阀从据点出发，要穿城绕基地才能到正门 | 东向正门与东北干道直接接合，保留城缘地形限制 |
| 攻下一个补给哨所就让所有军阀基地断粮 | 补给哨所支路化，工业后方分别连驻地、前线和外部 |
| 秘密基地随便放在东侧 | 回查Nyx情报，移至西边谷地并重排后期支路 |
| 只说接近禁区，图却把伏击和支援画进机器控制区 | 调整范围与事件接近线，当前样例点和三条陆路在色块之外 |
| 所有公社贸易必须穿过A基地 | 保留南侧东西货路及组织独立支路 |
| 残垣失养就导致A断水，或AVP水自然逆坡北流 | 取水、局部生态、航道与可选处理出水分开，保留提升与隔离要求 |
| 近处炮位与远处据点使用同一距离 | 三尺度共用数据，但分别解释战术与区域距离 |

本轮检查覆盖当前JSON引用、正式入口集合、候选道路长度、东西方向，以及事件区和接近路线是否进入自定机器范围。它只说明这版草图没有上述静态矛盾，不证明道路通车、水量持续、炮击可达或反击一定及时。

下一轮可以直接围绕这一份草图改动：优先细化基地东坡与边缘通行廊、两城与公社的可见接合、水系交点和事件区的不同接近面。少量灰盒随后验证遮挡、体量和镜头；美术机的精细建模仍在布局与灰盒形成可评审底稿之后。外交确址、AVP补给占比和完整地下工程不必阻断这一步。

当前已进入上述灰模步骤，工具入口为[荒漠灰模空间审阅](../tools/desert-graybox/README.md)。区域、城市、基地近区共用地理锚点与物理高度场，分别保留语义分组和正式入口；可比较正交与弱透视、旋转、定位和近看。模型导出、三角形/边界与锚点复读、输入一致性检查属于候选几何证据，不能代替游戏接入或人类美术验收。
