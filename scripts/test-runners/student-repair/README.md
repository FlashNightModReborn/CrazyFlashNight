# 军阀与黑仔原生素材专项

唯一编辑源为 `flashswf/arts/new/大学人员/大学人员.xfl` 和 `flashswf/arts/new/Codex黑仔素材/Codex黑仔素材.xfl`。军阀起身以 `things0/sprite/Symbol 144` 的前 25 帧为动作权威；后续帧不属于起身。黑仔复制大学 NPC 的固定外观，普攻沿用 things0 的正式短柄动作，保留 NPC 原件。固定外观槽与关节元件使用不同名称，克隆的多段填色 `DOMShape` 保留原生 `isFloating`，并核对实际填色，不能仅检查轮廓外框。

修改素材后分别用 `scripts/compile_test.ps1 -Target <对应.xfl> -PublishOnly -VerifySwf <对应.swf>` 进行 CS6 发布。新增库通过 `things-new.fla` 第 4 帧的 `Codex黑仔素材` 共享导入锚点加载；导入关系有变化时还需发布 `things-new.swf`。这些独立素材不通过 main 或 asLoader 编译。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run-student-repair-asset-tests.ps1 -TimeoutSeconds 360
```

统一 runner 管理编译锁、TestLoader scratch、唯一 runId、新鲜诊断和恢复。不要覆盖遗留 scratch 或删除异常 marker 以绕过编译恢复。

70 个实际 AVM1 时间轴案例覆盖两种朝向的军阀起身、死亡冻结、受击、击飞落地恢复和长枪近战，以及黑仔普攻、迅斩、凶斩、霸体、MP、冷却、技能选择、受击/死亡/目标死亡中断、暂停恢复、行走、生产 Enemy AI 追击与内力成长。黑仔普攻使用 things0 的正式 `兵器攻击容器-短柄1连招`：108帧，五段，首窗第11帧，共39个刀口发射请求。残影不能占用真实武器的 `刀` 实例名；兵器使用/攻击标签保留原生自隐藏初始化。第14帧等所有窗口必须能读到真实球棒的刀口坐标。1127处普攻肢体与武器关键帧矩阵对照原生短柄。

迅斩前14帧沿后弓承重、后摆棒和转前弓举棒的路线蓄力；第13帧起加入蹬腿、送髋、胸肩前压和分拍制动，第22–27帧收后脚、抬身并降棒。第13–21帧手棒轨迹与原有刀光形状保留，首次出弹仍为第16帧，挥棒声音位于第15帧。凶斩首次出弹保持第20帧。39 / 9 / 12 为普攻 / 迅斩 / 凶斩的发射请求数，不代表实际命中次数。2026-10-07空手协同稿仅改自由手上臂、前臂和拳的2–25帧矩阵：前引、转肩、出棒回拉、制动回护；第1/26/27帧、腿脚、身体、持棒手、棒与刀光保持。实际26帧回读和独立视觉复核用于确认连接与遮挡，不能仅凭关节长度或编译通过声称视觉合格。历史前摇稿的13帧、208处原生矩阵对照不适用于后来调整的身体与收势；当前迅斩以实际发布素材连续画面、发射时点和人类视觉验收为准。

霸体仅30级及以上可用，安全距离180–350，或贴身小于105且冲击累计超过韧性上限55%，同轨偏差不超过30，要求待机、非硬直、活目标且无既有刚体。不检查或消耗 MP，独立冷却15秒，原生施法36帧，刚体持续90个未暂停帧（正式游戏30fps约3秒），不加减伤或无敌。自身死亡、目标死亡、受击/击倒/投掷中断清理自有来源；正常施法恢复不会提前清除刚体，结束不能覆盖外部写入的刚体。死亡入口同时覆盖待机零血。专项验证29/30级、距离与韧性门槛、零 MP 施放且无扣除、独立冷却、暂停、施法恢复、到期、目标丢失、死亡及外部刚体写入。脚本层关键帧明确写出12/12/11/1帧跨度，另从实际SWF读回脚本帧1/13/25/36；执行证据要求13与25帧都经过后才正常恢复，避免脚本被发布器压到第4帧。

真实迅斩同时检查前摇身体角度变化和突进前无位移，并输出原生 BitmapData 连续画面。技能发射带招式名，检查额外内力不改变迅斩威力、每点内力在一级凶斩增加9点发射威力；取真实发布素材的击倒分母，通过生产 ImpactHandler 验证迅斩在相同伤害下产生原生迅斩两倍冲击。凶斩伤害与击倒分母保持正常。迅斩水平击退默认8（配置范围4–12），通过原生受击移动和冲击状态摩擦处理。连续位图读回逐帧分批导出；增加普攻和霸体画面后，观察到完整回执晚于90秒，因此本专项异步等待改为300秒。仍要求唯一完整runId、零失败、新鲜Compiler 0/0与32K重试0；其它专项不变。冷却断言核对精确的迅斩截止值被保留以及凶斩独立截止值，而不假设批量截图结束前5秒冷却仍未到期。ARGB按两个16位段序列化，避免有符号最小整数产生无效十六进制。

测试加载已发布的两个 SWF，使用生产状态/移动/AI、技能属性与伤害公式、刀口发射核心和死亡位图渲染。人物数值、装备输入、音效/奖励和出弹接收端是隔离夹具；军阀落地信号是夹具，落地后的恢复播放使用真实素材。军阀击飞按原素材停在第 9 帧等待落地，不强行播放至第 17 帧。原生 BitmapData 读回同时检查尸体连贯范围、身体几何与黑衣填色。

此专项不读取真实玩家档案或写存档，不覆盖随机长枪换装、完整伤害命中结算、关卡地形和玩家物理输入。最终视觉、招式节奏、实战强度与正式入口验收仍须游戏实测。共享大学素材回归可另运行既有 `university-enemies` 专项。

黑仔允许单位参数 `技能配置.内力加成`（默认 0；负数或非有限值回退 0）、`技能配置.内力每级` 与 `技能配置.内力成长起始等级`，成长为 `max(0,等级-起始等级)*每级`，加在显式内力加成之后。非法等级、负增长或非有限增长回退0；专项检查10/20/30级、非法输入及两种朝向。单位传入的整份技能配置覆盖XML配置，平坦内力实验不会暗中叠加XML成长。`技能配置.迅斩冲击倍率` 默认2、有效范围1–4。内力只加在敌人标准初始化完成后，固定皮肤不跳过武器属性初始化。独立敌人对当前目标单订阅生产 hit / ToughnessBroken 事件，真实迅斩命中/破韧给出有时限的凶斩机会。NULL几何事件、免疫击退或刚体的普通命中不授予位移机会。打开 `黑仔标定观测=true` 时记录招式、结算伤害、真实破韧、招式序号、起手距离和借势标志；更换目标、目标死亡或自己死亡解绑。NULL 几何命中不计入，伤害记录包含过杀，不能当作净 HP 扣除。观测读取已加载的 DamageResult 身份，不将完整伤害/特效闭包重复编入素材 SWF。关闭该标志时只保留AI必需的当前目标订阅，不输出标定消息。

黑仔私有AI将凶斩常态起手限定在水平105–140、同轨偏差≤20；迅斩实击后允许90–135借势，迅斩范围70–230。距离基于本轮发布素材真实刀口bounds：凶斩前两窗约81–158、后两窗64–130。贴身且凶斩就绪时以原生行走短暂退步，单次≤600ms/45px、间隔≥1800ms，保持朝向、地图碰撞和每帧一次移动；受击可中断。迅斩成功后仅在自身恢复结束时解除两招之间的通用等待，独立5秒/8秒冷却照常，迅斩、凶斩和霸体均不检查或消耗 MP；贴身退步也不以 MP 为条件。专项同时验证两种朝向的贴身/超距拒绝、轨道偏差、退步预算/中断、NULL/刚体/击退免疫守卫、目标切换解绑、机会过期、原生迅斩→凶斩发射窗口。事件输入是夹具合同，不冒充完整伤害命中；真实命中和击退空间仍由下一段的实际斗兽证明。

实际斗兽须另走 `tools/arena-calibration/run-unattended.js`，使用独立测试存档、冻结 manifest、实际候选身份和素材哈希，并保留原始结果及存档保护回执。蓝方原生 HP×3 与黑仔 MP÷10 会影响同等级对比，等资源实验需要显式校正初始化参数，并从真实初始化及结果读回确认；这不会修改场地或普通游戏数值。原生专项、真实斗兽和玩家亲测分别报告，不互相替代。

影子与零 MP 专项加载实际发布的黑仔和体育老师 SWF。黑仔普通动作统一引用库内已能正常发布的原生影子 `Codex黑仔/原生/sprite/Symbol 3`，击倒补齐地面影子层，迅斩、凶斩和霸体的动作 XML 不变。血腥死亡有七个随机分支 a0–a6，各自在末帧移除人物；检查覆盖每个分支的存续帧，不能将整个随机动作当作固定49帧。体育老师实际AI选择的燃烧指节、虎拳、日字冲拳、破极拳、旋风腿和平踢在 MP0 下发出攻击；诛杀步只执行追踪移动指令。库内闲置玩家技能容器的 MP 条件不能作为体育老师实际出招规则。
