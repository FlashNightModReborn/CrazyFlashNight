首个源码提交为 `8bddc78b9b275a755e2cb70c4d2a22439631cc5b`，其原生源码审计、路径预算与 AS2 归属三项远端检查通过。v1 本机构建取得 43 文件产物及 X509 签名；生产门保留三项失败：隔离目录尚未恢复 Playwright 依赖、材料目录 sidecar 未随本批输入更新、套装名称缺少统一要求的“套装”后缀。名称修正为“统合61号工程·全装型套装”，五件物品名、套装 ID、数值与事件逻辑保持不变；材料派生差异经审阅后重建，依赖从现有锁文件恢复。此后使用新的 v2 源码标签和 immutable request，不改写 v1 原件。

v2 冻结前同步远端 `765da3371482b899e903dfed202259168bf081ac` 的两份 NPC 对话 XML 增量；本轮 AS2、C# 与原生构建输入没有因此变化。没有强推覆盖远端更新。

另一次生产门在开始检查前因生成后的 Git 文件状态拒绝执行；八个文件逐项证明 filtered Git blob 与冻结 HEAD 相同，刷新 index 状态后源码树仍完全一致。该次没有生成政策回执，原日志保留。

隔离 checkout 还暴露了原稿归档的换行转换：SVG 内容一致，但 Git 的 CRLF 转换破坏了 manifest 的逐字身份。24 项原稿均先对主目录原件核验哈希，再按原字节恢复到隔离目录，并为该归档路径添加 `-text` 属性；保留原 manifest，不重算哈希接受漂移。现役 XFL 与已编译 SWF 没有因此改变。
