## 范围与选择

NPC 功能菜单使用现有 NativeHud 的 C# 合成窗口，复用 NativeHudTheme、NativeHudFonts 和 Flash 1024×576 逻辑坐标。打开菜单不申请 Web Panel 的暂停租约。对话、商店、雇佣、任务、技能训练仍调用现有 AS2 领域入口，任务优先判断留在原 NPC 点击调用链。

查看详细菜单、修改详细菜单的“开发中”界面退役，保留同名兼容对象及默认禁用的 `npc.viewDetail` / `npc.modifyDetail` 扩展标识。此轮不实现单位编辑器，也不迁移普通对话框。

注释采用一份 AS2 内容聚合结果、两套展示实现：场景中的注释由 C# 绘制，Web 面板中的注释由共享 tooltip 模块绘制。复用原 TooltipComposer 的装备实例与技能规则，不让 C# / Web 各写一份业务计算。没有新增常驻全屏 Web 合成层。

## AS2 兼容与发布范围

主时间轴三个旧实例通过 `_root.__nativeMenu` 接到 NativeMenuBridge 的同名普通对象。NPC 素材中的 `_visible → _x → _y → 当前NPC → 刷新显示()` 调用保持不变；不改全局 MovieClip 原型，不逐个重编 NPC 素材。

NativeMenuBridge / NativeInteractionContext 由 BootSequencer 引用并编入 asLoader；主 XFL 的实例生命周期接线另需发布 main。逻辑注入文件与主文件必须分别验证，发布 asLoader 不能代替 main。兼容路径与连接失败行为以当前 NativeMenuBridge / NativeTooltipBridge 实现为准；旧素材兼容仍须通过实际 SWF 调用验证，源码扫描不能代签。

场景身份复用世界上的普通对象 token；NPC 目标另存普通对象 token。AS2 的 MovieClip 引用可能重指向同路径的新实例，因此不能仅按目标名字或旧 MovieClip 引用接受迟到动作。

## 交互协议

AS2 使用 `ServerManager.sendTaskToNode("native_interaction", payload, null)`。外层 payload 包含 `version:1`、`kind:menu|tooltip`、`op:show|hide`、`requestId`、`sceneId`；show 的 `x/y` 是 Flash 逻辑锚点。

- 两路共用 NativeInteractionContext 的全局递增请求号 `ni:<正整数>`，场景切换不重置序号。
- 场景切换先撤销旧浮层，再轮换 sceneId。hide 只清理相同 kind/requestId/sceneId 的当前实例，不因另一种浮层有更新 show 而拒绝匹配 hide。
- menu.show 带 `targetName`、`title`、`actions:[{id,label,enabled}]`。动作闭集为 dialogue/shop/hire/task/train。
- Host 通过现有 cmd 通道返回 nativeInteractionAction / nativeInteractionCancel，携带 version/requestId/sceneId，动作另带 actionId。AS2 重新验证场景、目标 token 与当前动作资格，并在执行前消费请求。
- 断线、失焦、面板压隐、场景切换及关闭的收敛由现有宿主生命周期承担；键盘与滚轮复用现有输入观察。不得新增另一套全局钩子。

## 注释语义文档

`document = {version:1,title?,icon?:{kind,name},profile,layoutType?,sections:[{role,runs:[{text,color?,bold?,italic?,underline?,fontSize?,fontFace?}]}]}`。

profile 为 simple/dense/pinned；role 为 intro/description/body。标题和 run.text 均是纯文本。旧 HTML 的 font/b/i/u/br/p 与实体在聚合边界解析一次，C# / Web 不得再次解析文字中的 `<b>` 或 `&amp;`。渲染时只进行各自绘图或 HTML 安全转义。 可选字号为 1–96 的整数，字体名经过字符及长度限制并由运行时字体目录映射，不接受任意 CSS；3 位颜色展开为 6 位。样式随嵌套、换行和分片保留，测量与绘制须采用一致的字体与样式。

名称查询与真实物品实例投影保持区分。InventoryPanelService.buildTooltipProjection 应使用已经校验的真实实例、强化/进阶/配件及 getData 外观覆盖；展示不能重建运行态装备或将实例默认成一级。旧 introHTML/descHTML 出口暂留，Web 消费者有有效 document 时优先使用，缺失时保留原展示。

Host 的严格响应不能因可选 document 全局放宽。文档经有结构和长度上界的 sanitizer，原请求关联、领域字段、未知字段拒绝及迟到响应规则保持。AS2、Host 的手工投影和 Web 调用点都要实际接通，不能把共享 API 存在称为生产迁移完成。
