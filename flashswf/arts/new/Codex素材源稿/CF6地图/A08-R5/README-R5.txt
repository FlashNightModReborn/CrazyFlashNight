CF6 A8 赛车 R5：驾驶舱、玻璃与枪架遮挡返修

基线 A8 R4。只改 1823 赛车，其他地图不改。画布 411×144、原注册点与场景矩阵保持不变。
主要修正：
1. 驾驶舱独立绘制座椅、仪表台、方向盘和远侧内壁，保持不透明；玻璃随后以 0.16–0.22 左右的透明着色/反射叠加，不穿透车体显示外背景。
2. SVG 分组 cockpit-interior-r5 / cockpit-glass-r5 / cockpit-frame-r5 保留独立可编辑性；另有分组单独 SVG 便于装配。
3. 远侧枪先画、再画车体，枪向下移 4 单位，让车壳自然遮蔽下部底座。近侧枪最后画，保持前景关系。
4. 原被视为风挡加强筋的结构现按枪架支撑处理：较短三角斜撑直接接机匣和底座，不跨风挡假装车体构件。
5. M134 仍使用项目原生枪管矢量与同源参照重绘的机匣/马达；不宣称整枪原封复用。

运行：python source/rebuild.py
依赖：Python3、Pillow、numpy、scipy、fontTools、Inkscape。全部参考已随包，无网络/原SWF依赖。
可编辑 SVG + 程序化微纹理混合，不是全纯矢量。预览为原关卡矩阵重组，不是实机截图。未做 Windows/Flash 导入或玩法验收。
主源：source/vehicles_props.py，car / cockpit_r5 / gun_cradle_brace_r5。
复验：qa/car-r5-local-scope.json、qa/source-validation.json。

R5 追加：按原图可见轮廓估计，风挡前下角由 (311,47) 改为 (319,60)，上前缘改至 (322,30)。同步调整黑色前舱盖交界、银色门肩终点与仪表台。不是整片玻璃下移。原图坐标是栅格视觉估计，不宣称恢复原始矢量。近侧三角枪架随前边界调整；远侧同构枪架上部露出、底部被车壳遮挡。
