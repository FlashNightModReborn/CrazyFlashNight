## 动作与联动

| 动作 | 来源与接线 |
|---|---|
| 站立、行走 | 原 901/902 时间轴；行走兼作跑步外观 |
| 重劈 | 原 910，37 帧；第 20/22 帧各一次 ×2.4 物理判定；第 9–18 帧通过真实移动接口压进，每次至多 8 像素，接近目标 185 像素时停止 |
| 横扫 | 原 912，49 帧；第 19/22/25/28/31/34 帧各一次 ×1 物理判定，前后各三次 |
| 波光束 | 原 906，31 帧；保留 903/905 原生特效，第 11 帧一次 ×1 魔法／波判定，选择射程 250–600，冷却 90 帧 |
| 受击 | 原 913 的两个分支，分别在第 8/19 帧回到正常状态 |
| 击飞、倒地、被投 | 原受击姿势衔接 CF7 浮空、落地和恢复生命周期 |
| 死亡 | 原 924 的完整 58 帧、916–923 八组机械碎片，最终结算一次 |

重劈使用水平击退速度 24、垂直速度 0。收招后保留 45 帧的同目标联动窗口；目标仍存活、实例身份一致、进入射程、纵深合适且光束冷却结束时，优先接光束。目标没有实际被推远时不强制改坐标；同名新实例也不能继承旧联动。

重劈第 1–30 帧、横扫第 1–40 帧、光束第 1–11 帧持有临时刚体与抗击退，正常承受伤害；收招、中断、死亡后恢复此前状态。仇恨仍由通用 AI 提供，私有控制负责距离、纵深、招式和动作 token。暂停或外部硬直会阻止新命中，旧剪辑不能继续出手。高度超过 80、但不超过 150 像素的目标，仅在 190 像素内选择横扫。

重劈与横扫的区域高度分别为 180/200 像素，光束区域跟随原特效横向跨度。它们通过 `攻击点.area` 和正式 `子弹区域shoot传递` 结算，子弹速度为零；没有直接扣目标 HP、百分比伤害或强制进入联动射程。命中率输入 30，仍进入正式闪避结算。

## 公共击退修正

实际命中夹具暴露了共用敌人模板回调中的作用域错误：`this.speed -= 减速度` 读取不到单位自身摩擦力，会得到 NaN。修正为 `this.speed -= this.减速度`，其他代码和文件编码保持原样；同时经真实 CS6 重新发布 asLoader。

原函数逐字抽取的独立夹具先得到 2 passed / 5 failed，修复后 7 passed / 0 failed，覆盖左右移动、独立摩擦力、暂停式硬直、抗击退和有限停止。大刀专项为 **409 passed / 0 failed**，28 组真实时间轴动作、15 状态 × 2 方向，并包含三组正式伤害／冲击／被击移动的集成夹具：两侧目标从距离 185 被推到 308 后各接一次有效光束；抗击退目标保持 185，不触发联动。这是隔离夹具中的实际生产函数验证，实际对战结果另列。

共用修正后，大头机器人另跑 18 场全部获胜，翼虎专项 389 passed / 0 failed。旧 asLoader、失败尝试、原始编译和恢复回执保留在新证据包中；不把旧测试结果自动升级为新资源结果。
