## 转写试跑与资源预算

本机可用 `ffmpeg 8.0.1`，并安装了中文 Windows Speech Recognizer
`MS-2052-80-DESK`；没有可调用的 Whisper、faster-whisper、Transformers 或
ONNX ASR 入口。本次最低码率音轨下载量约 2.65 MiB，转为 16 kHz 单声道 PCM
约 12.9 MiB。

60 秒 Windows 离线识别试跑返回 0 条识别结果；完整异步试跑未能稳定完成。
这不足以产生可用转写，所以状态保持 `pending_transcription`。PaddleOCR 对故事板的
服务器模型在 CPU 两线程下可用，但首批十格约需 91 秒；它适合少量章节卡核验，
不应冒充音轨转写，也不应在本机有其他压力时全量跑图。
