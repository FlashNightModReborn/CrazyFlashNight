# 黑铁会总部：游戏集成与E4收口

2026-09-20。当前范围为现有 Web 选关集成。用户在E4交付后回复“可行，提交推送”，整体认可本轮结果并授权提交；这不补造未执行的逐项游戏进关、返回或目标GPU验收记录。本轮没有修改真实存档、C#/AS2领域协议或正式runtime。

## 如何验收

### E4：选关标签与连接线（本轮采用版本）

用户反馈整体方向可行，测试群指出标签排列及连线辨识仍需改善。截图显示“总堂外围”和“黑龙堂外围”的连线穿过了其他标签；E3的规则只排除了方框相交，没有排除连线关联歧义。本轮只改选关UI，不调整已认可的镜头、模型或外围街区。

- 地图标题已经说明黑铁会总部，地图标签采用“翅虎堂·外围 / 内部”“总堂·外围 / 内部”等短称，并统一为104×32的单行标签。无障碍名称、悬停资料、简报和进关请求保留正式全称与原ID。
- 翅虎与火凤向左标注，黑龙向右，总堂、支援事件、外交分别就近安排。派生规则同时约束标签/标记碰撞、连线穿过其他标签与连线交叉，不再只按空隙塞方框。
- 总部与废城共用SVG连接线：2.5逻辑像素的浅金线配5像素深色底边，悬停/键盘焦点/选中时加强到3.5像素。连线裁切在圆点外缘与标签外沿之间，不穿过自身标签；连线不截获点击。
- 键盘聚焦入口时也联动建筑高亮。旧关卡状态、锁定原因、难度、外交直达与返回协议不变。

已在三种总部固定视角检查实际DOM/SVG：名称和40像素标记可点，无重叠/越界，连线不穿其他标签或互相交叉，简写后完整accessible name保留。废城原布局保持，新增清晰连接线并跑既有回归。用户已整体认可E4；自动检查仍只证明其明确覆盖的范围，不升级为全部真实游戏旅程已通过。

### E3：以街区走势暗示方圆（模型方向获认可，UI由E4改进）

用户认为E2地纹过于刻意，本轮撤掉圆环描边、界石和太极地纹，同时移除“方圆纹样”开关。默认仍为原镜头放大12%；三种镜头对比及“周边环境”开关保留，总部核心GLB、11个入口与内部布局未改。

外围改为三条不闭合、宽度略有变化的旧街/支路：西侧旧街轻微外弯，前街外侧支巷与直行主街相接，后侧检修路沿坡脚转折。西侧和前方房屋随道路转向、错开退距并留空地；后侧只用部分挡墙与浅沟延续边缘。东侧货场保持矩形工作地块。没有统一圆心、完整S线或阴阳点，宗教意味只作为疏密和外围轮廓的设计含义。

主门直路、东西侧接近路线和后部中央检修进路继续开放；新增房屋先避让路带、总部占地和检修开口，再生成带转向的体块。当前外围21栋低层体块，约10,380三角形、3次绘制；实际画面的观感和生活合理性仍由人类验收，不以自动生成的避让规则代替完整导航或人群模拟。

必要检查已覆盖实际GLB载入、默认/原镜头标签与命中区、环境开关、特写返回，以及旧纹样控件已移除。请重点看：外弯街道是否自然、房屋是否像沿街生长、外圈是否仍显得像刻意画出的符号。可用“原镜头”多看一点外围，再与放大版比较。

### E2：原镜头放大与方圆纹样（已被E3替代）

按用户反馈，默认切到 **“原镜头·放大”**：保留原来的36.5°俯视、偏侧22.7°，将画幅跨度从约310.96减到277.64，主体线性放大12%。左下角仍可切“原镜头”和“正面俯视”，并分别控制“周边环境”和“方圆纹样”。11个入口世界坐标和内部布局不变，显示位置重新校核。

设定依据：[敌人对话原文](../data/dialogues/enemy_dialogues.xml)中的“堂主称圆，圆即圆满，延申方正。圆满方正，即是维护教义，监察教行。”位于当前文件444行；[黑铁会前身](黑铁会前身.md)说明自治区的道教思想背景。此处把“方形总部＋外部圆弧”作为建筑语言，**天圆地方、太极铺装仍是本轮视觉提案**，不据此添加已经实装的宗教仪轨或政治制度。

外部圆环半径118、铺装宽3.4相对单位，采用旧铜/暖石色，与现有直行道路、建筑相遇时断开；低界石也避让道路。西侧候礼小坪增加低对比太极地纹，属于门外装饰，不新增第三座主祭坛、不增关卡，不改变已认可的两级祭仪分工。其余低层街坊和后勤场继续保留。

E2纹样增加约1,792三角形及1次绘制，可独立关闭。默认总览实测约66,236三角形、46次主画面提交，后期另计。已核对默认放大视角与原镜头的22个名称/命中区、纹样/环境开关及特写返回；实际游戏观感由人类验收。重点看放大后总部是否更突出，圆环是否像园区秩序与仪式铺装，以及太极是否过于直白或抢眼。

### E1：默认镜头与外围环境候选（上一轮）

本轮默认改为正面偏侧10°、俯视47°的正交镜头，画幅跨度300相对单位。总部总览左下角新增 **“正面俯视 / 原镜头”** 和 **“周边环境”** 开关；两种镜头均可开关外围，便于分别比较镜头和接地效果。切入关卡特写时隐藏这组对比控件，返回总览恢复所选镜头。实际观感仍由人类决定，本轮没有宣布E1通过人类验收。

外围为独立的程序化布局候选：连续地面和前街、西侧低层旧街坊、东侧装卸/货棚、后侧坡面与检修联系。没有增改总部GLB或11个世界锚点；外围不参与关卡命中，中央后部检修进路保持开放。周边37栋低层体块，约11,102三角形，合并为3次绘制；1024×576默认总览实测约64,444三角形、45次主画面提交，后期另计。材质和细部是本次环境试样，不等同新的全套美术精修。

请重点比较：正面主次是否更清楚、地表延伸到画框后是否仍有沙盘底板感、左右环境是否抢戏，以及公祭坛/各堂是否更容易看清。可先固定“周边环境”比较两种镜头，再在喜欢的镜头下切换环境。

镜头和标签由 `tools/lib/blackiron_presentation.py` 确定性派生，外围源为 `stage-select-blackiron-environment.js`。新候选取景预设与旧版隔离，旧值未删除。2D回退继续使用采用包的原镜头截图，并切回其对应屏幕锚点，避免把新镜头坐标投到旧截图上。后续堕落城复用可独立选择外围，不与总部核心资产捆绑。

本轮最小检查：两种镜头的22处名称/命中区无重叠且可点、环境开关恰好增减3次绘制、特写返回保持所选镜头。没有追加实际游戏操作验收。

从项目正常游戏入口启动，进入已有角色后打开选关，切到“黑铁会总部”。如果游戏已在施工前启动并缓存旧JS，请正常退出游戏后重开；这轮不需要重新编译Flash或部署C#。

重点观察：

1. **总览**：暖色夜景、四层台地和虎/凤/龙/铁是否清楚；11个入口名、鼠标命中是否合适。总部边缘先于翅虎，未新增序号或入口。
2. **内外与事件**：分别点翅虎/火凤/黑龙的外围和内部，看特写与高亮是否对应；总堂与被攻击事件共用总部模型。
3. **出战与返回**：简报、情报、真实锁定/任务和难度仍来自游戏。按原流程确认普通进关、战后/选关返回、修炼场外交直达。
4. **换页与游览**：总部→基地门口→基地车库→总部，模型不能串页；游览退出回原取景，进入特写和返回总览不卡住。
5. **表现与恢复**：留意实际窗口/显卡上的载入、柔光和鼠标响应。总部3D失败应仍能使用二维入口，重试可恢复。

上述是观察提示，不要求额外填写制式表单。直接指出发现的问题或确认可以继续即可。
