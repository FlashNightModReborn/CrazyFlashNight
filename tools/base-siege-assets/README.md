## 玩法与对白

第一图先独自击退突击兵和狗，再由本关普通制式兵种470/471的A兵团战士A/B以Lv20入场，共同打退编组追兵，结束后介绍中继任务。两人使用制式五件套、战斗专家军牌和AK74/m14等普通进阶武器，不沿用后期兵种280/281的精致套与精锐项链。第二图两名友军继续参战；第一波结束才通过对白开放操作，操作后防守第二波，完成后两人留下。第三图由玩家补上伤亡小组的中继，守住后回基地。

防守目标复用废城环线的 `特殊友军-保护仪器`：友方、5000 HP、threat=30；反扑单位的threatThreshold=15。原生单位负责受击、仇恨与死亡事件，本图只隐藏其旧机体并对齐当前中继的受击框。设备摧毁进入原失败流程，第二波通过既有WaveSpawnWheel事件触发。没有额外的每帧索敌、设施扫描或手写敌人移动。

基地五图保留原波次、数量、等级、间隔、出生点、友军和出口。`source/original-base-combat.json`记录施工前配置指纹，验证器逐项核对。屋顶只以对白交代BPK护送小F进入旁侧设备楼并在楼内恢复链路，小F不生成到玩家视野；清敌后结束对白即进入原通关，没有护送距离、站位确认或维修计时任务。屋顶保留原4块碰撞，R4包内新增2块不用于本轮原版玩法。

## 资产与性能

三张变体的编辑源在 `flashswf/backgrounds/gk1_3_BG_围攻/`、`gk1_2_BG_围攻/`、`gk20_5_BG_围攻/`。线圈、中继、屋顶机体、设备分别在 `base_siege_coil/`、`base_siege_relay/`、`base_siege_hind/`、`base_siege_equipment/`，通过Instances加载。当前地图中的佣兵为新画的深色短寸，参考SVG不覆盖继续编辑的XFL。

两张外围背景不再烘焙完整固定线圈；独立线圈SWF在场景启动时即加载并负责实体和人物遮挡。R5宿主包含73帧tower↔shield与49帧tower→interference机械路径：互动先逆播shield回到共同tower，再正播interference；稳定后停帧并删除观察器，异步重载直接停干扰末端，不重复展开。柜体帧1/2/3为过载/断电/恢复。机械变形期间关闭cacheAsBitmap，稳定后只缓存静止机体与中继；电效子时间轴独立播放；大背景沿现役贴背景图流程烘焙。

常驻目标栏及其文本重写已移除。控制器只在外部素材/保护单位尚未就绪时短暂观察，初始化完成即删除onEnterFrame；防守战和基地普通房间没有常驻检测。专项测试记录旧空闲轮询片段的脚本耗时，该探针不测渲染或完整游戏帧率，不据此断定卡顿根因。

## 设备载入与修改器

第一图追兵的两个刷新点与A/B入场点统一置于左侧。主角继续出生在右侧残骸旁。

中继与屋顶道具使用MovieClipLoader的onLoadInit回执和资源根路径。载入完成后重置位置、缩放、状态与深度，并刷新静止玩家的互动候选。失败最多重试一次；HeroMoved只检查两件道具是否仍有内容，发现移除/空壳才启动一次短暂恢复；没有常驻帧扫描。替换道具前注销DepthManager记录，避免同路径MovieClip引用复用留下旧深度缓存。

修改器原有“完成当前地图”调用StageManager.debugClearStage：先释放本关控制器的目标门槛，停止当前刷怪器，再走原clearStage和出口。普通战斗完成仍检查设施/波次；已经结束为失败的行动保持失败终态，界面提示返回后重进，不改写成胜利。

专项runner使用BaseSiegeNativeHost原生XFL显式导入正式保护仪器素材。检查实际battle-world模板、背景烘焙、设备并行载入/移除恢复、全局互动事件、原生仪器动作/受击框及三处调试完成；HP/碰撞器和玩家为隔离夹具，不能替代标准客户端完整战斗/存档验收。首次排查的R2真实容器载入并未复现线圈消失，因此这轮不把单一根因视为已确认。

原生实体与通电效果分离，设备不会随异步效果载入而凭空出现。两张外围图的车辆统一采用防御地带高地同平面45%基准，每图两辆；犀牛图全部为犀牛坦克，猛虎图为两辆步战车。犀牛图刷新点位于最左侧，猛虎图刷新点位于步战车后侧，沿原生AI进入战斗，不添加逐帧移动脚本。

猛虎出口矩形为世界(765,610)–(820,640)，完整落在两垛沙袋碰撞内缘760/825之间。门口新增本关专用背景移除直升机与阴影，公共原图保持原样。屋顶机身由约686px校为915px，对照普通基地屋顶约917px；接地线仍为Y274，接触损伤同步缩放，设备与原四块碰撞保持原配置。第一图坠毁机也与屋顶同源总成统一使用100%缩放，并保留舱门附近锚点和原接地线。当前参数见source/revision-r5-layout.json。

## R7 屋顶与门口的同一段防线

两张围攻变体共用原生 M2 的两种损坏总成：上侧枪位断管、下侧枪位枪管下垂。枪体、残管和佣兵沿用原生轮廓、色块与线宽；沙袋局部开线、漏砂，枪位内侧有弹壳。门口视角同步移除原有两座完好 M2，加入对应的受击枪位和两名枪手；墙面与屋面弹着点分别按各自平面绘制。

屋顶为四名静态阵亡守军：两名贴近右侧枪位内侧，另两名沿通往左下入口的撤离路线倒地。地面扫射痕迹分段穿过该路线，避开设备楼；弹药殉爆限制在原储放区，使用原生弹体的断段与局部焦痕，删除 R6 的整块简笔残骸和线缆。此轮均为背景布景，不生成战斗单位，不改碰撞、出生、波次或奖励。

权威源仍为两个背景的原生 XFL。`refine_roof_r7.py` 重建本轮独立图层，`source/r7-*.svg` 保存可编辑表面细节，`source/revision-r7-detail.json` 记录两视角的枪位与阵亡位置。编译、读回与静态预览不替代标准客户端的人眼画风验收。


## R8 受弹枪位与六名佣兵的身份区分

当前屋顶及门口使用 R8 枪位与阵亡图层。上枪位保留完整原生枪体及承托三脚架，在机匣上表现受弹失效；下枪位为整枪、整副支架倒在掩体内侧。替换 R7 的截断枪体、旋转残管和花瓣状沙袋破口，沙袋仅作局部压瘪、开线和少量漏砂。既有屋面扫射、墙面弹着点与储弹区殉爆位置保留。
