# 版本记录

从左侧选择版本查看更新内容。带“整包”的节点可以在 GitHub Releases 下载；“公开视频”节点提供当期前瞻。当前开发节点同时维护下一期更新视频提纲。

## 2.718 · 当前开发

**状态：E 阶段开发中**

2.718 是 AS2 权威迁移期间持续推进的开发阶段。主线剧情尚未进入下一大阶段，因此版本号仍以 2 开头；形成稳定玩家包时才会追加下一位。

### 玩家正在获得的变化

- C# 启动器逐步接管启动、存档传输、主要数据权威与多存档流程。
- 选关、仓库、理发店、设置与关卡结果等常用流程迁入启动器面板。
- 商城、仓库、角色构筑、竞技场与装备调制复用双栏工作台，候选、槽位、拖放与物品注释趋于一致。
- 佣兵换装、双药剂组，以及装备进阶、插件变换与强化度交换扩充构筑能力。
- 军阀演习、佣兵标定、黑市鉴定和跨子图限时关卡进入源码。
- 增加物品与击杀播报，并将高频打击伤害数字迁入原生层。
- Web 界面音效与静音偏好跨页面统一。
- 关卡结果、奖励领取、返回基地、转场与复活恢复形成连续流程。

### 本轮前门收尾

- 新存档可在 Launcher 内完成角色名、槽位显示名、初始外观与难度选择，纸娃娃首帧就绪后才开放操作。
- 多存档把角色名作为玩家主身份；槽位显示名用于个人整理、允许重名，并保留旧档兼容。
- 发型直接使用理发店真实目录，创建时不随机、不扩充脸型；进入游戏后仍可免费更换。
- 初始装备和发型复用物品图标、紧凑/完整视图与项目注释，减少只看文字猜外观的情况。
- 前门音乐由 Launcher 接管，在选档与建角期间播放，并在片头或正式进入游戏时让出音频焦点。

### 下一期更新视频提纲

1. **入口为何变化**：旧 Flash 前门与 Launcher 长跑宿主的任务对照。
2. **完整路线实录**：启动 → 选档/新建 → 角色创建 → 片头 → 进入游戏 → 返回基地。
3. **存档权威迁移**：多槽位、显示名、备份恢复、旧档兼容，以及为何不清洗玩家手改存档。
4. **常用界面迁移**：选关、仓库、理发店、设置、角色构筑与结算的前后对比。
5. **物品与构筑**：双栏工作台、佣兵换装、两组药剂、装备进阶与插件变换。
6. **新挑战与玩法**：按最终整包实录军阀演习、标定、鉴定、限时任务及新增内容。
7. **原生反馈**：玩家信息、打击数字、战利品、音频与动画如何避免遮挡游戏区。
8. **一局如何收尾**：结果、奖励、返回基地、转场与复活恢复的连续路线。
9. **发包说明**：最终版本号、下载位置、升级方式、已知问题与下一阶段目标。
