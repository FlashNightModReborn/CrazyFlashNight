后续 2.71 稳定整包页链接了这支 2.7 更新前瞻。视频展示的玩家变化包括：

- 界面部分展示了装备合成、情报、佣兵、任务接取和波次界面的调整。
  （故事板 `02:45`、`03:25`、`03:45`、`03:50`；部分源码见下表）
- 局外美术部分展示了 `shop girl`、`The girl`、黑龙、黑铁、将军、丽丽丝、牛仔和老兵的
  立绘优化。（故事板 `04:25`–`05:00`）
- 材料、技能与流派项链图标展示了重做版本，摇滚公园外交地图也展示了更新画面。
  （故事板 `05:25`–`05:45`；材料图标源码见下表）
- 系统机制部分展示了新的阵营划分：玩家、友军与两类敌军使用不同标识，画面说明除玩家与
  友军外，不同阵营之间会互相敌对。（故事板 `06:20`；源码见下表）
- 局内美术章节集中展示了新单位、武器装备和武器动画；新技能章节展示了多段技能演示。
  （官方章节 `11:43`、`21:51`，故事板 `14:55`、`19:20`、`21:10`、`22:10` 等）

剧情、新单位、武器装备和技能的完整名称与规则仍需音轨转写或人工逐镜核字。当前草稿只保留
