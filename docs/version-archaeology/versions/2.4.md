2.40 稳定整包页所链接的更新前瞻展示了以下玩家变化：

- 动作部分展示了手雷动作改动和人物站姿的连贯性优化。（故事板 `00:05`、`00:25`）
- 武器部分展示了炎魔斩的两种形态、毒蛛与龙炎、能量武器等美术调整；套装部分还展示了
  异形套、试作原体套装和多组通缉犯套装，并标出部分套装具有独有攻击动作。
  （章节卡 `00:50`，展示 `00:55`–`03:30`）
- 场景部分展示了欧塞城/废城的背景更新，以及诺亚前线基地工厂的入口、中枢等区域。
  （章节卡 `03:50`，展示 `03:55`–`04:50`）
- NPC/敌人部分展示了“军阀（Itinerant）”、怀旧敌人、方舟相关单位和天网机甲部队；
  其中部分单位另有技能改动画面。（章节卡 `05:15`，展示 `06:00`–`08:37`）
- 副本与交互部分展示了生存战的肉鸽化方向、新增冷兵器商人、近战武器售卖和 NPC 商店分类；
  夜视仪也展示了新增效果。（章节卡 `09:02` / `09:27`，展示 `09:07`–`10:12`）
- 技能部分展示了气动波增强、攻击段数修复、取消击中僵直、用生命/能量换取内力，以及
  新主动技能“能量盾”等内容。（章节卡 `10:27`，展示 `10:32`–`11:57`）
- 战斗机制段展示了敌人掉落数据、击飞反击、内力攻防等级拆分、特殊弹药效果，以及
  狙击弹对怪物的伤害加成说明。（故事板 `13:42`–`14:37`）
- 音乐系统在画面中明确标为“持续优化重构中”，片尾同时展示了原创 BGM；前者属于进行中状态，
  不能写成 2.4 已完成的稳定交付。（故事板 `15:07`、`15:42`）

完整技能数值、全部单位专名与口述限定仍需音轨转写或人工逐镜核字。当前条目只采用画面上
足够清晰的标题和操作说明，不根据战斗演示推断最终数值、掉落规则或发包状态。
