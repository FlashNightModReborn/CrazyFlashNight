## 1. 范围与决策

- **P0 服务面板共享动效**：换装扫描光从建角 `ccPreviewSwap` / 角色构筑 `cbDollSwap` 同签名提取进 `appearance-service.css`（`.appearance-service-swap-flash` + `appearanceServicePreviewSwap`，服务面板 canonical 版本，reduced-motion 收束）；同文件新增按钮 / 输入 / 性别卡的微交互过渡基线。建角与角色构筑两处既有拷贝刻意不动（不同文档上下文且均已人类验收），本文件起服务面板以共享块为唯一真源。
- **整形反馈补强**：接入 BootstrapAudio 语义音效（select/activate/success/unknown/rejected/illegal/back）；业务错误（如 K 点不足）改走共享 `appearance-service-error` + `role="alert"` 红行并联动面板 `data-state="error"`，中性提示仍走 hint 行；身高缩放 canvas 补 `transform` 过渡对齐建角手感；性别 / 身高变更触发扫光。
- **P1 理发店目录**：manifest PNG 图标网格（紧凑 36×36 默认 / 完整卡切换，独立 localStorage key `cf7.hairdresser.catalog-density`）；名称剥前缀（「发型-男式-黑暴走头」→「黑暴走头 · 男式发型」）；列数感知键盘导航（实测列数）+ 防跳动滚动；`aria-posinset/aria-setsize`；紧凑格悬浮全名（生产 overlay 走 PanelTooltip，无模块环境退化 title）；目录顶部「当前发型」槽卡；底栏变更摘要「当前：X → 试戴：Y」。
- **P2 性别页签**：全部 / 男式 / 女式，性别仅从 catalog name 前缀确定性解析，光头（中性）随每个页签显示；纯展示分组——不排序、不去重、不改 wire 顺序与重复行；选中试戴不因切页签丢失。计数：全部 77 / 男式 52 / 女式 26。
- **P2 全身预览切换**：脸部特写（默认，原对话 rig 路径逐字保留）/ 全身（共享 `CharacterAppearancePreview`，battle rig、七站姿合并取景、maxScale 12、zoom 1.0 / margin 12、animate:false）。理发店按试戴场景**不应用头盔遮发**（调用点覆盖共享组件的 `hairHidden`，注释标明场景化偏离，整形 / 角色构筑语义不变）。`portrait` 缺失（旧 asLoader）时切换控件完全隐藏、静默胸像。
