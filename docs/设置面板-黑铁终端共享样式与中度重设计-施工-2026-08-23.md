# 设置面板中度重设计 + 黑铁终端共享样式层（terminal.css）施工记录 · 2026-08-23

## 背景与目标

设置面板自 Flash 迁移到 Web Panel 后停留在"够用"水平：色板五色并存、~45 个一次性硬编码灰/黑字面量、无字号/间距阶梯、几乎无动效；启动页（bootstrap/welcome）与设置面板之间的共享模式是**手工复刻**，改一边不联动另一边。本轮做中度重设计，并把共享模式抽成单一真源反哺启动页。

范围边界：不动整体布局骨架（三行 shell、三 tab）、不动控件数量与 id/data-tab/状态 class、不动 AS2 与 Host 协议、不动启动页结构与其他 workbench 面板。

## 产出

### 1. token 治理（`launcher/web/css/workbench/tokens.css`，只增不改）

新增黑铁终端族派生 token，全部 color-mix 自既有 `--launcher-*` 色板，不引入新色相：

- 表面层级：`--term-surface-veil` / `--term-surface-inset` / `--term-surface-card`（收敛 7 种近黑面板底）
- 墨色阶梯：`--term-ink-hi/md/lo/faint`（收敛 19 个一次性 hex 灰）
- 控件度量：`--term-control-h: 28px`

### 2. 共享组件层 `launcher/web/css/terminal.css`（新文件）

两页（`bootstrap.html`、`overlay.html`，dev harness 同步）直接 link；不进入 `panels.css` @import 链，check-workbench-css-bundle 无需变更。

组件（结构在共享层，页面只调 `--term-*` 旋钮）：

- `.term-brand-seal` 品牌铭牌（◉ + 切角 + 锈红底）
- `.term-kicker` 等宽微型代号标签
- `.term-heading-rule` 标题分隔线（1px 全线 + 左端青色辉光短段）
- `.term-status-dot[data-state]` 语义状态点（ready/loading/warning/error）
- `.corner-brackets` 四角 L 角标（自 welcome.css 迁入，同名同旋钮）+ `.term-corner-tick` 单角轻量版
- `.term-scanlines` 扫描线
- `.term-btn` + `.primary/.secondary/.warning/.danger` 切角按钮族（含 hover/focus/disabled 与 `--wb-motion-*` 过渡）
- `.term-card` 终端卡片基座（锈红左边条 + 切角 + 表面渐变）
- `@keyframes termBoot` 面板入场

### 3. 设置面板重设计（`settings-panel.css` 重写 + `settings-panel.js` 仅加类名）

- 色板纪律：青=交互/焦点/主行动；锈红=品牌/区块身份/危险；骨金=标题；dust=次要；琥珀只剩 warning 语义。`尝试复活` 从 warning 提为 primary（主行动），与 `立即返回基地`（danger）构成两级动作层级。error 态文本从暗锈红 `#b83a2e` 改为语义红 `--wb-semantic-danger`（暗底可读性）。
- 字号阶梯 `--settings-fs-*`：8/9/10/11/12/14/20 七档（原 6–21px 十余档）；间距阶梯 `--settings-sp-*`：4–20px。
- 控件：select 自绘 chevron、checkbox 对勾居中化 + micro 过渡、range 自绘轨道/切角滑块（替代纯 accent-color）、focus 环统一 1px 描边 + 辉光。
- 页签去底盒改下划线指示；状态灯牌/关闭钮 token 化；模态层淡入 + 对话 termBoot 入场；reduced-motion 面板级总开关。
- JS 侧只新增共享类（`term-brand-seal/term-kicker/term-heading-rule/term-card/term-corner-tick/term-btn`）与复活按钮 warning→primary；DOM 结构、控件数量、id、状态 class 全部不变。

### 4. 反哺启动页（`welcome.css` / `bootstrap.css` / `bootstrap.html` / 5 个 modal 模块）

- `brand-seal`、`brand-sub`(kicker)、`bg-scan`、`pulse-dot`、`slots-header`、`modal-header`（about/archive-editor/diagnostic-log/display/repair-card 五个模块统一加类）切换到共享组件，页面文件只留 `--term-*` 旋钮。
- `.corner-brackets` 组件定义从 welcome.css 迁入 terminal.css（同名，`bootstrap-main.js` 动态加类的槽位卡不受影响）。
- `state-badge` 三色从自造绿/橙/暗红收敛到 `--wb-semantic-success/warning/danger`（welcome 覆盖层与 bootstrap fallback 双份同步，消除漂移）。
- 删除 welcome.css 四个从未接线的死 keyframes（scan/breathe/pulse/hum）。
- 未动：`bootstrap-main.js` 全部状态钩子 class、`--user-fs-scale` 注入、`has-art` 内联背景、view 进出场时序；bootstrap.css↔welcome.css 的 modal 双份维护属既有结构性债务，本轮仅登记不扩张。
