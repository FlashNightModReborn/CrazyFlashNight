# 对白权威迁移 wire v2：协议全文与分期立项（2026-09-16 冻结稿）

**文档角色**：对白系统从「AS2 权威 + C# 呈现」迁移到「C# 持会话节奏、AS2 持数据装配与责任代理」的协议级立项。本稿是 Wave 1 六路调研（`tmp/dialogue-authority-study/`）的收敛结果，供 Wave 2 对抗复核与外部架构裁决使用；**尚未授权实现或发布**。

**输入报告**（本稿不重复其证据，只收敛结论与裁决）：
X=AS2 权威依赖全图、Y=C# 设计空间、L1=生产者形态穷举、L2=潜伏路径实查、L3=暂停/事件对抗、L4=协议字节级对抗、L5=帧泵判定与预算复核（均见 `tmp/dialogue-authority-study/*.md`）。

---

## 1. 背景与目标

现状：AS2 `NativeDialogueService` 持会话（句序/finish/cancel/暂停 claim/followingEvent），每句发一帧快照给 C# 呈现；advance/close 经 socket 回 AS2 裁决再发下一句。

目标分两步：

- **方案 A（一期）**：会话入口整本下传（`op:"book"`），C# 本地驱动换句/打字/换图/预取；AS2 保留剧情权威（finish/cancel/followingEvent/claim 原样），终态走 `verb:"finish"` 回执。
- **方案 A+（二期）**：静态对白源的装配也迁 C#（C# 直读 stage XML 对白/task 文本/NPC 固定对白——多数已在 `DataQueryTask`/`XmlDataLoader` 现役管道内）；AS2 只回答身份/外观快照查询与动态佣兵人格对白。

**明确不做**：followingEvent 发布（dispatcher 在 AVM1 对象图）、暂停 claim（PauseManager claim-OR）、外观冻结（读活 MC）、facade 桩化（AVM1 显示列表行为）、佣兵人格对白选择逻辑、AS2 零对白状态。

## 2. 收益核算（L5 修正版，取代 Y 报告原始口径）

| 项 | 量级 | 依据 |
|---|---|---|
| advance 典型延迟 | 现状 ~8–25ms → A 后 ~4–12ms | L5 真探针 117 样本：命令路径事件时刻分发，**帧泵税不成立**（Y 的 ~16ms/句帧边界税作废）；现状主导项是 AVM1 工作段+C# 合并窗 |
| 延迟尾部 | 现状 ~110ms → A 后 ~35ms | 尾部=主线程长脚本占用+33ms 合并窗，A 移除 AS2 工作段 |
| AVM1 帧内 CPU | 每句 ~4–8ms 归零（A 后） | c 段 parse+stringify+socket 真实成本，低帧机直接还帧预算 |
| GC 对象数税 | 持久池数千~万级对象（task_texts/MercLibrary/enemy_dialogues），单次 GC 标记的 1–5%；A+ 后大头退役 | X/L1 对象盘点；AVM1 标记成本∝对象数；随内容增长只增不减 |
| 链路稳定性 | book 单帧原子采用，消除 v1 每句一次的部分失败面 | — |

**诚实口径**：典型感知收益是 4–13ms/句 + 尾部收窄 + 帧时间归还 + GC 减压，不是"去一帧"。

## 3. 权威划分（A 一期）

- **C#**：整本行副本、当前句 index、本地 revision（每 requestId 单调 ++，与 index 方向无关）、换句/打字/立绘/配图状态、closing 暂定终态。
- **AS2（escrow 代理）**：会话生命周期（beginSession/finishSession/cancelSession 原样）、followingEvent 持有与一次性消费、stage claim、追加/覆盖入口语义、场景 teardown 取消、发送失败/断线兜底、facade。
- **共享不变量**：requestId 由 AS2 唯一发号（`nd:<n>` 单调）；`_maxSequence` 前沿 + hide 墓碑语义零改动；socket-only 边界（Web 不可伪造）零改动。

## 4. wire v2 协议全文

### 4.1 版本与能力握手（caps-required）

- `native_dialogue` task 内 v1/v2 共存；`TryParse` 按 `version` 分派，未知 op fail-closed。
- **caps 下行通道 = `bootstrap_handshake` 响应捎带**（callId 回调路由，免疫 rewardPending 门，零新增 wire 面）：C# 在握手响应中附 `dialogueCaps:{modes:["snapshot","book"]}`。
- AS2 侧三条纪律：① caps 闩按 socket generation 作用域，`onSocketClose` 清闩；② **未见本代 caps 不发 book**（旧 Core 收 book 会静默丢→会话悬挂）；③ `wireMode` 按会话闩于 beginSession（v1 起头终身 v1）。
- `config.toml [dialogue] authorityMode="auto|snapshot"` 只可向下强制 v1，不得越过 caps 向上强制 book。

### 4.2 AS2→C# 帧（version:2）

```jsonc
// 会话入口（替代 sendLine(0) 的 show）
{"version":2,"op":"book","requestId":"nd:<n>","sceneId":"...",
 "mode":"ordinary"|"stage","epoch":1,"startIndex":0,"advanceKey":13,
 "lines":[{"name","title","text",
   "portrait":{"kind":"static"|"doll","key","expression","appearance"?},
   "imageAction":"keep"|"show"|"clear","imagePath"}]}

// 追加（复刻 v1 append 语义：扩数组+回 restartIndex）
{"version":2,"op":"append","requestId":"nd:<n>","sceneId":"...",
 "epoch":2,"lines":[...],"restartIndex":0}

// 低频变更（白名单字段：advanceKey）
{"version":2,"op":"set","requestId":"nd:<n>","sceneId":"...","epoch":3,"advanceKey":32}

// hide：v2 会话带 version:2，字段与 v1 同形（requestId+sceneId 墓碑语义不变）
```

- **epoch（行集代际）**：AS2 每发一个会话级 op（book/append/set）对 requestId `epoch++`（book=1），随 op 下发。C# 记录本地已应用 epoch。
- **append 约束**：逐行复用 v1 校验，任一行畸形→整包 fail-closed；`restartIndex` 是合并后数组下标（0≤i<合并后行数），缺省=0。
- **book 非幂等**：要求 `sequence > _maxSequence`；`==` 且同 requestId 的重发 book 拒绝。
- **op 字段上限**：`Text(op, 8)`，白名单枚举 {book,append,set,hide,show}。
- **book 大小双上限**：`lines.length ≤ 4096` + **payload 字符总数 ≤ 256KB**（实测最长任务 38 行 ~40KB，6 倍余量），超限整体拒绝 + `bookAck reject`（防 `_acceptTransitionLock` 内 head-of-line 堵 F 快车道）。
- **A 阶段 C# 禁止发号**：C# 不得自造 requestId；A+ 阶段用租号制（§7）。

### 4.3 C#→AS2 回执（复用 `task:"cmd"` / `nativeDialogueAction`，不新增通道）

```jsonc
// 终态回执（末行 advance 或显式 close）
{"task":"cmd","action":"nativeDialogueAction","requestId":"nd:<n>",
 "sceneId":"...","verb":"finish","epoch":<C#已应用代际>,
 "finalIndex":<C#终态行号>,"reason":"advance_past_end"|"close"}

// mutation 受理回执（对 book/append/set 必回）
{"task":"cmd","action":"nativeDialogueAction","requestId":"nd:<n>",
 "sceneId":"...","verb":"bookAck","epoch":<被 ack 代际>,
 "result":"ok"|"reject",
 "reason":"malformed"|"oversize"|"stale_sequence"|"finish_pending"|"wrong_session"}
```

- **AS2 `handleAction` 分版本**：v1 维持 requestId+sceneId+revision 三重校验；v2 校验 requestId+sceneId(+epoch)，verb ∈ {finish, bookAck}，其余拒绝。会话对象存 `wire:"v1"|"v2"`（beginSession 闩定）。C# 对称：per-session 记 wireMode，**不可对 v1 会话发 finish**。
- **rewardPending 门禁维持吞掉本 action**（不加白名单，见 §5 裁决）；C# 回执必达化补偿（§4.4）。

### 4.4 closing 状态机（finish 必达 + 跨向交叉封堵，L3/L4 收敛项）

C# 侧 per-requestId 状态：`active → closing → closed`：

- 末行/close → **closing**：可即隐面板，book 保留、不立墓碑；发 `finish` 回执。
- closing 态收到同 requestId 的任何非 hide op（append/set）→ **复活重开**（按 restartIndex/当前 index 续播）；收到 hide / 更高 sequence book / finAck{accepted:true} → closed（终态化，立墓碑）。
- **回执必达**：AS2 `sendHide` 即天然 ack；C# 在 closing 态未收到任何状态变更（hide/新 op/新序/断线）前**有界重试 finish**（不依赖玩家输入）；`HandleTransportDisconnected` 清空重试状态，跨 generation 不重发。

AS2 侧 epoch 裁决表（写进协议，不许实现自定）：

- `receipt.epoch == session.epoch` → `finishSession()`（正常终态：terminal→清事件→清会话→放 claim→hide→publish，顺序不变）。
- `receipt.epoch < session.epoch`（AS2 已追加 C# 不知道的代际）→ **finish 仍赢**：`finishSession()` 照常，然后把追加尾部按**新 requestId 重发 book**（followingEvent 已消费不带）——复刻 v1「close 先到再 append」的结局，两端确定、内容不丢。
- `finalIndex != 本会话末行` 且 `epoch == session.epoch` → 异常状态：按 `finishSession()` 处理并记日志（C# 视角行集与 AS2 一致时代际必然一致，此分支防御性）。
- `bookAck reject` 到达 → `finishSession()`（复刻 send-fail 兜底）；pending mutation 超 ~90 帧（30fps≈3s，联调按 PerfTrace 收紧）无 ack → 同兜底（watchdog 挂 EventBus `frameUpdate`）。

### 4.5 revision 本地化纪律

本地 revision = **每 requestId 独立单调计数器，每次 ShowFrame ++，与 index 无关**（v1 sendLine 语义即如此）。widget 的迟到帧拒绝/手势绑定/SetPortrait 接受门/排版缓存 key/同图跳过语义全部保持（L4 §4 核对表逐条通过）。**禁止按 index 派生**（append restartIndex 归零会触发迟到帧拒绝）。

### 4.6 A+ 追加项（二期边界）

- C# 自装配 book 时 requestId 用**租号制**：caps/bookAck 载荷携带 `ndGrant:{lo,hi}`，AS2 发放时 `_reqSeq` 跳过该区间；租约按 socket generation 作用域（断线作废，AS2 只是跳号）；用尽经 `verb:"ndGrantRequest"` 续租。tombstone 语义零改动。
- AS2 提供**身份/外观快照查询**（一次性 cmd 应答）：性别/脸型/发型/装备栏/立绘类型/角色名/活 MC 外观冻结（现 `NativeDialogueAppearance` 白名单格式原样复用）。
- A+ 装配器覆盖清单以 L1 §4 的 C1–C16 为准（含字符串 key 丢覆盖标志、null 降级显式建模为 no-op 会话、[7]/[8] 扩展槽显式废弃、池条目包装层迁移）。

## 5. 失败注入封堵对照（收敛 L3 矩阵 + L4 缺陷清单）

| 注入 | 现状 | A 后 | 封堵 |
|---|---|---|---|
| C# 崩溃/socket 断 | AS2 断线兜底 finishSession | 不变（escrow 在 AS2） | 天然 |
| book/append 畸形被拒 | v1 show 静默丢→悬挂（既有面） | bookAck reject→finishSession + 90 帧 watchdog | **收窄既有面** |
| finish × append 跨向交叉 | revision 门吞 verb，追加续播零丢失 | epoch 裁决表 + closing 复活重开 | §4.3/§4.4 |
| finish 遭 rewardPending 门吞 | v1 自愈（UI 还在可再点） | C# closing 有界重试至 hide/断线；**不加白名单**（保 D/W/R 真值表语义，L3 裁决压倒 L4 白名单方案） | §4.4 |
| teardown 落 closing 窗口 | cancel→绝不 publish、放 claim | 不变（cancel 始终 AS2 发起） | 天然 |
| stage overwrite 移交 | lease+event 同步块原子移交 | 不变；wire 上 hide(n)→book(n+1) 有序 | 天然 |
| 断线 × 本地 finish 双消费 | terminal 幂等单消费点 | 不变（C# 终态=UI 层，AS2 终态=escrow 层，无交叉面） | 天然 |
| 压隐/失焦 | SetHostSuppressed 停打字不终结 | 不变（略收窄：revision 迟到面消失） | 天然 |
| 双击去抖窗塌缩 | v1 窗口内第二击被吞 | v2 每击生效（补全下一句），响应更跟手 | **写进真机复验清单**（可感知节奏漂移） |

L4 的实现陷阱已分别并入：P0-1（epoch+closing → §4.3/§4.4）、P0-2（不加白名单改重试 → §4.4）、P0-3（handleAction 分版本 → §4.3）、P0-4（禁止 C# 发号/租号 → §4.2/§7）、H-5（op 上限 → §4.2）、H-6（revision 纪律 → §4.5）、H-7（caps 走 handshake 捎带 → §4.1）、H-8（watchdog → §4.4）、M-9（book 双上限 → §4.2）、M-10（caps-required+wireMode 闩 → §4.1）、M-11（closing 软墓碑 → §4.4）、M-14（零碎边界 → §4.2 各条目）。

## 6. 分期与里程碑

**一期 A（5–7 人日）**
- M1 协议落地：双端解析（C# `NativeDialogueTask` op 分派+book/append/set 校验、AS2 `buildBook`+epoch+wireMode 闩）、caps handshake 捎带、config 开关。（1.5d）
- M2 C# 会话宿主：`AdvanceLocal`+自驱预取+closing/重试状态机+bookAck；widget 零改动定向测试绿。（2d）
- M3 灰度与回退演练：双模共存矩阵（新 Core+新 AS2=v2；新 Core+旧 AS2=v1；旧 Core 人工核查不回退）、断线/teardown/overwrite 回归。（1d）
- M4 发布列车 + 真机复验清单（换句手感/双击节奏/连续对话/暂停交叠/reward pending 中关闭对白/追加续播）。（0.5–2d 窗口）

**二期 A+（+3–5 人日，A 稳定后启动）**
- M5 C# 静态装配器：stage XML 对白/task 文本/NPC 固定对白直读（复用 XmlDataLoader）+ 身份外观快照查询 + L1 C1–C16 分支复刻与对拍测试。
- M6 租号 ndGrant + AS2 镜像退役（`读取NPC对话` 类死路径清理）；动态佣兵对白仍走 AS2 装配下传。

**不做项与替代**：B（escrow 化）在 A+ 后视收益再议；C（零对白）不做。

## 8. 风险与未决项

1. **watchdog 阈值**（90 帧）为经验值，联调按 PerfTrace 实测收紧——P1。
2. **双击节奏漂移**（M-12）需真机手感复验，若差评可在 C# 侧加 40–80ms 换句去抖窗（协议外选项）。
3. **`s.index`/`对话进度` 冻结**：L2/L4 确认无生产读者（仅 `_visible` 惰性影子+`关闭()`+测试断言），接受冻结；beat 不做。
4. **A+ 的 `角色名` sendLine 时延迟解析**：L2 判定生产数据零产出（防御性兼容），buildBook 冻结期物化即可，不设 wire 面。
5. **旧 Core 混流**：caps-required 保证 AS2 不对旧 Core 发 book；反向（旧 AS2+新 Core）走 v1 全路径——需发布说明注明配对关系。
6. **潜伏路径**：E6/E7 已单独立项修复（commit `424f28276e`）；场景门库项 `sprite/场景门 废弃` 留作死资产登记，下次 XFL 窗口清理。
