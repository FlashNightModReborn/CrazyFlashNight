# 接入说明与待验项

## 替换边界

1. 在原工程副本中接入，保持 `aw-僵尸-女` 根 1694 及原动作控制逻辑。
2. 按原 characterId 对应活体 1619–1628 和死亡 1635–1692。Shape ID 是这份源 SWF 的身份，不可套用到 CF7 金发女或其他构建。
3. 导入 SVG 时必须保留其 viewBox 表示的局部负坐标及注册点；不要按可见图形自动居中，不要把导出预览的 3 倍像素宽高误当原游戏坐标尺寸。
4. 原矩阵按 `[a,b,c,d,tx,ty]`，局部点映射为 `x'=a*x+c*y+tx`、`y'=b*x+d*y+ty`。本包不修改原帧矩阵、深度或 alpha 倍乘。
5. 55 个原生血液/组织矢量保留即可；3 个混合碎片件已替换内部 23 个头部图集 fill，不可只换活体头却漏掉这 3 件。

## 交接前检查

- 先在项目副本验证站、行走、攻击、受击两标签、抓、倒地完整循环。
- 检查头颈、肩肘、手腕、髋膝、踝处接缝以及躺倒/手臂伸展的遮挡关系。
- 分别触发死亡 a0 / a1 / a2；检查飞出的头发细片、断腿与鞋、血液层级、最终姿势和 stop/goto。
- 检查导入软件是否支持 clipPath / use 引用以及是否改变注册点、曲线或嵌套变换；必要时在副本中展开，但保持局部坐标。
- 接入后再做游戏运行时验收。本包的静态矩阵覆盖、GIF 和非空检测不能替代此步骤。
