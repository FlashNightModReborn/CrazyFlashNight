## 1. 功能边界

医务室原 AS2 按钮保留，直接调用 `_root.打开整形手术()`，由现役整形服务打开 `surgery` Web Panel。旧整形 XFL 元件及其 24 个专属按钮/图形依赖全部删除，两个舞台实例、25 条 Include、linkage 索引、通用 UI 加载器旧名称特判与 `openPlasticSurgery` 兼容命令一并移除。运行源码不保留旧界面或兼容回退；按钮开启失败仍显示中文提示。

整形仅编辑姓名、性别和 150–200 厘米身高，价格维持 **5 K 点**。不修改发型、装备、背包、进度、难度或存档槽身份。相同资料不收费；编辑和取消只操作 Web 草稿。确认成功后当前角色立即更新，并严格保存成功；不再要求出门换装备刷新性别。

本功能涉及 AS2、C# 和 Web。隔离 candidate 已完成人类确认；合并上游后的正式发布使用新的 immutable source 与本地、云端独立生产者，不沿用开发 candidate 的 native identity 或 payload closure。

建角的性别切换仍按原规则重置初始外观；整形只更改草稿性别，保留当前发型、装备和身高。建角仍由 Bootstrap 管理存档与入场；整形使用普通运行态 PanelHost 暂停与关闭生命周期。编辑表单采用与建角相同的固定画布和纯控件组合，不挂载库存工作台的装备写入会话。

首次整形实机画面暴露了共享遗漏：原适配只复用了绘图器，没有沿用角色构筑的主体取景，武器光效进入包围盒后使人物缩小。建角也使用过这一默认内容自适应路径，但初始装备不含武器，不能把潜在风险称为已实测故障。现将取景从 `character-build-pose.js` 收至共享预览组件；该 pose 文件只决定装备与选中槽对应的姿势。三处都通过同一个 `create()` 和 `render()`：身体、头部、臀腿脚参与取景，手臂、手、武器与光效只绘制；每次按当前性别与装扮合并七种站姿并留白，禁止按旧性别或会话缓存陈旧范围。身高仍通过独立比例呈现，不被重新取景抵消。

AS2 刷新复用 `DressupInitializer.updateDressupKeys`、`DressupReferenceManager.refreshAll`、`DisplayNameInitializer.refreshName`、`UnitUtil.getHeightPercentage`。整形没有调用完整 `StaticInitializer.initializeUnit`，也不走旧“刷新装扮”时间轴。名称刷新不会重抽称号；横向缩放保留原朝向，`myxscale` 保持正基准值。

第二轮人工反馈暴露了头盔遮发与画面密度的遗漏。AS2 的 `DressupInitializer` 已在 `helmet` 为真时清空演员发型，角色构筑原本读取该演员投影；整形却用保留的 `_root.发型` 重新组装预览，覆盖了遮挡结果。现由共享 `buildStateFromEquipment()` 读取头部装备的 `helmet` 标记，在预览中排除发型绘制和取景，保存的发型不变；摘下头盔、换不遮发的帽子后可恢复显示。理发店保持发型试戴场景定位，预览不应用头盔遮发；2026-09-08 起理发店新增全身装备预览模式（仍始终绘制试戴发型），见[理发店目录图标网格与共享外观服务动效-2026-09-08.md](理发店目录图标网格与共享外观服务动效-2026-09-08.md)。

## 3. 协议与一次性付费

| Web cmd | C# Task / AS2 action | AS2 服务 | 回包 task | 写权限 |
|---|---|---|---|---|
| `snapshot` | `PlasticSurgeryTask` / `plasticSurgerySnapshot` | `PlasticSurgeryPanelService.handle("snapshot", params)` | `plastic_surgery_response` → `panel_resp` | 只读游戏资料、建立操作 token |
| `commit` | `PlasticSurgeryTask` / `plasticSurgeryCommit` | `handle("commit", params)` | 同上 | 应用身份、扣费、严格保存；重试只保存 |
| `query` | `PlasticSurgeryTask` / `plasticSurgeryQuery` | `handle("query", params)` | 同上 | 只读原 token 结果 |

Web/Host envelope 固定 `panel=domain=surgery`，必须携当前 `panelInstanceId`。公开 opener 只接受 `world_plastic_surgery`。Host 组合既有 `PanelPendingCallTracker`，不另建 timer 或 pending map。

payload 固定 `{v:1}`、`{v:1,token}` 或 `{v:1,token,draft:{characterName,gender,height}}`；`gender` 为 `male|female`。调用方不传价格、余额、脸型或存档路径。AS2 独占当前资料、5 K 点扣减、按性别设置基本脸型与保存。

完整状态回包包含 `v/operation/token/phase/current/draft/cost/balance/portrait/changed/saved/success`。`portrait` 为当前装备 identifier、发型与脸型的只读投影。Host 与 Web 分别验证字段、有限整数、token 和状态组合：

- `editing`：尚未应用，没有扣费，`changed=false/saved=false`。
- `save_pending`：资料已应用且已扣一次费，`changed=true/saved=false`，明确显示“重试保存不会再次扣费”。
- `applied`：同一份资料已严格落盘，`changed=true/saved=true`，允许成功提示与关闭。

整形先核对角色/存档能力与 snapshot 基线，再刷新外观；刷新失败恢复身份且不扣费。接受写入后冻结 draft，同一 token 的不同 draft 被拒绝。保存使用现役 `flushDurableNow("ui.plastic_surgery_paid")`，只有本轮 `SharedObject.flush() === true` 才回成功。已接受操作重试不重复扣费、换皮或播报。

未知写禁止直接重提：Host 保留原 token，Web 只发 `query`。关闭重开遇到未决操作先查询原 token；AS2 的 pending 保存按实际 `savePath` 与保存 owner 绑定，可在同一存档的场景重建后继续保存，且不再持有旧场景引用。成功后只保留最近一次不可变结果；这不是持久账本或跨存档事务。重启以实际存档读回为准。

所有关闭入口先发送 exact close，再清 Web 状态；发送失败保留面板与重试权。关闭、断连和销毁清理请求、预览、事件与缩放句柄；未知业务结果不会被清理动作伪装成未执行。
