## 公共入口与换档

- **材料入口**：游戏右上 **装备** 打开角色构筑，再选其右上 **整备 ▾ → 材料**，进入“材料档案”。若有筛选，回到分类根并关闭“已持有”“有用途”，再搜索材料名。
- **配方入口**：材料详情下方 **会用在哪里 → 对应产物 → 前往合成**。在配方材料行选择写明商人名的 **前往购买**；同一物品可能有多个来源，务必点本步骤指定的那一行。
- **换档**：回到基地房间点书架，进入“基地收藏室”；打开 **角色档案**，选目标角色，点 **切换角色**。先关闭当前商店并等保存/切场完成。普通常驻角色之间可这样在同一进程内切换。
- 商店左侧选商品，进入 **交易结算**，数量设为 **1**，核对待购后 **确认交易**。以下余额按只做指定交易计算；打开、预览、取消均不应扣钱。
