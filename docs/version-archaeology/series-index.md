# 2.x 系列索引与玩家页投影

**文档角色**：将逐版本证据压缩成玩家可读更新记录，并给后续更新视频提供统一入口。

**最后核对代码基线**：commit `7db6e154276176e1f46744847615c21b43b3abed`（2026-08-30）。

本页的“玩家页投影”可以直接移植到启动器历史页；镜头台账、视频元数据、提交范围和待确认项
留在对应单版本记录，不把维护者免责文字重复展示给玩家。

## 版本号边界

- 主线仍是 2.x；`E` 是 AS2 权威迁移阶段标识，并持续到 AS2 权威彻底转移。
- E 阶段只在稳定发包节点追加一位，普通开发提交沿用当前阶段号并由发布频道区分；迁移完成后
  才冻结最终 2.x 标识。
- 这是当前/未来维护规则，不追认成历史制度。早期小版本按当时节点命名，不补造 2.710–2.717。
- 合集中没有 2.1 更新前瞻，保留缺口。
- GitHub 可核验稳定整包为 2.40、2.50、2.60、2.65、2.66、2.71；详情见
  [稳定发包边界](release-boundaries.md)。2.0、2.2、2.3、2.45 与当前 2.718 暂无对应 Release。

## 玩家页可直接投影摘要

### 2.0 更新前瞻

- 新近战动作、黑铁武士和蛙型仿生僵尸等单位展示。
- 武装 JK 随等级成长，并获得新技能和装备。
- 多类武器新增动作/战技，摇滚公园与星座武器也有更新。
- 虎拳、兽王崩拳、翻滚换弹、一瞬千击、时间停止、重力场等技能展示。
- 剧情推进到黑铁会，并加入主线引导支线和新关卡对话表现。
- 重量减伤、任务提醒、佣兵混合与打击数字等系统调整。
- 后勤战营、仓储售卖、健身房、外交/情报和 NPC 挑战等游戏性内容。
- 多种武器/近战音效优化，并预告新地图。

### 2.2 更新前瞻

- 角色立绘、界面与文本 UI 优化。
- 属性/元素机制及抗性关系展示。
- 毒属性拆分为普通毒与剧毒。
- 新技能“火舞旋风”和“不卸之力”。
- 冰雪场景、新敌人与新增单位。
- 彩蛋地图与任务展示。

### 2.3 更新前瞻

- 战宠、佣兵和装备强化被列为三个独立更新板块。
- 主界面 UI 重置，状态条显示当前值与上限。
- 战斗中新增实时伤害/状态数据展示。
- 酒馆/委托界面重置，并展示阵营任务入口。
- 主动/被动技能升级展示等级与威力变化。

### 2.40 稳定整包（更新视频标题为 2.4）

- 手雷动作和人物站姿连贯性调整。
- 炎魔斩、毒蛛/龙炎、能量武器与多组套装美术更新。
- 城市背景和诺亚前线基地工厂区域展示。
- 军阀、怀旧敌人、方舟相关单位与天网机甲部队展示。
- 生存战肉鸽化方向、冷兵器商人、商店分类与夜视仪效果。
- 多项技能增强/修复，并展示新主动技能“能量盾”。
- 掉落、击飞反击、内力攻防等级与特殊弹药等战斗机制。
- 音乐系统继续重构，并展示原创 BGM。

### 2.45 更新前瞻

- 新单位、新地图和新动作方向。
- 酒馆招募与一键强化。
- 技能最高等级上限可变化，解锁点与升级点拆分。
- 兽王崩拳加入追踪能力。
- 新战技“回旋裂地”和“破坏殆尽”。
- 数条与 `shopgirl` 相关的短支线。

### 2.50 稳定整包（更新视频标题为 2.5）

- 新敌人、改造体和摇滚公园等 BOSS 调整。
- 通缉任务背景与明暗度设置。
- AWM、M82A1、M79、MGL、SPAS12 等枪械展示。
- 手雷偏角/切换、平板快速移动、推荐等级和彩蛋/强化界面。
- 夜间模式效果进入测试展示。
- 新主动技能与若干技能调整。
- 任务第二阶段、支线/隐藏支线和开局流派/新手装备选择。

### 2.60 稳定整包（更新视频标题为 2.6）

- “材料大全”补充材料用途和掉落场景/单位/概率；物品栏拆出材料与情报分类，情报随收集进度展开。
- 装备悬停提示卸下，抓取时以黄框提示可替换槽位；背包支持一键整理。
- 地图传送按楼层/房间高亮并标出 NPC；关卡内可用 `E` 标记掉落物，对话界面同步更新。
- BPK 三人组、King 等人物立绘及多种新敌人得到更新。
- 基地增加走廊与食堂区域，并实装前后景不同速度移动的远景视差。
- 防御地带、研究院和武器仓库加入或重做多段区域与关卡流程。
- 完善部分材料描述、堕落城酒吧 NPC 对话，以及全局/音乐音量设置。
- 更新前瞻还展示了实验性可视化关卡编辑器；该工具未随 2.60 整包发布。

### 2.65 稳定整包

- 任务界面重做；事件日志可查看任务线和已完成任务记录/对话，并可拖动时间线。
- 地图传送加入随剧情解锁的阵营入口，烹饪界面更新，挑战模式额外奖励改为可见。
- 增加第一防线防区、堕落城商业街等外交地图，并更新多名角色立绘。
- 微调空手普攻衔接，优化震地、日字冲拳、兴奋剂动画和部分武器刀光。
- 加入大量食材、多套装备及多批新武器/投掷物；大圣套装是正常流程不可得的彩蛋。
- 僵尸逆袭、堕落城骚动、宝石线人挑战增加补充世界观的情报物品。
- 四项大型副本调整刷怪，并展示动态出生点、可破坏障碍和索降敌人。
- 推进后勤/食堂支线和佣兵/战宠进阶，加入肩炮追踪与 `Ctrl` + 拾取键直接穿戴。

### 2.66 稳定整包

- 修复战宠出战数量限制错误。
- 修复牛仔战宠数据未加载导致的强度错误。
- 修复任务完成后感叹号显示错误。

### 2.71 稳定整包（更新视频标题为 2.7）

- 合成显示材料收集状态；强化与背包/插件面板联动，物品注释、情报解密和任务/购买/波次提示更新。
- 恢复消耗增加动画反馈，设置可调整缩放与画质；多存档、车辆快传/驾驶和新箱子领取流程扩展。
- 以黄、绿、红和粗体白名区分阵营并明确敌对关系，部分保护目标关卡加入失败条件。
- 基建面板可查询/升级多类设施；实验室可合成药剂，部分商店材料需情报解锁，任务 NPC 增加提示。
- 加入破击伤害与附加伤害体系，并扩展异形战宠、黑龙进阶及大圣副本。
- 多名角色立绘、材料/技能/流派项链图标与摇滚公园外交地图更新，并加入新区域和新敌人。
- 加入多批武器、防具与拳套，扩展拳套连招、枪管/弹链/弹匣余量和近战长枪等武器动画。
- 加入“死亡绽放”、霸体抗性升级、剑系战技和逆向技能掉落调整，并推进废城支线与情报内容。

### 2.718 当前开发前瞻

- C# 启动器逐步接管启动、存档传输、主要数据权威与多存档流程。
- 选关、仓库、理发店、设置、关卡结果等常用流程迁入启动器面板。
- 商城、仓库、角色构筑、竞技场和装备调制复用双栏工作台体验。
- 佣兵换装、双药剂组与装备调制扩展构筑能力。
- 军阀演习、佣兵标定、黑市鉴定和跨子图限时关卡进入源码。
- 增加物品/击杀播报，并将高频打击伤害数字迁入原生层。
- Web 界面音效与静音偏好跨页面统一。
- 关卡结果、奖励、返回基地、转场与复活恢复形成连续流程。

## 维护层缺口

- 2.0、2.2、2.3、2.45 仍只有公开视频证据，没有当前可核验的稳定整包。
- 2.40–2.66 的最初发布日期、资产 SHA-256 和旧仓库提交区间仍缺失。
- 2.6、2.65、2.7 的制作稿已经找回，但不是逐字音轨；专名、数值和否定句仍按需回到
  单版本台账、公开视频或包内数据核验。
- 2.718 只有当前源码进展，没有 GitHub 稳定整包；正式发包后再提升为 `release_verified`。
