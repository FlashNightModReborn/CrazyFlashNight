# JK 白丝、黑丝变体图标

`3XD的素材` 中的裙子和鞋子分件是画稿真源。`assemble.py` 沿其原生图标的遮罩、取景、矩阵和分件引用，将四款变体图标确定性装配到已有 `Codex专用素材` 库。两条裙子保留原作者裙摆取景，并用对应鞋袜的小型分件提示区分黑白款；原白丝裙子图标保留，新版使用独立 `Codex-jk套装白丝裙子` 链接，避免与原库重复导出。

原库普通 JK 上衣的图标已改名为 `图标-JK校服校服`。本装配同时提供旧物品所需的 `图标-JK校服` 兼容链接，保持已有商城与背包引用。

从仓库根运行 `python -X utf8 tools/jk-variant-icons/assemble.py`，再用 `--check` 检查源摘要、装配内容与 Include。生成的依赖不导出 AS 链接；只有五个物品图标导出所需名称，避免重复变装链接。依赖保留为原生矢量，不复制其他武器、文字或原作者整库。

分件修改后重新装配，并通过标准 `scripts/compile_test.ps1` 指定 `flashswf/arts/new/Codex专用素材/Codex专用素材.xfl` 发布到相邻的 `Codex专用素材.swf`。该库已有 `things-new` 共享库入口，无需新增库或重新发布主文件。随后重扫 `asset_source_map.xml`，通过物品素材工作台为受影响物品生成、预览及应用 Web 图片。`manifest.json` 记录原始分件和生成文件的 SHA-256；图片、纸娃娃与商城消费验证遵循项目现有美术、商城验证入口。
