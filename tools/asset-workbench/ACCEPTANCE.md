## 本次复验

1. 正式发布后从平常的游戏入口启动，进入 **其他 → 工具 → 物品素材工作台**。开发复验仍可使用根目录 **本地开发启动.cmd**，它按当前源码身份选择隔离候选。关闭旧进程后重新启动，使本次 Web 修改生效。确认工作台占满游戏可用区域。
2. 搜索 **强化石**。当前物品图标应自动播放，取消“播放动画”后显示静态首帧。选择“仅图标”生成预览，在当前/候选间切换检查动画和裁切；完整展示仍是单独的用途槽位，不与物品图标交替播放。
3. 筛选应依次是 **全部物品 / 待补图 / 冲突**，随后是实际 SWF 素材库及物品数。目录已经取消分页，连续滚动即可查看全部匹配物品；点击物品保留位置，修改搜索或筛选时回到顶部。选 **3XD的素材.swf**，搜索 **大赦、mini14、杠杆式霰弹枪**，继续体验图标、完整展示和人物装扮；装扮动画默认停播。
4. 重新生成所选物品后，可体验“应用到项目”和“撤回本次应用”。重点判断裁切、透明边缘、握持、注册点以及操作文案。其他消费者仍需重启游戏查看新图。

上一轮的三个 3XD 预备候选和人类首测任务仍可查看。本次内核更新后，旧任务的输入摘要已过期，应用前请重新生成。连续保留多件应用结果时，每件应在上一件应用后生成；来源或清单后续变化也会阻止旧候选覆盖当前文件。

本次已备好 **强化石** 的新图标候选，可在最近任务中选择“强化石 · 可预览”。实际 SWF 导出得到 120 帧时间线、119 张不同画面、24 FPS 的 128×128 动画 WebP（919,810 字节）；浏览器已验证当前/候选播放、停播首帧、金钱 PNG 序列换帧及关闭释放。当前项目素材没有应用这次候选。
