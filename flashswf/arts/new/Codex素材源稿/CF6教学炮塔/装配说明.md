# CF6 A01 自动炮塔原生装配说明

本目录含**原作原生字节**（raw-tags/ + manifest.json v2）、提取出的位图/音频源
（bitmaps/）与本说明。确定性 XFL 源由 `tools/cf6-tutorial-turrets/build-turret-xfl.py`
生成；工具本身不启动 GUI 或生成 SWF，导入与编译由主控在真实 Flash CS6 中执行。
本目录名称沿用提取任务名，两门原作炮塔实际位于 A01，不在空教学室。

## 内容

- `raw-tags/` — 从原作已校验 SWF（SHA256 `b52af10e2dda43332e0b2ffb9549d2fad474f298b9f6c67d848ffc33ff589b01`）
  按原偏移提取的 **13 个** Define 标签原字节（含 tag 头）。
- `manifest.json`（schema v2）— 每个 tag 的 charId、类型、原偏移、长度、SHA256，
  由 `tools/cf6-tutorial-turrets/build-manifest.py` 确定性重建（`--check` 字节校验）。
- `bitmaps/` — 由 build-turret-xfl.py `--extract` 从 SWF 解码：机身 `turret-body-1588.png`
  （160×196）、枪管细节 `turret-detail-927.png`（293×278）、枪口焰 `muzzle-flash-502.png`
  （43×30 ARGB）、对应 .jpg 原件与射击声。用于导入的是
  `fire-sound-1169.import.mp3`（2392B），与独立 FFDec 输出一致；旧
  `fire-sound-1169.mp3`（2396B，误含4B SWF字段）保留为历史原件，不导入。

## r14 修正（取代 r13 结论）

- **枪口焰不是无效引用**：503/504/505 的 FillStyleArray 各含一个 `0xFFFF` 死条目
  （任何 edge 都不选用它）和一个有效位图填充 **502**（实际渲染用）。按原语义保留死条目，
  不渲染、不以纯色替代。
- **1536 是 r13 解析器幻影**（readMatrixEnd 位读取错误 + 对 JPEG 体误扫描），
  实际是无关 DefineEditText，不属于本闭包。
- **机身 1589 还引用 927**（DefineBitsJPEG3，293×278 枪管细节纹理），r13 因
  newStyles 对齐 bug 完全漏掉。
- **帧1 滤镜确认为一个 ColorMatrixFilter**（20 个 float 原值见 fragment），不是阴影；
  XFL 无原生节点，由生成的元件帧1 脚本原值应用。
- **帧12 有 StartSound → DefineSound 1169**（MP3，包络 11022/9533），r13 漏报。

## 主控装配流水线（串行执行）

```bash
# 0.（幂等，已执行过可跳过）解码 SWF → bitmaps/ + generated/geometry-r14.json
python -X utf8 -B tools/cf6-tutorial-turrets/build-turret-xfl.py --extract
python -X utf8 -B tools/cf6-tutorial-turrets/build-turret-xfl.py --jsfl

# 1. 真实 Flash CS6 GUI：运行 tools/cf6-tutorial-turrets/generated/import-assets.jsfl
#    （自建 CF6_A01_Turret.xfl、原生导入 3 PNG + 1 MP3 到库 CF6Turret/* 并保存；
#     拒绝覆盖已有 XFL；回执写 tmp/cf6-roguelike-20261021/validation/）
#    --jsfl 会准备目标父目录；原生脚本显式建库文件夹、移动并核验四个完整库名。

# 2. 写入符号/时间轴 XML + PublishSettings（确定性，可重复）
python -X utf8 -B tools/cf6-tutorial-turrets/build-turret-xfl.py --assemble

# 3. 校验装配树（XML 良构、媒体字节 SHA、linkage、确定性再生）
python -X utf8 -B tools/cf6-tutorial-turrets/build-turret-xfl.py --check

# 4. 编译（要求本轮新鲜 Compiler 0/0；marker 不作成功证据）
scripts/compile_test.ps1 -Target flashswf/backgrounds/cf6/CF6_A01_Turret/CF6_A01_Turret.xfl -PublishOnly -VerifySwf flashswf/backgrounds/cf6/CF6_A01_Turret.swf
```

硬性要求：

- 元件 linkage `CF6教学炮塔-A01自动炮`（由 assemble 生成的 00004 符号导出），
  只存在于该独立 SWF 自有命名空间，**不登记进 things-new 资产注册表**。
- 元件内保留名为 **`枪口位置2`** 的标记子件与 3 帧枪口焰子件（均已生成在符号 XML 中）。
- 不迁移原作 onClipEvent 射击脚本——CF7 射击由服务经 `_root.子弹区域shoot传递` 发出，
  元件只负责视觉与帧12 射击声（否则双重开火）。
- 保持 18 帧时间轴长度和首帧 `stop()`；开火节拍由服务帧计数控制，进入帧12前先检查
  暂停和发射能力，防止显示资源自主播放出声或双重开火。
- `--check` 校验帧12事件声及 `SoundEnvelope` 的 level0=11022 / level1=9533，
  同时检查符号XML确定性字节与语义。真实 CS6 保存若改变序列化或声音包络，先保留
  保存后的原件并区分格式/语义差异；不能反复 assemble 覆盖现场来取得假通过。
- 原生导入、指定 SWF 的 Compiler `0/0`、实际 linkage、服务加载和听感各有独立证据；
  模拟装配树通过不代表真实资源已导入或播放。
