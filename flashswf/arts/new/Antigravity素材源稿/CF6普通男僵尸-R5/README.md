## 可复建源

inputs/live/十个SVG本身是完整可编辑的冻结活体绘制源；生成死亡件不依赖历史R1–R4脚本、开发机或临时路径。inputs/death-reference/包含原shape每填充path/matrix/色、392图集、完整timeline、映射和控制证据。source/build_death.py使用精确原矩阵与裁切；classify_mapping.py只作4×采样分类诊断，采样mask绝不用于生成画稿。

## 画风与来源

用户原文：“闪客快打6通过滥用渐变上色营造了金属色的独特的美术风格，但重制版复刻里面我感觉不太可能和其他画法融入，后续施工会话的时候也需要适当取舍，把不必要的金属渐变去掉”。来源Sentinel_ce45154084208191987a38de78db1fbe。保持CF6造型、配色和辨识特征，以融合CF7现役画风为目标；布料与皮肤去不必要金属渐变，真正金属材质有控制地保留高光，不机械禁止一切渐变。
