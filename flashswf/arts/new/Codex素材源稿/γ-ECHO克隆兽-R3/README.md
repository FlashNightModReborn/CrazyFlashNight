# γ-ECHO 克隆兽 R3 交接归档

这里保留维护者认可的双配色 SVG 交接原件、13 类分件的局部原点，以及绘制和配色来源清单。旧说明中的“尚未装配”描述的是交接时点，不代表当前游戏状态。

当前唯一美术编辑源为相邻 `Codex专用素材` XFL 的 `Codex/γECHO克隆兽/` 命名空间；后续死亡碎尸和爪根、牙根、骨刺连接修补均在原生源完成，归档 SVG 不回写。

- λ型克隆兽：兵种 459，阶段 8，深褐灰配色，无固有吸血。
- 暴君克隆兽：兵种 460，阶段 9，红褐配色，固有 5% 吸血。

操作入口、数值来源、原生动作、试验边界与成本见 [统一接入说明](../../../../../tools/gamma-echo-assets/README.md)。原件身份由本目录 `drawing-manifest.json` 绑定；原生现状由该工具目录 `native-manifest.json` 绑定。
