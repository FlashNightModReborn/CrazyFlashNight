③拳套方向错 → 逆时针 90°。**只给代码，用户自己贴 CS6。**

**尺寸**：`基准缩放` 100 → **70**；拳套分支 150 → **105**（同步 ×0.7，保持各类型相对大小）。

**拳套位置**：`_y` 0 → **25**。依据：飞剑挂点矩阵 `a=d=-0.577, b=-c=0.167` ⇒ scale **0.6006** /
rot **163.86°**（**det>0，无镜像**）；该坐标系下局部 +y 映射到屏幕 **(-0.167, -0.577)** = 左上、主要向上
⇒ 局部 `_y` 越大越往前（屏幕上往上）。每 +10 ≈ 屏幕上再往上 6px。

★ **朝向速查表（以后调任何挂装朝向直接套）**：设 `R = 装扮._rotation`，则
| 子元件 `_xscale` | 屏幕朝向 | 说明 |
| --- | --- | --- |
| 正（无镜像，如刀） | `163.86 + R` | 线性相加 |
| 负（自带镜像，如枪） | `-(163.86 + R)` | 手感反向 |

- 刀 `R=-164` → 屏幕 ≈ 0°（正）✓
- 枪 `R=-254` 且 `_xscale<0` ⇒ 屏幕 **+90°（顺时针）** ✓ 与之前结论一致
- ⇒ 同一个 `-254`，有镜像/无镜像相差 180°，两处别串用
