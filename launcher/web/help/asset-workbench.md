# 物品素材工作台帮助

画师通过游戏里的工作台操作，Agent 使用同一素材内核的 CLI。这份文档同时供游戏帮助页和仓库维护者阅读。

## 画师上手

### 1. 发布并找到自己的素材

在 Flash CS6 完成画稿后，先发布对应的 SWF，再从游戏 **其他 → 工具 → 物品素材工作台** 进入。工作台读取已发布的 SWF，未发布的 FLA 修改不会出现。

筛选前三项是 **全部物品 / 待补图 / 冲突**，后面按 SWF 素材库分组。先选自己的库，再搜索物品；搜索和筛选会叠加。新增或改了导出链接时，点 **重新扫描来源**；只改已有元件的画面，可直接生成。

目录连续显示筛选后的全部物品，向下滚动即可找完，不需要翻页。点击物品后保留当前位置，改变搜索或筛选条件时回到列表顶部。

### 2. 生成候选，检查图片

选择物品和范围，点 **生成预览**。图标类物品可选“仅图标”；武器或服装通常选“图标 + 人物装扮”。生成完成前可以阅读帮助或关闭面板，任务会继续；重新打开后从“最近素材任务”找回。

生成不会改项目中的正式图片。完成后，用 **当前 / 生成前** 与 **候选** 对比：

- **物品图标**：检查特写裁切、底影和透明边缘。带动画的图标默认播放，取消“播放动画”可看静态首帧。
- **完整展示**：检查完整外形。这是图标元件的另一个用途槽位，不会和物品图标交替播放。
- **人物装扮 / 单独装扮**：检查握持、注册点与外形，切换男女和相关站姿；装扮动画默认停播。

### 3. 应用并确认实际效果

画面确认后点 **应用到项目**。想恢复时，选回这个已应用任务，点 **撤回本次应用**。如果后来又修改了相关素材，工具会拒绝覆盖后续修改；保留现场并请维护者检查。

画师的首次实操建议就走一遍：**用自己发布的素材生成 → 比较后应用 → 在实际使用场景查看，并体验撤回**。重点判断画面和操作是否符合制作习惯。机器导出和回归测试只能提供技术证据，不能代替这次实操判断。

工作台会刷新自己的预览。查看其他已打开面板或游戏消费者中的新图，请重启游戏。

### 需要 Agent 协助时

点帮助页底部的 **复制当前任务信息**，再补充“做了什么、哪里不对、期望是什么”，必要时附一张截图。Agent 可以据此直接读取本机任务和日志，不用画师手抄路径、哈希或整段错误。

## Agent 协作

### 先接回同一个任务

这份帮助的维护真源是 `launcher/web/help/asset-workbench.md`。从项目根目录运行下面的命令；输出是一条 UTF-8 JSON。GUI 与 CLI 共用 `tools/asset-workbench/core.py`。

先读画师提供的物品、SWF 和任务信息，再读目录与已有任务。`catalog` 返回近期任务；有任务 ID 时直接查同一个任务，避免重复生成。

```powershell
python -X utf8 -B tools/asset-workbench/cli.py catalog
python -X utf8 -B tools/asset-workbench/cli.py status --job <任务ID>
```

对应任务目录是 `tmp/asset-workbench/jobs/<任务ID>/`，重点看 `job.json`、`export.log` 和已有的导出报告。需要检查来源时，沿物品 XML → 来源索引 → 已发布 SWF → 候选图片核对；不要把索引存在当成画面正确。

### 与画师使用同一组操作

| 工作台操作 | CLI 操作 | 结果 |
| --- | --- | --- |
| 重新扫描来源 | `rescan` | 生成候选来源索引，随素材应用写入项目 |
| 生成预览 | `start --item <物品名> --kind all` | 后台生成候选，返回任务 ID |
| 等待生成结束 | `bake --item <物品名> --kind all` | 等待候选结果，不应用 |
| 刷新任务 | `status --job <任务ID>` | 读取原任务结果 |
| 应用到项目 | `apply --job <任务ID>` | 合并所选素材与清单 |
| 撤回本次应用 | `undo --job <任务ID>` | 恢复该次应用，保护后续修改 |
| 取消生成 | `cancel --job <任务ID>` | 请求结束正在生成的任务 |

`--kind` 可用 `all`、`icons`、`dressup`。命令中的尖括号内容是需要替换的参数。仅在当前任务范围需要且已获授权时执行生成或写入；画师反馈“看起来不对”不等于允许覆盖素材。

例如，按已授权范围为大赦生成候选：

```powershell
python -X utf8 -B tools/asset-workbench/cli.py start --item 大赦 --kind all
```

请求结果未知时，用原任务 ID 查询；`start --job <任务ID>` 可重用同一个 32 位小写十六进制 ID，不能改绑物品。来源、配方、清单或候选发生变化时应重新生成，不绕过漂移检查，不手改任务状态来强行应用。

### 把真实体验交还画师

Agent 负责定位、修复、定向回归和准备可检查的结果；画师负责真实导出操作、裁切与透明边缘、动画观感、握持与注册点，以及实际使用场景的判断。把一次复验需要的动作集中说明，完成后记录具体样本和现象。

技术实现、事务规则和环境说明见仓库 `tools/asset-workbench/README.md`。候选启动和本轮验收记录在 `tools/asset-workbench/ACCEPTANCE.md`。机器测试通过、候选可运行、画师实操通过和正式发布应分别陈述，不互相替代。

## 常见问题

### 找不到物品，或刚画的内容没有出现

先清空搜索，切回“全部物品”。确认物品已登记到项目，并检查当前显示的 SWF 路径；确认 CS6 已发布到该路径。新增或修改导出链接后重新扫描来源，再生成预览。

### “待补图”和“冲突”有什么区别？

待补图表示所需图片尚不完整；冲突表示同一素材链接有多个来源，需要维护者确定归属。同一物品可能同时符合两项。冲突物品也会显示在相关 SWF 库中，工作台不会擅自选择冲突来源。

### 为什么已知动图仍然不动？

先选“物品图标”并勾选“播放动画”，确认看的版本是当前图片还是候选。没有勾选能力时，该条目目前没有可播放的动画产物；从已发布 SWF 重新生成后再比较。仍不对时，复制任务信息交给 Agent 检查导出报告，不把静态封面当成动画丢失的唯一证据。

### 生成较慢，或者想先关闭工作台

大素材库首次导出可能需要几分钟。可以关闭帮助或工作台，后台任务继续；回来后选择原任务并刷新。真正不需要这次生成时点“取消生成”。失败时展开“诊断信息”，保留原任务供维护者查看，不反复创建相同任务。

### 应用被拒绝，提示来源、配方或产物变化

旧候选已经不是基于当前项目生成的。确认正在使用正确源文件，再重新生成；多件素材依次保留应用结果时，下一件应在上一件应用后生成。不要删除校验信息或强行覆盖。

### 导出环境尚未就绪

请维护者根据诊断配置 Python 3.11+、Pillow、FFDec 和 Java 8+；大图标库建议使用 64 位 Java。依赖与排错说明在 `tools/asset-workbench/README.md`，画师无需自行猜测安装路径。

### 应用后，其他地方还是旧图

先在工作台确认应用成功，再重启游戏查看对应消费者。本阶段支持手动生成与工作台内刷新；**发布后自动监听、更多消费者缓存刷新、CS6 发布包装**仍不包含在内。
