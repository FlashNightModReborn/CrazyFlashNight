### 6.2 token 化映射原则

旧配方逐条转写、不设例外：`#hex` / `rgba()` 一律改为 `var(--dls-*)/var(--theta-*)/var(--wb-*)` 或 `color-mix(in srgb, <token> X%, <token 或 transparent>)`；背景贴图 `url()` 不受限（非颜色）并纳入 css-bundle 本地闭包校验；`filter:brightness()` 非颜色属性，仅用于 hover 提亮；动效只消费 `--wb-motion-*` / `--wb-ease-*`，不新增 keyframes、不写 `transition:all`、不写 outline、不写 `!important`、不覆盖壳级 grid-template。

## 7. 第三轮：暖色人文垫图层（同日，Phase E）

第二轮「战术军械」皮肤上线后用户验收反馈：配色与垫图的差异导致气质仍然不对——战队系统在设计上偏人文关怀，旧版用暖色与特制角色垫图让玩家感到「有伙伴在身边」，而 Phase D 整体偏冷青（SKIN 节用 `--dls-crystal-dim` 派生 surface）、无垫图，气质冷硬。本轮在**纯 CSS + harness 断言**（不改 pet-panel.js / merc-panel.js / team-panel.js 任何 JS）前提下，把面底色温拉回旧版中性暖灰并为四个 tab 复原角色垫图背景。主工作面 `css/workbench/team.css`（1700 → 1781 行）。

配方原则（旧 CSS 原话）：「灰白渐变底 + 英雄烤在其上（整体偏中性灰、英雄清晰可辨），而非把英雄埋在近黑重罩下压成黑泥」——轻灰罩只做层次（86%~90%），中灰渐变兜底明度对齐旧 `#41444b→#2a2c32`，不许压成近黑。
