# 统合61式分件与接口约束

本包工作 SVG 来自现役原生元件，原生实例矩阵已经进入 SVG 的分组变换。尤其是四个下臂，已带入现役肘腕覆盖修正。不要再次按旧稿套用同一拉伸，也不要把 R38 存档当成当前坐标基准。

## 文件与坐标

- assets/unified 是唯一工作目录，共24个 SVG。文件名和相对路径保持不变。
- 保留每个文件的 viewBox、width、height 和局部注册坐标。分件局部原点是 (0,0)，y轴向下。
- 画布内容不自动居中、不按透明外框重新缩放，不把分件换成整机截图的裁片。
- 可以添加语义分组和更清楚的局部名称，保留有效且唯一的 SVG id。
- 装配矩阵、顺序和分件映射由 data/catalog.json 与 data/poses.json 提供。不要修改它们来补偿画稿漂移。

文件中的宽高是局部坐标画布大小，不是角色上屏像素。拼接程序取 SVG 内部图元，按 holder 矩阵放置，不依赖 root SVG 自动适配或裁切。

## 胸甲接口

胸甲的 closed、open、fire分别对应原生第1、2、3帧。除男女躯干外，其他18个闭合分件不需要复制状态版本。

炮口实例名为“炮口位置”，位于躯干局部坐标 (47,-19)，矩阵为：

    [1, -0.6, 0.25, 0.95, 47, -19]

局部前向向量为 (1,-0.6)。保持炮口与舱门几何相对位置；该逻辑接口另存于 data/constraints.json，不应在绘稿里画一个可见的十字作为游戏素材。

## 可返回的 SVG

采用自包含矢量：path、rect、circle、ellipse、line、polyline、polygon、g、defs、linearGradient、radialGradient、stop、clipPath。变换、纯色、透明度、描边和上述渐变可以使用。

所有颜色、描边和渐变属性直接写在图元或分组上，不依赖 CSS 样式表。文字转为路径。渐变优先显式使用 userSpaceOnUse 和完整数值，裁切采用 userSpaceOnUse。避免叠加多层裁切；孔口参考现役稿。

不使用外链、嵌入位图、image、use、脚本、事件属性、foreignObject、filter、SVG mask、style、vector-effect 或动画。网页能显示某种效果不代表现有原生转换链支持它。需要柔和明暗时用受控渐变和色块表达。

## 现役修正的来源

data/constraints.json 记录本次读取的四个下臂矩阵。data/export-report.json 记录逐个 SVG 的源元件、帧、输入文件和静态导出边界。data/source-provenance.json 绑定当前输入字节；MANIFEST.json 绑定交接包字节。

source_snapshot/unified-native 保存本轮69个元件 XML。它是接回时的核对材料，缺少整个原生工程所需的外部结构，不作为独立 Flash 工程使用。

## 接回 Windows

返包仍是待接入候选；游戏原生 XFL 是现役权威。由 Windows 维护者对照 snapshot、局部原点和绑定输入，定向回装本套实际改动，保留下臂覆盖、胸炮接口和图标分层。禁止运行初次导入脚本覆盖整套现役编辑。

按所属 Codex 素材库执行真实 CS6 编译，并核对新鲜编译结果、胸炮三态、图标双帧、男女姿势与受影响消费者。重新生成 Web 派生图后检查实际游戏显示。离线 SVG、PNG 和网页预览都不能代签 Flash、连续动作或游戏验收。
