# CF6 原生玩家判定压力对照

**角色**：四个 CF6 素材修复的定向原生对照，当前入口 `scripts/run-cf6-player-pressure-tests.ps1`。

改前四个 SWF 与 `manifest.json` 已冻结在 `tools/cf6-soldier-assets/evidence/20261031-pressure-baseline/`，仅供本测试使用。入口先核对版本化源文件，再将缺失文件补到 `tmp/cf6-performance-repair-20261031/before/`；已有文件摘要不符时拒绝覆盖。`-PrepareOnly` 只准备并核对基线，不调用 CS6。manifest 使用 `files[].name/sha256`。改后使用当前 `flashswf/arts/new/`；两版顺序装入独立世界，不把同名导出混在同一世界。

共 68 条：蛮蛮、大刀、大头、保安 × 改前／改后 × 左右 × 站定、后撤、换线、跳跃，另加大刀左右墙体用例。使用真实 RSL 时间轴／AI、主角男来源受击框、生产 AABB、移动、伤害与冲击结算。每例 180 有效帧，统一测试属性（单位 HP 30000、空攻 100；目标 HP 10000、防御 300、175cm），目标输入按冻结帧表驱动，命中不掷随机闪避；散弹只测中心弹，不能把记录的伤害当作完整散弹 DPS。

有意控制开局动作以隔离机制：蛮蛮拖斧（狼跳处于冷却）、大刀斜挥冲刺、大头伸缩冲击（后撤爆破处于冷却）、保安枪托。其后由单位真实动作与私有 AI 继续运行。蛮蛮在拖斧第 24 帧承受一次同强度真实冲击结算，以比较中断与接近；大刀墙体用例走实际 Mover。普通索敌、人物完整装备／技能初始化、随机弹丸分布和人类反应不在此夹具范围内。

`[CF6_PRESSURE]` 原始行记录接触请求、命中、已结算伤害、首次命中／射击、中断和越墙。保留负结果和正确躲避，禁止通过调整预期值把失败改成通过。本套件只证明受控条件下的原生差异；整场斗兽、真实玩家构筑、物理输入手感与人类验收仍分别取证。
