# H3 短过场创作手册

本文整理一次“旧低分辨率游戏动作 + 人类画师立绘 + H3 视频生成 + 人类选卡 + 后期剪辑”的真实迭代经验。它记录已观察到的方向和风险，不把单次模型版本、硬件速度或审美判断写成永久定律。

## 1. 先冻结产品功能

生成前先写一句话和五项硬约束：谁出现、为什么播放、是否有对白、总时长/节奏、游戏交付尺寸与帧率。短过场最常见的失败不是模型不能出图，而是“漂亮镜头”没有承担产品功能。

本次可复用的结构性结论：首次遭遇类 CG 应迅速交代身份、危险性、标志动作和团队关系；它不是人物画廊。对白由独立系统承担时，生成片应保持无对白，避免嘴型和临时台词污染剪辑。

## 2. 素材权威按职责拆分

发生冲突时，不按文件新旧或分辨率高低判断，而按素材负责的事实判断。

| 素材 | 权威范围 | 不应负责 |
|---|---|---|
| 人类画师立绘 | 面孔、身份、发型、服装、配色、插画完成度 | 动作时序、重心、机械展开路径 |
| 游戏序列帧/动作视频 | 姿势、手位、发力、重心、武器结构和轨迹 | 最终脸部与人体细节、CG 画风 |
| 原始 SWF/FLV/XFL/XML | 来源追溯、完整时间轴和缺失信息复核 | 直接作为现代生成/剪辑入口 |
| 原版过场 | 展示功能、角色顺序、节奏基准 | 逐镜复刻和最终画质 |
| 世界观原文 | 阵营、能力来源和叙事边界 | 逐镜导演指令 |
| H3 原始输出 | 可剪的真实像素和运动候选 | 身份、人体或机械设定的最终裁决 |
| 人类标注 | 观察、偏好、硬约束和放权范围 | 自动替代专业剪辑决策 |

典型合并方式是“立绘定身份，动作帧定姿势/器械，静态构图卡定镜头，H3 只负责在这些边界内生成运动”。不要把低分辨率游戏角色直接放大后要求模型同时修脸、修身体、重做动作和保持机械结构。

## 3. 先抽构图，再抽视频

对多人镜头，先低成本生成 4–6 张宽幅静态关键帧，检查：

- 三人的前中后景是否不同，还是平排人物选择界面；
- 标志器械是否完整，握把、琴键、枪管、麦架等拓扑是否可读；
- 身体弧线与发力方向是否互相区分；
- 主次是否明确，最终帧能否成为闪白、切黑或转场落点；
- 构图是否给相机小幅推进、Dutch roll、烟雾和灯光留下空间。

第一轮只动画化最强的两张，各一个种子。确认运动潜力后，才给胜出构图补第二种子，再为缺失角色或功能补专属镜头。一次夜间批次通常安排 3–5 个互补任务，比给所有构图无差别各抽两张更容易得到可剪的差异。

建议批次结构：

1. 两个已胜出构图的第二种子；
2. 一个当前最弱角色的强前景动作；
3. 一个机械结构风险最高角色的清晰动作；
4. 一个三人终幕或转场落点。

## 4. FL2VA 与动作参考的职责

- 首帧驱动适合冻结身份、构图和第一帧机械结构，但提示词若只写“展示角色”，模型容易产出慢推、眨眼和美女站姿。
- 动作参考适合约束发力、手位和变形过程，但不应成为脸、服装和线稿质量真源。可先把动作帧降为中性轮廓/灰度运动指南，减少低清外观污染。
- 本地对照中，16 步相对低步数在脸、手、服装边缘和动作闭合上出现明显收益，像是跨过了可用阈值；这个结论必须在新模型/新硬件上用同输入、同种子 A/B 复核。
- 一段 2–3 秒源片不需要完整进入成片。生成目标是提供动作峰值、过渡帧和可切段，不是让模型完成最终剪辑。

## 5. 动作提示词的骨架

把提示词写成一个连续镜头的时间分段，而不是形容词堆叠：

```text
0.00–0.18s  立即继承首帧；明确每个角色的位置、身份和器械，不得停顿。
0.18–0.95s  只完成一个主动作；描述手、肩、髋、重心和器械的物理路径。
0.95–1.65s  其他角色在同一强拍完成互补动作；灯光/烟雾作为节拍，不代替动作。
1.65–2.33s  小幅反弹后停在最强剪影；只允许最后数帧供剪辑定格。
```

每条提示至少明确：

- **首帧是真源**：脸、服装、颜色、位置和器械不可重分配；
- **一个主要动词**：下劈、横扫、展开、弧斩、前冲等，不让一条短片承担三套招式；
- **身体力学**：肩髋反向扭转、前膝推进、后脚支撑、动作后的回弹；
- **器械拓扑**：哪只手固定握哪一侧、连接杆是否刚性、变形从哪里开始到哪里结束；
- **小而明确的相机运动**：沿器械推进、短促 Dutch roll 或观众席低机位，不做无目的环绕；
- **可剪终点**：最终 3–6 帧允许保持动作峰值，但头发、烟雾仍显示余势；
- **负面约束**：额外角色/肢体/器械、镜像换边、弯曲连接件、静态合影、魅惑摆拍、字幕和 logo。

“更有动感”不是足够的指令。要写清楚谁的哪只手沿什么路径、身体如何承受反作用力、镜头在第几个强拍移动。

## 6. 结构连续性高于单帧美感

多人乐器、长柄武器和机械展开最容易在视频中漂移。以下任一发生都应降为局部可用或重抽，而不是靠闪光掩盖：

- 握把从左侧跳到右侧；
- 琴键或枪管数量变化；
- 一只手在器械两侧瞬移；
- 麦克风与支架断开、弯曲或复制；
- 普通乐器直接变成无关武器，缺少连续展开过程；
- 角色脸、发色、服装配色在三人之间交换。

闪白、抽帧和分屏适合隐藏轻微生成噪点，不应掩盖身份或机械拓扑错误。

## 7. 分辨率与画质

游戏原生分辨率是交付合同，不必等于模型最佳推理分辨率。已经验证的稳妥策略是：

1. 在模型较稳定、且略高于交付尺寸的原生档生成；
2. 保留原始输出；
3. 最终只做一次确定性裁切/缩小；
4. 不先放大到通用 1080p 再压回游戏尺寸。

对 `1280×736 → 1024×576`，先居中裁成 `1280×720`，再一次双三次缩放。额外动漫超分在本地样本中放大了脸、手和器械伪影，主观结果反而更差；因此默认不锐化、不去噪、不生成式修复。若尝试增强，必须保留无增强 A/B，且不能声称恢复了源片从未存在的真实细节。

24→30 fps 默认采用确定性帧保持/重复。高速手部、琴键、刀刃、枪管和火焰不适合整片光流；需要插帧时只对单镜实验并保留旁路版。

## 8. 快闪剪辑不是把生成片顺序拼接

曾被明确否决的结构是“三段慢推肖像 + 每人一个定格 + 三分屏收尾”，因为它把危险角色剪成了美女展示。更有效的语法包括：

- 剪影 → 聚光灯逐个开启 → 立刻进入动作峰值；
- 肖像只作 2–8 帧闪回、撞帧或节拍断点；
- 战斗动作在展开完成、打击峰值或回弹处定格；
- 分屏、黑帧、闪白、抽帧和局部特效让每个切点提供新信息；
- 三人演唱状态与战斗状态交错，展示多面性；
- 终幕以主角色居中、另外两人向内侧身的三角/V 字关系收束，再转场回游戏。

后期应从原始 H3 片段挑帧和片段，不从带编号、停帧、缩放和标签的 review reel 回剪。

## 9. 人类评价只提供观察与偏好

标注建议区分：

- `hard_constraint`：不可违反的产品边界；
- `observation`：结构错误、身份漂移、某段动作有效等画面事实；
- `preference`：喜欢/不喜欢及强度；
- `suggestion`：可能的解决办法，剪辑者可不用；
- `defer_to_editor`：主动放权。

结果档位可用 `keep / usable_segments / reroll / reject / defer / unreviewed`。每条标注绑定媒体 SHA-256 和秒级区间，不依赖可变文件名。剪辑者可以拒绝普通建议，但应记录关键分歧的处理；标注本身不修改 pipeline、不删除素材、不自动启动重抽。

## 10. 音乐与权利

不要把多段模型生成音频硬拼成音乐，连贯性和卡点通常都很差。使用一条完整、明确可分发的音乐真源，再按强拍剪画面。

允许原创音乐、CC0，或条款明确允许游戏内商业分发/改编/永久保存的素材。禁止改编可识别现有歌曲、模仿具体艺人、使用来源不明的“免版税”下载或缺少许可证证据的 AI 音乐。每条外部/生成音频保存文件哈希、来源、作者/工具、日期、许可证原文、署名要求和第三方采样声明。

## 11. 交付与归档

建议最终时间线冻结为目标游戏尺寸、CFR 和 SDR；原始素材保持原字节，不在入库前统一转码。长期保留最小可重剪闭包：

- 游戏候选和高质量母版；
- 剪辑时间线/脚本/工程及字体插件说明；
- 实际使用的完整源片；
- 原始立绘、动作参考、旧过场和设定简报；
- pipeline、提示词、种子、模型标识和输入/输出哈希；
- 音乐母版、分轨与权利记录；
- 人类标注和剪辑取舍。

成片锁定且闭包通过哈希后，才删除未使用抽卡、代理、接触表、网页缓存和失败增强件。只留成片与文字无法应对未来换音乐、延长切点或修补一秒镜头；相同种子也不能保证在未来模型版本逐字节重建。
