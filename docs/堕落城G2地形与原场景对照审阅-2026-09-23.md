## 逐项裁决

| 原始意见 | 裁决 | 核证与处理 |
|---|---|---|
| A-1 货运线低于桥面 6 单位 | 驳回 | `scene.js` 的 `line()` 默认经过 `H()`，输入高度 8 实际映射为 14。原报告漏算映射。复跑检查及桥面端点核对不支持该断差。 |
| A-2 缺口像港池 | 采纳 | 中层 14、平底 -4，北岸连续直壁，沙体稀少；与用户目视反馈一致。破口应体现原工业地面破坏和沙埋。 |
| A-3 沙舌淹没低路与楼梯 | 收窄采纳 | 新地形必须联合调整路面和入口；不接受“全部沙面不得高于 -1”等无角色尺度依据的硬阈值，也不要求每个桥墩基础都露出。 |
| A-4 沙海方向构成源冲突 | 不认定源冲突 | 侧向破口与沙侵是用户已选择的布局提案；不能因为旧剧情未指定方位而撤回授权。继续标明灾因/护盾细节属于提案，不从北区荒漠推导风向。 |
| B-1 沙坡绕过摇滚低口 | 收窄采纳 | 校验新增连续可达面和墙端绕行；不采纳坐标单位与世界宽度混用的豁口阈值。 |
| B-2 阶地变成低槽上桥捷径 | 收窄采纳 | 破坏面可不规则，但不得无意补出低槽直达货场/桥面的连续坡。拒绝没有角色尺度依据的 2.5/3.5 跃越阈值。 |
| B-3 桥下交点硬编码 | 采纳检查建议 | 变更下层路线时，应从最终折线与桥体求交点和净空，不沿用旧常数；当前检查未证明沙体新增后的通行。 |
| B-4 城外沙脊截断补给 | 收窄采纳 | 哨所外接补给、正常货运口及左侧服务道均需与沙体联合设计；不采纳无来源的覆盖率 30% 或固定净宽门槛。 |
| C-1 缺口与桥的水工读感 | 合并 A-2 | 不能仅打断桥栏杆来解决，主要修地面、墙体和工业设施的整体关系。 |
| C-2 南侧道路为长堤 | 采纳 | `line()` 除检修院跨越段外均把道路侧壁延伸至 -6。城外长引道应选择与地形相接的路堤、局部高架或旧路基。 |
| C-3 沙体/残骸吞掉走廊 | 收窄合并 A-3/B-2/B-3 | 新增体量必须参与检查。现有已登记 box 已有路线抽样，不能说现有检查完全不检查残骸；新沙体和未登记几何尚无覆盖。 |
| D-1 游寇半附属关系写成未定 | 采纳 | `text1.json` 的 `$MAIN_GET_25` 明说上次盗贼为黑铁会半附属部队；结合游寇任务链，当前 `bandit.boundary` 过度保留不确定性。依附不等于完全可控，也不证明所有小团伙均为黑铁代理。 |
| D-2 正门待检场缺支撑 | 采纳 | gate 源框 `[475,850,95,90]` 在城市下层多边形南边界 830 之外；slab 底为 2，底地坪顶为 -6，路堤只能支撑局部。需补前庭地基/坡脚或明确高架支撑，而非只扩大顶板。 |
| D-3 残骸成为上桥阶梯 | 合并 B-2 | 保留桥端控制与上下分层，不能把“非直连”升级为任何角色都绝无能力攀爬。 |

## 下一版施工建议

1. **地形和支撑**：破口由平盆改为沙侵旧工业地面；同时修南侧引道路基、待检场基础与外部连续起伏沙地。完整城防段与灾损段使用不同剖面。
2. **道路与沙体联动**：先确定货运、哨所补给、低槽冲突、摇滚退路、服务小路的通行带，再放沙坡与残骸。允许合理改线，不把 G2 每个路点冻结成不可移动。
3. **功能级灰盒**：依据上表分割校园、舞台前场、沿街商业、住宅巷道、围合货院。先解决体量、院落、入口和服务面，不急着制作窗框或贴图。
4. **叙事关系**：游寇按半附属身份靠近黑铁控制节点；其他小势力分别保留生计、控制和退路。护盾、灾因与方向保持提案层边界。
5. **逐区对照**：以“原场景片段 → 应保留的空间信息 → 灰盒对应区域 → 可重排内容”比较。同一背景复用不证明同一地址，横版左/右门不直接锁定城市东西向。

检查时从最终几何读取路线交点、支撑和沙面，覆盖新增体量及新增连通关系；相对单位不冒充米制规范。人类重点看缺口低视角、南入口地基和去掉标签后的区域识别。当前 G2 复跑 2840 处道路—盒体样本、2710 处道路—台地样本均未报碰撞/埋路；这不覆盖本轮发现的支撑缺失、形态误读和未来 G3 沙体。
