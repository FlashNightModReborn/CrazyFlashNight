# 九龙药剂图标

2026-10-15 将批准的 r07 矢量稿装入游戏。唯一运行时编辑源为 `flashswf/arts/new/Codex专用素材/` XFL 目录；本目录的 SVG 是入库时的源稿归档，不是第二套运行时真源。

## 覆盖与接口

- 28 张图标：九族各一至三型，以及狴犴零型。
- `data/items/消耗品_药剂_九龙.xml` 的 25 个既有物品使用新图标；负屃三张只导出为预留素材，没有新增物品或药效。
- 裸图标名为 `Codex-九龙-<物品名>`，AS2 链接为 `图标-Codex-九龙-<物品名>`。
- 库目录为 `Codex/九龙药剂/`，包含 28 张原生画稿、28 个图标外壳及一个系列总览，共 57 个元件。
- 图标外壳两帧均为完整注射器，首帧 `stop()`。第二帧供地面可拾取物调用；消耗品沿用同样的完整展示尺寸。没有套用武器的首帧局部特写规则。
- 可见轮廓最大边约 23.4 像素，以可见几何中心为注册点。静态二次曲线测量为 23.3918–23.3960 像素，两帧一致。

## 保存、发布和派生

所有新增形状均为 Flash 原生矢量，不包含位图、嵌入 SVG、字体或外部绘图组件。先在独立 XFL 中由 Flash CS6 原生保存，再将已保存的 57 个元件转入正式库；已有元件不随该保存重写。

由正式 `Codex专用素材.xfl` 发布 `flashswf/arts/new/Codex专用素材.swf`，并沿既有共享库锚点发布 `flashswf/arts/things-new.swf`。入口沿用 `main → things-new → Codex专用素材`；没有改动主文件。锚点的新增总览层在第一帧为空，第二帧保留系列总览，避免在运行时停帧入口堆放整套画稿。

物品来源表通过既有 `tools/linkage_scanner/scan_linkage.py` 的 `scan_xfl` 和 `write_xml` 生成函数定向刷新 Codex 来源；其他来源以装配前的干净来源表为基线。验证仅新增 28 项，既有项无变化。受影响的 25 张 Web 图标由 `tools/bake-icons-offline.py` 定向生成。

`assembly-manifest.json` 登记每张图的命名、倍率、帧合同、原稿和原生元件 SHA-256；`source-integrity.json` 固定本目录归档输入。原生 XML 仅将 CS6 保存结果的换行统一为仓库规定的 LF，归档 SVG 和清单也固定 LF，校验值绑定规范化后的实际文件字节。以后编辑以正式 XFL 为准，重新发布并更新受影响 Web 派生，不直接修改 SWF。
