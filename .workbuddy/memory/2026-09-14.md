**这轮学到的（已写进 `topics/素材与图标管线.md`）**：
1. **环形不要用"外圈正走+内圈倒走"的单多边形挖洞**——尽管非零环绕语义正确，在起始角 θ=0 的径向接缝处会出一整条楔形漏空（本机 Pillow 实测；CS6 未验，但没必要赌）。改成**由外向内叠实心盘**（内层盖外层，层间露出即成环带）：无接缝、任何填充规则下结果一致，点数还减半。同理高光弧做成"两端收尖的梭形"而不是扇环。
2. **外缘别做"一圈小三角"毛边**：突出量和格距同量级时看着就是一排齿轮齿。改用几层更大更暗、竖直抻长、边缘带细碎起伏的大盘 → 柔和的阶梯式外晕（还顺便把 60 个图元省成 3 个）。
3. 边界摆动幅度必须钳在**相邻圈宽的 45%** 以内（`JAG_K=0.45`，等比圈宽下最坏 `0.45×(1/1.11+1)=0.85×圈宽`，恒不串圈）；`JAG_K>0.5` 必串。
4. 自检里"帧 0 vs 帧 N 逐点比对"要**比格式化后的输出文本**，不能比原始浮点——`2π*24/24` 与 `0` 会带来 1e-13 级差异，会把"无缝"误报成 199 处不同。真正判据是 SVG 文本逐字节相同。
5. 参数坑：`abs(cos t0)` 是**水平**方向，竖直方向是 `abs(sin t0)`（我第一版把竖直外泄做成了左右外泄）。

## 王之财宝「光圈」返工三：外圈改「镂空 + 金/淡黄弧带」（21:05-）

## 王之财宝 技能三件套代码设计（调研完成，代码已交付聊天，**未改任何文件**）

需求：`王之财宝`（子弹）从金币商店/商城/合成里**所有**武器随机抽一把，按 `(武器面板 + 对应加成) * 技能等级 * 0.5 + 伤害加成` 重写自身子弹威力，并把装备类型/装扮传给子元件 `王财宝具` 展示。三份代码：技能容器生成子弹 + 子弹元件 + 素材元件。

**关键结论（这几条以后还会用到）**
- **attachMovie 的 initObject 字段能在元件第 1 帧脚本里直接读**（裸变量名）。铁证：`特效与子弹/裂地拳.xml` 自己帧脚本写 `this.子弹威力 *= 0.5` 生效；`空中小火焰爆炸.xml` 直接读裸 `发射者名`；`BulletFactory.createBulletInstance` 把 `Obj` 原样当 initObject 传给 `gameWorld.子弹区域.attachMovie(Obj.baseAsset, ...)`。
- `prepareBulletData` 六步（setDefaults/initializeBulletProperties/setTypeFlags/setFlagDependentDefaults/inheritShooterAttributes/calculateKnockback）**都不读 子弹威力** ⇒ 元件第 1 帧再改威力完全来得及（伤害在命中时才读 `bullet.子弹威力`）。
- `BulletInitializer.initializeBulletProperties` 里 `Obj.发射者名 = Obj.发射者`，所以子弹里能用 `_root.gameworld[发射者名]`。
- 子弹种类 `"王之财宝"` 无 `-联弹` 后缀 ⇒ `BulletTypesetter.getBaseAsset` 返回全名 ⇒ 直接当 `attachMovie` 的 baseAsset，**不用注册新子弹类型**；`MovementSystem.createMovementForBullet` 查不到就回退 `LinearBulletMovement`，所以 `子弹速度 = 0` 即"原地播自己的时间轴动画"。命中盒靠实例名 `area`（王之财宝 图层3 有）。
- **运行时物品库 = `_root.物品属性列表[物品名]`**（`ItemUtil.as` / `引擎_鸡蛋_lsy_物品系统.as` 写入）：`.use`（刀/手枪/长枪/手部装备）、`.data.power`、`.data.punch`、`.data.dressup`。**装扮(dressup)名就是 attachMovie 的 linkage id**，和黑铁落剑那 10 个 `刀-*` 一致。
- 三个商店源：`_root.shops[shopId]`（index→物品名，值是 string 或 `{name,requiredInfo}`）、`_root.kshop_list`（`[{id,item,type,price}]`）、`_root.改装清单对象`（name→recipe，来自 `BootSequencer.applyCraftingData`）。`ItemObtainIndex` 也有 craft/shop/kshop 索引但**没有"列全部物品名"的接口**，且 obtainIndex 是 private ⇒ 直接遍历三个原对象更省事。

- 容器侧：`技能容器-王之宝库`（`（未实装）技能容器-王之宝库.xml`，109 帧，**完全是空骨架**，只有 刚体标签 里那段通用的 `skillShadow` clipEvent）。参照 `技能容器-上帝之杖.xml`：脚本在**第二个名字叫 `as` 的图层**，`_parent` = 单位（用 `_parent.方向/技能等级/攻击目标/是否为敌人/_name`），发子弹在 index 6，走 `_root.gameworld.attachMovie("上帝之杖", ..., {子弹威力:...})`。王之宝库要连发就把生成段放到释放帧并复制到多帧。

## 第四轮：王之财宝 枪械摆位排查（只给代码，**未改任何 XFL** —— 用户明确要求的）

用户报两个现象：① 枪械装扮体积巨大且角度不对（要水平翻转+缩小）② 玩家朝左时子弹左右没变，`_xscale=-100;_yscale=-100` 那段"没效果"。

### 查实的三条硬事实（以后会复用）

1. **朝左时引擎已经把整发子弹转了 180°** —— `ShootingAngleCalculator.calculate(Obj, shooter)`：
   `if ((shooter.方向=="左") ^ ((子弹速度<0) && …)) return 180 + shooter._rotation + (Obj.角度偏移 = -角度偏移);`
   我们的容器设 `子弹速度 = 0` ⇒ `0<0` 为假 ⇒ 朝左时角度 = **180**；`BulletFactory.createBulletInstance` 里
   `Obj._rotation = (ZY比例&&速度X&&速度Y) ? … : scatteringAngle`，ZY比例没配 ⇒ `_rotation = 180`，
   再随 initObject 落到子弹上。⇒ 用户自己加的 `_xscale=-100; _yscale=-100` 本身就是"再转 180°"，
   **两个 180° 相乘 = 单位阵**，所以"看起来完全没变"（这正是现象②的精确解释）。**正解 = 删掉那 4 行。**
2. **`attachMovie` 的第 4 参 initObject 先于元件第 1 帧脚本生效**，且 `prepareBulletData` 六步、`createBulletInstance`
   全程都不写子弹的 `_xscale/_yscale`（唯一写它的 `BulletFactory.as:199` 只在"对象化联弹"分支里）
   ⇒ 子弹第 1 帧改缩放本身是安全的，问题只出在上面那条 180° 相消。
3. **`王财宝具` 的挂点 `飞剑` = `各种图素材等/Symbol 5612`，自带 `a=d=-0.576995849609375, b=-c=0.166778564453125`
