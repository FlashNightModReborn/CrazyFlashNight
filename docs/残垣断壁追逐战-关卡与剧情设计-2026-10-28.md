## 1 关卡定位与确定方向

玩家在残垣断壁救出键盘后，乘上其他A兵团人员接应提供的战斗吉普，沿营地外道路突围。军阀摩托与运兵车赶上并实施截击。玩家消灭这批追兵，脱离对方直接视线与火力，再到外侧接应点登上直升机。

这是主线救援关的后半段高潮，采用短篇车战的内容规模。它承担救出人质后的释放感、军阀兵种组合展示，以及主线33、34反转前的胜利体验；通关仍归主线32，不新增独立奖励关入口。

维护者已确定的方向：

- 敌车只做双人侧斗摩托与运兵卡车两个主要底盘。
- 三辆教学摩托分别搭载突击兵、狙击兵、弹药兵，依次引入。
- 卡车依次出现三名突击兵、三名狙击兵、三名弹药兵，最后一名重装兵。
- 普通乘员随血量下降逐个摔下车，真实减少火力；三人全部退出后换下一批。
- 摩托与卡车共用普通乘员坠落动作；重装兵不制作完整坠落，以整车爆炸遮挡收尾。
- 尽量复用现有军阀攻击。狙击保留连续三发，不预设改成长预警、激光锁定或单发攻击。

下文的时长、尺寸、生命预算及车位为制作候选，不属于已经验证的平衡数值。第一版不加入坦克、步战车、敌方直升机、额外投掷兵、独立驾驶员弱点或自由上下车。

## 3 与基地崩溃的剧情因果

### 3.1 两种不同的追踪结果

玩家必须真的救出键盘，也真的击败公路追击队。车战结束的结论是「追兵无法继续咬住这辆吉普，直升机可以安全接人」，不是「军阀的整个侦察网已被清除」。

现役[主线34对白](../data/task/text/text1.json)已经说明军阀顺着这次行动摸清基地外围布防；[主线34设计](主线34基地崩溃重写-剧情编排与设定体系-设计讨论稿-2026-09-14.md)进一步限定：敌人本来就知道基地存在，这次获得的是明面兵力、出入口、接应路线和布防信息。

本稿采用的补全因果如下：

1. 摇滚内部的军阀间谍误导King，利用保护雇主原则引出救援行动；保留当前主线31、32的起因。
2. King与玩家分头找人。玩家找到键盘后请求接应，附近外派小组调来吉普；这次增援是对现场险情的响应，不是A兵团预知了全部陷阱。
3. 军阀在营地与沿线观察救援方向；另一批外围侦察人员利用A兵团出动、联络和接应的时机，确认基地明面防线与人员调动。重要报告在最后一辆追击车被击毁前已传回。
4. 公路追兵负责拦截、拖延及施压，不是唯一掌握情报的人。玩家打掉他们，实际保障了人质和接应人员的撤离。
5. 主线33由King表达救援得手；主线34由Andy揭露军阀已完成侦察、趁人员分散调集重装部队围攻。

不把Wings经键盘作用于主角的暗线改写成军阀侦察手段，不让普通军阀士兵获得对该暗线的解释权；键盘的沉默、犹豫和被救后的反应继续保留。

### 3.2 接应人员与直升机

接应小组默认采用两名普通A兵团战士的角色规模，称谓暂为「接应队员」。他们提供车辆、指示外侧接应点并掩护上车，随后沿另一条维护支路撤离。此处不新增具名元老、不暗示额外大军，也不安排两人阵亡。

本稿不把这两人自动等同于主线34的同伴A/B或第三阵地的伤亡小组。后续如要建立人物连续性，应明确对应并核对[现役基地崩溃流程](../tools/base-siege-assets/README.md)，不能仅凭共用兵种模板认定同一人物。

营地废墟与敌方火力不允许直升机在扣押点安全悬停。飞行员转移到外侧开阔点接人；吉普将人质带出受控道路，击退追兵后经林缘遮挡接近会合点。无需为此新增全域防空系统或电子隐身设备。

King从另一条搜索路线撤出，在剧情中确认会合；不要求为她增加车顶战斗或骑乘动画。主线32返回后仍找King交付，33再找Andy，不自动越过现有任务交付链进入基地战。

### 3.3 玩家知道什么

| 时点 | 玩家得到的信息 | 暂不揭露的内容 |
|---|---|---|
| 入营地 | 键盘被抓、现场有埋伏 | 完整侦察目的 |
| 请求接应 | 安全落点在外侧，吉普已经接近 | 基地外围侦察的结果 |
| 车战 | 敌车赶上并试图封住撤离路线 | 情报是否已汇总 |
| 登机 | 本地追击已经解除，人质安全撤出 | 不出现「敌人已无法追踪A兵团」的全知结论 |
| 主线33 | King因救援成功而得意 | 保持下一步揭露的空间 |
| 主线34 | 追兵被打掉之前，另一批人已借救援调动摸清外围布防 | 基地核心仪器能力仍不向军阀公开 |

## 4 关卡流程与对白草案

### 4.1 从步行救援到登机

| 段落 | 场景和行动 | 推进条件与表现 |

| D 摩托 | 三辆侧斗摩托先后从后侧赶上、超车至前方，依次为突击、狙击、弹药兵 | 每辆失去射手后司机减速退走；上一辆的有效攻击结束后再引入下一种 |

| F 脱离 | 通过遮挡明确的岔路、干渠转弯或林缘道路，远离刚才交火位置 | 短段无新敌人的行驶，飞行员确认可以接近；登机演出结束后产生一次关卡通关 |

残垣断壁按[荒漠空间草图](荒漠区域草图空间逻辑-2026-10-02.md)位于南方林缘旧聚落服务区。使用旧道路、干渠与林缘维护支路承接撤离，不增设一座大型永久军营，也不把地表道路与A兵团地下取水链绑在一起。

敌车在玩家前方是超车截击的结果。敌车尾部朝后、吉普机枪朝前，两边保持同向行驶；玩家沿既定撤离道路突破阻截，没有改为追杀逃跑的军阀车队。卡车爆炸后保留一小段真正的脱离过程，不在火球旁立刻让直升机降落。

### 5.3 允许适配的部分

保留单个乘员一次招式内的击发次数、顺序、弹型、发射间隔和辨识动作；先沿用原弹速与散布。将脚下移动、索敌和攻击方向改为载具提供的车位、目标与后向射界，去掉步兵寻路、跑近、近战派生及跳跃。

三人卡车通过错开招式起点增加密度，不压缩每人的招式。乘员死亡即取消其尚未发出的攻击；已发射的弹丸按原生命周期继续。死亡槽位不由其他乘员补射，也不把全车原射速平均分给幸存者。

狙击没有新增激光线、锁定条、长停顿或单发限制。既有举枪和枪口表现承担辨识；若原型证明大车体在当前空间内不可避，优先检查受击框、可移动宽度、敌我距离及招式间等待，再决定是否需要局部参数变化。

火箭不预设「同屏最多一至两发」作为硬玩法规则。先测试三个原攻击周期错峰后的实际密度；如需压低压力，增加整车招式间隔或缩短危险重叠时间，并明确记录差异。

## 6 车辆操作与战斗规则

### 6.1 玩家吉普

本稿采用自动向前行驶、四向调整相对车位、攻击键发射固定前向机枪的操作。横向输入表现加减速，上下输入表现变线；不做挡位、漂移、燃油、逐轮物理或离车战斗。玩家接手车辆控制，键盘乘坐车内，接应队员留在外部掩护后撤。

车载机枪使用任务固定配置，不消耗玩家背包弹药、不依赖驾驶技能，不开放角色武器切换、手雷和技能输入。P13外形上的其他武器模块首版仅保留造型，不因此全部开放。射速与威力按摩托和卡车目标时长确定，具体数值留原型标定。

为减少新状态，本稿采用现有CF6适配的基本方向：主角HP仍为唯一受伤与死亡权威，吉普提供显示和受击代理，不再建立第二条车辆耐久。HUD继续显示玩家生命，不把它另称一条独立的「车体HP」。角色现有防护、无敌与复活规则需在车载代理上保持一致，不能因隐藏人物而旁路伤害结算。

键盘上车后不再独立受击、寻路或触发步行人质死亡检查。车辆损伤可用火花、烟和短促颠簸表现；不同时扣玩家、键盘及车辆三份生命。上车和下车不会保存新载具装备、复制人质单位或凭空恢复玩家HP。

### 6.2 摩托

每辆只有一名有效射手、一个伤害主体和一块围绕侧斗乘员的宽容受击区。司机是表现角色，不提供第二血条或精确狙杀分支。射手被击败后立即停火并坠落，司机减速退场，不额外要求撞毁车体。

基础顺序固定为突击、狙击、弹药三辆。首版普通难度不把三种教学同时压给玩家；退场车不再造成碰撞伤害。重复游玩和高难度可以压缩入场间隔，但不在本稿中增加第四种底盘。

### 6.3 运兵卡车

卡车是一个敌方战斗主体。后厢使用一块共享受击区，三个乘员没有独立HP、寻路、掉落或完整单位生命周期。驾驶室和前轮不另设弱点，也不能出现「射击车头却毫无提示地打落后厢乘员」；宽容受击区应覆盖可见后厢火力区域。

| 阶段 | 出场乘员 | 减员与阶段结束 |
|---|---|---|
| 一 | 3突击兵 | 当前编组生命预算依次跨过三分之二、三分之一、零，形成3、2、1、0人 |
| 二 | 3狙击兵 | 同样逐个减员；各人仍完成原三发攻击，只错开开始时间 |
| 三 | 3弹药兵 | 同样逐个减员；不为维持压力让剩余射手加速装填 |
| 四 | 1重装兵 | 单独生命预算；使用原机枪招式，击败后停火、失控、整车爆炸退场 |

实现可以用一条总HP划分四段预算，界面显示当前编组与乘员数量；不要表现为「同一辆车每打空一次就修复满血」。不额外增加独立车体结构生命或护甲破坏层。

减员顺序固定为远侧、中间、近侧，保留最后一名清楚可见的射手。每次减员立即关闭相应攻击挂点；坠落表现不参与命中或通关计算。一次伤害跨过多个阈值时，所有对应减员都生效，不设置每次攻击最多击落一人的隐形限制。

跨编组的大额伤害按总HP继续计入，不丢弃溢出、不回填HP。阶段表现只进入实际存活的下一组；全部预算耗尽直接收束。固定车载武器下正常游玩应能看清各阶段，但不能为展示动画而制造不可解释的锁血。

三人归零后有短暂停火和补位表现：射击位空出，帘内出现下一批人。空位期间不接收新的伤害，也不制造弹药消耗；上一击的溢出已经计入。三个新乘员就位后按原招式开始攻击，没有瞬间齐射。建议换批约0.6至1.0秒，最终时长随原生动画验证调整。

重装兵占一个大位置，三普通位全部关闭。死亡先让枪停止、身体失衡，再以爆炸遮挡并换残骸。爆炸为退场表现，首版不增加玩家必须躲避的最后一击或贴脸殉爆伤害。

### 6.4 空间与碰撞

道路用滚动背景表现整体前进，车辆位置表示局部相对关系。敌车在可见空间内进入，给玩家辨认时间；不能在玩家受击框中突然生成。卡车在前方保持截击位置，纵向变化按预设动作进行，不每帧精确贴住玩家车道。

活动空间要允许吉普完整移动和回避高速弹；人物枪口高度、画面Y和地面纵深分开处理，不能让较高的后厢子弹因坐标混用永远命不中。首版车辆接触只分离位置并限制重叠，不新增连续碾压伤害、撞车秒杀或撞击跳阶段。

草木、废墟和岔路主要承担速度与地理表现。三种摩托教学期间不叠加需要另一套规则才能规避的致命路障。

## 7 节奏 难度与奖励

车战目标时长约2至3分钟，作为原型调参目标而非必须等待的计时门。摩托部分约占四分之一，卡车及换批占主要时间，收尾保留短暂喘息。通过条件是有效战斗结果与撤离抵达，不是撑够固定秒数。

每批卡车火力由3人降到1人，形成可感知的压力下降；新一批重建压力，同时换一种玩家已经在摩托段见过的武器。最后重装兵凭体量、密集机枪和整车毁灭建立终战，不需要再引入新解题规则。

普通难度先保证原攻击在车战空间内可回避。高难度优先调整编组生命预算、招式间等待及敌车站位；不默认增加精英弹型、同步九连射、攻击中持续锁定或新的追踪弹。

车载乘员不各自实例化普通掉落，不要求高速拾取材料。首版保留任务32原奖励和既有结算来源；车战是关卡完成条件的一部分，不独立重复发奖。是否给车战增加额外奖励，留后续数值评审，不能从视觉上十名乘员反推十份战利品。

## 8 美术与声音范围

敌方新增内容以配套[美术规格](残垣断壁追逐战-摩托车与运兵车美术规格-2026-10-28.md)为准，包括一个侧斗摩托底盘、一个运兵卡车底盘、固定司机、四种现有乘员的车载适配、普通乘员共用坠落、卡车爆炸与残骸。

玩家吉普的行驶、开火、键盘乘坐与上车表现，道路滚动层、营地接应边缘和直升机登机表现，是关卡必须另行承接的内容；不藏进「只画两种敌车」的报价或完成声明。吉普来源P13是静态AS3作者工程，后续需按游戏AS2工程导入纯美术，不能直接使用其发布设置。

保留现有枪声和火箭、爆炸声音的辨识，新增或复用的发动机循环应受统一音量与暂停控制。三人开火音量不能简单叠成三倍；玩家需要听清换批停火和最终武器哑火。此处不触发正式runtime发布流程。

## 9 后续程序接入与恢复边界

原兵种时间轴包含发弹、父级取值、移动和动画完成调用。美术复用不等于直接运行整套步兵脚本；车战控制器负责单一载具身份、挂点坐标、攻击调度和取消，已有子弹与伤害系统负责命中结算。

| 场景 | 必须保持的行为 |
|---|---|
| 上车 | 先确认资源与目标身份可用，再取得车辆输入；不先隐藏人物再等待无法恢复的加载 |
| 键盘登车 | 在明确的登车成功点解除步行护送检查；正常移除不能伪造成UnitDeath |
| 暂停 | 车辆、背景滚动、攻击、弹丸及换批表现一致暂停，不从后台补发攻击 |
| 玩家死亡与复活 | 沿现役死亡、复活权威暂停和恢复同一战斗；不凭表现对象自行复活或重置Boss |
| 失败 退出 重开 | 释放本次输入、相机、HUD、声音、射手和投射物；旧回调不得作用于新世界 |
| 卡车终结 | 只产生一次有效终结；乘员坠落与残骸离场不再重复计杀或奖励 |
| 登机完成 | 由关卡管理器一次性交付原「残垣断壁」完成结果，不从动画脚本直接改任务或存档 |
| 加载异常 | 明确失败并恢复可退出状态；不能以超时视为战斗完成 |

首版不新增永久检查点或特殊存档槽。已有复活可沿当前车战会话恢复；整关失败重进仍走原关卡路径。若实际体验要求上车点重试，应单独明确恢复内容，不能通过重放奖励或恢复真实存档实现。

## 10 后续施工顺序与验证

1. 用占位车体做「一辆突击摩托、三人突击卡车、逐个减员与换批」的短流程，验证现有攻击能在吉普空间里命中和躲避。
2. 接入狙击三发、火箭和重装原招式，对照第5节逐次验证弹型、击发时序、坐标、伤害来源与减员取消。
3. 完成美术规格的纯美术资源、真实CS6发布与消费者验证，再接入道路、接应、登机及主线33、34对白。
4. 在不使用真实玩家槽位试写的条件下验证关卡失败、复活、重开、完成和任务交付；实际驾驶手感、视野与连续流程由完整游戏验收。

重点验收：三类摩托与卡车同类乘员的攻击可辨认为同一招式；狙击仍连续三发；减员真实降低发射机会；大额命中和延迟回调不重复换批；死亡/暂停不继续开火；键盘不上车后跑出车体；车战成功不提前完成主线34；普通任务交付及后续围攻因果保持连贯。

机器可验证动作、事件和身份，不能据此宣称驾驶好玩或场景已经适合普通玩家。具体执行沿[测试选择矩阵](../agentsDoc/testing-guide.md)与[美术装配](../agentsDoc/art-asset-assembly.md)，本稿不创建新发布门。

## 11 原型需要确定的参数

| 参数 | 目前约束 | 决策依据 |
|---|---|---|
| 吉普受击区与移动范围 | 宽容碰撞、允许回避，不照搬人物小框 | 原攻击三发、火箭及机枪下的真实驾驶 |
| 固定车载武器 | 前向机枪、任务弹药、不依赖玩家枪械 | 摩托消灭时间及卡车各阶段长度 |
| 卡车四段生命预算 | 一个权威HP，普通组逐个减员，重装独立末段 | 减员反馈与终战时长 |
| 多乘员错峰 | 保留单人招式内部节奏，死者空拍不补位 | 原生时序与可躲避空间 |
| 接应图使用gk19_4或gk19_5 | 压缩重复护送，保留人质情感交流 | 实际地图出口、吉普占地与镜头 |
| 车体与乘员比例 | 以同场P13和普通军阀合成为准 | 配套美术规格中的尺寸对照 |

以上参数不妨碍按配套规格准备纯美术。新的玩法变更、关卡接入或美术制作仍由后续明确任务授权；本稿不是施工回执。
